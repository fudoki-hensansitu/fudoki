# 新しい自治体を取り込む

1自治体の予算・決算・事業評価・プレス発表を、調査から PR まで1本の流れで取り込むときの方針。各工程のやり方は工程の reference とコードにある。

## 取る範囲

- 資料は当初予算・決算（歳出）・事業評価・プレス発表。補正予算は取らない。
- 年度は R6〜R8 を必ず選び、同じ様式（同じ宣言で読める）で公開されている過去の年度も足す。様式が変わる年度の手前で止め、資料の種類ごとに判断する。公開されていない年度は欠けたままにする。
- 読み方を別に書く必要がある様式の会計は、選定の scope だけ入れて取り込みを見送り、issue に残す。

## 進め方

- 最初に公開の頁を調べ、資料ごとの年度・様式・会計を1表にして、取る範囲を依頼者へ1回だけ伝える。
- 1年度・1会計で読み方を固めてから、同じ宣言を他の年度・会計へ写す。
- 待ち時間の長い OCR は早く始め、その間に text PDF・評価・プレスを進める。
- 款の和を、出典に印字された総額（会計別の総括など）と全会計で突き合わせる。
- 自治体に固有の読み方は宣言（opt-in の rule）に書き、共通コードを変えない。
- 決めたこと・取れなかったものは自治体の README に残す。refresh は回さない（全部 merge した後に1回）。
