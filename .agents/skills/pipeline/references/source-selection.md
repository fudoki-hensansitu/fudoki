# A. source_selection — 取り込む1資料を確定する

出典対象（自治体・年度・資料区分）ごとに、必要な情報を持つ1資料を選び、R2 に保存するまで。型は [schema.ts](../../../../pipeline/source_selection/schema.ts) が正本。

## 範囲と順序

- 補正予算は当面取らない（[ADR 0039](../../../../docs/adr/0039-defer-supplementary-budget-ingestion.md)）。既存の補正の選定と保存済みの object は残す。
- 新しい自治体は R6〜R8 と、同じ様式の過去年度（[新しい自治体](new-jurisdiction.md#取る範囲)）。
- 当初予算・決算の歳出を会計別に先に終える。歳入や補正の整理を先行しない。
- 続きから調べるときは、既存の選定を年度・資料区分・状態で集計し、公式の掲載一覧との差分だけを調べる。保存済みで範囲を確かめた資料は取り直さない。
- 「最新」は会計ごとに判断する（一般会計が R7、企業会計が R6 までなら、R6 の企業会計も最新として選ぶ）。

## 選べる資料

- 歳出は、その会計の**款ごとの金額がすべて**印字され、会計の合計を確かめられる資料だけを選ぶ。決算書・予算書の本体を優先し、無ければ決算審査意見書などの会計別・款別の表を選ぶ。
- 一部の事業だけを載せる資料（主要施策の成果・事務報告など）、都道府県が独自の区分で集計した統計、普通会計の表は選ばない（[ADR 0037](../../../../docs/adr/0037-do-not-ingest-statistical-settlements.md)）。
- 一般会計が未公表なら、一部の会計だけで選ばない。`selected_candidate_id: null`・`archive: null` にし、理由の先頭に「未公表（確かめた頁・日時）」と書く。公表済みでも款の金額を持つ資料が見つからなければ「未取得」と書く。
- 会計名・金額の意味・単位を推定しない。分からないものは不足として理由に残す。丸めた単位（万円など）は注記を残せば選べる。
- 同じ内容なら CSV、文字 PDF、画像 PDF の順。単独の資料で覆えるなら分冊の組み合わせより優先する。
- 理由には、確かめた表の構成・列名・金額の段階・頁を具体的に書く。選ばなかった候補にも理由を残す。

## 探し方

- 公式 HP と公式のオープンデータ（東京都オープンデータカタログなど）から探す。その範囲で選べるなら広げない。
- 404 は改名か廃止かを現行の一覧で確かめる。200 の HTML でも中身が案内頁のことがある。JavaScript で描く一覧はブラウザで描画して読む。リンクが見えないことを未掲載の根拠にしない。
- 実物は `fetch.ts` で取り、返る `sha256`・`final_url` をそのまま選定に写す。R2 に保存したコピーを正とし、Wayback などから取ったときはその URL を理由に残す。
- PDF は目次から全会計と分冊をつかみ、必要な頁だけを確かめる。範囲は物理頁で書く。見開きは左右の両頁を含める。単位は金額列ごとに確かめる。
- `pdf_type` は範囲の各頁の読み方で決める（読むのに画像が要れば `scan`）。

## 事業評価とプレス発表

- 事業評価（`evaluation_selections`）の年度は、題ではなく評価シートに印字された実績の年度列で決める（「令和N年度評価」は令和 N-1 年度の決算）。Power BI でしか出ていないものは [ADR 0034](../../../../docs/adr/0034-evaluation-origin-from-power-bi-report-api.md)。
- プレス発表（`press_selections`）は、当初予算の主な施策を事業名と予算額つきで説明する資料を選ぶ。年度は題の「令和N年度予算（案）」の N。
- どちらも、探して見つからなかった年度を `candidates: []` で書き、探した頁と確認日を理由に残す。

## 検査・保存

- 台帳は JSON として読み、対象のオブジェクトだけを更新する。
- `check.ts` で検査し、`archive.ts` で保存する（選択肢はスクリプトの usage）。終了コードで成否を見る。
- 取り込みを止めて残すときは、報告の先頭に「何が問題か」「決めること」「再開の合図」を置く。
