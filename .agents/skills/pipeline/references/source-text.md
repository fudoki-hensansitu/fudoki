# 出典の頁の文字

web のアシスタントが `read_source_page` で読む頁の文字（D1 の `source_page_text`）を作る。`dbt:prepare` が事業の取り込みの出典（評価・プレス）から作る。設計は [docs/prd/page-words/dd.md](../../../../docs/prd/page-words/dd.md)。

## 新しい種類の資料を足す・抜き出し方を変えるとき

- 本番に出す前に、最初の数頁と表のある頁を画像と見比べる（入口は `source-text:preview`）。表の1行の値が左から列の順に並び、見開き・2段組みが分かれ、抜けや重複が無いこと。表が崩れていると、アシスタントは同じ頁から回ごとに違う数字を答える。
- 語は Poppler の版で変わるので、`mise.toml` で固定した版で実行する。
- 直すときは資料の種類ごとの書き分けを足さず、どの資料にも効く直し方にする。
