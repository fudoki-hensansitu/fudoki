# 議会の会議録

議会の会議録を会議と発言の単位に切り、D1 の `assembly_*` に差分で書く。入口は `assembly:ingest`。決定は [ADR 0054](../../../../docs/adr/0054-assembly-minutes-direct-to-d1.md)。

## 持つもの

- 会議（会議体・種類・開催日・出典の URL）と発言（印字のままの話し手・議員／進行／理事者の区分・本文）だけを持つ。
- 推定でしか決まらない項目（問いと答えの対応・款・理事者の役職）は持たない。議員のフルネームは、印字・名簿・出席者の欄で1人に決まるときだけ入れ、決まらなければ空にする。

## 取り方

- 議会のサイトから手元で取る。CI・Actions では回さない。
- robots.txt や利用規約で巡回や一括の取得を禁じているところからは取らない。会議録を横断で集めたサービス（自治体マップなど）も、規約が網羅的な取得を禁じているので使わない。
- サイトに負荷をかけない。1本ずつ間を空けて取り、並列にしない。取ったものは cache から読み、取り直さない。範囲は要る年だけにし、自治体は1つずつ順に流す。
- クラウドから繋がらない会議録のシステムは Mac で取る。

## 自治体を足す

- 読み方は会議録のシステムごとに1つの module に置き、同じシステムの自治体は一覧に足すだけにする。自治体ごとに読み方を書き分けない。
- 本番に書く前に、手元の D1 に入れて確かめる。話し手の区分ごとの件数を数え、「その他」や名前の決まらない議員の印字が多ければ、読み方を直す。
- 本番に流す前に、書き込む行数を見積もる。D1 の月の枠を超えるときは、流す前に確かめる。
- 発言の印（○◆◎ など）が何を表すか、印字に役職の欄があるか、発言でない印（世田谷の △ は議事の見出し）は自治体ごとの設定なので、会議録で確かめた自治体だけ一覧に書く。姓だけの印字が議員のものか理事者のものかを、本会議・常任委員会・予算特別委員会の会議録で先に確かめる（世田谷で姓だけなのは理事者で、議員はどの会議でもフルネームだった）。議員の印字が姓だけで名前が1人に決まらない自治体は、名簿で決める読み方ができるまで一覧に足さない。
- 1つの発言が D1 の文の上限（約100KB）を超えると書き込みが止まる。会議録の末尾に付いた議案説明資料などの添付が最後の発言に混ざっていないかを先に疑う。

## 会議録のシステムと robots.txt（2026-11-25 確認）

- DiscussNet（ssp.kaigiroku.net）: robots.txt が `/tenant/` 以外を禁じ、会議録を返す API も禁止に入る。画面の頁は中身の無い SPA なので、このシステムの自治体からは取らない（都内では新宿・墨田・渋谷・北・荒川・練馬・立川・青梅・昭島・小平・東大和・清瀬・武蔵村山・瑞穂・小笠原）。
- VOICES: 業者の置く既定の robots.txt が会議録の CGI（`/voices/cgi/`・`/voices2/cgi/`）を禁じていて、会議録はその CGI からしか出ない。robots.txt が無い、または CGI を禁じていない自治体だけ取れる（杉並・世田谷は取れる。港・台東・大田・板橋・足立・江戸川・調布・町田は禁止）。
- robots.txt は自治体を足すたびに、その自治体のホストで見直す。同じシステムでもホストや置き場所（杉並は `/voices/voices/cgi/`）が違えば結論が変わる。
- 島しょ（2026-11-27 確認）: 会議録を出しているのは神津島村・利島村・八丈町で、どれも文字の読める PDF（`islands.py`、八丈は号ごとの冊）。大島・新島・三宅・御蔵島は会議録を出していない（議会だより・結果・年報だけ）。青ヶ島はサイトに議会の頁が無い。
- 小さな町村の PDF の会議録は、表紙が縦書きで文字の順が崩れる。題と日付は1行の中だけで探す。議員の名前は、その冊の出席議員の欄に印字のフルネームがあるときだけ入れる。
