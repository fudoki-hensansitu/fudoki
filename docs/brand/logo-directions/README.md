# ロゴの方向性（2026-11-05）

五本の短冊（棒グラフ）のマークは、どこにでもある汎用アイコンと見分けがつかなかった。そこで方向性の違う4案を比較し、2026-11-05 に A（区画）を採用した。比較画像は `options.png`。各案のフォルダに、横組み・マークとそれぞれのダーク版の SVG を置いている。

- A / 区画: 町の土地を区画に割った形で、予算の内訳（ツリーマップ）にも読める。一区画だけ朱にした。
- B / 落款: 朱の印に明朝の「土」を入れ、字も明朝にした。記録・公文書の格がある。
- C / 風の流れ: 一本の流れが三つに分かれる形で、「風」とお金の流れを表す。画面の流れ図とも見た目がそろう。
- D / 字だけ: マークを使わず明朝の字で立たせ、朱の点を付けた。小さい所だけ「風」の角印を使う。

各案は、大きく表示した場合、サイドバー（薄い緑 #f5f8f5）、ダーク、ファビコン（16 / 32 / 64px）で比較した。

A の字はいったん Zen角ゴシック New Black で作ったが、太すぎたため4段階の太さを比べた（`weights.png`）。Black（900）、Bold（700、以前のロゴ）、Medium（500）、Regular（400）を比べ、マークの塊との対比が出て、26px のサイドバーでも潰れない Medium を採用した。

採用値の正本は `apps/web/brand/config.json` と `apps/web/brand/geometry.py`、生成は `bun run --cwd apps/web build:brand`。この比較のための SVG は生成スクリプトから独立した記録で、再生成しない。
