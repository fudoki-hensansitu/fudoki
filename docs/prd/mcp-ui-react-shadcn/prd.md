# MCP Apps UI の React・shadcn/ui 移行

## Problem

現行の MCP Apps UI は、結果の描画と操作状態を手動の DOM 更新で扱っている。ページ追加と戻る履歴、tool の応答、原典 PDF の描画を継続して変更するために、状態と画面の対応を明示する必要がある。

## 導出

風土記の Story にある、団体・年度の支出を事業単位で見る操作と、原典で数字を確かめる操作を保ったまま、UI の構成を移す。

## Overview

利用者は団体と収録範囲、歳出の検索結果、明細と軸ごとの内訳を、直接参照できる。原典 PDF の項目と金額が別頁にある場合は、両頁を同時に確認できる。

### Goals

- 既存の閲覧・絞込み・追加取得・戻る・原典確認を維持する。
- 読込み中、0件、取得失敗を利用者が判別できる。
- 接続先のテーマと狭い表示領域でも文字・操作・原典の枠を確認できる。

### Non-Goals

- 新しい検索フォーム、団体比較、年度の推移グラフ。
- 財政明細の意味、金額の和、金額の段階、粒度、公開 schema の変更。
- 配布 plugin、認証追加、公開 web の刷新、デプロイ。

## Acceptance Criteria

- 団体一覧の収録範囲に年度・資料の種類だけを直接表示し、絞込みと追加取得を利用できる。
- 歳出検索から内訳へ進み、軸ごとの子を見て、追加済みの行を含む前の結果へ戻れる。
- 0件・読込み・失敗が分かり、追加取得の失敗後も既存結果から再試行できる。
- PDF の既知の項目頁と金額頁を、別頁なら項目を左・金額を右に表示する。同頁・片方だけの頁は隣接頁と見開きにし、前後の頁へ送れる。各頁の有効な枠と中心の縦横ガイドだけを描く。
- 歳出検索結果に原典列を置かない。款・項・目の同じ親・軸・団体・年度・資料区分・会計の明細を円グラフで表示し、階層の選択で複数のチャートを切り替える。返った印字額を使い、親子の合算や総額の再計算をしない。取得途中と金額欠損は明示する。
- 狭い host と light/dark テーマで、既存の操作と原典確認ができる。

## Non-Functional Requirements

- React と shadcn/ui を用い、HTML・JS・CSS は既存 CSP 下で動く単体 HTML に同梱する。
- App bridge の接続とtool呼出しを重複させず、遅い応答、購読解除、PDF の取得・描画のキャンセルを扱う。
- PDF の中継経路・取得情報・警告・メモリ上限と、MCP resource の内容 hash・MIME type・旧 `ui/resourceUri` キーを維持する。

## Success Metrics

厳しい CSP と sandbox を備えたローカル AppBridge host で受入条件の操作を検証する。実接続先の検証とは区別する。
