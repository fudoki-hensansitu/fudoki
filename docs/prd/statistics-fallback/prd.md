# 自治体の資料が無い決算を統計で款まで見せる

## Problem

自治体が決算の事項別明細書を公開していない年度は、出典の選定が null になり、利用者には「データなし」と返る。小さな村ほどこの状態になりやすく、その自治体の支出の大まかな配分さえ比べられない。一方、総務省の地方財政状況調査は全自治体の決算を同じ様式で集めており、款（一部は項）の粒度なら公開されている。

## 導出

Story の「自治体をまたいで、または年をまたいで比べる」は、比べたい自治体・年度に何かしらの数字があることを前提にする。「出典と合っているかを確かめる」ため、統計から埋めた数字は自治体の資料由来の数字と区別でき、出典まで辿れる必要がある。収録範囲の考え方は [自治体と収録範囲の参照](../jurisdiction-coverage/prd.md)、金額の意味の区別は [予算の変更と決算の実績を区別して比較する](../fiscal-records/prd.md) に従う。

## Overview

自治体の決算資料を選定できなかった年度は、地方財政状況調査の目的別歳出を款（内訳がある款は項）まで収録する。利用者は、その数字が統計由来で、普通会計の決算であり、事業の単位までは無いことを、収録範囲と明細の両方で知れる。後から自治体の資料を選定できたら、その年度は自治体の資料に置き換わる。

### Goals

- 自治体の決算資料が無い年度でも、款の配分を他の自治体・年度と比べられる。
- 統計由来の数字を、自治体の資料由来の数字と取り違えずに使える。

### Non-Goals

- 当初予算の穴埋め（地方財政状況調査は決算だけ）。
- 統計の普通会計と自治体の一般会計の換算・突合。両者は別の会計として並べる。
- 選定済みの年度を統計で補うこと（一部の会計・款の欠けの穴埋め）。
- 統計がまだ公表していない年度（令和7年度決算など）の推定。

## Glossary

**統計の決算（statistical settlement）**:
総務省の地方財政状況調査が自治体ごとに集めた普通会計の決算。目的別歳出を款（一部は項）で持つ。自治体が公開した決算書とは別の出典として扱う。

**普通会計**:
地方財政状況調査が自治体間の比較のために一般会計と一部の特別会計を組み替えた会計。風土記の一般会計とは範囲が違い、合計も一致しない。

## Domain Model

- 統計の決算を使うのは、決算の出典の選定結果が null の自治体・年度だけである。選定結果が付けば、その年度は統計を使わない。この判断は選定の宣言に書かず、選定結果から決まる。
- 統計の決算は一つの全国共通の出典で、自治体ごとに行を引く。
- 統計の決算の会計は普通会計で、一般会計とは別の会計として収録する。会計をまたいで合算しない。
- 収録の粒度は款まで、または項までで、目・事業は持たない。

## Acceptance Criteria

- 利用者が、決算資料の選定結果が null の自治体・年度を収録範囲で引くと、統計の決算が普通会計として返り、出典（地方財政状況調査）の標題・URLを得られる。
- 利用者が、その自治体・年度の歳出を検索すると、款（内訳がある款は項）の金額を得られ、それが統計由来で目以下を持たないことを結果から知れる。
- 自治体の決算資料を後から選定して再構築すると、その自治体・年度は統計の決算ではなく自治体の資料の明細が返る。
- 統計の款の合計は、同じ出典の歳出合計と一致する。

## Success Metrics

収録範囲が空だった自治体・年度（決算）のうち、統計の決算で埋まった数。
