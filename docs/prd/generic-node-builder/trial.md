
`trial.py`（[trial/](trial/)）は観測・修復・パターンの選択まで含む汎用の流れをそのまま呼び、表を `.cache/generic-trial/<団体コード>/general-{nodes,amounts}.parquet` に、木の検査（`check_tree`）・単位の確かめ（`units.check`）・款と科目の金額・選んだパターンを `general-trial.json` に書く。設定は頁の範囲だけ。正解の表は無いので、次の4つで確かめた。

1. 木の検査（親＝直下の子の和）の組の一致・不一致・問題の数（軸ごと）。
2. 款の支出済額の和と、原典に印字された歳出合計の一致（`units.check`）。
3. 外部の照合: 総務省の市町村決算カード。
4. 目視の抜き取り: 目を等間隔に10個選び、款・項・目の名前と当初予算額・予算現額・支出済額を原典の頁の文字（`pdftotext -layout`）と見比べる。

### 132225 東久留米市 — (b) 少しの差

- 科目: 款12・項30・目112。木の検査の科目の組は 422 すべて一致。款の支出済額の和が印字の歳出合計と一致。目の抜き取り10か所（議会費・研修福利費・森林環境譲与税基金費・東久留米市長選挙費・国民健康保険事業費・生活保護費・勤労者福祉対策費・私道整備助成費・事務局費・学校給食費）は、名前（2行に割れて印字された名前も1つに結べている）と3つの金額がすべて合う。
- 節: 820ノード、木の検査 666 組すべて一致。
- 備考: 5,713ノード、組 1352/1556 一致（86.9%）。原因は2つ。
  1. **金額だけの行を番号の項目と読む**（項目の段）: 名前が長い項目は、金額を次の行の右端に単独で印字する（「北多摩議長連絡協議会負担金」→ 次の行に「10,000」）。この行を「番号 10、名前 ,000」の新しい項目にし、元の項目は金額なしになる。名前が「,」で始まる備考のノードが 475 件ある。
  2. **備考の段の型の選び違い**（関係の段）: 事業（「1 財政管理事務(財政課)」x=944）の下に、節の内訳（「8 旅費」x=958〜962）と細目（x=971）が字下げで並ぶ。事業も節も算用数字の番号なので、軸ごとの選び方で「番号の形」が選ばれると同じ段になり、事業の和が2倍になる（和が2倍の組が 31 件）。字下げなら事業の子になる。1. で番号の項目が増えたことが、選び方を「番号の形」に寄せた可能性がある（未確認）。
- 注記: 「2-1-1-090000-7へ流用」のように2つの流用を1行ずつ印字した所で、同じ見出しに2つの金額が当たる（金額の衝突 39件）。

### 132250 稲城市 — (c) 合わない（型: 款ごとの表・番号の帯の結合）

- **款ごとに表を区切る作り**（帯・見出しの段）: 款が変わる所で、頁の途中に「２款 総務費（決算額 4,764,369,474 円）」の題と見出しの塊（科目・予算現額・節…）をもう一度印字する。見出しの下端は頁の最初の見出しだけで決めるので、途中の見出しの語が本文の項目（名前「項目」「科目」の科目ノード 18件）や金額の欄の語になる。款は表の外の題にしかなく、明細の木に款が無い（款12 は scope に含まれる総括表 p9–11 から来たもので、明細とは別の木）。
- **狭い番号の帯で番号が1語に結合**（観測・項目の段）: 項の帯（x 20–31）と目の帯が狭く、続きの頁の「１ １」（項1・目1）を Poppler が1語「１１」（x 21–41）にする。本文の語は罫線で割らない（「10」が狭い款の帯からはみ出しても1語のままにするため）ので、項の番号「11」「13」「21」…の名前の無い項が 63 個できる（明細の項 102 = 正しい項 30・偽の項 63・見出しの語「項目」9）。目は名前・金額とも原典と合うものが多いが、親がこの偽の項になる（木の検査の科目の組 195 不一致）。
- **歳出合計が読めない**: 合計の行の支出済額が「44,406,439,217明許」と翌年度繰越額の欄の「明許」につながった1語で、金額と読めない。合計の行を選べず、最大の「計」（公債費の計）を選んで不一致で止めた。確かめの段としては正しく止まっている。
- 目の支出済額が取れたのは 83/114。

### 132195 狛江市 — 型が違う

選定された原典は「主要な施策の成果説明書・決算資料」で、事項別明細書ではない。p39–40 は歳出総括（款・項の千円）、p42 以降は款・項・目ごとに 主管課・事業名・事業説明・金額・財源内訳（一般財源・特定財源）・節・節説明・不用額 を千円で並べる。帯・見出しは読めて単位（千円）も頁の印字から取れたが、

- 金額の欄の見出しが「金額」（総括は「合計」）で、共有辞書の決算額（executed）に引けない。款の和が0になり、歳出合計の確かめができない。
- 事業説明・節説明は自由な文（人数・回数・単価の式）で、木の検査は 180/374。

八王子（132012）の事務報告書と同じく「決算書の事項別明細書」型の外にある。ただ、罫線の表ではあるので、例外にするより「成果説明書の型」として後回しにするのがよいと考える（決めるのは親）。この団体の事項別明細書が別に公開されているなら、選定を見直す方が早い（未確認）。

## 共通の規則の案

いずれも団体名・座標を含まない。**実装していない**（既存45表への影響を測ってから入れる）。

| 段 | 案 | 直る所 | 注意 |
| --- | --- | --- | --- |
| 項目 | 名前の帯で、行全体が桁区切りの金額だけの行は番号の項目にしない。前の項目に金額がまだ無ければ、その項目の金額にする（名前の折り返しの逆で、金額の折り返し） | 東久留米の備考 475件 | 「10」のような桁区切りの無い数字だけの行は今のまま |
| 関係 | 内訳の段の型の選び方で、同じ番号の形の項目が字下げで2つ以上の位置に分かれて並ぶ軸では「番号の形」を候補にしない（字下げを優先する） | 東久留米の事業と節が同じ段になる所 | 杉並の介護の備考（閉じ具合と正解が食い違う例）と同じ種類の問題。和（S）で区画を確かめる推奨の流れの2段目でも直る |
| 観測・帯 | 本文の語でも、縦罫線が字の境目（1pt 以内）を通り、両側がそれぞれ番号の字なら罫線で割る | 稲城の「１１」 | 字の途中を通る罫線（はみ出した「10」）では割らない。字の箱は修復の段が pdfium で取っている |
| 帯・見出し | 頁の途中に、頁の最初の見出しと同じ語の並びの塊があれば、そこで表を区切り、見出しの塊を本文に入れない。塊の直前の表の外の行「n款 名前」を款の項目にする | 稲城の款ごとの表 | 款の題が表の外にある団体は、題を款として木に入れる規則が要る（頁上部の見出しから名前を補う今の規則の延長） |
| 確かめ | 合計の行の金額は、隣の字とつながった語（「…217明許」）からも行末の金額の部分を取る | 稲城の歳出合計 | 金額の切り出しの規則（くっついていれば文字の位置で割る）を合計の行にも当てる |

## 参考: 宣言を使う前に測った3団体（分類には数えない）

最初は団体を自分で探して、練馬区（131202、令和6年度 事項別明細書 p34–91）・町田市（132098、令和7年度 決算書 p84–188）・調布市（132080、令和6年度 p78–425）で測った。親の指示で宣言から選び直したので分類には数えないが、汎用の規則で崩れた所は共通の規則の案の材料になるので残す。

- 練馬: 科目 款14/項32/目106 と節は木の検査が全部一致（939組）、予算現額の款の和は印字の歳出合計の予算現額 346,113,871,439 円と一致。ただし **支出済額の欄が帯ごと消えた**。A3 の見開き1枚で支出済額の欄が綴じ目の右にあり、欄の左の縦罫線が無い（横罫線が x=640 から始まる）ので、綴じ目の隙間と一緒に「表の外」になった。案: 本文の横罫線がそろって始まる x も帯の境界にする。
- 町田（令和7年度）: 款の支出済額の和が印字の歳出合計 202,880,996,944 円と一致、目の抜き取り10/10一致。備考の2段（「1.議員人件費」→ 1字下げた「議員報酬等事務」）が平らになり、和が2倍の組が多い（備考 1/129 一致）。子の字下げが親の番号の位置より深く、名前の位置より浅いため、字下げでも番号の形でも子にならない。名前に番号の区切りの「.」が残る（「.議会費」）。令和6年度（様式が A4 縦に変わる）でも同じ結果で、令和6年度の決算カードと比べると議会費 −8,269 千円・公債費 +3,668 千円の差（普通会計との違いの範囲）。
- 調布: CropBox で A3 の見開きを左右の頁に分けた PDF で、観測が CropBox を見ないので全頁が二重になった。重複を除いても、款項目の見出しが1つの枠に斜めに「款 項 目」と並び番号の3つの帯がすべて「款項目」になって科目の欄が見つからず、予算現額の5欄が「円」の印の行を文字と数えて名前の帯になった。案: 観測で CropBox の外の字・罫線を捨てる、帯の種類の集計で単位の印（円・千円）を数えない。

## ループ1: 共通の規則を足した結果

実測 2026-10-12。上の案のうち狛江向け（型を足すとき）以外を `pipeline/ingestion/generic/` に入れた。団体名・座標は含まない。単体テストは `generic_test.py` の `TrialRulesTest`。

| 規則 | 段 | 場所 |
| --- | --- | --- |
| R1 行全体が桁区切りの金額だけの行は、番号の項目ではなく上の項目の金額 | 項目 | `tree._split_line` |
