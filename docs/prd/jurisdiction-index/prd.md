# 自治体一覧

## Problem

自治体一覧（`/jurisdictions`）は、都道府県の見出しの下に自治体名のリンクを並べるだけで、どの自治体がどのくらいの規模で、どの年度まで収録されているか、どこにある街なのかが分からない。利用者は名前を知っている街しか開けず、隣の街や規模の近い街へ広げるきっかけがない。

## 導出

Story の「ある自治体・年度の支出を事業の単位で見る」と「自治体をまたいで比べる」の入口にあたる。個別の自治体ページ（`/tokyo/shinagawa`）へ辿る前に、収録している自治体を場所と規模で見渡せるようにする。

## Overview

利用者は一覧を開くと、まず地図で収録している自治体の場所と歳出の規模を見て、自治体を押して個別ページへ進む。頁の上の検索で名前から自治体へ進め、地図の下には同じ自治体を並べた表があり、都道府県・区・市・町村で絞る、人口・1人あたりの歳出・歳出の総額で並べ替えるといった操作で比べてから個別ページへ進める。

### Goals

- 利用者が、自治体名を知らなくても、地図の場所から収録している自治体に辿り着ける。
- 利用者が、個別ページを開く前に、自治体どうしの人口・1人あたりの歳出・歳出の総額を見比べられる。
- 未収録の地域が見え、風土記がどこまで収録しているかが正直に伝わる。

### Non-Goals

- 地図の塗りを1人あたりの歳出にすること（後述「後から加えるもの」）。
- 都道府県（東京都自体）の財政ページ。別の作業で作り、この一覧はそれを前提にした導線だけを用意する。
- 全国の市区町村を一枚の地図に塗ること（全国化の形は [DD](dd.md#全国に広げるとき) に置く）。

## Acceptance Criteria

- 利用者が一覧を開くと、収録している自治体が地図上で歳出総額の濃さで塗られ、未収録の自治体と区別できる。
- 利用者が地図か表で自治体を押すと、その自治体の個別ページへ進む。
- 利用者が頁の上の検索に自治体名を入力して選ぶと、市区町村ならその個別ページへ進み、都道府県ならその地図が開く。表は、都道府県・区・市・町村のタグから候補を選んで絞り込め（複数選べる）、人口・1人あたりの歳出・歳出の総額の列で並べ替えられる。
- 表は30件ずつ読み込み、全自治体を一度に描かない。JavaScript が動かない環境や検索エンジンには、表の最初の30件と sitemap から自治体へのリンクが届く。
- 表示する金額は API の値だけで、仮の値を混ぜない。どの年度の決算の値かが分かる。金額の印字が無い款を含む総額は、印字のある款の和を出す（一部の款の和である印・注記は、2026-11-05 に画面から外した）。

## 後から加えるもの

- **地図の塗りを1人あたりに**: 表は 2026-11-06 に1人あたりの歳出を加え、既定の並びにした。地図の塗りはまだ歳出の総額。
- **年度の揃え**: 自治体ごとに最新の決算の年度が違う（令和6・7年度が混在）。年度を選んで揃える切り替えは、収録年度が揃ってきた段階で検討する。
