# 財政データのAPI

## Problem

提供用データを団体・年度・科目などの条件で取得する口が必要になる。 パイプラインの完成後に、利用者の問いと完成した提供用データから要件を定める。

## 導出

Storyの「支出を事業の単位で見る」「団体や年をまたいで比べる」を支える将来の機能である。

## Overview

現在は設計・実装の対象外である。公開web・API・MCP・docsの実装は一時的なHTTP 500応答を返す。旧APIのURL・応答・tool・保存契約を、今後の要件として引き継がない。

### Goals

パイプライン完成後、収録範囲・粒度・出典・判断を保って財政データを取得できる方式を検討する。

### Non-Goals

現在の段階でのAPI・MCP公開、D1への反映、配布版の公開方式・保持方式の確定。

## 再開条件

採用入力からingestion〜martsを再構築し、原典対応・金額・粒度・分類・収録範囲を検証できること。再開時に利用者の問い、受け入れ条件、利用指標を定める。
