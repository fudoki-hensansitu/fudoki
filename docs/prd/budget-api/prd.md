# 財政データのAPI

## Problem

提供用データを自治体・年度・科目などの条件で取得する口が必要になる。 パイプラインの完成後に、利用者の問いと完成した提供用データから要件を定める。

## 導出

Storyの「支出を事業の単位で見る」「自治体や年をまたいで比べる」を支える将来の機能である。

## Overview

提供用データ（marts）の歳出の木をD1に載せ、RESTとMCPで返す。設計と実装は [ADR 0022](../../adr/0022-serve-marts-via-worker-d1-rest-and-mcp.md) に従う。公開web・docsは引き続き一時的なHTTP 500応答を返す。旧APIのURL・応答・tool・保存契約は引き継がない。

### Goals

収録範囲・粒度・出典・判断を保って、自治体・年度・科目などの条件で財政データを取得できるようにする。

### Non-Goals

自治体ごとの配布版の公開方式・保持方式の確定。

## 見直しの条件

APIの設計を見直す前提として、採用入力からingestion〜martsを再構築し、出典対応・金額・粒度・分類・収録範囲を検証できること。見直し時に利用者の問い、受け入れ条件、利用指標を定める。
