# 全自治体の決算を統計の普通会計で款まで並べる

## Problem

自治体が決算の事項別明細書を公開していない年度は、出典の選定が null になり、利用者には「データなし」と返る。小さな村ほどこの状態になりやすく、その自治体の支出の大まかな配分さえ比べられない。また、自治体の資料から取り込んだ一般会計は、自治体ごとに特別会計との切り分けが違い、同じ物差しで比べにくい。総務省の地方財政状況調査は全自治体の決算を普通会計という共通の組み替えで集めており、款（一部は項）の粒度なら公開されている。

## 導出

Story の「自治体をまたいで、または年をまたいで比べる」は、比べたい自治体・年度に同じ物差しの数字があることを前提にする。統計の普通会計を一部の自治体だけに入れると、普通会計どうしで比べる相手がいない。そのため、選定が null の自治体に限らず、対象の全自治体・全年度に入れる。「出典と合っているかを確かめる」ため、統計の数字は自治体の資料由来の数字と区別でき、出典まで辿れる必要がある。収録範囲の考え方は [自治体と収録範囲の参照](../jurisdiction-coverage/prd.md)、金額の意味の区別は [予算の変更と決算の実績を区別して比較する](../fiscal-records/prd.md) に従う。

## Overview

地方財政状況調査に行がある対象の全自治体・全年度について、普通会計の目的別歳出を款（内訳がある款は項）まで収録する。自治体の資料から取り込んだ一般会計とは別の会計として並べ、置き換えない。統計に行が無い年度は推定せず、収録なしのままにする。利用者は、その数字が統計由来で、普通会計の決算であり、事業の単位までは無いことを、収録範囲と明細の両方で知れる。

### Goals

- 自治体の決算資料が無い年度でも、款の配分を他の自治体・年度と比べられる。
- 全自治体を普通会計という同じ組み替えで比べられる。
- 統計由来の数字を、自治体の資料由来の数字と取り違えずに使え、二重に数えない。

### Non-Goals

- 当初予算（地方財政状況調査は決算だけ）。
- 統計の普通会計と自治体の一般会計の換算。両者は別の会計として並べる（大きなずれを見つける目安としての比較は別途検討する）。
- 統計がまだ公表していない年度（令和7年度決算など）の推定。

## Glossary

**統計の決算（statistical settlement）**:
総務省の地方財政状況調査が自治体ごとに集めた普通会計の決算。目的別歳出を款（一部は項）で持つ。自治体が公開した決算書とは別の出典として扱う。

**普通会計**:
地方財政状況調査が自治体間の比較のために一般会計と一部の特別会計を組み替え、会計間の繰入・繰出を除いた会計。風土記の一般会計とは範囲が違い、合計も一致しない。

## Domain Model

- 統計の決算は、選定結果に関係なく、統計に行がある対象の全自治体・全年度で収録する。選定の宣言には書かない。
- 統計の決算は一つの全国共通の出典で、自治体ごとに行を引く。
- 統計の決算の会計は普通会計で、一般会計とは別の会計として収録する。同じ自治体・年度に両方が並びうるが、会計をまたいで合算しない。
- 収録の粒度は款まで、または項までで、目・事業は持たない。

## Acceptance Criteria

- 利用者が、統計に行がある自治体・年度を収録範囲で引くと、普通会計の決算が返り、出典（地方財政状況調査）の標題・URLを得られる。自治体の決算資料の選定結果が null でも返る。
- 自治体の資料の一般会計も収録済みの自治体・年度では、一般会計と普通会計が別の会計として返り、どちらか一方だけを選んで集計できる。
- 利用者が普通会計の歳出を検索すると、款（内訳がある款は項）の金額を得られ、それが統計由来で目以下を持たないことを結果から知れる。
- 統計の款の合計は、同じ出典の歳出合計と一致する。

## Success Metrics

- 決算の収録範囲が空だった自治体・年度のうち、統計の決算で埋まった数。
- 普通会計で款を比べられる自治体・年度の数。
