# ADR 0015: 自治体マスタを財政の記録から独立させる

状態: 採用（2026-10-01、2026-10-03 に配布・検索の保存方式を除外）

## 背景

自治体コードで識別する自治体の定義と、年度や資料に属する財政の記録が混在していた。自治体の同一性を、個別の金額や収録範囲から区別する必要がある。

## 決定

`jurisdiction_master` は自治体コードだけを主キーとし、Git の `packages/jurisdictions/jurisdictions.json` から名称と OCD ID を生成する。財政データセットは自治体コードでこの共通定義を参照する。

出典の名称や収録範囲・注意点は資料の説明として保持し、自治体マスタの定義と混同しない。配布版や公開時の保存方式は後段で検討する。

## 結果と代替案

自治体の同一性を、年度ごとの予算・決算とは独立して参照できる。自治体情報を明細ごとに埋め込む案では定義が重複するため、共通マスタを用いる。このマスタは改称・合併を有効日付きで管理する履歴マスタの代用ではない。
