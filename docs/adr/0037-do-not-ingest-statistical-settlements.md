# 統計の決算は取り込まず、収録の無い年度は MCP で統計へ案内する

自治体が決算書を公開していない年度は出典の選定が null になり、利用者には「データなし」と返る。総務省の地方財政状況調査（e-Stat の年次ファイル・市町村別決算状況調・決算カード）は全市町村の普通会計の決算を款・項まで同じ様式で公開しており、決算年度 2005〜2024 を取得できる（[実測](../survey/fallback-statistics-sources.md)）。これを全自治体・全年度の普通会計として取り込む設計を一度まとめたが、取り込まないことにした。

- 風土記の価値は事業の単位（目以下）で比べられることにある。統計は款・項までで、その価値に何も足さない。
- 同じ物差しの款・項の数字は、総務省・e-Stat がすでに全国分を公開している。風土記が持っても写しを1つ増やすだけになる。
- 全国1本の出典は、自治体・年度ごとの選定と管理 JSON、選定結果を出所にする `origin` の作りに合わない。通すには入力宣言・`origin`・入力準備に統計専用の分岐が要る。さらに、普通会計は一般会計と一部の特別会計を含むので、他の会計と足すと二重に数える。その説明も配布物に増える。

## Consequences

風土記の取り込み・marts は、自治体が公開した資料だけを出典にする方針を保つ。普通会計の会計の種類は足さない。

収録の無い自治体・年度を利用者が MCP で引いたときは、統計の数字を返さず、地方財政状況調査（決算カード・e-Stat の年次ファイル）へ案内する。案内に載せるのは出典の名前と URL で、普通会計であること、事業の単位は無いこと、風土記の一般会計とは合計が一致しないことを添える。選定の null は「資料が無い」ことを示す判断のまま変えない。

当初予算と統計の未公表年度（令和7年度決算など）は、案内先にも数字が無い。案内はその旨を返す。
