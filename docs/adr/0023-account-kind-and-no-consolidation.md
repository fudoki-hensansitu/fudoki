# ADR 0023: 会計の種類は語の辞書で付け、連結（消去）はせず繰出に印を付ける

状態: 採用（2026-10-11）。

## 決定

1. 会計の種類（`account_kind`）は、会計名に含まれる語と種類の対応（`seeds/fiscal/account_kind_map.csv`）で付ける。語彙は最小の5つ（一般会計・国民健康保険・介護保険・後期高齢者医療・その他）にする。
2. 語に当たらない会計名は構築を止める。黙って「その他」にしない。用地・駐車場・下水道は「その他」の行として明示する。
3. 連結（会計間の繰出の消去）は**しない**。金額は消さず、次のノードに会計間の繰出の印（`is_interfund_transfer`）を付け、受け手の会計の種類（`interfund_transfer_to`、同じ辞書で引く）を付けられるものに付ける。利用者は印を除いて集計する。受け手の切り出しは会計で終わる名前に限り、基金への繰出（例：財政調整基金繰出金）は印を付けない。`支出金` の形は対象外である。
   - 科目の目で名称が `^(.*会計)繰出金$` のもの。
   - 科目以外の軸（節・備考・説明）で名称が `繰出金` または `^(.*会計)繰出金$` のもの。法定の節28「繰出金」は定義上ほかの会計への繰出であり、一般会計の費の目の下に隠れた移転（例：131156 の福祉総務費の下の節繰出金）を拾う。節・備考の同名でも会計で終わらない内訳（例：保険基盤安定繰出金）は一会計の中の法定の負担で移転ではないため含まない。
   - 印は枝の最も上だけに付け、同じ目の下で節と備考の両方には付けない（節が優先）。印の付いた金額はそのまま足せる（二重なし）。
   - 節の軸が無い団体は備考・説明の軸で拾う（131041）。節も備考も無い団体（132012）は拾えず、項「繰出金」（132012 の介護 320M・後期 24M）も印を付けない。印は網羅ではない。

## 理由

団体をまたいで「介護保険の会計どうし」を比べるには、団体ごとに違う会計名（介護保険特別会計／介護保険事業会計／介護保険会計）の名寄せが要る。`fund_directory` は団体×会計名の完全一致で、団体・会計を足すたびに行が要る。方針（団体ごとの行は足さない。団体共通の辞書や機械的な規則に寄せる）に沿い、語の辞書を新設した。`fund_directory` は使わない。

消去しないのは、決算の歳入を取り込んでいないため、消した金額が受け手側の会計の収入と一致するかを確かめられないからである。受け手の会計が入力に無い場合（例: 下水道事業会計）も印は付ける。受け手が特定できない目（例: 132063 後期高齢者医療特別会計の他会計繰出金）は、印だけ付けて受け手を NULL にし、推測の種類を付けない。

印は、科目の目の会計名繰出金に加え、科目以外の軸の「繰出金」または会計名繰出金にも付ける。法定の節28「繰出金」は定義上ほかの会計への繰出なので、一般会計の費の目の下に隠れた移転を拾うために含める。節・備考の同名でも会計で終わらない内訳（例: 保険基盤安定繰出金・介護給付費繰出金）は、一会計の中の法定の負担区分であり、会計間の移転ではないため含まない。

## Consequences

- 未知の会計名・受け手が現れたら構築が止まる。辞書に語の行を足して対応する。既知だが入力に無い受け手（例：132047 の介護サービス事業特別会計繰出金。`cofog_rules` の `transfer-kaigo-service` が知っている）は先回りで辞書に入れず、現れたときに介護保険へ寄せるかその他へ寄せるか決める。
- 一般会計＋特別会計の合計は、印の目を含む。印を除いた集計は利用者が行う。印の付いた金額はそのまま足せる（二重なし）が、節も備考も無い団体の移転は拾えない（132012 の一般会計は不明、特別会計の項「繰出金」344Mは印なし）。
- 決算の歳入を取り込んだら、受け手側との一致を条件に消去の連結を再検討する。
