# ADR 0023: 会計の種類は語の辞書で付け、連結（消去）はせず繰出に印を付ける

状態: 採用（2026-10-11）。

## 決定

1. 会計の種類（`account_kind`）は、会計名に含まれる語と種類の対応（`seeds/fiscal/account_kind_map.csv`）で付ける。語彙は10つ（一般会計・国民健康保険・介護保険・後期高齢者医療・用地・駐車場・下水道・介護サービス事業・土地区画整理・財産区）にする。このほか、繰出金の受け手だけに付く「不明」がある（下の3。2026-10-13 に「土地区画整理」と「不明」を、同日に「財産区」を足した。「後期高齢者事業特別会計」と印字する自治体（133621 利島村）は、語を1行足して後期高齢者医療に対応づけた）。中身の違う会計を「その他」に寄せると区別できなくなるため、分けておき、利用者が後でまとめる（逆はできない）。
2. 語に当たらない会計名は構築を止める。黙って寄せない。
3. 連結（会計間の繰出の消去）は**しない**。金額は消さず、次のノードに会計間の繰出の印（`is_interfund_transfer`）を付け、受け手の会計の種類（`interfund_transfer_to`、同じ辞書で引く）を付けられるものに付ける。利用者は印を除いて集計する。受け手の切り出しは会計で終わる名前に限り、基金への繰出（例：財政調整基金繰出金）は印を付けない。`支出金` の形は対象外である。
   - 科目の目で名称が `^(.*会計)繰出金$` のもの。
   - 科目以外の軸（節・備考・説明）で名称が `繰出金` または `^(.*会計)繰出金$` のもの。法定の節28「繰出金」は定義上ほかの会計への繰出であり、一般会計の費の目の下に隠れた移転（例：131156 の福祉総務費の下の節繰出金）を拾う。節・備考の同名でも会計で終わらない内訳（例：保険基盤安定繰出金）は一会計の中の法定の負担で移転ではないため含まない。
   - 繰出先の種類が決まる内訳へ印を付け、同じ目の節と備考を二重に数えない。既に繰出先の決まる上位の印は保持する。節が受け手を特定できず、備考・説明の繰出名がすべて受け手を特定し、その金額の和が節の全額と等しい場合は、より細かい内訳へ移す。一部の額しかない内訳や、受け手が不明な内訳では節と祖先名を維持する。出典の額・親子・名前は変更しない。
   - 節の軸が無い表は備考・説明の軸で拾う。新宿一般は汎用移行で節が加わるが、国保と後期の額を合わせた節8,485,855,706円を、受け手の分かる備考4,913,384,649円と3,572,471,057円へ分けて印を保持する（2026-10-14）。節も備考も無い自治体（132012）は拾えず、項「繰出金」（132012 の介護 320M・後期 24M）も印を付けない。印は網羅ではない。

## 理由

自治体をまたいで「介護保険の会計どうし」を比べるには、自治体ごとに違う会計名（介護保険特別会計／介護保険事業会計／介護保険会計）の名寄せが要る。`fund_directory` は自治体×会計名の完全一致で、自治体・会計を足すたびに行が要る。方針（自治体ごとの行は足さない。自治体共通の辞書や機械的な規則に寄せる）に沿い、語の辞書を新設した。`fund_directory` は使わない。

消去しないのは、決算の歳入を取り込んでいないため、消した金額が受け手側の会計の収入と一致するかを確かめられないからである。受け手の会計が入力に無い場合（例: 下水道事業会計）も印は付ける。受け手が特定できない目（例: 132063 後期高齢者医療特別会計の他会計繰出金）は、印だけ付けて受け手を NULL にし、推測の種類を付けない。受け手が「特別会計」とだけ印字され、どの会計か特定できない繰出金（134015 八丈町の目「特別会計繰出金」。133621 利島村・132225 東久留米の備考の「特別会計繰出金」は、同じ目の節に印が付くため備考には印が付かない）は、印を付け、受け手の種類を「不明」にする（2026-10-13。辞書の `scope` が `recipient` の行で、受け手の名前が語と完全に一致するときだけ当てる。会計名には当てず、特別会計が1つの自治体ならその会計、といった推測はしない）。

受け手が自分の名前で決まらない印（受け手が NULL または「不明」）は、親・祖父の名前に印字された会計名から引く（2026-10-13）。例: 132225 の「国民健康保険事業費」の下の節「繰出金」は国民健康保険、「介護保険事業費」の下なら介護保険になる。一番近い祖先から順に見て、辞書の語（`scope` が空の行）を含む最初の名前で決め、同じ祖先の名前に2つ以上の種類の語があれば決めない。その名前の種類が送り出す会計自身の種類と同じときも決めない（国民健康保険の会計の中の「国民健康保険事業費」は送り出す側の話で、受け手ではない）。祖先に語が無ければ NULL は NULL、「不明」は「不明」のまま。すでに種類が付いた印は変えない。名前に印字された会計名は出典に出ている証拠として使い、印字の無い推定（会計が1つしかない、など）はしない。この規則で NULL から種類が付いたのは決算18・当初予算1の節「繰出金」で、自治体名では分けない（`int_fiscal__expenditure_transfers` の `ancestor_name_kinds`）。

印は、科目の目の会計名繰出金に加え、科目以外の軸の「繰出金」または会計名繰出金にも付ける。法定の節28「繰出金」は定義上ほかの会計への繰出なので、一般会計の費の目の下に隠れた移転を拾うために含める。節・備考の同名でも会計で終わらない内訳（例: 保険基盤安定繰出金・介護給付費繰出金）は、一会計の中の法定の負担区分であり、会計間の移転ではないため含まない。

## Consequences

2026-10-23追記: 会計名繰出金の末尾にある `【所管課】` は、受け手の照合時だけ除く。同じ目の備考・説明の一つの軸にある所管課付きの繰出金の内訳が節の全額と一致し、その受け手の種類が一つに定まる場合は、受け手不明の節にその種類を付ける。部分内訳、複数の受け手、金額の無い内訳では節の受け手を決めない。品川区2024年度の「介護保険特別会計繰出金【高齢者福祉課】」4,424,754,000円（決算書冊2物理76頁）が節の全額を説明する例。節に印を維持し、備考の同額に二重に印を付けない。既存の受け手別内訳の印を別の段へ移さないため、節への補完は新たに照合できる所管課付きの内訳だけに限る。

- 未知の会計名・受け手が現れたら構築が止まる。辞書に語の行を足して対応する。
- 一般会計＋特別会計の合計は、印の目を含む。印を除いた集計は利用者が行う。印の付いた金額はそのまま足せる（二重なし）が、節も備考も無い自治体の移転は拾えない（132012 の一般会計は不明、特別会計の項「繰出金」344Mは印なし）。
- 決算の歳入を取り込んだら、受け手側との一致を条件に消去の連結を再検討する。
