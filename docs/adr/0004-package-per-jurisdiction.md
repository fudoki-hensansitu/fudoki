# 配布物は自治体ごと・判断は列で区別する

配布の単位は自治体で、市が公表した事実と風土記の判断（cofog 等）は、同じ明細の別の列として持ち、列の説明で区別する。分類は明細と常に一緒に確定する判断で、別リソースにすると結合の鍵と識別子が一つ増えるだけになる（[ADR 0016](0016-cofog-master-and-assignment.md)）。2026-10-11 に、判断を別リソースに分ける当初の決定を改めた。自治体をまたぐ結合ファイルは作らない — 正本ごとに違うライセンスと出典を1つのライセンス表示に潰す害がある。自治体をまたいで正本を揃えることもしない — 階層の構成が自治体ごとに違い、揃えること自体が「同じ概念だ」という判断になる。

## Considered Options

- 判断を `derived/` へ自治体をまたいで1ファイルに集める — 横断は派生ではなく glob で読めるので、配布物を畳む理由にならない
