# ADR 0049: 予算案のプレス発表（施策）を取り込まない

状態: 採用（2026-11-15 yuito）。[事業評価とプレス発表を取り込む設計](../prd/jurisdiction-page-data/dd.md) のプレス発表の部分と、出典の選定の `press_selections` を置き換える。

1. 予算案のプレス発表は、選定・取り込み・marts（`budget_proposal`・`budget_proposal_origin`・`budget_measure`）・API（`/v1/budget-proposals/*`、`get_budget_proposal`・`search_budget_measures`）・web の施策の表示ごと消す。
2. 新しく始めた事業は、予算書の事業の始めた年度（`project.first_year`）で出す。やめた事業は終えた年度で出す。
3. 事業は予算書・決算書の内訳から作る。事業名を印字しない自治体は、予算の概要などの別の資料から事業を作る（[事業評価を整理する](../prd/evaluation-model/dd.md)）。

2026-11-15 時点で、プレス発表は56の宣言で読み、施策の約3分の1は予算書の事業に紐付かなかった。紐付けは Dice 係数と Jev の判断で、取り込みのたびに seed の更新が要った。プレス発表は自治体が選んだ一部の施策しか載せず、様式も自治体ごとに違う。事業の表が全自治体で予算書から作れるようになり（ADR 0046）、新しく始めた事業は始めた年度で全件出せる。

## Considered Options

- **プレスを残し、事業の説明として付ける**: 一部の施策にしか付かず、紐付けの判断と様式ごとの読み方を持ち続ける。
- **プレスを事業の出どころにする**: 予算書に事業の内訳がある自治体では重複し、一部の施策だけでは事業の全体にならない。

## Consequences

- 自治体の頁の「新しく始める事業」は、前の年度と比べられる年度（事業の収録があり、前の年度もある）だけに出る。事業の収録が無い自治体では出ない。
- R2 に保存したプレス発表の PDF（`press-initial*`）は残す。選定の記録は git の履歴にある。
- 本番 D1 の3表は `sync_d1.py --drop-legacy` で消す。
