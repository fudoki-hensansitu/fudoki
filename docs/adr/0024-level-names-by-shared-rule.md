# ADR 0024: 段の名前は共通規則で付け、fiscal_level_map を廃止する

状態: 採用（2026-10-11）。[ADR 0021](0021-level-and-phase-map-in-dbt-seed.md) の段の名前の対応（団体・表・軸・深さ → 段の名前）を改訂する。金額の段階への対応（共有辞書）は変えない。

科目軸（款を載せる軸。表により科目・款項・款項目）の深さ1/2/3は款・項・目とする。それ以外の軸は、ノードの表の印字された見出し `level_header` があればそれを使い、なければ「内訳1」「内訳2」…（深さ）とする。科目軸の深さと印字見出しが食い違った場合、科目軸以外に款・項・目の印字があった場合は構築を止める。

## 理由

団体・表を足すたびに seed に行が増える運用は、表の追加を人の手に縛る。実測した 2025年度決算・歳出の全 PDF 表では、科目軸の段はすべて款・項・目が印字され、科目軸以外の段は印字見出し（金額・区分・事業・説明1…）か無印字かのどちらかだった。無印字の段に表ごとの名前（事業・項目・細目・節）を与える判断は、金額の集計を変えない表示上の名付けであり、共通規則に寄せられる。節の一覧のように軸名と段名が同じになる場合も、軸（`axis_header`）は原典のまま残るため、集計の単位としての区別は失われない。

## Consequences

- `seeds/fiscal/fiscal_level_map.csv` とその宣言・検査を削除する。表を追加しても seed に行を足さない。
- slice の科目軸の目数・金額は変わらない。科目軸以外の段名は変わりうる（131041・131156・132021 の備考の 事業・項目・節・細目 → 内訳n、節の一覧の 節 → 内訳1）。`node_kind` を条件にする下流（COFOG は目だけを見る）への影響はない。
- 科目体系が違う会計（132071 下水道事業会計のように款・項・目に番号がない表）は、この規則でも木として通らない。特例を足さず入力から外す。
