# ADR 0039: 補正予算は当面取り込まない

状態: 採用（2026-11-07）。

補正予算（`document_kind: supplementary`）は、当面取り込まない。取り込む資料区分は当初予算と決算に絞り、そちらを先に揃える。

補正の資料は号ごとに分かれ、会計別の号数、債務負担行為・繰越明許費だけの号、款・項の表だけで目・事業の明細を持たない議案などがあり、選定と取り込みの手間が当初予算・決算より大きい。また補正の明細は増減額で、指定時点の予算額を出すには当初予算の基準額と全号を揃えて積み上げる必要がある（[ドメインモデル](../prd/fiscal-records/fiscal-domain-model.md)）。

## Consequences

補正予算の取り込みの宣言・レイアウトは作らない。出典の選定でも、補正号の候補を新たに探したり整理したりしない。

既存の補正の選定結果と保存済みの R2 の object は消さずに残し、再開するときの出発点にする。[source_selection の手順](../../.agents/skills/pipeline/references/source-selection.md)にある補正の規則も、再開するときのために残す。
