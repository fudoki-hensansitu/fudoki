# ライセンスは層ごとに分ける（コード=MIT、データは各層で宣言）

コードは fudoki のものだが出典と正本は各自治体のもので、持っていない著作権にライセンスは与えられない。root の MIT LICENSE がデータまで及ぶと読ませると CC BY が求める帰属を下流が落とすので、層ごとの宣言を配布物と出典の選定に持つ。出典の利用条件が未判断の自治体では配布物に `licenses` を書かない（未確定は書かないことで表す）。

判断（2026-10-11 からは同じ明細の列。[ADR 0004](0004-package-per-jurisdiction.md)）を CC BY 4.0 にできるのは出典が継承を求めないからであり、CC BY-SA の自治体が入ればこの選択は成り立たない。
