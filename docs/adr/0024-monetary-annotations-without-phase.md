# 金額の注記は段階と合計から分けて保持する

流用・充用・不用額などの注記は、科目の予算額や執行額を説明する金額であり、独立した支出ではない。原典の文言を持つ「注記」軸のノードと、そのノードに属する金額・単位・印字位置を取り込む。見出しは既存の「注記金額」とし、金額の段階を付けず、木の親子の合計と支出済額の選択から外す。同じ目の節間流用は目の予算現額を変えず、目間の変更も既存の増減列に反映されているため、注記を加算すると二重計上になる。

注記の種類は `pipeline/shared/fiscal_annotation_map.csv` の共通の語で解決し、原文の流用元・流用先を分類名に置き換えない。「へ」のような広い語は使わない。数字だけの継続行は同じ備考欄の折返しだけを継承する。金額の段階の辞書へ注記の全文を列挙する方法は、意味の異なる分類を混ぜ、団体ごとの原文を増やすため採らない。stagingは注記も保持するが、現在の歳出の木のintermediateには含めない。

基準額は実例のある印字に限定する。「月額」は既存の内表の月額セルの中だけ、「1回…円」は同じ括弧内の円付き金額だけを保持する。回数の1や一般の単価という語だけでは採用しない。

「予備費」だけでは注記にしない。充用・充当を明示する文言で種類を解く。「事業へ支出」は、既存の備考セルの文で、親科目名が「予備費」と完全一致する場合に限る。この3条件は共通処理の1か所で判定し、予備費から充てた通常の事業費を注記へ移さない。

予備費の備考が科目名を列挙して「へ」で終わる省略形は、同じ原典に同額の明示的な充用注記があり、その親科目名が行先の文言に含まれる場合に限って取り込む。「へ」は辞書には加えず、金額の一致だけでも採用しない。

議決番号（第n号・その列挙）や年号・日付の数字は、注記の見出しに当たっても金額にはしない。分割された文字を位置と書式で結び、網羅検査と注記の抽出に同じ非金額の規則を用いる。裸の数字は金額の候補として残す。

## 追記（2026-10-13）: 備考の金額が採用されない共通の原因

Jev の聞き直し（[ADR 0026](0026-jev-recheck-printed-digits-stop-only.md)）が、辞書に語があるのに採用されていない注記の金額を拾った。原因は団体ではなく、注記の抽出（`annotations.py`）の3つの共通の取りこぼしで、いずれも共通処理で直す。

- 金額セルは末尾に `円` が付く印字（`5,073,000円`）も金額として読む。以前は数字・記号だけを金額セルとしたため、`円` 付きの備考は金額と見なされなかった。
- 行の備考が節の行の「備考」列（接頭辞のない列）に全文で保持される書式は、最も近い目・項・款を所有者とする。款・項・目の備考列にはその先頭の1行だけが入る。
- 備考の行の所有者は、見開きの右頁の行割当（その行の金額が属する科目）で判断する。左頁に科目名、右頁に備考と金額が印字される書式では、科目の位置だけでは右頁の行がどの科目のものか決まらない。複数行の備考は科目の行の上から始まる（科目の行より2行分以内で、間に別の科目が始まらないとき）。金額が次の行に折り返されるときは、直上の見出しだけの行の所有者に従う。

予備費の備考が「第2款 総務費 216,665,000円」のように充用した款・項・目と金額だけを列挙する場合も、親科目名が「予備費」と完全一致するときは充用先として取り込む（「事業へ支出」「へ」の省略形と同じ条件）。

備考欄に原文のまま保持した経費内訳（事業・項目・細目の分解）は注記ではない。各変換器は、保持した語のうち、注記の辞書の語が現れる行より前の行を、`経費内訳` の非採用の範囲として宣言する（`annotations.remark_prose_lines()`。辞書の語が2行に割れて印字される場合も、その語の位置より前だけを範囲とする）。
