# PDF取り込みの読み方を変換ごとに固定する

書式ごとの処理を共有ファイルに集めると、一つの読み方の変更でも多くのPDFが再変換対象になる。agentが選んだ表・見出し・科目・内訳のパターンと必要な補正を、変換ごとの `options.workflow` に固定する。通常の変換はその選択を使い、指紋には共通処理、選択実装、その依存と参照データを含めることで、書式固有の変更の影響を利用対象へ絞る。

## Consequences

再生成は対象となった変換全体を実行する。工程途中の新しい保存は設けず、その必要性は再生成コストを見て判断する。既存の文字観測キャッシュと固定済みOCR観測は維持する。

文字PDFと画像PDFは、文字・座標の取得と固有の補正を各入口で行い、共通の表現へ揃えた後は同じパターン群を使う。OCR由来の座標の揺れなど、共通処理に必要な入力情報は残す。共通処理の変更は広い再変換が必要であり、合否だけを決める検査は既存の [ADR 0027](0027-refresh-fingerprints-by-table-content.md) に従って保存済みの表へ当て直す。

設定、移行と検証の境界は [設計書](../prd/pdf-workflow-patterns/dd.md) に記す。
