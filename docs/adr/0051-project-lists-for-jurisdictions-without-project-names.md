# ADR 0051: 予算書に事業名の無い自治体は、事業の一覧の資料から事業を作る

状態: 採用（2026-11-15 yuito）。

1. 予算書に事業名を印字しない自治体（港区・北区・神戸市）は、事業名と金額を並べた別の資料（事業の一覧の資料）から事業を作る。北区は予算の概要の「主要事業」、港区は事務事業評価の一覧、神戸市は局別の予算説明書。
2. 一覧の資料は出典の選定の `project_list_selections`（対象はその年度の当初予算、保存先は `project-list-initial`）で選び、`ingestion/project` が読む。様式ごとの読み方は `ingestion/project/layouts/`。読むときに資料の中の合計（北区は項ごとの掲載事業小計）と合うかを確かめ、合わなければ止める。
3. 一覧の行は予算書の内訳（`expenditure_detail`）に混ぜず、別の表（`project_list_origin`・`project_list_line`）にする。行は資料の印字のまま（名前・会計・款項目・所管課・当初予算額）で、科目は会計と款・項・目の名前で同じ年度の当初予算の科目に当てる（風土記の判断、下の段から当て、当たらなければ上の段）。
4. 事業の年度は一覧の行を外部キー（`initial_project_list_line_id`）で指す。一覧から事業を作るのは、その年度の当初予算に「事業」の内訳が1行も無い自治体・年度だけ。
5. 決算の事業は作らない。

## Considered Options

- **一覧の行を予算書の内訳に入れる**: 事業の作り方は今のままで済む。ただ、内訳は「予算書が科目の下に印字した行」で、科目と内訳の合計の検査や印字の位置は予算書を前提にしている。別の資料の行が混ざると、その前提が崩れる。
- **実施計画から事業を作る**: 施策との紐付けも取れる。ただ、実施計画は全事業を載せない。

## Consequences

- 北区の一覧は主要事業だけ（項の合計の一部）なので、ある年度の一覧に載らなくても事業を終えたとは言えない。一覧から作った事業の始め・終えの扱いは、一覧の行から事業を作る変更で決める。
- 一覧の表を D1 に入れる変更と、一覧の行から事業を作り API が読む変更は分ける。後者を先に D1 に写すと、一覧の表を読めない今の API が名前の無い事業を返すため。
