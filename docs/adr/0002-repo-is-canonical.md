# 正本はリポジトリと非公開 R2 の組、API・ダッシュボードは派生物

状態: 採用（2026-11-06 に実態に合わせて書き直した。2026-11-11 に R2 に置くものを fudoki が変換を担うものに限った）。当初は「配布物・出典・証跡をリポジトリに commit する」と決めたが、出典と取り込み表は [ADR 0010](0010-monorepo-data-storage.md) で非公開 R2 に置くよう改めたので、リポジトリだけでは作り直せない。

正本は、リポジトリ（コード・宣言・判断・保存参照）と非公開 R2（fudoki が変換を担う資料と取り込み表。資料は出典と人口の資料）の組とする。D1・API・ダッシュボード（fudoki.dev）はそこから作る派生物で、D1 には同期の script（`pipeline/serving/sync_d1.py`）だけが書き込み、表ごとに全件を入れ替える。手で D1 に値を入れない。独立した証跡ファイルは作らない（用語集の「証跡」）。

当初の狙いは、運営者が消えても止まらない形にすることだった（先行事例は個人運営の消滅・買収後の有料化・標準自体の停止という3つの死に方をした）。R2 が非公開の今はこれを満たしていない。配布を API 単独にしないこと、第三者が作り直せる形で配布物を外に出すことは、配布・公開の方式を決める段（パイプライン完成後）で改めて決める。
