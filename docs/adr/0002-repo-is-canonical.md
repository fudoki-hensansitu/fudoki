# 正本はリポジトリ、API・ダッシュボードは派生物

状態: 採用。下の「原典・証跡はリポジトリに commit し」は当初の決定で、原典と取り込み表は [ADR 0010](0010-monorepo-data-storage.md) で非公開 R2 に置くよう改めた。リポジトリに commit するのはコード・宣言・判断と保存参照で、独立した証跡ファイルは作らない（用語集の「証跡」）。

配布物・原典・証跡はリポジトリに commit し、API・ダッシュボード（fudoki.dev）はそこから生成する派生物とする。運営者が消えても止まらない形にするためで、先行事例は個人運営の消滅・買収後の有料化・標準自体の停止という3つの死に方をした。配布を API 単独にすることはしない。
