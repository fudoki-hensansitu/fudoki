# 予算データ源の実測（2026-08-30）

調査時点の観測記録。現在の出典確認は [source_selectionの手順](../../.agents/skills/pipeline/references/source-selection.md) を参照する。

#### ① CKAN に事業単位のデータは存在する。ただし探し方が要る（2026-08-30 実測）

調査では**自治体ごとにデータセットを全件列挙し**、
候補 818 件の列構成を測った結果、**目以下に到達したものが実在した**
（2026-08-30 実測）。
歳出の粒度を測るのが目的なので、**歳入ファイルは自治体の代表にしない**。

予算資料を持つのは17自治体、**歳出の粒度を測れたのは4自治体**、
うち事業単位（目より下の事業階層）に届いたのは3自治体（三鷹市・狛江市・多摩市）で、
残りは候補が見つからないか、歳出だと分からないか、列から粒度を測れなかった。
「N自治体で確認した」以上の主張をしない。

⚠️ **ただしこれは「カタログに何があるか」の話でしかない。**
残り45自治体はカタログに予算資料を1件も持たないが、**予算書・決算書は市サイトに置いてある**。
形式で絞らず（PDF も含めて）、語彙を「会計 / 経費 / 公会計」まで広げても
カタログ側の候補は17自治体から増えなかったので、**カタログの探索はここで尽きている**
（2026-08-30 実測）。カタログが空であることを「データが無い」と読み替えないこと —
それは母集団を取得経路で張っているのと同じ誤りである。

#### ① サイト側まで張ると、62自治体中53自治体で目より下に届く（2026-08-30 実測）

62自治体すべてについて取得元を探索し、**見つけた資料を実際に開いて中身で測った**。

| | 自治体 | 何が分かっているか |
|---|---|---|
| **収録済み** | 3 | `sources.toml` に登録済み（カタログの CSV） |
| **確定** | 50 | 事項別明細書を開いて**節**（目より下）まで届くことを確認した |
| **目どまり** | 4 | テキスト経路では節に届かない。組版が部分的に読めないので OCR で再確認が要る |
| **OCR 待ち** | 1 | 資料はあるが文字がアウトライン化されており、テキスト抽出が成立しない |
| **照会が要る** | 1 | CloudFront の WAF がブラウザ以外の UA を全部拒否する（robots.txt すら 403） |
| **測れていない** | 1 | 資料は挙がったが、開いても科目の語が1つも無く判定が付かない |
| **資料が無い** | 2 | 探索が回っても資料が1本も挙がらなかった（島嶼部の村） |

⚠️ **「測れていない」と「資料が無い」を1つにしない。** 前者は開いた上で判定が付かなかった状態、
後者は資料が挙がらなかった状態で、別のことを言っている。潰すと測っていないものが結果として出る。

⚠️ **判定は資料名ではなく本文の節の語で行う**。
地方自治法施行令の様式により、事項別明細書は款・項・目に加えて**節**と**説明**欄を持つ。
款項どまりの集計表には節が現れないので、これが名前に頼らない判別になる。
「予算に関する説明書」という名前は粒度を保証しない。

⚠️ **UA を偽装して WAF を回避しない。** 取得を拒否された資料は照会に回す。

⚠️ **「資料が無い」は3自治体だけで、しかも公開の仕方の問題である。**
大島町は予算書を役場の窓口でしか閲覧させておらず、
これは「データが無い」のではなく「オンラインに無い」。区別して書くこと。

⚠️ **測っていないものを結果として出さない。** 以前は歳出か歳入か判別できない資料も
自治体の代表にしており、財政指標の表（「財政力の状況」「財政健全化判断比率算定結果」）が
5自治体ぶん**歳出の粒度**の欄に並んでいた。測っているのは「歳出がどこまで届いているか」なので、
歳入はもちろん、歳出だと分からない資料も代表にしてはいけない。
収録済みの自治体と、その出典が何を持っているか（執行額の有無・名称の有無など）は
`ingestion/budget/jurisdictions/<自治体コード>.md` にある。

⚠️ **母集団を全文検索のクエリ語で張っていたときは、この半分しか見えていなかった。**
クエリ4本（歳出 / 当初予算 / 決算書 / 予算データ）で候補が出たのは8自治体で、
かつ **CSV だけを見ていた**ので、XLSX / XLS でしか予算を出していない9自治体
（練馬区・大田区・目黒区・調布市・町田市ほか）が丸ごと「予算データ無し」に見えていた。
さらに事業階層の推定語に「細目」が無く、多摩市が `account-item` と判定されて
**事業単位に届く3自治体目を落としていた**。母集団の誤りがそのまま出た形で、
**「無い」と言えるのはその自治体の全データセットを見たときだけ**である。

⚠️ **列構成で判定できるのは列の有無まで。** 事業列があっても名称が無い自治体が実在した。
名称の有無まで測るには実物を収録するしかない。

⚠️ **manifest の `openData.budget` は自治体ごとの代表1件であって、母集団ではない。** 初版のこのスクリプトはそこだけを見て「事業単位のデータは0件」という誤った結論を出した（事業単位に届く自治体が28件のデータセットを持ち、代表1件がたまたま指標表だった）。**フィールド名を中身の保証と取り違えたうえ、代表1件を母集団として扱った。**
