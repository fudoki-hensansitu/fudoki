# 未選定の自治体の穴埋め候補: 統計系の出典の実測（2026-10-27）

`selected_candidate_id` が null の対象（自治体が事項別明細書を出していない、または未公表）を、統計で款・項まで埋められるかを調べた。結論は、**決算の過去年度なら総務省の「市町村別決算状況調」で款・項まで取れる。当初予算と令和7年度決算は、今回確認した資料（2026-10-27 時点）では埋まらない**。款の内訳（項）が付くのは一部の款だけで、残りの款は款まで。

## 実測の結果

| 出典 | 粒度 | 年度 | 取得 | 判定 |

- 神津島村（133647、令和6年度）で実測した。市町村別決算状況調は議会費 41,089 千円・総務費 799,564 千円で、決算カードの目的別歳出と一致した。項の内訳列があるのは総務費・民生費・衛生費・農林水産業費・土木費・教育費・災害復旧費の7款で、議会費・労働費・商工費・消防費・公債費・諸支出金・前年度繰上充用金は款だけ（`001061676.xlsx` の見出し行で確認。単位は千円）。
- e-Stat API の統合表の時間軸は表全体で 1989〜2018 年度。千代田区・八王子市・神津島村・奥多摩町で確認し、どれも同じだった。一方、同じ調査の**年次ファイル**（年ごとの xlsx）には 2024 年度分があり、神津島村（133647）の行も読めた（レビューの指摘で判明。初版は統合表だけを見て「2018年度まで」と結論していた）。
- 決算カード・市町村別決算状況調はどちらも**普通会計**。風土記の一般会計の款とは組み替えが違い、合計も一致しない。

## e-Stat の年次ファイルの表の構成（2026-10-29）

一覧は e-Stat API の `getDataCatalog`（`statsCode=00200251`）とデータセットの頁で、中身は xlsx を openpyxl で読んで確かめた。

- 目的別歳出は表07〜13「歳出内訳及び財源内訳（その1〜その7）」に分かれる。列が目的別の款・項（一部はその下の区分）、行が性質別で、1行が1団体・1性質。各表は行の範囲で `_1`〜`_3` のファイルに分かれる（2026-10-29 実測、決算年度 2024 の `statInfId=000040375643`〜`000040375657`）。
  - その1 議会費・総務費、その2 民生費・衛生費、その3 労働費・農林水産業費・商工費、その4 土木費、その5 消防費・教育費、その6 災害復旧費・公債費・諸支出金・前年度繰上充用金、その7 歳出合計と財源内訳。
  - 内訳の列が無い款は議会費・商工費・消防費・公債費・前年度繰上充用金。土木費の都市計画費、教育費の保健体育費、災害復旧費の各施設は、その下の区分まで列があり、上の区分の合計列は無い（災害復旧費は区分ごとの総額列がある）。
  - 列名は「款・項」を `・` で繋ぐが、項の名前自体に `・` を含むもの（戸籍・住民基本台帳費）があるので、`・` で機械的には分けられない。
- 款・項の金額は、性質別の行のうち「歳出合計」の行から取る（各表の `_2` 以降のファイルにある）。決算年度 2024 の全 1741 市町村で、款の和が その7 の歳出合計に、内訳の列の和が款の総額に一致した。
- ファイルには一部事務組合・広域連合（団体区分 6・7）と全国合計の行も入る。市町村（団体区分 1〜5・8・9）だけを使う。
- 決算年度 2005〜2024 の年次ファイルは同じ列・行の形（決算年度 2005・2010・2015・2019・2024 の表07 で確認）。e-Stat のデータセットの「調査年」は決算年度の翌年（2025年のデータセットが決算年度 2024）。2004 年度以前は表の分け方が違う。
- 単位は千円。

## 埋まらないもの

- 当初予算: 決算統計系は決算のみ。次の選定が null の当初予算は残る（2026-10-27 時点の宣言）: 神津島村 2023〜2026、青ヶ島村 2023〜2026、小平市 2023〜2026、三宅村 2023・2024（2025・2026 は選定済み）。
- 令和7年度決算（未公表29件）: 今回確認した総務省・e-Stat の決算統計は2026-10-27 時点で令和6年度が最新で、補完できない。

## 再現手順

認証なしの curl と Python（openpyxl）で確認した。スクリプトはリポジトリに置いていない（1回限りの実測）。

- 市町村別決算状況調: 各年度の頁（令和6年度は `https://www.soumu.go.jp/iken/zaisei/r06_shichouson.html`）から「(3) 目的別歳出内訳」の xlsx を取り、団体コード（133647）の行を読む。
- 決算カード: `https://www.soumu.go.jp/iken/zaisei/card-25.html` から都道府県別 xlsx を取り、団体名のシートを読む。最新年度は `card.html` の一覧で確認した。
- e-Stat API の統合表: `getMetaInfo`（`statsDataId=0003172923`）で時間軸、`getStatsData`（`cdArea=13364`）で団体の値を取る。appId が必要。
- e-Stat の年次ファイル: 上の `file-download` の URL から xlsx を取り、団体名の行を読む。

## 判断

統計の数字は風土記に取り込まない。理由と、収録の無い年度の扱いは [ADR 0037](../adr/0037-do-not-ingest-statistical-settlements.md) に置く。
