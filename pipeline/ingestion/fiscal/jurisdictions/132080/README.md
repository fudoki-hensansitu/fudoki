## 2023年度決算・歳出（R5、2026-11-16）

一般会計・特別会計4つ（国民健康保険事業、用地、介護保険事業、後期高齢者医療）を、1冊の決算書の scan から読む。見開きの左頁に款・項・目と予算現額・節、右頁に支出済額・翌年度繰越額・不用額・備考を印字する。5つの変換は同じ workflow を使う。

- OCR の依頼は R7 当初と同じ `dashed_rules: true`・`page_strips: 1`・`detection_limit_side_len: 3600`。
- 款・項・目と節・細節の番号の欄を点線で区切り、OCR が点線に接する番号を読み落としたりつなげたりする。枠の最初の欄の点線を罫に足し（`dotted_column_rules`）、点線の切れ端を罫の墨とみなす（`rule_ink`）。見出しは `header.staircase: "款項目名"` で、科目は名前で段を読む（subject `names`）。
- 右頁は左頁より少し大きく刷られ、位置が最大8pt ずれる（`scaled_spread_pages`）。
- 続きの頁は科目の欄の頭に、開いている目の名前を括弧で繰り返す（`5 5 5(議会費)`）。金額の無いこの行を捨て、開いている科目の下で読み続ける（`bracketed_repeats`）。
- 節の欄は節の番号の右に細節の番号を印字する。同じ頁で開いている節の番号の右端より右で終わる番号を細節とする（breakdown `setsu_ends`）。
- 備考は字下げで段を読み（`indent_chars: 1`）、行頭の ◎、○、・ が段を示す。OCR が読み落とした ◎ は、名前の左にある丸い墨から足す（`unread_marks`）。
- 流用の注記が2行にわたり、次の行に所管の課を括弧で印字するとき、課の行は注記に入れ、その次の事業は別の行とする（`tree.ends_transfer`）。
- 翌年度繰越額の欄の下段の見出し（継続費逓次繰越・繰越明許費）と頁422の不用額は、OCR が読めなかったので頁ごとに `header_readings` で読む。
- OCR が罫をまたいで金額を1語に読んだ頁201・207は、その読みを捨てて位置で読み直す。後期高齢者医療の頁551で款と項の番号を1語（510）に読んだところも同じ。
- 名前の読み違い（`一般行理費`、`福祉総`、頁555の罫を読んだ「内」など）は `name_corrections` で印字に直す。

## 2024〜2026年度当初予算・2024年度決算・歳出（特別会計、2026-11-17）

国民健康保険事業・用地・介護保険事業・後期高齢者医療の4会計を、一般会計と同じ読み方で取り込む。当初予算は 2024・2026年度が scan、2025年度は国民健康保険が scan でほかは文字 PDF。2024年度決算は文字 PDF で、国民健康保険の p455 だけ文字層が空なので OCR で読む。

- 一般会計の説明の `line_starts` は一般会計の頁にだけ当たるので、特別会計には写さない。特別会計の頁で `◎` を落として金額と1語に読んだ行は、その頁の `line_starts` に書く。
- 用地と後期高齢者医療の scan（2024・2026年度）は、款・項の2桁の番号が1桁の番号より1字左から始まる。2桁の番号は1桁の番号の始まりに揃えて読む（`codes_across_level_rules`）。
- 2025年度の国民健康保険で、その年に無くなった目は番号と名前の間に `△` を印字し、番号を `△` の幅だけ左にずらす（`10△退職被保険者等…`）。番号の始まりで読むと項と目の間に入り段がつながるので、`△` の付いた行は `△` の幅だけ右で読む（opt-in の quirk `codes_before_marks`）。名前の `△` は一般会計と同じく残す。
- 2行の数字を1つに読んだ枠・番号に付いた墨の点は `dropped_readings` で除き、`amount_readings`・`code_readings` で読み直す。

一般会計 2024年度決算（p382）は、文字 PDF の中の OCR の頁を、scan の冊の読み方（段の欄の左端）でなく文字の頁と同じく番号の始まりで読むよう共通のコードを直した（`indent` の staircase は全頁が OCR の冊だけ）。この形の既存の宣言は 090000 2026年度当初予算だけで、変換の結果は変わらない。
- 2025年度当初の用地（文字 PDF）は、2桁の款「10」が1桁の番号より1字左から始まり、段が款・項・目の3段に分かれなかった。2024・2026年度と同じく `codes_across_level_rules` で2桁の番号を1桁の始まりにそろえる。
- 2026年度当初の介護 p30 の頭の項「15 その他諸費」は OCR が「1」を読み落として「5」と読んだ。`dropped_readings`・`code_readings` で「15」に直す。
