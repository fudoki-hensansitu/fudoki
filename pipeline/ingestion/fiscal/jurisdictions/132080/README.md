## 2023年度決算・歳出（R5、2026-11-16）

一般会計・特別会計4つ（国民健康保険事業、用地、介護保険事業、後期高齢者医療）を、1冊の決算書の scan から読む。見開きの左頁に款・項・目と予算現額・節、右頁に支出済額・翌年度繰越額・不用額・備考を印字する。5つの変換は同じ workflow を使う。

- OCR の依頼は R7 当初と同じ `dashed_rules: true`・`page_strips: 1`・`detection_limit_side_len: 3600`。
- 款・項・目と節・細節の番号の欄を点線で区切り、OCR が点線に接する番号を読み落としたりつなげたりする。枠の最初の欄の点線を罫に足し（`dotted_column_rules`）、点線の切れ端を罫の墨とみなす（`rule_ink`）。見出しは `header.staircase: "款項目名"` で、科目は名前で段を読む（subject `names`）。
- 右頁は左頁より少し大きく刷られ、位置が最大8pt ずれる（`scaled_spread_pages`）。
- 続きの頁は科目の欄の頭に、開いている目の名前を括弧で繰り返す（`5 5 5(議会費)`）。金額の無いこの行を捨て、開いている科目の下で読み続ける（`bracketed_repeats`）。
- 節の欄は節の番号の右に細節の番号を印字する。同じ頁で開いている節の番号の右端より右で終わる番号を細節とする（breakdown `setsu_ends`）。
- 備考は字下げで段を読み（`indent_chars: 1`）、行頭の ◎、○、・ が段を示す。OCR が読み落とした ◎ は、名前の左にある丸い墨から足す（`unread_marks`）。
- 流用の注記が2行にわたり、次の行に所管の課を括弧で印字するとき、課の行は注記に入れ、その次の事業は別の行とする（`tree.ends_transfer`）。
- 翌年度繰越額の欄の下段の見出し（継続費逓次繰越・繰越明許費）と頁422の不用額は、OCR が読めなかったので頁ごとに `header_readings` で読む。
- OCR が罫をまたいで金額を1語に読んだ頁201・207は、その読みを捨てて位置で読み直す。後期高齢者医療の頁551で款と項の番号を1語（510）に読んだところも同じ。
- 名前の読み違い（`一般行理費`、`福祉総`、頁555の罫を読んだ「内」など）は `name_corrections` で印字に直す。
