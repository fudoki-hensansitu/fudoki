# 三宅村（133817）

## 2024年度決算・歳出

一般会計を款の粒度だけで取り込む。出典は「三宅村財政のあらまし（令和7年12月分）」2頁の「歳出（目的別）」表（文字PDF、千円）。款13行（0円の労働費を含む）の決算額で、款の和 4,378,690千円は表の「計」と一致する（2026-11-10 に確認）。項・目以下、特別会計・公営企業会計は出典に無い。

- 同じ頁に「歳入」「歳出（目的別）」「歳出（性質別）」の3表が同じ列で縦に並ぶ。汎用の読み方は同じ列の表を1つの枠と読み、頁の最初の見出し「歳 入」で頁ごと歳入として読み飛ばすので、reading `purpose_summary`（`layouts/summary-2024.json`）で読む。表のパターン `purpose_section` が「目的別」の見出しの下の表だけを残す。
- 構成比・村民一人当たり・一世帯当たりの列は款の金額ではないので、`columns` で読まない列と宣言する。
- 合計の行は「計」で「歳出合計」ではないため、保存の関門の単位の確かめは桁だけになる。款の和と「計」の一致は上のとおり手で確かめた。
- 款の粒度の表は款の番号を印字しないので、dbt では 2024 の一般会計の款を番号でなく名前で同定する（seed `fiscal_kan_name_identity`）。
