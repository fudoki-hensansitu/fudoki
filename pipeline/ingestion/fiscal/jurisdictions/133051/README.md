# 日の出町 133051

## 2024〜2026年度当初予算・歳出（一般会計）

一般会計予算書の事項別明細書を読む。1頁に目・節・説明を並べ、頁の上に `（款） 1 議会費 （項） 1 議会費` を1行で印字する。項の表は次の頁へ見出し無しで続き、頁の頭に目の名前を `（議会費）` と括弧で繰り返すので、`continued_pages` に `header.carried_names` を付けて読む。

- 範囲は総括の頁（款の金額と歳出合計）と明細の頁に絞る（`pages`）。財源内訳の欄は取り込まない。
- 説明は7桁の事業コードの事業（`1000100 議会運営経費`）と、その下の8桁のコードの品目（`01100110 議員報酬`）の2段。コードは名前と離して印字するので `spaced_project_codes` で番号として読む。名前が数字で始まる品目（`10101002 3R推進…`）もある。
- 説明の名前が折り返して金額だけを次の行に印字するので、`bare_amounts` で前の名前の金額として読む。
- 目の欄は、目・折り返した名前・項の `計`・次の表の見出しの間に罫線を引かない（`open_subject_cells`）。名前の続きが数字で始まることがある（`13 日の出町合併` / `70周年・町制` / …）。
- その年に無くなった目は番号の代わりに `△` を印字し、説明に `廃目` と書く（`abolished_marks`）。
- 説明の分け方は「事業」。
