# 品川区の決算書を読む

2024年度の特別会計の冊は文字PDFであり、数字の文字対応表だけが壊れている。書式設定の `text_layer.character_map` で U+0013〜U+001C を 0〜9、U+000F をカンマに置き換える。2025年度の国民健康保険事業会計にも同じ対応表を使う。出典PDFのバイト列と印字位置は変えない。

2026-10-23に品川区公式の決算書一覧を確認したところ、2024年度の3冊は `r6/r6_1.pdf`〜`r6_3.pdf`、2025年度は `r7/r7_1.pdf`〜`r7_3.pdf` に掲載されていた。2024年度の新URLの各冊は、保存済みの各冊と本文テキストが全頁一致する。保存済み出典のSHAと保存先を維持し、候補の取得URLを更新する。保存記録の `final_url` は過去に取得したURLなので書き換えない。

2025年度の一般会計歳出は冊2の物理1〜236頁。特別会計の冊は前年と異なり先頭に空白頁があり、国保歳出13〜30頁、後期高齢者医療歳出41〜48頁、介護保険歳出67〜90頁、災害復旧歳出95〜96頁となる。議案の総括や参考資料を明細へ加えない。

一般会計の2024年度取り込み表には予算現額・不用額も残る。予算現額は金額辞書で `adjusted`、不用額は段階を持たない欄であり、決算の中間処理は `executed`（支出済額）を選ぶ。APIへの同期は提供用データの列をそのまま写すため、両額は現行APIに出ない。決算歳出明細を支出済額一つで扱う既存の設計による。

2025年度の一般会計は現行の書式設定で試したが、保存前の階層の合計検査で8件の不一致が残り、未採用。物理142頁の各種がん検診の続き・予防接種費・感染症予防費を取り込めないほか、太陽光設備と幼稚園改築の内訳の所属、児童手当の数量を含む行の読み分けが残る。出典の印字の誤りとは確定していないため、ずれの宣言で通さない。一般会計を収録済みとして扱わず、特別会計の表だけを別に採用する。

採用済みの歳出は2023・2024年度の一般会計・国民健康保険事業会計・後期高齢者医療特別会計・介護保険特別会計と、2025年度の国保・後期・介護。両年度の災害復旧特別会計（2026-11-17）は、予算現額の升が「継続 0」「予備 0」のように 0 と並ぶ種類の行ばかりで名前の欄と読まれていたので、2023年度決算と同じ quirk `zero_kind_lines` を選んで取り込んだ。款の和は印字の歳出合計と一致する（2024年度 1,864,882円・2025年度 95,418,977円）。

## 当初予算（予算事項別明細書）

2024〜2026年度の当初予算の歳出は、各会計の予算事項別明細書（文字PDF、見開きで1物理頁）を共通の `generic_text` で読む。2024・2026年度は1冊、2025年度は全4冊のうち一般会計歳出が冊2・冊3に分かれる（各冊の表は `partial`）。

- 款・項は表の上に `1款 総務費 … 24,930,655千円` / `1項 総務管理費 … 14,998,332千円` と印字され、同じ頁で項が変わると表を閉じて次の表の上に印字する。表のパターン `stacked_titles` が、表と表の間の語を帯の外へ移して款・項の見出しとして読む。見出しの金額には見出しが無く、`header.title_amount` で `本年度予算額` と宣言した。継続頁で繰り返す見出しは再掲として扱う。各会計の先頭の総括（款の一覧）も選定の範囲に含まれ、款のノードと本年度予算額・前年度予算額・比較を持つ。
- 本年度予算額の財源内訳の4欄は取り込まない（`excluded`、種類は財源内訳）。目の行の財源額の下に財源の種類と額が複数行で積まれ、名前と金額を1対1に組めないため。
- 説明の欄の継続費・債務負担行為の内訳（総工事費・総委託費・債務負担行為額・差引計上額）は事業の内訳ではなく、注記（種類は債務負担行為）にした。国保の審査支払手数料の単価×件数＝円の算式も注記（種類は積算）にし、金額の後ろに印字された円を単位として持つ（`yen_marked`）。「補充用消火器購入」は充用の注記ではない（`plain_names`）。名前の下の行に3桁の金額だけを折り返す内訳がある（`bare_amounts`）。
- 番号の印字が無い廃目（国保の退職被保険者等療養費など、本年度0・前年度1）は、名前が行の中で折り返す。目の名前が4行に折り返し、行の間隔が字の高さより開くもの（2025年度 介護 頁50 `地域密着型`／…／`事務費`）も、目の金額の欄の罫で区切られた行の中にあれば同じ目の名前とする。
- 国保の `73（ナナサン）歯科健診事業` は、数字の直後に括弧で片仮名の読みが続くので番号ではなく名前とする。
- 2025年度の冊は見出しの字が罫で割れて読める（`説`／`明`、`本年度予額の財源内訳`／`算`）。`columns` で説明の欄の見出しと軸を `説明` と宣言した。
- 2026年度の一般会計 頁176 の下水道管改修事業は、実施設計委託 50,000千円が耐震化推進事業と同じ字下げで印字され、印字の字下げでは事業の和が 50,000千円合わない（耐震化推進事業の下に置くと両方閉じる）。印字値と字下げを書き換えず、`expenditure.layout.json` の `source_inconsistencies` で宣言した。

## 2023年度当初予算・歳出（R5、5表、2026-11-15）

2024年度の当初と同じ宣言で読む。ノード/金額は一般会計 3,781/3,915・国保 192/265・後期 94/121・介護 260/344・災害復旧 15/19。款の和は5表とも印字の歳出合計と一致する（一般会計 198,794,000千円）。

- **R5 の冊は文字の層が二重で、同じ文字が 10.6pt 左に見えない写しとして重なる**。quirk `shifted_hidden_copies` に `reach: [8, 14]` を足し、既定（60〜200pt）より近い写しを落とす。宣言した距離では、切り抜き（clip）で見分けられる組だけで頁の写しの距離を決める（款別総括の頁で並んで印字された同じ数字を写しと読まないため）。
- 括弧で始まる行（`［…］`）が1段深く読めるので repair `em_boxes` を選ぶ。
- 一般会計 頁132 の幼稚園維持管理費・浜川幼稚園改築は字下げが1段ずれて印字され、印字の字下げでは事業の和が合わない。印字値と字下げを書き換えず、`2023/initial/expenditure.layout.json` の `source_inconsistencies` で宣言した。
- 総借上料は債務負担行為、療養費の単価（`療養費20.79円`）は積算の注記にした（`note_kinds`）。

## 2023年度決算・歳出

一般会計（冊2）と国保・後期・介護（冊3）を、2024年度の読み方を写して取り込む。災害復旧特別会計（2026-11-17）は、2024・2025年度と同じく国保の宣言に quirk `zero_kind_lines` を足して読む。款の和は各会計の印字の歳出合計と一致する。

| 会計 | ノード | 金額 | 款の和＝印字の歳出合計（円） |
| --- | ---: | ---: | ---: |
| 一般会計 | 3,995 | 6,878 | 194,155,568,533 |
| 国民健康保険事業会計 | 203 | 733 | 36,596,116,315 |
| 後期高齢者医療特別会計 | 93 | 318 | 9,957,034,876 |
| 介護保険特別会計 | 273 | 1,008 | 27,024,894,423 |
| 災害復旧特別会計 | 13 | 46 | 46,762,106 |


- **予算現額の欄**: 特別会計の冊は予算現額を1つの升に「計／当初／補正／継続／予備」と種類を付けて重ねる。「継続 0」「予備 0」のように 0 と並ぶ行が多く、種類の行と数えられずに欄が名前の欄に読まれていた。介護保険の変換で quirk `zero_kind_lines` を選び、0 と並ぶ種類の行も種類の行として数える。
- **数から始まる名前**: 一般会計の備考の「2人目加算延5,186人」「3人目以降加算…」の数を項目の番号と読んでいた。「人目」を数の後に付く語（`COUNTED`）に足した。「８３運動経費」（8・3運動）は、番号を半角だけで印字する書式なので quirk `full_width_names` で名前とした。
- **字下げのずれ**: p108 幼稚園維持管理費の内訳「施設維持管理業務委託 156,810」は浜川幼稚園改築と同じ字下げで印字されるが、金額は浜川幼稚園改築の子として閉じる。印字は書き換えず、`2023/settlement/expenditure.layout.json` の `source_inconsistencies` で宣言した。

## 歳入（R6〜R8 当初・R5〜R7 決算、2026-11-15）

歳入は歳出と同じ冊の、選定が歳入と宣言した頁にある。読み方は同じ冊の歳出の宣言を写し、歳入の頁で違う欄だけを足した（`revenue.json`）。木は款・項・目・節。設計は [docs/prd/fiscal-revenue/dd.md](../../../../../docs/prd/fiscal-revenue/dd.md)。

- 当初予算の説明・決算の備考は、節ごとの充当事業・負担（補助）基本額と率・調定額と収入率で、節の内訳ではない。除外し（種類は歳入の説明）、木に入れない。決算の備考の見出しは `注 △印は減` を印字する頁としない頁があり、両方の見出しに除外を書く。2025年度当初の冊は見出しが `説`・`説／明` に割れて読める頁があり、その見出しにも書く。
- 決算の `不納欠損額／収入未済額` は1つの欄に2段で印字される（`columns.lines`）。調定額・不納欠損額・収入未済額は金額の段階を持たず、取り込みの表にだけ残る。
- 2025年度当初の一般会計の歳入は冊4の1冊に収まるので、歳出と違い `partial` ではない。2025年度決算の一般会計は、歳出は未採用だが歳入は 2024年度の決算の宣言を写して取り込めた。
- 当初予算は5会計とも款の和が印字の歳入合計と一致する（2026年度一般会計 236,914,000千円）。決算は頁に歳入合計の印字が無く、一般会計は桁の確かめだけ（2025年度の款の収入済額の和 247,973,497,670円）。
- 番号の無い廃款（2026年度当初 `款 特別区債 … 0千円`）、`1` `歳計現金利子` の番号、決算書 p97 の隠れた写しに重なる見出しは、共通コードで読めるようにした。
