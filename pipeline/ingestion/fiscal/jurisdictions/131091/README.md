# 品川区の決算書を読む

2024年度の特別会計の冊は文字PDFであり、数字の文字対応表だけが壊れている。書式設定の `text_layer.character_map` で U+0013〜U+001C を 0〜9、U+000F をカンマに置き換える。2025年度の国民健康保険事業会計にも同じ対応表を使う。出典PDFのバイト列と印字位置は変えない。

2026-10-23に品川区公式の決算書一覧を確認したところ、2024年度の3冊は `r6/r6_1.pdf`〜`r6_3.pdf`、2025年度は `r7/r7_1.pdf`〜`r7_3.pdf` に掲載されていた。2024年度の新URLの各冊は、保存済みの各冊と本文テキストが全頁一致する。保存済み出典のSHAと保存先を維持し、候補の取得URLを更新する。保存記録の `final_url` は過去に取得したURLなので書き換えない。

2025年度の一般会計歳出は冊2の物理1〜236頁。特別会計の冊は前年と異なり先頭に空白頁があり、国保歳出13〜30頁、後期高齢者医療歳出41〜48頁、介護保険歳出67〜90頁、災害復旧歳出95〜96頁となる。議案の総括や参考資料を明細へ加えない。

一般会計の2024年度取り込み表には予算現額・不用額も残る。予算現額は金額辞書で `adjusted`、不用額は段階を持たない欄であり、決算の中間処理は `executed`（支出済額）を選ぶ。APIへの同期は提供用データの列をそのまま写すため、両額は現行APIに出ない。決算歳出明細を支出済額一つで扱う既存の設計による。

2025年度の一般会計は現行の書式設定で試したが、保存前の階層の合計検査で8件の不一致が残り、未採用。物理142頁の各種がん検診の続き・予防接種費・感染症予防費を取り込めないほか、太陽光設備と幼稚園改築の内訳の所属、児童手当の数量を含む行の読み分けが残る。出典の印字の誤りとは確定していないため、ずれの宣言で通さない。一般会計を収録済みとして扱わず、特別会計の表だけを別に採用する。

採用済みの歳出は2024年度の一般会計・国民健康保険事業会計・後期高齢者医療特別会計・介護保険特別会計と、2025年度の国保・後期・介護。両年度の災害復旧特別会計は、現行の生成機が款の支出済額を拾えず、款の和0に対し印字合計が2024年度1,864,882円・2025年度95,418,977円となって単位の検査で停止した。未採用の候補と選定済みの出典は保持する。

## 当初予算（予算事項別明細書）

2024〜2026年度の当初予算の歳出は、各会計の予算事項別明細書（文字PDF、見開きで1物理頁）を共通の `generic_text` で読む。2024・2026年度は1冊、2025年度は全4冊のうち一般会計歳出が冊2・冊3に分かれる（各冊の表は `partial`）。

- 款・項は表の上に `1款 総務費 … 24,930,655千円` / `1項 総務管理費 … 14,998,332千円` と印字され、同じ頁で項が変わると表を閉じて次の表の上に印字する。表のパターン `stacked_titles` が、表と表の間の語を帯の外へ移して款・項の見出しとして読む。見出しの金額には見出しが無く、`header.title_amount` で `本年度予算額` と宣言した。継続頁で繰り返す見出しは再掲として扱う。各会計の先頭の総括（款の一覧）も選定の範囲に含まれ、款のノードと本年度予算額・前年度予算額・比較を持つ。
- 本年度予算額の財源内訳の4欄は取り込まない（`excluded`、種類は財源内訳）。目の行の財源額の下に財源の種類と額が複数行で積まれ、名前と金額を1対1に組めないため。
- 説明の欄の継続費・債務負担行為の内訳（総工事費・総委託費・債務負担行為額・差引計上額）は事業の内訳ではなく、注記（種類は債務負担行為）にした。国保の審査支払手数料の単価×件数＝円の算式も注記（種類は積算）にし、金額の後ろに印字された円を単位として持つ（`yen_marked`）。「補充用消火器購入」は充用の注記ではない（`plain_names`）。名前の下の行に3桁の金額だけを折り返す内訳がある（`bare_amounts`）。
- 番号の印字が無い廃目（国保の退職被保険者等療養費など、本年度0・前年度1）は、名前が行の中で折り返す。目の名前が4行に折り返し、行の間隔が字の高さより開くもの（2025年度 介護 頁50 `地域密着型`／…／`事務費`）も、目の金額の欄の罫で区切られた行の中にあれば同じ目の名前とする。
- 国保の `73（ナナサン）歯科健診事業` は、数字の直後に括弧で片仮名の読みが続くので番号ではなく名前とする。
- 2025年度の冊は見出しの字が罫で割れて読める（`説`／`明`、`本年度予額の財源内訳`／`算`）。`columns` で説明の欄の見出しと軸を `説明` と宣言した。
- 2026年度の一般会計 頁176 の下水道管改修事業は、実施設計委託 50,000千円が耐震化推進事業と同じ字下げで印字され、印字の字下げでは事業の和が 50,000千円合わない（耐震化推進事業の下に置くと両方閉じる）。印字値と字下げを書き換えず、`expenditure.layout.json` の `source_inconsistencies` で宣言した。
