# 羽村市 132276

## 2024年度決算・歳出

一般会計・特別会計4つ（国民健康保険、後期高齢者医療、介護保険、羽村駅西口土地区画整理事業）・公営企業会計2つ（水道、下水道）を取り込む。

一般会計・特別会計の決算書は見開きの scan で、偶数頁に科目・予算現額・節、奇数頁に支出済額・翌年度繰越額・不用額・備考を印字する。公営企業会計は文字 PDF。

- 欄が細く、頁の分割の継ぎ目が欄を切るので、OCR の依頼を `page_strips: 1`、`detection_limit_side_len: 3600` にし、`rule_steps` を書く。
- 備考は字の位置で読む（`position`）。全角の開き括弧は字の右半分に墨があるので、字下げを半字戻す（`opening_bracket_ink`）。
- 7桁の事業番号の名前の折り返しは、番号と空白の幅の見積もりより少し右から始まる（`name_start_slack`）。
- 頁の先頭に繰り返された見出し（`医療費` / `02市単独事業`）は番号の名前に結ばない（`heading_repeated_over_code`）。金額のない行として残す。
- 一般会計の備考に3桁以下の金額だけの行がある（`796`）ので `bare_amounts` を書く。
- 流用の注記の行頭の○を OCR が読み落とした行は、観測の修正で○を足す。注記の本文に残る読み違い（`サ一ビス`）は直していない。
- 名前の読み違いは `name_corrections` で印字に直す。
- 公営企業会計は金額の欄の見出しを「決算額」に宣言し、収益的支出と資本的支出を別の表にする。どちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`generate_sources.py` の `EXCLUDE`）。

### 名前の注意

節の細目（`04その他`）に金額がなく、下の行が1行だけの行は、1つの名前に結ばれる（`その他審査支払等委託料`、`消耗品費管理用消耗品`）。印字の語はすべて残り、金額には影響しない。
