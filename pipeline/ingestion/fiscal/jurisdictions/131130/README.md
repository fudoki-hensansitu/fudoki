# 渋谷区 131130

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険事業、介護保険事業、後期高齢者医療事業）を取り込む。

決算書は1冊の scan で、見開きを物理2頁に分けて印字する。左頁に科目（款・項・目）・予算現額・節の区分、右頁に節の金額・支出済額・翌年度繰越額・不用額・備考がある。4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 152–277 | 2,507 | 5,950 | 126,364,173,801 |
| 国民健康保険事業 | 308–339 | 183 | 627 | 24,309,504,400 |
| 介護保険事業 | 378–393 | 180 | 477 | 16,195,877,409 |
| 後期高齢者医療事業 | 422–433 | 54 | 221 | 6,585,239,565 |

- **見出し**: OCR が升の字を重ねて読む（「不用用額」「継続費及び繰越事業費繰越額越額」）。罫線の位置はどの頁も同じなので、升ごとの印字を `header_readings` で宣言した。「節」の升は左頁の右端にあり、その金額の欄は綴じ目をまたいだ右頁の左端にある。左頁の「予算現額／節区分」を節の名前の欄（`columns` の `axis_header`）、右頁の「金額」を節の金額の欄にした。右頁の翌年度繰越額は継続費逓次繰越・繰越明許費・事故繰越を1欄に合わせて印字する。
- **節**: 2行に折り返した節（「13 使用料及び賃借料」）は番号を2行の間の高さに印字する。名前は番号の右の欄に揃うので、`name_column` で番号の行の上下の行を名前に結ぶ。
- **備考**: 部を `[総務部]`、事業を `1 職員人件費 (86,980,729)`、細事業を `(1) 職員人件費 75,897,282` と、印のある行で印字する。字下げは OCR の枠で揺れるので、`marks` で印から段を決めた（`[`＝1、番号＝2、括弧の番号＝3）。括弧の金額は `amount_brackets` で金額として読む。
- **2行に折り返した科目**: 番号を名前の2行の間の高さに印字し、OCR が番号を読まないことが多い。番号は墨の位置で `code_readings` に宣言した。頁の最初の行（款・項）では番号と名前が別の科目に分かれるので、行ごとの読みを `dropped_readings` で除き、番号と名前を1つの科目として宣言した。
- **読み残し**: 頁176・185・277は Paddle が金額の欄の印字を読まなかった（不用額など）。この3頁だけ OCR の依頼を分け、`page_strips`・`detection_limit_side_len` を変えて読み直した。頁176の予備費支出及び流用増減は右隣の計の先頭の字までつないで読んだ（58,959,2551）ので、`dropped_readings` で除き `amount_readings` で宣言した。
- **算定の内訳**: 国民健康保険の頁313は、療養給付費・療養費のア〜オの額の下に「① 給付対象費用額」「② 保険者負担割合」を印字する。額の計算根拠で事業の内訳ではないので `dropped_readings` で除いた。
- **印字の不一致**: 国民健康保険の目「7 審査支払手数料」の細事業「(1) 審査支払手数料」は 65,676,181 円と印字し、下の4行の和は 54,338,876 円。差の 11,337,305 円の行は印字されていない。`expenditure.layout.json` の `source_inconsistencies` に記録し、印字値は書き換えない。
- **名前の読み違い**: 長音「ー」を「一」と読んだ行、「税」を「稅」と読んだ行、折り返した名前の最後の字が次の行に分かれた行などは `name_corrections` で直した。
- **網羅の検査**: 備考の統計の行に印字された日付（「戸籍数（R7.3.31）」）と日数（「2泊3日」）を、網羅の検査（`coverage_checks.py`）が金額でない数字として扱うようにした。
- **COFOG**: 既存の規則に当たらない目「保健施設費」は `cofog_rules.csv` の `shibuya-2024-01` で、名称から仮に保健（07）に分類した（`tentative`）。
