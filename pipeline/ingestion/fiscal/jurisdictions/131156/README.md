# 杉並区 131156

## 2023〜2026年度当初予算・2023〜2025年度決算・歳入（2026-11-17）

一般会計・国民健康保険・介護保険・後期高齢者医療の歳入を、歳出と同じ出典の冊から generic で取り込む（`revenue.json`）。

- 当初予算（予算書、文字PDF）は歳出の宣言を写し、説明の欄を除外の種類「歳入の説明」で外す。款・項の題の行は本年度・前年度・比較の3つの金額を印字するので `header.title_amount` に3つの見出しを並べる。2024年度は総括の頁の枠の上の罫が無く（quirk `unruled_frame_top`）、科目の番号と名前の間が 1.7pt しか空かない（quirk `narrow_number_gaps`）。
- 決算（決算書、`ruled`・`bands`・節は `indent`）は備考を「歳入の説明」で外す。項の名前が下の目の行まで折り返すので quirk `names_in_own_column`。2023年度の国保は数字を CJK 拡張 A の字に割り当てたフォントで、`text_layer.character_map` で戻す。
- 2025年度決算の一般会計の歳入は別冊（`r7kessan3_sainyuu.pdf`、全頁が scan）で、選定に3冊目として足した。Paddle OCR（`ocr_inputs` 9件）で読み、淡い罫を `rules.dark: 150` で拾う。番号を名前から離して読む行があるので節は `flat`。OCR の読み違い（壳・预・纳・强・卜など）は `name_corrections`。
- 2025年度決算の特別会計の冊は、文字層が △ を `•`、0 を `゜`、`歳入合計` の「合」を `^`＋`ロ` にしている（quirk `substituted_glyphs`）。
