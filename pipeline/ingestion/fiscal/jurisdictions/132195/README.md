# 狛江市 132195

## 2024年度決算・歳出

一般会計・特別会計4つ（国民健康保険、後期高齢者医療、介護保険、駐車場事業）・下水道事業会計を取り込む。2025年度は事業別の表で別の読み方をしている。

決算書は1冊の scan（文字層なし）。罫線が薄い灰色なので、OCR の依頼に `rule_dark: 215` を書く。

- 特別会計は一般会計と同じ様式なので、一般会計の読み方（`workflow`）と OCR の依頼をそのまま使う。
- 国民健康保険（物理134）と後期高齢者医療（物理144）の範囲の末尾は白紙で、OCR が止まるので選定の範囲から外した。
- 均等割付の名前で OCR が字を落とした・順を入れ替えた行（`出産育児一時金`・`介護予防サービス等諸費`）は、原画で確かめて `name_corrections` で直す。
- 下水道事業会計は収益費用明細書（物理205-206）と資本的収支明細書の支出（物理207）を別の表にする。頁の分割の継ぎ目で行が落ちたので `page_strips: 1` で読み、金額の欄の見出しを「決算額」に宣言する。節は字下げでなく形（`shape`）で段を決める。名前が2行に折り返し番号が2行の中ほどにある節は、2行目だけが名前に結ばれるので `name_corrections` で直す。どちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`generate_sources.py` の `EXCLUDE`）。
