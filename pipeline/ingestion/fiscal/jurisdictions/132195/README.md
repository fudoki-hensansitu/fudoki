# 狛江市 132195

## 2024年度決算・歳出

一般会計・特別会計4つ（国民健康保険、後期高齢者医療、介護保険、駐車場事業）・下水道事業会計を取り込む。2025年度は事業別の表で別の読み方をしている。

決算書は1冊の scan（文字層なし）。罫線が薄い灰色なので、OCR の依頼に `rule_dark: 215` を書く。

- 特別会計は一般会計と同じ様式なので、一般会計の読み方（`workflow`）と OCR の依頼をそのまま使う。
- 国民健康保険（物理134）と後期高齢者医療（物理144）の範囲の末尾は白紙で、OCR が止まるので選定の範囲から外した。
- 均等割付の名前で OCR が字を落とした・順を入れ替えた行（`出産育児一時金`・`介護予防サービス等諸費`）は、原画で確かめて `name_corrections` で直す。
- 下水道事業会計は収益費用明細書（物理205-206）と資本的収支明細書の支出（物理207）を別の表にする。頁の分割の継ぎ目で行が落ちたので `page_strips: 1` で読み、金額の欄の見出しを「決算額」に宣言する。節は字下げでなく形（`shape`）で段を決める。名前が2行に折り返し番号が2行の中ほどにある節は、2行目だけが名前に結ばれるので `name_corrections` で直す。どちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py` の `EXCLUDE`）。

## 2023年度・2022年度決算・歳出

2024年度決算と同じ様式なので、2024年度の宣言を写して頁の範囲と OCR の依頼をその年の冊に合わせた。2023年度は一般会計・特別会計4つ・下水道事業会計、2022年度は下水道事業会計が無く一般会計・特別会計4つ。

- 国民健康保険と後期高齢者医療の範囲の末尾は白紙（2023年度は物理132・142、2022年度は物理136・146）で OCR が止まるので、2024年度と同じく選定の範囲から外した。
- 2023年度の下水道事業会計は、収益費用明細書（物理203-204）と資本的収支明細書の支出（物理205）を別の表にする。
- 2022年度の一般会計の備考には `事故繰越` の行があるので、`note_kinds` で金額の注記にする（款・項の項目に数えない）。
- 2023年度の一般会計の物理73頁は金額の頭に罫線を `3` と読むので `amount_corrections` で直す。均等割付の名前で字を落とした行（`出産育児一時金`・`介護予防サービス等諸費` ほか）は、原画で確かめて `name_corrections` で直す。
- 2022年度の名前は `負担金,補助及び交付金` のように読点がカンマで印字されているので、そのまま取り込む。

## 2020・2021年度決算・歳出（一般会計、歳出事項別明細）

選定先は事業別の歳出事項別明細（文字PDF、2021年度219頁・2020年度216頁、単位千円）で、2025年度決算と同じ様式なので2025年度の宣言を写した。特別会計の明細は掲載が無い。冊に歳出合計の印字が無いので、款の決算額の和が財源内訳（一般財源・国・都・地方債・その他）の和と一致することで確かめた（2021年度 33,282,004千円、2020年度 38,899,366千円）。ノード/金額は 2021年度 5,564/9,026、2020年度 5,460/8,950。

- 字間を空けて印字した名前の最後の長音（`シ ル バ ー`・`セ ン タ ー`）は、字の間隔のまま置かれているので名前の字として読む（共通の `tree.py`）。
- 主管課だけで名前の無い事業（2020年度 物理88頁 `子ども発達支援課`）は、主管課が縦に1語で読まれる。字ごとに行を分けて、2行目の財源（都 23,325）を事業に結ぶ（quirk `rows_from`）。
- 節説明の単価（`12,300円×延 8人`）は Poppler が `12,30` と `0円×延` に割るので、単価として桁の網羅から外す（共通の `coverage_checks.py`）。

## 2023年度当初予算・歳出

2024年度の当初予算と同じ様式（予算事項別明細書、`continued_pages`）なので、2024年度の宣言を写して頁の範囲だけを2023年度の冊に合わせた。説明欄に「岩戸北三・四丁目」のように「目」を含む語がある頁（物理229）が、見出しを持つ頁と読まれて続きの頁にならなかった。見出しの「目」は枠の左の4分の1でだけ探すよう、共通の `continued_pages` を直した（2024〜2026年度の当初予算と 133051 の表は変わらない）。

## 歳入（当初 R5〜R8・決算 R7）

当初は歳出と同じ冊の「２．歳入」（予算事項別明細書、`continued_pages`）を、歳出の宣言を写して読む。説明の欄は「歳入の説明」で外し、款・項・目・節で取り込む。範囲は歳出と同じく総括の歳入の頁と明細の頁。

- 続きの頁の頭に、開いている目と節の番号だけを刷り直す（`２.` / `１.`）。節の quirk `repeated_code_at_top` で開いている節として読む（目は題字の繰り返しとして既に読める）。
- R7 は無くした項（新型コロナウイルス感染症対策地方税減収補てん特別交付金）を番号 `０.` で刷り、目も `０.` から始める。文書の quirk `zero_coded_drops` で、目 `0` から始まる項の表も揃った表として款の題字の金額を読む。

R7 決算は決算状況の冊の「（１）歳入」の表（款・項・目・節と予算現額・調定額・収入済額・不納欠損額・収入未済額・備考）で、歳出とは書式が違うので `ruled` の宣言を新しく書いた。備考（還付未済額）は「歳入の説明」で外す。款の和は歳入合計と一致する。R4〜R6 決算（scan）は別に取り込む。
