# 狛江市 132195

## 2024年度決算・歳出

一般会計・特別会計4つ（国民健康保険、後期高齢者医療、介護保険、駐車場事業）・下水道事業会計を取り込む。2025年度は事業別の表で別の読み方をしている。

決算書は1冊の scan（文字層なし）。罫線が薄い灰色なので、OCR の依頼に `rule_dark: 215` を書く。

- 特別会計は一般会計と同じ様式なので、一般会計の読み方（`workflow`）と OCR の依頼をそのまま使う。
- 国民健康保険（物理134）と後期高齢者医療（物理144）の範囲の末尾は白紙で、OCR が止まるので選定の範囲から外した。
- 均等割付の名前で OCR が字を落とした・順を入れ替えた行（`出産育児一時金`・`介護予防サービス等諸費`）は、原画で確かめて `name_corrections` で直す。
- 下水道事業会計は収益費用明細書（物理205-206）と資本的収支明細書の支出（物理207）を別の表にする。頁の分割の継ぎ目で行が落ちたので `page_strips: 1` で読み、金額の欄の見出しを「決算額」に宣言する。節は字下げでなく形（`shape`）で段を決める。名前が2行に折り返し番号が2行の中ほどにある節は、2行目だけが名前に結ばれるので `name_corrections` で直す。どちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py` の `EXCLUDE`）。

## 2023年度・2022年度決算・歳出

2024年度決算と同じ様式なので、2024年度の宣言を写して頁の範囲と OCR の依頼をその年の冊に合わせた。2023年度は一般会計・特別会計4つ・下水道事業会計、2022年度は下水道事業会計が無く一般会計・特別会計4つ。

- 国民健康保険と後期高齢者医療の範囲の末尾は白紙（2023年度は物理132・142、2022年度は物理136・146）で OCR が止まるので、2024年度と同じく選定の範囲から外した。
- 2023年度の下水道事業会計は、収益費用明細書（物理203-204）と資本的収支明細書の支出（物理205）を別の表にする。
- 2022年度の一般会計の備考には `事故繰越` の行があるので、`note_kinds` で金額の注記にする（款・項の項目に数えない）。
- 2023年度の一般会計の物理73頁は金額の頭に罫線を `3` と読むので `amount_corrections` で直す。均等割付の名前で字を落とした行（`出産育児一時金`・`介護予防サービス等諸費` ほか）は、原画で確かめて `name_corrections` で直す。
- 2022年度の名前は `負担金,補助及び交付金` のように読点がカンマで印字されているので、そのまま取り込む。

## 2020・2021年度決算・歳出（一般会計、歳出事項別明細）

選定先は事業別の歳出事項別明細（文字PDF、2021年度219頁・2020年度216頁、単位千円）で、2025年度決算と同じ様式なので2025年度の宣言を写した。特別会計の明細は掲載が無い。冊に歳出合計の印字が無いので、款の決算額の和が財源内訳（一般財源・国・都・地方債・その他）の和と一致することで確かめた（2021年度 33,282,004千円、2020年度 38,899,366千円）。ノード/金額は 2021年度 5,564/9,026、2020年度 5,460/8,950。

- 字間を空けて印字した名前の最後の長音（`シ ル バ ー`・`セ ン タ ー`）は、字の間隔のまま置かれているので名前の字として読む（共通の `tree.py`）。
- 主管課だけで名前の無い事業（2020年度 物理88頁 `子ども発達支援課`）は、主管課が縦に1語で読まれる。字ごとに行を分けて、2行目の財源（都 23,325）を事業に結ぶ（quirk `rows_from`）。
- 節説明の単価（`12,300円×延 8人`）は Poppler が `12,30` と `0円×延` に割るので、単価として桁の網羅から外す（共通の `coverage_checks.py`）。

## 2023年度当初予算・歳出

2024年度の当初予算と同じ様式（予算事項別明細書、`continued_pages`）なので、2024年度の宣言を写して頁の範囲だけを2023年度の冊に合わせた。説明欄に「岩戸北三・四丁目」のように「目」を含む語がある頁（物理229）が、見出しを持つ頁と読まれて続きの頁にならなかった。見出しの「目」は枠の左の4分の1でだけ探すよう、共通の `continued_pages` を直した（2024〜2026年度の当初予算と 133051 の表は変わらない）。

## 歳入（当初 R5〜R8・決算 R2〜R7）

当初は歳出と同じ冊の「２．歳入」（予算事項別明細書、`continued_pages`）を、歳出の宣言を写して読む。説明の欄は「歳入の説明」で外し、款・項・目・節で取り込む。範囲は歳出と同じく総括の歳入の頁と明細の頁。

- 続きの頁の頭に、開いている目と節の番号だけを刷り直す（`２.` / `１.`）。節の quirk `repeated_code_at_top` で開いている節として読む（目は題字の繰り返しとして既に読める）。
- R7 は無くした項（新型コロナウイルス感染症対策地方税減収補てん特別交付金）を番号 `０.` で刷り、目も `０.` から始める。文書の quirk `zero_coded_drops` で、目 `0` から始まる項の表も揃った表として款の題字の金額を読む。

R7 決算は決算状況の冊の「（１）歳入」の表（款・項・目・節と予算現額・調定額・収入済額・不納欠損額・収入未済額・備考）で、歳出とは書式が違うので `ruled` の宣言を新しく書いた。備考（還付未済額）は「歳入の説明」で外す。款の和は歳入合計と一致する。

### 特別会計の当初（R6〜R8）

国保・後期高齢者医療・介護（R6・R7 は駐車場事業も）の歳入は、一般会計の歳入の宣言に各会計の歳出の宣言の欄（`区分` を節の欄、駐車場の `比較` を金額）と quirk を足して、特別会計の冊の歳入の頁で読む（表 `<会計>-initial`）。款の和は印字の歳入合計と全部一致した（例: R8 国保 7,442,145千円・介護 8,074,679千円・後期 2,678,801千円）。

- R7 介護は無くした目を番号 `０.` で刷り、その行の節の欄に番号 `１.` だけを刷る（物理57）。文書の quirk `zero_codes` と、節の新しい opt-in quirk `bare_code_under_dropped`（目 `0` の行の名前の無い番号を項目にしない、共通の `tree.py`）で読む。
- 目の名前が2行に折り返し、すぐ下に項の `計` の行がある目（介護 `その他一般会計繰入金`、R8 国保 `子ども・子育て支援事業費補助金`）は、テキスト層が `計` を名前に繋ぐので `name_corrections` で直す。一般会計の当初（R6〜R8 の `衛生費都負担金計` ほか、R8 物理29 `衛生費国庫補助金国庫補助金国庫補助金計`）にも同じ読みが残っている。

### 決算（scan、R2〜R6）

R4〜R6 は歳出と同じ決算書の冊（scan）の歳入の表を、一般会計と特別会計4つ（国保・後期・介護・駐車場）で読む。下水道事業会計（公営企業）は取らない。R2・R3 は決算状況の冊の「一般会計歳入歳出（事項別）決算状況（1）歳入」（scan、19頁）で、一般会計だけ。どれも R7 決算と同じ書式なので R7 の `ruled` の宣言を写し、罫線が薄いので OCR に `rule_dark: 215` を書く。款の和は全表で印字の歳入合計と一致した（例: 一般会計 R6 37,938,115,793円・R5 36,477,127,029円・R4 37,233,795,457円・R3 35,843,010,777円・R2 40,631,900,151円）。

- 頁を縦2つに分けて読む既定では継ぎ目が節の欄の見出しにかかり、`節` を `食` と読む。重ねを広げると名前を2度読む（`現年課税分三課税分`）ので、`page_strips: 3` で読む（継ぎ目は約281pt と561pt）。
- 3分割の継ぎ目で見出しの字の切れ端を2度読むので、見出しの帯の中で別の見出しの箱に入る短い読みを `dropped_readings` で捨てる（ID `<表>-seam-…`）。
- Paddle が `繰入`・`雑入`・`諸収入` の `入` を `人`、`橋りょう` を `橋りよう`、`コロナ` を `コ口ナ`、長音を `一`、`売` を `壳`、`資産` を `资产` と読む行は、原画で確かめて `name_corrections` で直す（ID `<表>-kana-…` ほか）。
- 歳入合計の行の調定額は2つ目の継ぎ目にかかり、末尾の字を2度読んだ箱が収入済額の欄に入る（R4・R6・R3）。読みを `dropped_readings` で捨て、`amount_readings` で印字の位置に読む（箱の右端は収入済額の箱から 1pt より離す。離れていないと単位の検査が2つの数を1つに繋ぐ）。R2 は調定額・収入済額とも読まなかったので `amount_readings` で読む。R6・R3 の繰越財源充当額・予算現額の計も継ぎ目で切れたので同じく読む。
- R2 は継ぎ目が繰越財源充当額の欄にかかり、2つの帯が同じ数を読む。文書の quirk `strip_rereads` で片方を捨て、残った左の帯が末尾の `0` を欠いた行（5件）は `amount_corrections` で直す。

## 特別会計の歳出（当初 R6〜R8）

国保・介護・後期高齢者医療（R6・R7 は駐車場事業も）の歳出は、一般会計の当初予算と同じ宣言を各会計の冊（同じ予算事項別明細書）に写して読む（表 `<会計>-initial`）。款の和は印字の歳出合計と全部一致した（例: R8 国保 7,442,145千円・介護 8,074,679千円・後期 2,678,801千円）。

- 範囲の最初は各会計の歳出の総括の頁。議案の表紙から始めると単位の検査が総括を読めない。明細の頁の後ろの給与費明細書・債務負担行為の調書は範囲から外す（`区分` の欄が節の見出しと読まれる）。
- 特別会計の冊は節の見出しを `区分` だけで刷るので、`区分` を節の欄（`axis_header: 節`）と宣言する。駐車場事業の冊は `比較` の欄を `kind: amount` と宣言する。
- R6 国保は無くした項を番号 `０.` で刷り、目も `０.` から始める。歳入と同じ文書の quirk `zero_coded_drops` に加えて、目の番号 `０.` を箇条の印として落とさないよう新しい opt-in quirk `zero_codes` を宣言する。
