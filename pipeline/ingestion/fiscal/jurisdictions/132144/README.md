# 国分寺市 132144

## 2024・2025年度決算・歳出

出典は決算書ではなく、監査委員の「各会計決算及び基金の運用状況審査意見書」の歳入歳出決算年度比較表（款だけ、見開き2頁）。歳入歳出決算書・事項別明細書は有償刊行物でウェブに無い。

- 一般会計・国民健康保険・介護保険・後期高齢者医療の4会計を共有の読み方 `compared_years`（`layouts/compared_years/reading.json`）で読む。
- 特別会計は1頁の上に歳入、下に歳出の表があるので、表は「支出済額」の見出しの下の年度の行で探す。
- 欄は今年度と前年度の2列ずつ。前年度の欄は前年度予算額・前年度決算額・前年度／不用額・前年度／翌年度繰越額とする。不用額の欄の括弧書きは表の注記のとおり翌年度繰越額（外数）。割合の欄は取り込まない。
- 合計の行の見出しは「合計」だけで、単位の確かめ（`歳出合計`）は印字の合計を拾えず、一般会計は桁だけ（`digits`）、特別会計は印字の合計も桁も確かめない（`unchecked`）。支出済額の款の和は、選定に書いた各会計の合計と一致する（2026-11-10 確認）。各行で 予算現額 = 支出済額 + 不用額 + 翌年度繰越額 を変換時に確かめる。

下水道事業会計（「下水道事業会計決算審査意見書」の予算及び決算の状況、収益的支出・資本的支出）はまだ取り込んでいない。同じ頁に収入の表があり、区分・予算額・決算額・不用額・執行率・前年度比較の別の書式なので、今の読み方では読めない。

## 特別会計・歳出（当初 R6〜R8、2026-11-17）

国民健康保険・介護保険・後期高齢者医療を、同じ年度の一般会計の宣言（scan の見開き、`running_titles`）を写して読む。款・項に金額を刷らない様式なので木の検査は目の欠けを見ない。各年度の末端の目の本年度予算額を翌年度の前年度予算額と突き合わせ、R6→R7・R7→R8 とも3会計で一致することを確かめた（R6 国保は当初 29億円ほどの目が欠けたまま検査を通っていた）。

- 1頁に2〜3つの表を重ねて刷り、傾いた scan で罫の端が淡い。quirk `skewed_frames`・`skewed_cell_rows` を宣言し、`rules.dark` は表ごとに 180（R8 後期だけ 230）。
- 共通の変換（`running_titles`・`skewed_frames`、`rules.skewed` のときだけ）を直した: 列の罫が表の下の罫を数 pt 越えても届くとみなす、左右の両端が淡い罫・最後の列の手前で切れた罫も表の幅の罫とする、段になって読まれた傾いた閉じ罫（R8 後期 p18）を1本の罫として枠を閉じる。一般会計の表は金額が変わらず、金額の枠の右端が 1pt 未満動くだけ（R5〜R8 で確認）。
- 重ねた表の2つ目の見出し「目」が名前だけの科目になる読み、3段の金額の升（本年度・前年度・比較）を1語に読んだ読み（`011`・`110`）、金額の右の罫に切られた桁は `dropped_readings`・`amount_readings` で読み直した（理由は各宣言）。

- 説明の行の頭が OCR の囲みの余白でずれる行は `line_starts`、事業をまとめる見出しは `group_heads` で宣言した。
