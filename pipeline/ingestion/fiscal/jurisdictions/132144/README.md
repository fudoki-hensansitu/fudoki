# 国分寺市 132144

## 2024・2025年度決算・歳出

出典は決算書ではなく、監査委員の「各会計決算及び基金の運用状況審査意見書」の歳入歳出決算年度比較表（款だけ、見開き2頁）。歳入歳出決算書・事項別明細書は有償刊行物でウェブに無い。

- 一般会計・国民健康保険・介護保険・後期高齢者医療の4会計を共有の読み方 `compared_years`（`layouts/compared_years/reading.json`）で読む。
- 特別会計は1頁の上に歳入、下に歳出の表があるので、表は「支出済額」の見出しの下の年度の行で探す。
- 欄は今年度と前年度の2列ずつ。前年度の欄は前年度予算額・前年度決算額・前年度／不用額・前年度／翌年度繰越額とする。不用額の欄の括弧書きは表の注記のとおり翌年度繰越額（外数）。割合の欄は取り込まない。
- 合計の行の見出しは「合計」だけで、単位の確かめ（`歳出合計`）は印字の合計を拾えず、一般会計は桁だけを確かめる。支出済額の款の和は、選定に書いた各会計の合計と一致する（2026-11-10 確認）。各行で 予算現額 = 支出済額 + 不用額 + 翌年度繰越額 を変換時に確かめる。

下水道事業会計（「下水道事業会計決算審査意見書」の予算及び決算の状況、収益的支出・資本的支出）はまだ取り込んでいない。同じ頁に収入の表があり、区分・予算額・決算額・不用額・執行率・前年度比較の別の書式なので、今の読み方では読めない。
