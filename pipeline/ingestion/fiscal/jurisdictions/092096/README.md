# 真岡市（092096）

栃木県真岡市。予算・決算は議会の頁（議案の別冊）、事業評価とプレス発表は市の頁から取る。取り込む年度は R6〜R8 を基本に、同じ様式で続く過去の年度も含める。

| 資料 | 年度 | 様式 |
| --- | --- | --- |
| 決算（歳入歳出決算書の事項別明細書） | R5・R6・R7 | text PDF（`generic_text`） |
| 当初予算（予算に関する説明書の歳出） | R7・R8 | scan PDF（`generic_scan`、Paddle の OCR） |
| 事業評価（事務事業マネージメントシート） | R2〜R6 | text PDF、1事業1ファイル（`ingestion/project/origins.json` の `sheets`） |
| プレス発表（主な新規・拡充事業、継続事業） | R5〜R8 | text PDF（`origins.json` の `press`） |

予算書（予算に関する説明書）は R6 以前を公開していない（会計別予算の概要の表は R2 からあるが、事業の単位の内訳が無い）。プレス発表は R4 以前の様式が違うので取らない。補正予算・予算付表・事業概要報告書は取らない。

## 決算

一般会計と6つの特別会計（国民健康保険・後期高齢者医療・介護保険の保険事業勘定とサービス事業勘定・休日夜間急患診療所・産業団地整備事業）は、各年度1冊の決算書（議案の別冊）に収まっているので、同じ PDF を会計ごとの頁の範囲（選定の scope）で読む。3年度とも同じ読み方で、款の和は各会計の歳出合計と一致する。

- 科目は款・項・目の名前を欄ごとに印字するので subject は `names`。
- 備考は目の額を分ける内訳ではなく注記として残る。分け方は節だけ（seed `fiscal_detail_breakdown`）。

## 当初予算

見開き2頁を1枚の横長の頁に収めたスキャン。左に款・項・目（款と項の番号は細い欄、目は番号と名前を同じ欄）・本年度・前年度・比較・財源内訳、右に節（区分・金額）と説明（事業の名前と金額）を印字する。7会計とも同じ様式なので、読み方（`workflow`）は共通にした。款の和は市の「会計別予算」の総括の額と全会計で一致する。

| 会計 | R8（千円） | R7（千円） |
| --- | ---: | ---: |
| 一般会計 | 39,430,000 | 38,860,000 |
| 国民健康保険 | 8,159,419 | 8,598,453 |
| 後期高齢者医療 | 1,208,507 | 1,071,682 |
| 介護保険（保険事業勘定） | 6,535,078 | 7,080,488 |
| 介護保険（介護サービス事業勘定） | 23,793 | 19,780 |
| 休日夜間急患診療所 | 69,374 | 71,734 |
| 産業団地整備事業 | 1,093,853 | 631,886 |

- **財源内訳**: OCR が見出しを「本年度の財源内／訳」「本年度の財源／内訳」とも読むので、見出しの読み方ごとに `excluded` を並べる。
- **説明**: 目の額を事業ごとに分ける（`position`）。分け方は節と説明（事業）。
- **款の名前の折り返し**: 款の名前は番号と別の欄に印字し、欄の幅で折り返す（「農林水産業／費」）。続きの行が目の名前の位置に来て目の行と読まれるので、続きの読みを `dropped_readings` で除き、1行目の読みに `name_corrections` で続きを足す。
- **説明の頭の「一」**: 「一般管理費」「一時借入金利子」などは OCR が頭の「一」の分だけ名前の始まりを右に置き、上の事業の内訳と読まれる。説明の `line_starts` で名前の始まりを欄の左にそろえる。「一」を読まなかった行は名前も直す。
- **比較の△**: △を左の罫線と1語に読んだ比較は `amount_corrections` で戻す。

## 事業評価

1事業1ファイルの事務事業マネージメントシート。2頁の詳しい版（1次・2次評価つき）と1頁の簡易版がある。科目と金額（総事業費の推移の事業費計の評価対象年度の実績）は詳しい版だけが印字する。R3（2021）年度の1件（J15921）は公開の頁のリンクが 404 で取れない。

## 取り込んでいないもの

水道事業会計・下水道事業会計は、出典の選定には範囲を入れたが取り込んでいない（決算は公営企業の決算書の様式、当初予算は別の冊の様式で、読み方を別に書く必要がある）。#575 で扱う。
