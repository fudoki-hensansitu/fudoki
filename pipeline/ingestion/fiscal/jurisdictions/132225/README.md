# 東久留米市 132225

## 2023年度当初予算・歳出（R5、一般会計、2026-11-16）

R5 の予算書は文字 PDF なので、2026年度の文字の宣言を移して読む（2024年度は scan）。5,771ノード/6,019金額、款の和 45,656,000 千円は印字の歳出合計と一致する。

- 説明欄で、事業の下に所管課の見出し（`(秘書広報課) 665`）を印字し、続く行の金額の和を見出しの金額とする箇所がある。見出しは行と同じ位置から始まるので、`group_heads` で16箇所を宣言した。

## 2023年度決算・歳出（4会計）

2024 年度の宣言を移して読む。備考の長い名前の下に、桁区切りの無い3桁の金額だけを欄の右に印字する行がある（`新型コロナウイルス感染症対策用消耗品費` / `962`、p86）。番号だけの行として読まれ、名前の無い項目になっていたので、欄の右半分に1つだけ立つ数字は番号でなく前の名前の金額として読むよう共通の読み方を直した。

## 歳入（当初 R5〜R8・決算 R5〜R7）

当初は一般会計の冊の総括の歳入（物理2–3）と「２ 歳入」の事項別明細（物理6から歳出の明細の前まで）を、歳出の宣言（`running_titles`）を写して読む。説明は「歳入の説明」で外す。R6 は scan なので、歳入の頁を OCR に依頼して読んだ（歳出と同じ依頼の設定）。総括の款と明細の款が2重に根になるのは歳出と同じ。

- R8 は年度で無くした項を番号を刷らずに `項 地方道路譲与税` と題字に印字し、その目も番号が無い。題字として読まれず、上の款の題字の名前に続いて2つ目の款2になっていたので、opt-in の quirk `unnumbered_titles` で番号の無い題字も題字として読む。
- 決算の選定は会計別の歳出事項別明細書だけだったので、同じ頁に掲載の歳入事項別明細書（4会計、文字 PDF）を選定に足した。歳出の宣言を写し、備考（還付未済額など）を「歳入の説明」で外す。特別会計の節は字下げでなく形（`shape`）で段を決める（字下げで読むと節の下に細節ができた）。

款の和はどの表も印字の歳入合計と一致する（当初 R5 45,656,000・R6 47,821,000・R7 50,760,000・R8 54,022,000 千円、決算の一般会計の収入済額 R7 54,519,431,858 円ほか）。
