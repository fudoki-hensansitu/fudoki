# 江東区 131083

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険会計、介護保険会計、後期高齢者医療会計）を取り込む。

決算書は scan で、一般会計が1冊、特別会計3つが別の1冊。見開きを物理2頁に分けて印字する。左頁に科目（款・項・目）・予算現額・節の区分と金額、右頁に支出済額・翌年度繰越額（継続費逓次繰越・繰越明許費・事故繰越）・不用額・備考がある。4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 85–195 | 1,198 | 7,652 | 261,954,790,490 |
| 国民健康保険会計 | 31–53 | 135 | 1,077 | 46,425,688,509 |
| 介護保険会計 | 85–107 | 132 | 1,008 | 39,161,165,053 |
| 後期高齢者医療会計 | 133–145 | 56 | 443 | 12,751,736,946 |

- **見出し**: 予算現額の「予備費支出及び流用増減額」の升は3行に分けて印字していて、OCR が上の行に「子」を足して読む（「予備費子支出及び流用増減額」）。見出しの辞書に無い語は予算現額に寄せられ、補正後の予算が流用の額に置き換わっていた。罫線の位置はどの左頁も同じなので、升の見出しを `header_readings` で宣言した。共有の見出し辞書の語（`予算現額／予備費支出及び流用増減`）に揃えて、末尾の「額」は外している。辞書に語を足すと、保存済みのすべての表の fingerprint が変わるため。右頁の「不用額」も、字を重ねて読む頁（「不用用額」）があるので宣言した。
- **節**: 節はすべて1段で、字詰めの名前（「13 使用料及び賃借料」）は名前の書き出しが左に寄る。この字下げで、次の節がその子に読まれていた。そこで `marks` で番号のある行を1段にした（`{"1": 1}`）。2行に折り返した節（「負担金補助及び交／18付金」）は、`name_column` で番号の行と上の行を結ぶ。
- **2行・3行に折り返した科目**: 番号は2行目の頭に印字する。OCR は行をまたいで字を縦に組んで読むことがあり（「高費」「障文」など）、名前が崩れて番号と別の科目に分かれた。番号と名前は墨の位置で `code_readings` に宣言し、升の中の行ごとの読みは `dropped_readings` で除いた。番号と科目の位置が正しく読めていて名前だけ崩れた科目は、`name_corrections` で名前を直した。国民健康保険の款「3 国民健康保険事業費納付金」は、2行目頭の番号と「費」を「32」と読んでいたので、番号も直した。
- **帯の継ぎ目**: Paddle は頁を縦の帯に分けて読み、継ぎ目にかかる欄を両方の帯で読む。頁88・89・91・94・99・141 では、片方の帯の切れた読みが隣の全桁の読みとつながり、1つの額になった（「1,9801,980,950」など）。切れた側の読みを `dropped_readings` で除いた。頁188、国民健康保険の頁48、介護保険の頁90・102 は、見出しの継ぎ目に読み残しが出た。この4頁だけ OCR の依頼を分け、`page_strips: 1` で読み直した。
- **負の額**: 原典は負の額を頭のマイナス記号で印字する（「−617,053,000」）。頁118の項「2 高齢者福祉費」では、OCR がこの記号を読まなかった。頁164の項「5 都市整備費」では、ダッシュ（–）と読んだため負の印として扱われなかった。どちらも、当初予算額から引くと計の額になることを確かめた。読みは除き、`amount_readings` で欄の額を宣言した。
- **名前の読み違い**: 字形の近い字（「務」→「务」、「土」→「十」、「予」→「了」、「入」→「人」、「負」→「负」など）を、`name_corrections` で直した。
- **COFOG**: 既存の規則に当たらない目が2つあった。衛生費の「医務費」と「障害者自立支援医療費等給付費」で、`cofog_rules.csv` の `koto-2024-01`・`koto-2024-02` で名称から仮に保健（07）に分類した（`tentative`）。

## 2024〜2026年度当初予算・歳出

一般会計・特別会計3つ（国民健康保険会計、介護保険会計、後期高齢者医療会計）を取り込む。

予算説明書は text で、一般会計が1冊、特別会計3つが別の1冊。見開きを物理2頁に分けて印字する。左頁に科目（款・項・目）・本年度・前年度・比較増(△)減・本年度の財源内訳・節の区分と金額、右頁に説明がある。3年度・4会計とも同じ様式なので、読み方は共有の reading `facing_explanations`（`workflow_text`）と1つの profile（`layouts/text_budget/reading.json`）にした。2024年度の冊は頁にトンボがあり枠の位置がずれるので、欄の位置は枠の左の罫線からの距離で宣言している。

印字の歳出合計は各冊の総括（歳出合計の行）の値。明細の頁には歳出合計の行が無いので、単位の検査は一般会計が桁の確かめ（`digits`）、特別会計は `unchecked` になる。

- **見えない複製**: 全頁の文字を、見えない複製と一緒に描いている（約19pt横。2026・2025年度は描画で墨が出ない複製、2024年度は文字の切り抜きの外に描いた複製）。見開きを1つの描画にして左右の頁で半分ずつ見せる作りで、左頁は1つ目、右頁は2つ目の文字が見える。共有の観測は語の多い頁でしか複製を落とさず、語の少ない続きの頁では見出しが「節節」と二重になるので、reading の中で文字の単位で複製を落とし、頁の語を組み直した（落とした文字の数は `reading.json` の report に頁ごとに残る）。欄の罫線の上に置かれた見えない区切り（「40,663,133」の後ろの「,」）も金額から外した。
- **科目**: 款・項・目はそれぞれ自分の行に金額を印字する。番号の書き出しの欄（款・項・目の階段）で段を決めた。本年度の金額が無い目は番号の代わりに「△」を印字する（2026年度の「△物価高騰重点支援給付金費」「△幼稚園施設建設費」など）。番号の無い目として取り込み、名前から「△」を外した。印字の見出し「本年度」「前年度」「比較増(△)減」は、共有辞書の「本年度予算額」「前年度予算額」「比較」とした。
- **続きの頁**: 頁をまたぐ目は、次の左頁の頭に名前を番号なしで、折り返して印字する（「社会福祉」／「総務費」）。行をつないで開いている目の名前と一致するものを再掲として扱い、その頁の説明を同じ目に続けた。
- **財源内訳**: 科目の行ごとに財源の名前と金額を印字する。本年度の金額の別の切り口なので取り込まず、網羅の検査では `財源内訳` の除外にした。
- **説明**: 右頁の行は左頁の行と同じ高さにあり、行の高さで目に結んだ。項目は字下げと印で読む。施策（4桁の番号、金額なし）、事業（番号と右端の金額）、施設などの内訳（「(1)塩浜福祉園」と右端の金額）、「・」の項目（右端の金額）の順に入れ子にした。事業は施策が無ければ目の直下に置く。人数・回数などの文中の数は `数量表`・`本文` の除外にした。「（選挙執行内訳）」の下の行は上の事業の金額を選挙ごとに分けた別の切り口なので取り込まず、`経費内訳` の除外にした。
- **扉頁**: 枠の無い頁は、`(3) 歳出` の扉（profile の `divider_text`）だけを読み飛ばし、ほかは止める。
