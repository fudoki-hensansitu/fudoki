# 稲城市 132250

## 2024〜2026年度当初予算・歳出（特別会計4つ）

国民健康保険事業・土地区画整理事業・介護保険・後期高齢者医療の特別会計を、各年度の特別会計予算書から会計ごとに読む。一般会計と同じ読み方（`workflow`）を写した。

- 選定の範囲の頭にある総括の款の表は明細の款と2度数えるので、明細の頁だけを `pages` で読む。
- 予算書は款・項に、説明の下に款・項ごとの `計` を印字する。この `計` は会計の歳出合計ではないので、単位の検査は款・項・目の行が自分で印字する額と同じ `計` をその節を閉じる行として扱う（共通の `units.py`）。
- 説明の所管課の行（`(保険年金課)` など）は `marks` で所管課として読む。

## 2023年度当初予算・歳出（一般会計）

2024 年度の宣言を移して読む。頁の頭に、前の頁の節の内訳で金額を印字しない行（`発達支援センター分室整備工事`、p90）があり、罫で区切られた同じ枠の下の事業（`8 重症心身障害児（者）等通所施設開設準備経費`）の名前の1行目として読まれていた。番号の行の上に空き行を挟んで立つ行は、その番号の名前の折り返しではないと共通の読み方を直した。説明の積算の注記（`年額13,000円` など2か所）は `excluded_boxes` で外す。

## 2023年度決算・歳出（5会計）

2024 年度の宣言を移して読む。翌年度繰越額の種類（`明許`）を金額のすぐ右に印字し、文字層では支出済額の数字と1語になる（`150,080` `,868明許`）。`split_at_rules` で欄の罫のところで切り、`carry_kind_words` で繰越明許費として読む（`split_at_rules` は語の頭が桁区切りの `,` でも切るよう直した）。網羅の検査も、計の行で `明許` が付いた語の数字を計として確かめる。土地区画整理事業特別会計は節の細節（`１消耗品費`）の番号が節の番号から 6.7pt しか右に無いので、番号の位置を字の幅で測る（`indent_chars: 1`）。

## 歳入（当初 R5〜R8・決算 R5〜R7、2026-11-17）

一般会計と特別会計4つを、歳出と同じ冊・同じ宣言で読む。範囲は選定の歳入の範囲（総括と歳入の明細）。説明・備考の欄は「歳入の説明」で外し、款・項・目・節で取り込む。下水道事業会計・病院事業会計は取り込まない。R5 当初の特別会計は歳出をまだ取り込んでいないが、歳入は一般会計の宣言で読める。

- 当初はこの年に無くした款・項・目を番号なしで刷り（`0 1 △1`）、名前を2行に折り返す。`unnumbered_abolished_names` で折り返しを1つの名前にし、`unnumbered_names_at_rule` で名前が次の欄の罫から始まる項を1段浅く読む。
- R7 の国民健康保険事業は無くした款「財産収入」の題字を `第　款 財産収入` と番号なしで刷るので、`unnumbered_titles` で番号の無い款の題字として読む（題字を読む `Layout.Logical.titles` にこの quirk の読み方を足した）。これが無いと、その項・目が前の款（諸収入）の下に付いていた。
