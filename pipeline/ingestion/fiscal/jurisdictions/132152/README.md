## 歳入 2023〜2026年度当初予算・2023〜2024年度決算（文字 PDF、2026-11-17）

歳出と同じ予算書・決算書の歳入の事項別明細書を、歳出の宣言を写して読む（`revenue.json`、歳入の頁は選定の scope）。当初予算は歳出と同じく一般会計だけ。決算は一般会計と国保・介護・後期高齢の3特別会計。

- 予算書の説明の欄・決算書の備考の欄は `歳入の説明` として除外し、款・項・目・節で取り込む
- 予算書の金額の欄 `本年度予算額(前年度予算額)(比較増減)` は歳出だけの宣言なので、歳入の宣言から外した
- 決算書の節は、長い名前を番号の行の上に1行で印字することがある（`戸籍住民基本台帳費委託` の下に `3.` `金`）。quirk `name_over_code_line` で、番号の行の直前の名前だけの行を、番号の縦の範囲に下端が入るときにその節の名前の頭にする。これが無いと `3 金` という節ができ、次の頁の節が細節になる
- 2025年度当初は歳入合計を物理28頁にだけ印字するので、頁は16〜27とし、単位は `digits`。ほかの11表は `matched`
- 2025年度決算は scan の資料で、この節には含めない
