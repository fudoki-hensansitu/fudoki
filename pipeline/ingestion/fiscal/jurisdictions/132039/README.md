## 当初予算・一般会計・歳出（2024〜2026年度）

一般会計歳出説明書（R6-04・R7-04・R8-04、文字PDF、見開きで1物理頁）を共通の `generic_text` で読む（2026-11-11）。表は各年度1つ（`general-initial`）。

- 款・項は枠の上に `１款 議会費　１項 議会費` と1行で印字され、継続頁でも繰り返す。`running_titles` が款・項の題字として読む。題字に金額は無い。
- 明細の冊は款の額と歳出合計を印字しない。項の額は項の末尾の `計` の行にだけあり、合計の行として扱われて項のノードの金額にはならない。款の額と歳出合計は総括（R?-02、1頁）にあるが、選定に含めていない別の冊なので、表は `partial: true` にした（単位の確かめは報告だけ）。目の本年度予算額の和は 81,523,000・88,028,000・94,227,000 千円（2024・2025・2026年度）で、総括（R6-02・R7-02・R8-02、2026-11-11 に市の掲載頁から取得して確認）の歳出合計と一致する。総括の冊を選定に足せば、款の額と歳出合計を別の表として持てる。
- 欄は `目`・本年度予算額・前年度予算額・比較・財源内訳4欄・`節`（区分・金額・節の説明）・`説明`。節の説明（`議員報酬 170,460` など）は欄が左右2つに分かれ、全頁で読むと金額の欄と判定されるので `columns` で `節／節の説明` を名前の欄と宣言した。節の説明は節の区分の行の高さに印字されるので、軸の癖 `under: 区分` で同じ罫の行の節の下に付けた。説明の名前が折り返して金額だけを次の行に印字する内訳がある（`bare_amounts`）。
- 2026年度 p101 は、上の表が見出しと `計` の行だけで閉じ、同じ頁の下に次の項の題字と見出しを印字する。右頁（節の説明・説明の枠）は上の表に数字が無く、見出しの下端を探すと2つ目の見出しの下まで延び、2つの見出しが1つに読まれた（`節／区分／節／区分`）。見出しは罫で囲まれた1行なので、文書の癖 `one_row_header` で枠の上端から最初の横罫までを見出しとした。
- ノード/金額は 7,098/7,689・7,263/7,854・7,069/7,660（2024・2025・2026年度）、木は一致 1,079・1,088・1,074（不一致 0）。Jev の聞き直しは各年度の `expenditure.digit-recheck.jsonl` から再現する。2026-11-11 に R2 へ保存した。#523 で opt-in になった判定に頼っていたので、保存済みの表と中身が同じになる quirks（`names_in_own_column` ほか）を選んでいる。
