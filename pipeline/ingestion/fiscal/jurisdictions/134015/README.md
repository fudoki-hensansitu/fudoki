# 八丈町（134015）

2025決算・歳出の一般会計と介護保険特別会計を `generic_text` で取り込む。対象頁は出典選定の scope から読む。宣言と保存参照は `2025/settlement/expenditure.json` に置く。

介護保険の頁をまたぐ科目名4か所（特例施設介護サービス給付費、財政安定化基金拠出金、介護予防・日常生活支援総合事業費、介護予防普及啓発事業費）を共通規則で結ぶ。ノード160→155件、金額851件は変化なし。名称の続きの行に属していた枝の親を訂正し、名称の印字位置は最初の頁を保持する。

2026-10-14にcoordinatorが再保存を承認した。一般会計は1,189ノード・5,063金額とも内容同一だが、両会計の指紋をそろえるため正規の手順で一緒に再保存する。

## 当初予算・歳出（2024〜2026）

当初予算書の介護保険特別会計と国民健康保険特別会計を `generic_text` で取り込む。宣言と保存参照は `<年度>/initial/expenditure.json` に置く。

- 2025 は前年度にだけあった目（国保の退職被保険者等の目・介護の総務費の目）が印字されず、項・款の前年度と比較の欄が子の和と合わない。本年度の欄は一致する。印字値は書き換えず、`2025/initial/expenditure.layout.json` の `source_inconsistencies` で宣言した。
- 一般会計（2025・2026）は罫線の表として読み、説明欄の金額の無い見出しの下の字下げした項目を見出しの子、節を字下げで1段下げる読み方を宣言して取り込む。前年度にだけあった目（選挙費、2026 は社会福祉費の下も）が印字されず、項の前年度と比較の欄が子の和と合わないので、同じく `source_inconsistencies` で宣言した。
- 一般会計（2024）は組版が違い、欄の見出しが節の最初の頁にしか印字されず、続きの頁は罫線だけが同じ。款・項・目の欄は款・項・目が始まる行にだけ横罫を引き、表の上下を閉じる罫も無い。`header.carried`（見出しの無い枠に、同じ縦罫の前の枠の見出しを引き継ぐ）と `header.open_frame`（枠を縦罫の両端まで取る）で読む。節は番号を名前の上の行に、金額を名前の行に印字するので、節の quirk `name_line` で、目の行に印字された最初の節の金額をその節に付ける。項「農林業費」の財源内訳は、項の行と目の和で一般財源とその他が 264 千円ずつ入れ替わって印字されているので、`2024/initial/expenditure.layout.json` で宣言した。
- 後期高齢者医療は予備費の財源の欄、公営企業会計4会計は収益の頁の混入や備考の金額の網羅で止まる。いずれも未保存。

## 2023年度当初予算・歳出

一般会計・介護保険・国民健康保険を取り込む。一般会計と介護保険は文字 PDF で、2024年度と同じ様式なので 2024年度の読み方を `generic_text` のまま使う。国民健康保険は scan で、2024年度の文字 PDF と同じ欄の並びを `generic_scan` で読む。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 40–122 | 2,970 | 3,602 | 11,537,432 |
| 介護保険 | 17–27 | 245 | 511 | 1,104,674 |
| 国民健康保険（scan） | 17–26 | 212 | 352 | 1,125,916 |

- **傾いた scan**: 国民健康保険の頁は少し傾いて刷られ、横の罫が切れて読まれるので `rules.skewed` にし、罫の切れ端を `rule_ink` で墨から除く。偶数頁は奇数頁より 16〜18pt 右に印字されるので、字下げの段を頁ごとにずらさないよう `shifted_pages` で頁の枠の左端を最初の頁に揃える（印字の位置は元のまま）。目の欄の見出しの下の罫のように、傾いて1画素の行に収まらない短い罫と、2つに切れて読まれた縦罫に挟まれた升の罫は `skewed_cell_rows` で読む（共通の opt-in の処理）。
- **見出し**: 科目の款・項・目の升は罫が見出しまで届かない頁があるので `header.staircase` で升を分け、見出しの読みが隣の升と1語になる頁（「本年度前年度」「国都支出金地方債その他」「科目」と「款項目」が1つ）は `header_readings` で升ごとに宣言する。款と項の間の罫だけ見出しまで届く頁（物理21頁）の「項目」も、款・項・目の升として読む（共通の処理）。頁をまたいで見出しを揃えると宣言が他の頁の見出しに置き換わるので `header.unagreed` にした。
- **財源内訳**: 見出しの升を分ける罫が頁ごとに違って読まれ、欄の見出しが揃わないので、財源内訳の4欄は取り込まない（`excluded`）。2024年度の文字 PDF の版は財源内訳も金額として取り込んでいるので、2024年度より金額の数が少ない。
- **読みの除き・直し**: 罫の切れ端を数字に読んだもの（物理17頁の「1」、物理25頁の「--」）と、物理20頁の見出しの「科目」の字を `dropped_readings` で除き、物理22頁の財源内訳の「.8,400」の点を `amount_corrections` で除いた。比較の欄は △ の額を読めずラベルの欄に分けられるので、`columns` で金額の欄に宣言した。
- **節**: 番号と名前が1語に読まれた節（「10需用費」）が前の節の子に読まれないよう、節の番号のある行を1段にした（`marks`）。
