# 小笠原村（134210）

## 当初予算・歳出（2024〜2026）

当初予算書の一般会計と特別会計5つ（国民健康保険、宅地造成事業、介護保険（保険事業勘定）、介護保険（介護サービス事業勘定）、後期高齢者医療）を `generic_text` で取り込む。宣言と保存参照は `<年度>/initial/expenditure.json` に置く。18表とも款の和は歳出合計の印字と一致し、木の検査に不一致は無い。

- **読む頁**: 出典選定の scope は款項の総括の頁と款別の総括の頁を含む。総括は明細の款・項を重ねて数えるので、各会計の `pages` で明細の頁だけを読む。
- **文字の位置**: PDF がフォントを埋め込んでおらず、文字の箱が印字より広い。数字の右端は欄の罫線を 2〜4.5pt はみ出す。
- **款・項・目**: 見出しは款・項・目の階段だが、本文の款・項・目の欄は1つの欄で、番号を右寄せにして `1.議会費` のように点で区切る。科目は `indent` で読み、文書の quirk `digit_set_codes`（1桁の幅 5pt）で2桁の番号を1桁の番号の始まりの位置として読む。その年にやめた款・項・目は番号の代わりに `×` を印字するので、名前の始まりから段を決める。
- **本年度の欄**: 財源内訳の欄（国都支出金・地方債・その他・特定財源）は目の財源額の下に財源の名前と額が欄をまたいで複数行で印字され、目の財源額と1対1に組めないので取り込まない（`excluded`、数字のはみ出しは `overhang` 5pt）。「本年度」の見出しが財源内訳の見出しの文字に含まれ、除外の宣言に当たってしまうため、`本年度` を金額の欄と明示する。
- **見出しの高さ**: 前の頁の説明の続きだけを印字した行（数字の無い行）が見出しの下に続く頁がある。`header.carried` で、同じ縦罫の前の枠と同じ高さで見出しを終える。
- **節**: 続きの頁の先頭に、開いている節を番号・名前・金額ごと印字し直す（2025 の その他基金費の積立金）。節の quirk `repeated_at_top` で開いている節として読む。
- **説明**: 番号の無い行に印字した小さい金額（`121`）は上の行の金額として読む（`bare_amounts`）。右寄せの2桁の番号が1つ上の段の1桁の番号と同じ位置から始まる箇所（2024・2025 の その他基金費）と、2段目が1段目より 4.5pt だけ右の箇所（宅地造成事業 2024・2025 の業務管理費）は、`line_starts` で同じ段の位置へ寄せる。
- **未取り込み**: 簡易水道事業会計と生活排水処理事業会計は公営企業会計の予算書（収益的・資本的収支）で、款・項・目の歳出明細ではないので取り込まない。
