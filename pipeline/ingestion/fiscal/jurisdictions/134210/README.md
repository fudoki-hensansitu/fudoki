# 小笠原村（134210）

## 当初予算・歳出（2024〜2026）

当初予算書の一般会計と特別会計5つ（国民健康保険、宅地造成事業、介護保険（保険事業勘定）、介護保険（介護サービス事業勘定）、後期高齢者医療）を `generic_text` で取り込む。宣言と保存参照は `<年度>/initial/expenditure.json` に置く。18表とも款の和は歳出合計の印字と一致し、木の検査に不一致は無い。

- **読む頁**: 出典選定の scope は款項の総括の頁と款別の総括の頁を含む。総括は明細の款・項を重ねて数えるので、各会計の `pages` で明細の頁だけを読む。
- **文字の位置**: PDF がフォントを埋め込んでおらず、文字の箱が印字より広い。数字の右端は欄の罫線を 2〜4.5pt はみ出す。
- **款・項・目**: 見出しは款・項・目の階段だが、本文の款・項・目の欄は1つの欄で、番号を右寄せにして `1.議会費` のように点で区切る。科目は `indent` で読み、文書の quirk `digit_set_codes`（1桁の幅 5pt）で2桁の番号を1桁の番号の始まりの位置として読む。その年にやめた款・項・目は番号の代わりに `×` を印字するので、名前の始まりから段を決める。
- **本年度の欄**: 財源内訳の欄（国都支出金・地方債・その他・特定財源）は目の財源額の下に財源の名前と額が欄をまたいで複数行で印字され、目の財源額と1対1に組めないので取り込まない（`excluded`、数字のはみ出しは `overhang` 5pt）。「本年度」の見出しが財源内訳の見出しの文字に含まれ、除外の宣言に当たってしまうため、`本年度` を金額の欄と明示する。
- **見出しの高さ**: 前の頁の説明の続きだけを印字した行（数字の無い行）が見出しの下に続く頁がある。`header.carried` で、同じ縦罫の前の枠と同じ高さで見出しを終える。
- **節**: 続きの頁の先頭に、開いている節を番号・名前・金額ごと印字し直す（2025 の その他基金費の積立金）。節の quirk `repeated_at_top` で開いている節として読む。
- **説明**: 番号の無い行に印字した小さい金額（`121`）は上の行の金額として読む（`bare_amounts`）。右寄せの2桁の番号が1つ上の段の1桁の番号と同じ位置から始まる箇所（2024・2025 の その他基金費）と、2段目が1段目より 4.5pt だけ右の箇所（宅地造成事業 2024・2025 の業務管理費）は、`line_starts` で同じ段の位置へ寄せる。
- **未取り込み**: 簡易水道事業会計と生活排水処理事業会計は公営企業会計の予算書（収益的・資本的収支）で、款・項・目の歳出明細ではないので取り込まない。

## 2023年度当初予算・歳出（scan）

2023年度の当初予算書は1冊の scan（文字層なし）。2024〜2026年度と同じ様式で、一般会計と特別会計5つを `generic_scan` で読む。文字 PDF の年度の読み方は OCR では成り立たないところがあるので、次のように変えている。

- **款・項・目**: 1つの欄に入れ子の枠を描き、項の枠は款の、目の枠は項の数 pt 右から始まる。OCR の行の箱は印字から 2pt ほどずれ、款と項の名前の始まりも 2pt しか違わないので、字下げでは段が読めない。文書の quirk `nested_subject_boxes` が、欄の語をそれを囲む一番内側の枠の左罫の位置から始まるものとして読む（`digit_set_codes` は使わない）。1行だけの項・目の枠の縦罫は短く、頁全体の検出から漏れるので、`rules.short_columns` で拾う。罫線が薄いので `rules.dark: 200`。
- **見出し**: 一部の頁（物理40・60・78・88）は見出しの「目」の升の罫が読めず「項目」が1つの升になる。`columns` の `款／項目` を目の欄と宣言して、右頁と見開きにつなぐ。
- **節**: 番号は右寄せで2桁の番号が5pt 左から始まるが、節に段は無いので `flat` で読む。
- **説明**: 段ごとに金額の右端が違う（事業 562pt、その下 538pt）ので `amount_ends` で段を決める。2行に折り返した名前（`…サービス` / `事業費 2,192`）は `wrap` と `name_start_slack`、行頭が種類の語（`事業費`）でも名前の続きとして quirk `names_end_with_kind_words` で読む。物理89頁の「1 減債基金積立金」の下の同名の行は金額が外の段の右端近くにあるので、文書の quirk `stepped_amount_lines` で、名前が右・金額が左に一段ずれた行を下の段として読む。
- **名前**: 片仮名の長音・小書きの読み違いと、`弹`・`X`（やめた目の `×`）・`口一ス` などを、原画と2024年度の名前で確かめて `name_corrections` で直す。
- **歳出合計**: OCR が「歳」を旧字の「歲」と読むので、単位の検査（`unit_checks`）は「歲出合計」も歳出合計として読む。

## 2023年度決算・歳出（特別会計8件、款の粒度）

出典は村の決算資料。特別会計8件（国民健康保険、簡易水道事業、宅地造成事業、介護保険（保険事業勘定）、介護保険（介護サービス事業勘定）、下水道事業、浄化槽事業、後期高齢者医療）は、各会計の「款別決算対前年度比較表（様式2）」の歳出（千円）を `generic_text` で取り込む。項・目以下の明細は出典に無い。款の支出額の合計は各表の「合計」と一致する。

- 款ごとに「５年度」と「４年度」の2行を印字する。表は本年度のものなので、前年度の行は repair `prior_year_rows` で外す（款の名前は両行にまたがるので残す）。
- 款の番号は印字せず、特別会計ごとに款の並びが違うので、`fiscal_kan_name_identity` で款名を識別に使う。
- 執行率と構成比の欄は金額ではないので取り込まない（`excluded`、数量表）。支出額の欄は `支出済額` として読む。
- 一般会計は表15「歳出款別決算額」（物理17〜18頁、円）。同じ頁に表14（村税）と本文があり、罫線の枠でも分けられないので、layout `titled_table` が題名（`表15`）から表の下の最初の「縦罫の通らない行」までを表として切り出す。18頁は題名が無いので `continued` に挙げる。款は名前だけを印字し（番号なし）、款の和は印字の「合計」と一致する。款の番号は `fiscal_kan_code_fill` で、款名と並びが歳出予算の款の区分と同じ（労働費の5を飛ばす）ことから当てる。
- 頁の先頭の款は前の頁から続く款の見出しの印字し直しではない（`reprints` を外す）。名前が1字違いの款（民生費と衛生費）を同じ款の誤読と見て巻き込まないため。
- 前年度の決算額の欄は `前年度決算額` として読み、比較（増減額・増減率）と主な増減理由の欄は取り込まない（`excluded`）。
