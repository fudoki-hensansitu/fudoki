# 千代田区 131016

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険事業会計、介護保険特別会計、後期高齢者医療特別会計）を取り込む。

決算書は scan で、会計ごとに1冊（一般会計は歳入と歳出が別の冊）。見開きを物理2頁に分けて印字する。左頁に科目（款・項・目）・予算現額・節の区分と金額、右頁に支出済額・翌年度繰越額（継続費逓次繰越・繰越明許費・事故繰越し）・不用額・備考がある。江東区2024と同じ様式で、4会計とも読み方（`workflow`）は共通にした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 1–76 | 731 | 3,338 | 65,973,842,102 |
| 国民健康保険事業会計 | 24–41 | 112 | 680 | 5,964,334,653 |
| 介護保険特別会計 | 26–45 | 125 | 698 | 4,744,116,097 |
| 後期高齢者医療特別会計 | 20–29 | 40 | 244 | 2,147,335,549 |

特別会計の選定の scope は款だけの総括（物理4–5頁）も含むが、総括は斜線の見出し（区分／款）の別の表なので、変換の `pages` で明細の頁だけを読む。OCR も明細の頁だけを依頼した。

- **右頁の欄の縁**: 右頁は支出済額の欄の左に縦の罫線を引かず、行の罫線だけが頁の端から伸びる。欄が罫線で閉じず、支出済額が読まれなかった。都2024と同じ `layout.pattern: open_edge` で、行の罫線の端を欄の縁にした。
- **見出し**: 予算現額の「予備費支出及び流用増減」の升は3行に分けて印字していて、OCR が隣の升の字とつないで読む（「継続費及び予」「流用增减」）。辞書に寄せられない見出しは予算現額になり、この欄の額が補正後の予算に足されていた。罫線の位置はどの左頁も同じなので、升の見出しを `header_readings` で宣言した。
- **折り返した科目**: 2行・3行に折り返した科目名は、番号を行の間の高さに印字する。OCR は名前を行ごとに読み、1行目が番号の無い別の科目に分かれた（一般会計の項「4 文化学習スポーツ費」など12か所）。番号と名前は墨の位置で `code_readings` に宣言し、行ごとの読みは `dropped_readings` で除いた。
- **続きの頁の番号の行**: 続きの頁の頭の行は款・項・目の番号だけを各欄に印字する（「4 1 2」）。欄が狭く、組み立てで3つの番号が1つ（412）につながり款の段の科目になった。款・項の番号は開いている款・項の繰り返しなので、その読みを `dropped_readings` で除いた（一般会計の頁27・73、介護保険の頁32）。
- **つながった金額**: 一般会計の頁71の目「1 財政調整基金積立金」で、当初予算額と補正予算額が罫線を挟んで近く、OCR が1つの読み（61,541,0001,197,627,000）にした。読みを除き、`amount_readings` で欄ごとの額を宣言した。
- **帯の継ぎ目**: Paddle は頁を縦の帯に分けて読み、一般会計の頁44・46・76で継ぎ目にかかる行（備考の「前年度繰越事業費不用額」、歳出合計の翌年度繰越額・不用額）を読み落とした。この3頁は OCR の依頼を分け、`page_strips: 1` で読み直した。
- **罫線の切れ端**: 各会計で表が頁の途中で終わる頁（一般会計の頁63・64、国民健康保険の頁36・37、介護保険の頁28・29、後期高齢者医療の頁22・23）の最後の行は、縦の罫線が行の罫線と接する所の小さな突起で切れ、下の一片が罫線の長さに満たず、OCR の取得が金額の欄の読まれない墨として残した。原画で罫線の一片と確かめ、`rule_ink` で宣言した。
- **名前の読み違い**: 「購入費」→「購人費」、「コミュニティ」→「コミュニテイ」、「サービス」→「サビス」を `name_corrections` で直した。

## 2020年度決算・歳出

決算書は text PDF で、会計ごとに1冊（一般会計・国民健康保険事業・介護保険・後期高齢者医療）。見開きを物理2頁に分けて印字し、左頁に科目（款・項・目）・予算現額・節の区分と金額、右頁に支出済額・翌年度繰越額・不用額・備考がある。2024年度（scan）と同じ様式なので、読み方は `open_edge`・`standard`・`bands`・節は `indent` で、4会計とも共通にした。

| 会計 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | ---: | ---: | ---: |
| 一般会計 | 765 | 3,431 | 76,528,868,511 |
| 国民健康保険事業 | 118 | 686 | 5,223,813,391 |
| 介護保険 | 123 | 702 | 3,841,475,442 |
| 後期高齢者医療 | 41 | 248 | 1,669,366,091 |

- **読む頁**: 選定の scope は款だけの総括（一般会計は物理6–7頁、特別会計は4–5頁）も含む。総括は明細と同じ款を別の表で持つので読まず、変換の `pages` で明細の頁だけを読む。款の和は明細の款から作り、総括でなく明細の頁に印字された歳出合計と一致する。
- **右頁の欄の縁**: 右頁は支出済額の欄の左に縦罫を引かない。`layout.pattern: open_edge` で行の罫の端を欄の縁にする（`ruled` のままだと支出済額が読まれず、単位検査が款の和 0 で止まる）。
- **見開きの罫のずれ**: 右頁の行の罫は左頁より上のほうが約3pt高く、下では揃う。一様なずれではないので共通の見開きの判定（`layout.same_rows`）が左右を結べず、款3「国民健康保険事業費納付金」のように2行に折り返した款の右頁が行を持たなかった。opt-in の quirk `drifting_spread_rows` で、他方の頁に4pt以内の罫があれば揃っているとみなす。

## 2022年度当初予算・歳出
