- **款・項・目**: 項ごとに枠の上へ「（款） 2 総務費」「（項） 3 徴税費」を印字し、枠の中は款・項・目の番号を細い3つの欄に、3段の名前をその右の1つの欄に印字する。見出しは3つの番号の欄と名前の欄にまたがる1つの升「款 項 目」なので、`header.staircase` の `款項目名` で4つ目の欄を名前の欄として読み、subject は `names` で読む。款の和が予算書（各会計予算）の第1条「歳入歳出予算の総額」と上の表のとおり一致することを別に確かめた（予算書は款の金額を持つが目を持たない）。
- **廃目**: その年度に無くなった項・目は、番号の代わりに「○」を印字し（`○ 参議院議員` / `選挙費`）、名前を次の行へ折り返す。文書の quirk `marked_subjects` で、○の行をその欄の段の番号の無い項目として読み、下の行を名前の続きとして読む。本年度は0円で、前年度の金額のまま取り込む。
- **財源内訳**: 特定財源は種類（国庫支出金・市債・その他など）と額を2行に印字し、名前と金額を1対1に組めないので、`excluded` で取り込まない。
- **節**: 節の欄は法定の節と、職員手当等の下の手当（扶養手当・地域手当など、番号なし）を印字する。breakdown の `shape` で、番号の無い行を1段下（axis の quirk `unnumbered_shift`）に置き、欄の金額が行ごとに項目を分ける（axis の quirk `amounts_beside_names`）。2026年度の一般会計の1件（物理159頁）は、金額を印字しない「宿日直手当」の行を上の「時間外勤務手当」の名前の続きとして読んでいる（金額は時間外勤務手当の 3,420 千円で正しい）。
- **説明**: 説明の欄は「・市税システム関連経費」のような経費の説明で金額を持たないので、`excluded` で取り込まない。事業の名前と金額は、市会の予算特別委員会に局が出した局別の「予算説明書」に載る。
- **2025年度の公債費**: 公債費の歳出の頁（物理390頁）は文字層の ToUnicode が壊れて文字化けしており、文字 PDF として読めないので取り込んでいない（選定の範囲にも含めていない）。

## 2026年度当初予算・歳出の所属の表（局別の予算説明書）

市会の予算特別委員会に局が出した局別の「予算説明書」（giann_etc/r8/yosantokubetsu.html、局ごとの1冊の text PDF）の「歳出予算の説明」を、局の所管分の款・項・目（所属の表、ADR 0030）と、目の説明の事業として `generic_text` の layout pattern `explained_subjects` で取り込む。全市の説明書の表と同じ出典対象（2026 initial）に入り、局ごとの款・項・目の額の和は全市の表の額と一致する（一般会計と特別会計8つ。dbt の `cross_table_subject_disagreement`）。公営企業（水道・交通）の冊、空港整備事業費（説明が金額の無い箇条だけ）と公債費（目ごとの額の再掲だけ）の頁は取り込まない。

- **表と説明**: 項ごと（局によっては目ごと）に款・項・目の罫線の表を印字し、その後に目ごとの説明（「（第１目）職員費」「第２目 「商工総務費」 1,271,574 千円」「（目） １ 職員費」など、局ごとに書き方が違う見出し）と項目（「1 地域福祉の推進 721,994 千円」「(1) …」「・…」など）を印字する。表は説明の欄を持たないので、`explained_subjects` が目の行を引き伸ばして足した「説明」の欄に、その目の説明の項目を置き、breakdown の `shape` で読む。見出しと項目の書き方は局ごとに `header.explanations`（`heading`・`item`・`skip` の正規表現）で宣言する。
- **見出しの無い説明**: 行財政局の議会費・繰出金・公債費は、見出しを持たず、目ごとの額を「○ …に要する経費 1,210,831 千円」と再掲するだけなので、事業にしない（数字は除外の枠）。
- **行政委員会**: 1冊に選挙管理委員会事務局・人事委員会事務局・監査事務局の3局の表を印字するので、変換の `pages` で3つの所属の表に分ける。
- **水族園費**: 経済観光局の冊は第13款第11項社会教育費の水族園費を第2目と印字するが、全市の説明書（R6〜R8）は第1目と印字し、項の目は水族園費だけなので、`name_corrections` の `corrected_code` で1に直す。
- **財源内訳の列**: 本年度の財源内訳（国県支出金・市債・その他・一般財源）は取り込まない（全市の表でも読んでいない）。除外の列は数字が右の罫線をはみ出す（市場事業費の `585,356`）ので `overhang` を置く。
- **行財政局の繰出金の目の名前**: 3行に字を空けて印字する目の名前（「港湾事業」「会　計　へ」「繰　出　金」）は、1行目に同じ位置の字が無いと2・3行目の字を縦書きの語（「計出」）と読んで字順が崩れるので、`name_corrections` で印字どおりに直す（4目）。
- **子ども子育て支援納付金分納付金**: 福祉局の冊は国民健康保険事業費の第1款第3項第4目を「こども・子育て支援納付金分納付金」と印字し、全市の説明書と字が違う。所属の表の目は全市の表の目と名前をそろえる（dbt の `cross_table_subject_disagreement`）ので、`name_corrections` で全市の表の名前に直す。

## 2025年度当初予算・歳出の所属の表（局別の予算説明書）

R8 と同じく、局別の予算説明書 R7（giann_etc/r7/yosantokubetsu.html、17冊）の歳出予算の説明を `explained_subjects` で取り込む。各局の読み方は R8 と同じ宣言（年度の見出しを1年ずらす）で、違うところだけ書く。

- **市長室・行財政局**: R7 は1冊なので、所属を「市長室・行財政局」とする。目の説明の最後に局の名前と目の額（「行財政局 5,514,257 千円」）を印字するので、`skip` で項目にしない。諸支出金の款の前年度は、この冊が印字しない項（本年度の予算が無い項）を含み、項の和と合わないので、前年度と比較の欄は読まない（`kind: ignore`）。
- **健康局**: 「(8) 保健所及び保健センターの管理運営等に要する経費 240,792 千円」の下の「・健康管理システムの標準化 82,844 千円」は主な経費の抜き出しで、足しても上の額にならないので `skip` で項目にしない。
- **港湾局**: 見出しが「7年度」「6年度」なので、本年度・前年度の見出しに読み替える。
- **番号と名前の直し**（`name_corrections`）: 経済観光局の援護諸費（第4目と印字、全市は第3目）と水族園費（第2目と印字、全市は第1目）は番号だけを直す。選挙管理委員会事務局の「8 市長選挙費」は、全市の表の「7 神戸市長選挙」に番号と名前をそろえる。行財政局の繰出金の目の名前4件は R8 と同じく字順を直す。
- **消防局**: 歳出予算の説明の頁（物理10〜11頁）の文字層の ToUnicode が壊れて文字化けしているので取り込まない（消防費の款には所属の表が無い）。

## 2024年度当初予算・歳出の所属の表（局別の予算説明書）

R8・R7 と同じく、局別の予算説明書 R6（giann_etc/r6/yosantokubetsu.html、18冊）の歳出予算の説明を `explained_subjects` で取り込む。各局の読み方は R8 と同じ宣言（年度の見出しを2年ずらす）で、違うところだけ書く。

- **市長室・行財政局**・**健康局**: R7 と同じ（局の名前と目の額の行、「・健康管理システムの標準化」を `skip`）。
- **文化スポーツ局**: 目の説明の金額をカンマの後で字を空けて印字する（「1, 940, 223千円」）ので、続く3桁と1語に読む。
- **地域協働局**: 本年度の予算が無い目（「1 職員費 －」）は目の説明の宛先にしない。同じ頁の別の項の第1目の説明を取ってしまうため。
- **人事委員会事務局**: 表の上の罫線を財源内訳の欄の上に引かないので、枠の幅に満たない上下の罫線は枠の幅で引き直す。
- **番号と名前の直し**（`name_corrections`）: 援護諸費は福祉局・経済観光局の冊がどちらも第4目と印字し、全市は第3目なので番号だけを直す。経済観光局の水族園費（第2目と印字、全市は第1目）も番号だけを直す。行財政局の繰出金の目の名前4件は R8 と同じく字順を直す。
- **消防局**: R6 の冊は文字層が読めるので取り込む。
