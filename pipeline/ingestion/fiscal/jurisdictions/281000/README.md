- **款・項・目**: 項ごとに枠の上へ「（款） 2 総務費」「（項） 3 徴税費」を印字し、枠の中は款・項・目の番号を細い3つの欄に、3段の名前をその右の1つの欄に印字する。見出しは3つの番号の欄と名前の欄にまたがる1つの升「款 項 目」なので、`header.staircase` の `款項目名` で4つ目の欄を名前の欄として読み、subject は `names` で読む。款の和が予算書（各会計予算）の第1条「歳入歳出予算の総額」と上の表のとおり一致することを別に確かめた（予算書は款の金額を持つが目を持たない）。
- **廃目**: その年度に無くなった項・目は、番号の代わりに「○」を印字し（`○ 参議院議員` / `選挙費`）、名前を次の行へ折り返す。文書の quirk `marked_subjects` で、○の行をその欄の段の番号の無い項目として読み、下の行を名前の続きとして読む。本年度は0円で、前年度の金額のまま取り込む。
- **財源内訳**: 特定財源は種類（国庫支出金・市債・その他など）と額を2行に印字し、名前と金額を1対1に組めないので、`excluded` で取り込まない。
- **節**: 節の欄は法定の節と、職員手当等の下の手当（扶養手当・地域手当など、番号なし）を印字する。breakdown の `shape` で、番号の無い行を1段下（axis の quirk `unnumbered_shift`）に置き、欄の金額が行ごとに項目を分ける（axis の quirk `amounts_beside_names`）。2026年度の一般会計の1件（物理159頁）は、金額を印字しない「宿日直手当」の行を上の「時間外勤務手当」の名前の続きとして読んでいる（金額は時間外勤務手当の 3,420 千円で正しい）。
- **説明**: 説明の欄は「・市税システム関連経費」のような経費の説明で金額を持たないので、`excluded` で取り込まない。事業の名前と金額は、市会の予算特別委員会に局が出した局別の「予算説明書」に載る。
- **2025年度の公債費**: 公債費の歳出の頁（物理390頁）は文字層の ToUnicode が壊れて文字化けしており、文字 PDF として読めないので取り込んでいない（選定の範囲にも含めていない）。
