# 荒川区 131181

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険事業、後期高齢者医療、介護保険事業）を取り込む。

決算書は1冊の見開きの scan（1物理頁＝印字2頁）で、科目・予算現額・節・支出済額・翌年度繰越額・不用額・備考を同じ明細に印字する。特別会計も一般会計と同じ様式なので、一般会計の読み方（`workflow`）と OCR の依頼をそのまま使う。

- 翌年度繰越額の欄は、印字の0を OCR が `。` と読むので `columns` で `kind: amount` を宣言する。
- 名前の長音「ー」を Paddle が漢数字の「一」に読んだ行は、原画で確かめて `name_corrections` で直す（一般会計の「センター」、介護保険の「サービス」）。

## 当初予算（予算説明書）・歳出

2024〜2026年度の当初予算の歳出は、各年度1冊の予算説明書（scan）から一般会計・国民健康保険事業・後期高齢者医療・介護保険事業の4会計を読む。読み方は表のパターン `staircase_codes` で、3年度とも同じ。前年度予算額の款の和は、どの会計も前の年度の本年度予算額の款の和と一致する。

- 見開きの左頁に款・項・目と本年度・前年度・比較・財源内訳、右頁に節（区分・金額）と説明を印字する。右頁は款・項・目の欄を持たないので、左頁につないで1つの見開きとして読む（行の高さが左右で違い、`layout.same_rows` は見開きと見ない）。
- 見出しの `款 項 目` は狭い番号の欄3つと名前の欄に分かれる。番号は欄の右に寄せて印字され、2桁の款（`10`）は1桁の款より左から始まるので、狭い欄の数字は欄の左端から始まるものとして読む（欄が段になる）。
- 名前の欄に収まらない目の名前（`財政安定化基金` / `拠出金`）は、次の行の続きとして前の行に足す。
- 枠の上に毎頁印字される続きの款・項（`(款) 2 総務費`）は、表の中の款・項の行と重なるので見出しとして読まない。
- 説明の文の中の登録人口・戸籍数・学校数などの行（`戸籍数 89,121戸籍`）は件数・人数なので、網羅の検査の除外枠（本文）にした。
- 2025・2026年度は、説明の欄の見出しを OCR が `說明` と読む頁や、見出しに欄の1行目がつながる頁（`説明／後期高齢者医療事務に従事する…`）がある。見出しがどちらかで始まる欄を説明の欄とする。
- 本年度の財源内訳（特定財源・一般財源）の欄は取り込まない（`excluded`、種類は財源内訳）。
