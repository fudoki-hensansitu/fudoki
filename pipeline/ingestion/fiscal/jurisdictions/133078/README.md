## 2024年度決算・歳出

一般会計と特別会計6つ（国民健康保険の事業勘定・診療施設勘定、都民の森管理運営事業、介護保険、介護サービス事業、後期高齢者医療）を取り込む。簡易水道・下水道の公営企業会計は取り込まない。選定先が決算書ではなく事務報告書で、事業・修繕・委託の一部の金額だけを載せ、費用科目の明細も資本的支出の明細もなく、会計名も印字しないため。

決算書は見開きの scan で、偶数頁に科目・予算現額・節、奇数頁に支出済額・翌年度繰越額・不用額・備考を印字する。

- 欄が細く、頁の分割の継ぎ目が欄を切るので、OCR の依頼を `page_strips: 1`、`detection_limit_side_len: 3600` にする。
- 縦罫の欠片を墨と数えないよう、OCR の依頼に `rule_steps` を書く。
- 科目は1列の字下げで読むので `indent`。節は形（`shape`）、備考は字下げで読む。
- 備考は金額のない行を見出しとして読む（`headings`）。介護保険の「償還金」の下に「国庫支出金返還金」などが並ぶ。
- 科目の範囲には款・項の総括の頁もあるので、`pages` で明細の頁に絞る。
- 折り返しの1行目が名前に結ばれない備考（頁を跨ぐものを含む）と、OCR の読み違いは `name_corrections` で印字に直す。

## 2025・2026年度当初予算・歳出（一般会計）

予算書（一般会計の冊）の事項別明細書を読む。見開きの左頁に `（款） 2.総務費` / `（項） 1.総務管理費` の題字と目の表、右頁に節と説明を印字するので、`running_titles` の見開き（`facing_pages`）で読む。

- 範囲は総括の頁（款の金額と歳出合計）と明細の頁に絞る（`pages`）。第1表の頁は款・項を3度目に印字するので読まない。
- 財源内訳の欄は取り込まない。総括の頁の「総額に対する割合」は金額ではないので読まない（`kind: ignore`）。
- その年に無くなった目は番号の代わりに `△.` を印字する（`△. 東京都知事選挙費 0 7,167 △7,167`）。印は名前に入れない（`abolished_marks`）。
- 説明は節ごとの経費の品目なので、分け方は「その他」にする。

### 2024年度当初予算・歳出（一般会計）

2025年度と同じ組み方で読むが、説明の読み方が違う。

- 委託料の説明の多く（議会事務補助委託料など）は出典が金額を印字していない（画像にも無い）。金額の無い行は名前の折り返しではなく品目なので、折り返しを読まず字下げで読み、金額の無い行も品目にする（`headings`、`bare_amounts`）。
- 説明は節の行に並べて印字するので、各品目を同じ行の節の下に置く（`under: 節`）。金額を1つも印字しない節（委託料）は合計を確かめない。見開きの次の頁の頭に続く品目は、前の見開きの最後の節に付く。
- 品目が節の子になるので、配る内訳の分け方は2025年度以降の「その他」と違い「節」になる。

### 2023年度当初予算・歳出（一般会計）

2024年度と同じ組み方で読む。頁は1つずれ、第1表（物理頁6-7）は款・項を3度目に印字するので読まない（`pages` は12と37-124）。

## 2024〜2026年度当初予算・歳出（特別会計）

一般会計と同じ予算書から特別会計を、一般会計と同じ見開きの読み方（`running_titles`、`facing_pages`、`abolished_marks`）で読む。2025・2026年度は6会計（国民健康保険の事業勘定・診療施設勘定、都民の森管理運営事業、介護保険、介護サービス事業、後期高齢者医療）。特別会計の冊は総括の頁も明細と同じ見開きなので、`pages` で絞らない。

- 2024年度は一般会計と同じく説明の金額の無い行を品目として読む（`headings`）。介護保険は見出しが罫線1段（`one_row_header`）。介護サービス事業は額が小さく比較の欄が名前と読まれるので、金額の欄に宣言する。
- 2024年度の国民健康保険診療施設勘定は、説明を節の行の下に置き（`under: 節`）、42頁と54-59頁を読む。57頁の委託料の品目の続きは金額が無く、次の頁の頭の「テレビ受信料」の金額だけの行が前の頁の最後の品目に運ばれてしまうので、同じ行に名前の帯がある金額は運ばない（`split_name_bands`）。59頁の「明」の欄は説明の見出しの欠けなので名前の欄に宣言する。
- 2024年度の国民健康保険事業勘定はまだ取り込まない。目の欄が2つの帯に割れて目の深さが2になり、各目の最初の節が注記になってしまう。

## 歳入（2023〜2026年度当初予算・一般会計、2023・2024年度決算・7会計）

歳入の事項別明細書は同じ冊の歳出の前にあり、様式も歳出と同じ。管理 JSON は歳出の宣言を写し、当初予算の説明と決算の備考（節の下の徴収区分などの品目・注記）を除外の種類「歳入の説明」で外した。範囲は歳出と同じく、当初予算は総括と明細の頁、決算は明細の頁。款の和は各会計の歳入合計と一致する。

- 2024年度決算は scan なので、歳入の頁の OCR を新しく取った（`ocr_inputs` の `*-revenue-ocr-*`）。歳出の名前の訂正は写していない。
- 2023年度決算の介護保険特別会計は款が `1`〜`9` と `10`・`11` で、2桁の款の番号が1字左から始まる。2桁の款が2つしかなく、番号の開始が4つ目の段に見えるので、`stray_subject_starts` で数の少ない段を近い段に寄せる。
