# 檜原村 133078

## 2024年度決算・歳出

一般会計と特別会計6つ（国民健康保険の事業勘定・診療施設勘定、都民の森管理運営事業、介護保険、介護サービス事業、後期高齢者医療）を取り込む。簡易水道・下水道の公営企業会計は取り込まない。選定先が決算書ではなく事務報告書で、事業・修繕・委託の一部の金額だけを載せ、費用科目の明細も資本的支出の明細もなく、会計名も印字しないため。

決算書は見開きの scan で、偶数頁に科目・予算現額・節、奇数頁に支出済額・翌年度繰越額・不用額・備考を印字する。

- 欄が細く、頁の分割の継ぎ目が欄を切るので、OCR の依頼を `page_strips: 1`、`detection_limit_side_len: 3600` にする。
- 縦罫の欠片を墨と数えないよう、OCR の依頼に `rule_steps` を書く。
- 科目は1列の字下げで読むので `indent`。節は形（`shape`）、備考は字下げで読む。
- 備考は金額のない行を見出しとして読む（`headings`）。介護保険の「償還金」の下に「国庫支出金返還金」などが並ぶ。
- 科目の範囲には款・項の総括の頁もあるので、`pages` で明細の頁に絞る。
- 折り返しの1行目が名前に結ばれない備考（頁を跨ぐものを含む）と、OCR の読み違いは `name_corrections` で印字に直す。

## 2025・2026年度当初予算・歳出（一般会計）

予算書（一般会計の冊）の事項別明細書を読む。見開きの左頁に `（款） 2.総務費` / `（項） 1.総務管理費` の題字と目の表、右頁に節と説明を印字するので、`running_titles` の見開き（`facing_pages`）で読む。

- 範囲は総括の頁（款の金額と歳出合計）と明細の頁に絞る（`pages`）。第1表の頁は款・項を3度目に印字するので読まない。
- 財源内訳の欄は取り込まない。総括の頁の「総額に対する割合」は金額ではないので読まない（`kind: ignore`）。
- その年に無くなった目は番号の代わりに `△.` を印字する（`△. 東京都知事選挙費 0 7,167 △7,167`）。印は名前に入れない（`dotted_abolished_marks`）。
- 説明は節ごとの経費の品目なので、分け方は「その他」にする。
- 2024年度は説明の金額が文字層に無い行（例規集運用業務委託料など）があり、同じ宣言では木が合わない。別に読む。
