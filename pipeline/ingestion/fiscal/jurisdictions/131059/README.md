# 文京区 131059

## 2023年度決算・歳出

令和5年度各会計歳入歳出決算書（一括版）の一般会計・歳出（97〜177頁）を、2024年度の読み方（`workflow`）を写して取り込む。見開きを物理2頁に分け、左頁に科目・予算現額・節の区分、右頁に節の金額・支出済額・翌年度繰越額・不用額・備考を印字する。ノード 1,183・金額 4,291。款の和 118,285,498,406 円が印字の「歳出合計」と一致する。

- **文字の層**: どの字も数 pt ずらした見えない写しを持つ。写しは pdfium の clip で落ちるので、宣言は要らない。
- **節の段**: 2024年度の `indent` では、番号が1桁の節と2桁の節の名前の始まりがずれて、2桁の節が1桁の節の子になった（不一致 414）。節の欄は法定の節だけを並べるので `flat` にした。
- **翌年度繰越額の種類**: 繰越のある行は金額の前に「明許」「事故」と種類を印字し、2つの種類がある行（p151「8 土木費」の 明許 20,942,000 / 事故 58,846,671）は1つの升に2行重ねる。quirk `carry_kind_words` で、種類の付いた金額を「翌年度繰越額／繰越明許費」「翌年度繰越額／事故繰越し」として読む。
- **備考の全角数字**: p127 民生費の備考「…議案第３１」/「号、…」の行末の「１」が金額に読まれ、注記が割れた。金額は半角で印字するので、quirk `wide_digits_in_names` で行末の全角数字を文の一部として読む。

## 当初予算・歳出（2023年度、2026-11-15）

2024年度と同じ書式（予算事項別明細書、`running_titles`）だが、一般会計を6冊に分けて印字し、冊の境で款・項・目が切れる（冊の末尾に次の款の最初の見開きを載せる）。

- **分冊の継ぎ目**: 第2〜5冊の頭は、前の冊の最後の目の続きの行（節・説明）から始まり、その目の行を印字しない（款・項は枠の上に題字として印字し直す）。変換 `general-initial-2`〜`-5` の `continued_rows` に目を宣言し、金額なしの行として印字し直した款・項の下に置いて、頭の行をその下に付ける。第4冊は説明の事業「5 協議会運営」の途中から始まるので、その事業を `children: 1` で宣言し（続きの1行だけを子にし、次の「6」からは目の下に戻す）。dbt で前の冊の同じ行とまとまる。
- **款・項の金額**: 冊の境でまたがる款・項の題字の金額も読む（`header.volume_titles`）。冊だけの子の和が印字の額にならないずれ（款・項・目と事業、14件）は `expenditure.layout.json` に宣言した。款・項の額は dbt で冊をまたいだ子の和と比べる。
- 説明の名前の下に人数だけを印字した行（`１９０人`）は項目にしない（共通の読み）。
