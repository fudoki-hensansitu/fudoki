## 当初予算の一般会計（2026-11-12）

2024〜2026当初の一般会計の歳出を、保存済みの特別会計と同じ管理 JSON に `generic_text` で足した（`--extend-plan`）。読み方は特別会計と同じで（財源内訳の4欄を除外、`本年度` は金額の欄、節は indent、説明は shape、`partial_headings`）、説明の軸に quirk を2つ選ぶ。

- **`glued_project_codes`**: 説明の事業は6桁のコードを名前にくっつけて印字する（`010111議会費職員人件費等（人事課）`）。下の特別会計と同じく6桁・7桁を番号として読み、事業・節・細節を3段にする。名前が数える語で始まる細節（`1801133時間延長型保育サービス事業補助金`）も、くっついた7桁をコードとして読む（`3時間` という数ではない）。
- **`names_over_pages`**: 頁の末で金額の無いまま切れた事業名が、次の頁の先頭に名前の続きと金額を印字する（R6 の `011044 文化財保護費会計年度任用職員(専門職)経` / `費…`）。続きが前の事業の名前の開始位置から始まるときに1つの事業に結ぶ。
