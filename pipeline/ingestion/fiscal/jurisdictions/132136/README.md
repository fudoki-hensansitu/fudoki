- **`long_numbers`**: 説明の7桁の事業コードは項目番号として読まない（番号の無い行として節の下に付く）。名前が全角数字で始まる事業（`1801109 １１時間開所保育対策加算補助金`、`1401102 ２号井戸流水計更新工事`）だけは、半角の数字に全角の数字が続く書き方（`11３歳児…`）の規則で7桁が番号になり、節と同じ段に上がって後ろの事業を子にしていた。
