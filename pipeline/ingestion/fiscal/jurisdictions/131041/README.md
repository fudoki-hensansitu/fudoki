## 2023年度当初予算・歳出

2024年度当初と同じ様式の予算事項別明細書（一般会計2冊・特別会計1冊）。頁は 600dpi の白黒画像で、文字層は Acrobat の Paper Capture が付けた OCR の文字なので、選定を scan にし、2024年度の読み方（`workflow`）で OCR から読む。一般会計は2冊で款が分かれるので各冊 `partial`。

| 会計 | ノード | 金額 | 款の和 |
| --- | ---: | ---: | ---: |
| 一般会計（第1冊・款1〜5） | 1,345 | 1,467 | 73,827,448 千円 |
| 一般会計（第2冊・款6〜13） | 1,578 | 1,735 | 95,633,121 千円 |
| 国民健康保険 | 182 | 258 | 38,851,961 千円（＝総括の歳出合計） |
| 介護保険 | 190 | 254 | 27,930,866 千円 |
| 後期高齢者医療 | 70 | 94 | 8,324,275 千円 |

- **面積の読み違い**: 説明の規模の「面積 1,950㎡」などは、OCR が ㎡ を読み落とし（または ² だけ・数字に続けて 2 と読み）、数字が説明の金額として読まれた。8件を `dropped_readings` で除いた。
- **款の総括の財源内訳**: 特別会計の款の総括は見開きの右頁に財源内訳だけを印字する。列は取り込まず、OCR が見出しを升ごとに割って読む（特／定財／源）ので、読んだ見出しのまま `columns` で除外を宣言した。
