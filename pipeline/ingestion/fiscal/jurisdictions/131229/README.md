## 歳入（当初 R5〜R8・決算 R5〜R6、6会計、2026-11-16）

管理 JSON は歳出の宣言を写し、歳入の頁で違う欄だけを変えた。款の和は全ての表で出典の合計と一致する。

- **当初予算**: 一般会計の歳入は予算説明書の「歳入」の冊（選定の最後の冊）で、特別会計の歳入は各冊の総括の後・歳出の前（物理5頁から）。様式は歳出と同じ（款・項・目、本年度・前年度・比較、右に節と説明）。説明（積算と主な収入の名前）を除外の種類「歳入の説明」で外した。一般会計の冊は歳入合計を印字しないので、款の和（R5 223,070,000千円、R6 239,850,000、R7 257,360,000、R8 282,960,000）は総括表の冊の歳入合計と手で照合した。特別会計は各冊の総括の歳入合計と一致する。
- **決算**: 事項別明細書の各会計の歳入は同じ冊の歳出の直前。款・項・目の番号の欄と名前の欄の上に「款 項 目」を1つ印字するので、科目は歳出と同じく `indent` で読む。見開きの左に「予算現額」の「予算現」、右に「額」を刷るので、合計の欄は `予算現／計` と読まれる。辞書の `予算現額計` に `columns.heading` で寄せた。備考（議案の番号・還付未済額）は「歳入の説明」で外した。収入済額の款の和は各会計の歳入決算額（R5 一般会計 253,844,682,711円、R6 265,985,034,215円ほか）と一致する。
