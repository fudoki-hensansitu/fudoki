# 武蔵村山市 132233

## 2024〜2026年度当初予算・歳出（一般会計）

予算書の歳出の事項別明細書（分冊の PDF、各430頁ほど）を読む。見開きの左頁に款・項・目・本年度・前年度・比較・財源内訳、右頁に一般財源・節・説明を印字する。款・項・目は表の中の欄（`bands`）。財源内訳の欄は取り込まない。

- 説明は番号つきの事業（`1 職員人件費 58,240`）、その下に節（`2 一般職給料`）と細節の品目。需用費の品目は細節の番号を名前の後ろに印字する（`消耗品費 1 … 104`）ので、`numbered_names` でその番号を名前の一部として読む。
- 品目を束ねる金額の無い行（`通信料等` / `インターネット通信料 56`）があるので、説明に `headings` を付ける。金額だけを次の行に印字する長い名前があるので `bare_amounts` を書く。
- 2024年度の消防費の `防災食育センター備品整備基金費`（その年に無くなった目）は目の番号を印字せず、款・項の番号だけが行にある。`codeless_beside_repeated_code` で目の欄の名前を番号の無い目として読む。
- 款の和は3年とも歳出合計と一致する（単位の検査）。
- 説明の分け方は「事業」。COFOG の規則を3つ足した（成人衛生費・保健相談センター費は保健、妊婦健康診査基金費は基金への積立で対象外）。

## 2024年度決算・歳出

下水道事業会計は決算書から取り込む。一般会計・特別会計の選定先は、2026-11-04 に選び直した監査委員の審査意見書（`6kessannshinnsa.pdf`）の款別歳出決算額前年度比較で、款の金額だけを印字し項・目が無い。選び直す前の事務報告書（`r6aresultreport.pdf`）の「主要な施策の成果」も、事業の行に目の番号（`（1・1・1）`）を添えて事業費を載せるだけで、親子の合計を確かめる木が立たず、保存の関門で止まった（同日に `generic_text` で実測）。

一般会計と特別会計4つ（2026-11-17）は、2025年度と同じく意見書の款の粒度だけを取り込む。2025年度の宣言を写し、欄の見出しの年度（令和6・5年度）を合わせた。款の和は選定に記した各表の合計と一致する（一般会計 36,300,808,398円・国保 7,720,499,535円・介護 6,115,643,636円・都市核 1,592,174,068円・後期 1,984,891,574円）。

下水道事業会計決算書（`kessan.pdf`）は傾いた低解像度の scan。

- 罫線の階段を墨と数えないよう、OCR の依頼に `rule_steps` を書く。
- 既定の縦2分割の継ぎ目が節の欄を切るので、`page_strips` を 3 にする。
- 金額の欄の見出しは「金額」とだけ印字され、決算額なので、見出しを「決算額」に宣言する。
- 収益的支出と資本的支出がどちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py`）。
- 備考の「予算額〇円」は表に入れていない。

## 2023年度決算・歳出

下水道事業会計は決算書から取り込む。一般会計と特別会計4つ（2026-11-17）は、意見書（`5kessannsinnsa.pdf`）の款の粒度だけを2025年度の宣言を写して取り込み（欄の見出しの年度は令和5・4年度に合わせた）、款の和は選定に記した各表の合計と一致する（一般会計 32,081,693,425円・国保 7,843,275,284円・介護 5,716,621,000円・都市核 1,443,958,057円・後期 1,965,918,643円）。下水道事業会計決算書は傾いた scan で、2024年度の宣言を写して頁を2023年度の冊（収益的支出 物理38〜40、資本的支出 物理42）に合わせた。

- 物理42頁は既定の3分割の継ぎ目が項「2 固定資産購入費」の行を切るので、別の OCR の依頼で `page_strips: 1`・`detection_limit_side_len: 3600` で読む。
- 見出しの汚れ（`款.`・`・金額`）を `columns` で款の欄と金額（決算額）の欄に宣言する。物理39頁は款の欄に字が無いので、款の欄（`kind: label`）と明示しないと項・目が1段浅く読まれる。
- 物理38頁の金額の欄で、傾いた縦の罫と行の罫が交わる所の切れ端（397–417pt・451–478pt）を OCR が読まない墨として残すので、quirk `rule_ink` で罫の切れ端と見る（2024年度の冊には無い）。
- 紙の汚れや鉛筆の印を OCR が数字と読んだ読みを `dropped_readings`、金額の読み違い（`68,461,304`→`68,451,304`、`376;500`）を `amount_corrections`、`流城`（流域）と折り返しの重なり（`運運営`）を `name_corrections` で直す。いずれも原画で確かめ、節の和が目に合う。

## 2025年度決算・歳出

監査委員の「令和7年度決算及び基金運用状況審査意見書」の款別歳出決算額前年度比較（一般会計 表18・物理23頁、国民健康保険事業 表24・28頁、介護保険 表28・31頁、都市核地区土地区画整理事業 表31・33頁、後期高齢者医療 表36・35頁）から、款の粒度だけを取り込む。項・目以下は出典に無い。

- 科目の欄の見出しは「区分」とだけ印字されるので、見出しを「款」に宣言する。
- 令和6年度の決算額の欄は前年度の金額なので、見出しを「前年度決算額」に宣言し、支出済額に数えない。構成比・増減率の欄は率なので読まない。対前年度比較の増減額は、金額の辞書で段階を持たない「比較」と見出しを宣言して持つ。
- 国民健康保険事業の款3「国民健康保険事業費納付金」・介護保険の款3「財政安定化基金拠出金」は2行に折り返して印字され、1行目が款2 の名称に結ばれるので、名称の訂正で直す。
- 下水道事業会計（同じ意見書の表1・表2、物理48-49頁）は取り込んでいない。同じ枠の中に収益・資本的収入の行と支出の行が並び、汎用の変換器に頁の一部だけを読む設定が無いため。

## 歳入（当初 R6〜R8・決算 R7）

当初は予算書と同じ頁に別の冊で載る「歳入 事項別明細書」（文字 PDF、款・項・目と本年度・前年度・比較、節の区分・金額、説明）を選定に足し、歳出の宣言を写して読む。説明の欄は「歳入の説明」で外す。

- R6 は歳出から写した quirk `codeless_beside_repeated_code` が番号と名前を切り離すので外した。
- R6 の節「消防費補助金」（物理16頁の頭）は見開きの右の頁で上の目の行の高さから刷られ、前の頁の目「消防費国庫補助金」（物理15頁）の子に読めないので、`parent_corrections` で原画の親に付け直す。

R7 決算は歳出と同じ審査意見書の款別歳入決算額前年度比較（一般会計 表・物理17頁、国民健康保険事業 26頁、介護保険 29頁、都市核地区土地区画整理事業 32頁、後期高齢者医療 34頁）から款の粒度だけを取り込む。見出しの宣言は歳出と同じ。

- 款の名前が2行に折り返し、番号が2行の間（2行目寄り）に刷られる行（`株式等譲渡` / `5 所得割交付金` など）は、quirk `code_between_name_lines` で1行目を番号の行の名前の頭に付ける。
- 介護保険は番号を右に揃えて刷り（`1`〜`9` と `10`・`11` の頭が5pt違う）、字下げでは款1〜9が1段深く読まれるので、科目を欄（`bands`）で読む。
