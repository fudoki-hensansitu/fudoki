# 武蔵村山市 132233

## 2024〜2026年度当初予算・歳出（一般会計）

予算書の歳出の事項別明細書（分冊の PDF、各430頁ほど）を読む。見開きの左頁に款・項・目・本年度・前年度・比較・財源内訳、右頁に一般財源・節・説明を印字する。款・項・目は表の中の欄（`bands`）。財源内訳の欄は取り込まない。

- 説明は番号つきの事業（`1 職員人件費 58,240`）、その下に節（`2 一般職給料`）と細節の品目。需用費の品目は細節の番号を名前の後ろに印字する（`消耗品費 1 … 104`）ので、`numbered_names` でその番号を名前の一部として読む。
- 品目を束ねる金額の無い行（`通信料等` / `インターネット通信料 56`）があるので、説明に `headings` を付ける。金額だけを次の行に印字する長い名前があるので `bare_amounts` を書く。
- 2024年度の消防費の `防災食育センター備品整備基金費`（その年に無くなった目）は目の番号を印字せず、款・項の番号だけが行にある。`codeless_beside_repeated_code` で目の欄の名前を番号の無い目として読む。
- 款の和は3年とも歳出合計と一致する（単位の検査）。
- 説明の分け方は「事業」。COFOG の規則を3つ足した（成人衛生費・保健相談センター費は保健、妊婦健康診査基金費は基金への積立で対象外）。

## 2024年度決算・歳出

下水道事業会計だけを取り込む。一般会計・特別会計の選定先は決算書ではなく事務報告書（`r6aresultreport.pdf`）の「主要な施策の成果」で、款・項・目の金額を印字しない。事業の行に目の番号（`（1・1・1）`）を添え、事業費を載せるだけなので、親子の合計を確かめる木が立たず、保存の関門で止まる（2026-11-04 に `generic_text` で実測）。公債費・諸支出金・予備費なども載らない。

下水道事業会計決算書（`kessan.pdf`）は傾いた低解像度の scan。

- 罫線の階段を墨と数えないよう、OCR の依頼に `rule_steps` を書く。
- 既定の縦2分割の継ぎ目が節の欄を切るので、`page_strips` を 3 にする。
- 金額の欄の見出しは「金額」とだけ印字され、決算額なので、見出しを「決算額」に宣言する。
- 収益的支出と資本的支出がどちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py`）。
- 備考の「予算額〇円」は表に入れていない。

## 2025年度決算・歳出

監査委員の「令和7年度決算及び基金運用状況審査意見書」の款別歳出決算額前年度比較（一般会計 表18・物理23頁、国民健康保険事業 表24・28頁、介護保険 表28・31頁、都市核地区土地区画整理事業 表31・33頁、後期高齢者医療 表36・35頁）から、款の粒度だけを取り込む。項・目以下は出典に無い。

- 科目の欄の見出しは「区分」とだけ印字されるので、見出しを「款」に宣言する。
- 令和6年度の決算額の欄は前年度の金額なので、見出しを「前年度決算額」に宣言し、支出済額に数えない。構成比・増減率の欄は率なので読まない。対前年度比較の増減額は、金額の辞書で段階を持たない「比較」と見出しを宣言して持つ。
- 国民健康保険事業の款3「国民健康保険事業費納付金」・介護保険の款3「財政安定化基金拠出金」は2行に折り返して印字され、1行目が款2 の名称に結ばれるので、名称の訂正で直す。
- 下水道事業会計（同じ意見書の表1・表2、物理48-49頁）は取り込んでいない。同じ枠の中に収益・資本的収入の行と支出の行が並び、汎用の変換器に頁の一部だけを読む設定が無いため。
