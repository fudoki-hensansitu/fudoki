# 日野市（132128）

2025決算・歳出は一般会計と4特別会計（国保・土地区画整理・介護・後期高齢者医療）を汎用text PDFの変換器で取り込む。宣言と保存参照は `2025/settlement/expenditure.json`。出典・頁・会計は選定scopeに従う。

日野市は令和7年度決算書の掲載を正誤表（款2項1目1の事業「1 特別職及び職員人件費（職員課）」の支出済額 誤3,003,925,159→正3,004,207,994）に合わせて差し替えた。一般会計は款ごとの13冊（`general-settlement-01`〜`13`、`partial`）、特別会計は会計ごとの1冊になった。2026-11-09 に差し替え後の17冊で取り込み直した。以前の `source_inconsistencies`（頁3の 282,835 円のずれ）は訂正されたので外した。

- 一般会計: 13冊の款の和 81,337,822,814 円＝差し替え前の印字の歳出合計。8,752ノード/12,815金額で差し替え前と同数。冊ごとの款の和は分冊のため印字合計と照合しない。各冊の左の不用額欄を `layout.options.columns` で金額欄と宣言する。農業費・商工費・消防費（06・07・09）は節の番号の字下げがそろわないので `節: shape` で読む。
- 特別会計: 款和＝印字の歳出合計（国保 16,166,621,180・土地区画整理 2,774,892,427・介護 16,760,592,262・後期高齢者医療 5,940,640,832 円）、網羅・単位matched。後期高齢者医療は差し替え後の冊の下端に印字された通し頁番号を旧変換器（workflow_text）が金額と区別できないため、汎用の変換器（表 `late-elderly-medical-expenditure`、`節: shape`）に移した。144ノード/364金額で旧表と同数。
- 内訳の5字の均等割付に対し、長い名称が1字左へ出る習慣を fitted_names（`overflow_left_chars`）で宣言する。末尾の括弧金額は amount_brackets で読む。頁またぎの金額は `wrap: amount_on_last_line` で結ぶ。

2026当初・歳出は一般会計を汎用text PDFの変換器で取り込む（宣言は `2026/initial/expenditure.json`、2025当初と同じ workflow）。款の和 83,775,000 千円、7,808ノード/8,148金額。2026の冊は目の名前を2行に字間を広く空けて組み（`平　和　と　人　権` の下に `推　進　費`）、下の行の字が上の行の字の真下に来る。上下の字を縦書きの1語に繋げないよう repair `spaced_letters` を選ぶ。
