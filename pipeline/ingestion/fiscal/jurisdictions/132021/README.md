# 立川市 132021

## 2024年度当初予算・歳出

一般会計を取り込む。2025・2026年度は文字 PDF の版で取り込んでいる。予算説明書は見開きの scan で、左の頁に款項目・本年度・前年度・比較・財源内訳・節、右の頁に説明（事業と、その下の節ごとの内訳）を印字する。読み方は 2025年度の版と同じにし、scan だけの違いを足す。

- 欄が細く、頁の分割の継ぎ目が欄を切るので、OCR の依頼を `page_strips: 1`、`detection_limit_side_len: 3600` にする。
- 節は1段なので `flat` で読む。左の財源内訳の額の末尾の数字が節の番号に付いて読まれる（`5728旅`）ので、法定の節の番号で終わる番号は法定の番号に読む（`legal_setsu_codes`）。
- 説明の番号の無い行は、上の番号付きの行の名前の位置から始まれば兄弟（`codeless_at_names`）。番号と名前が1語に読まれた行も、番号の位置で段を決める。
- 款項目の段の罫が1画素切れて短い片が検出されない頁がある（民生費の項「1 社会福祉費」の左の罫）。その片を罫として読む（`gapped_column_rules`）。
- 説明の `（特定財源 X 一般財源 Y）` は事業の財源の内訳で歳出の金額ではないので、注記にせず網羅の除外にする（`dropped_notes`）。
- 番号と名前、財源と節の番号が1語に読まれた行、額の枠が上にずれた行は、原典の描画で確かめて `dropped_readings`・`code_readings`・`amount_readings` で宣言する。

## 2024年度決算・歳出

一般会計・特別会計5つ（競輪、国民健康保険、駐車場、介護保険、後期高齢者医療）・下水道事業会計を取り込む。2025年度は文字 PDF の版を別の読み方で取り込んでいる。

合冊の決算書は見開きの scan で、偶数頁に科目・予算現額・節、奇数頁に支出済額・翌年度繰越額・不用額・備考を印字する。下水道事業会計は文字 PDF。

- 欄が細く、頁の分割の継ぎ目が欄を切るので、OCR の依頼を `page_strips: 1`、`detection_limit_side_len: 3600` にし、`rule_steps` を書く。
- 備考は字の位置で読む（`position`）。全角の開き括弧は字の右半分に墨があるので、字下げを半字戻す（`opening_bracket_ink`）。
- `(翌年度へ繰越明許費 …)` の行は上の名前を閉じる（`bracket_line_closes_name`）。繰越の額は名前の中に残り、金額の列には入らない。
- 頁の先頭にある事業番号が名前の数字と1語に読まれた行は `glued_numbers` で切る（`101歳6か月` は番号10）。
- OCR の枠が左に広がった行は `line_starts` で印字の位置に戻す。
- 名前の読み違いは `name_corrections`、金額の読み違いは `amount_corrections` で印字に直す。
- 下水道事業会計は金額の欄の見出しを「決算額」に宣言し、収益的支出と資本的支出を別の表にする。節の下の説明と金額の列は取り込まない。節の金額で科目の和が合い、説明の行は名前と金額が1対1に揃わないため。どちらも款1から始まるので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py` の `EXCLUDE`）。
