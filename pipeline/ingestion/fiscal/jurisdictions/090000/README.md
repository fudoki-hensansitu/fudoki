# 栃木県（090000）

栃木県（都道府県）。決算は会計課の頁、当初予算は財政課の頁（議会の議案）から取る。

| 資料 | 年度 | 様式 |
| --- | --- | --- |
| 決算（歳入歳出決算事項別明細書） | R3（一般会計のみ）・R4・R5・R6 | text PDF（`generic_text`）、会計ごとに1ファイル |
| 当初予算（予算に関する説明書の歳出） | R6・R7・R8 | text PDF、1冊（選定のみ。取り込みは後の PR） |

R7 の決算はまだ公開されていない。R2 以前の決算は事項別明細書の歳出を公開していない。R3 の特別会計の決算はアウトライン化された文字で text が無いので取らない。企業会計に近い6つの特別会計（流域下水道・電気・水道・工業用水道・用地造成・施設管理）は予算実施計画の様式なので取らない。

## 決算

一般会計と9つの特別会計（公債管理・県立病院貸付金・母子父子寡婦福祉資金・心身障害者扶養共済・国民健康保険・県営林・林業木材産業改善資金・中小企業高度化等資金・就農支援資金）。4年度とも見開きの同じ様式で、左頁に款・項・目・予算現額・節、右頁に支出済額・翌年度繰越額（継続費逓次繰越・繰越明許費・事故繰越し）・不用額・備考を印字する。款の和は全会計・全年度で歳出合計と一致する。

- 科目は款・項・目の欄ごとに名前を印字するので subject は `bands`。節は `shape`。
- 翌年度繰越額の3つの小見出しは2行に分けて印字し、text の順が崩れる（「繰明許費越」）。headers は文字で見出しを決める `characters`。
- 一般会計の1頁目は枠の上に「歳出」「単位：円」を印字するので `ignore_frame_title`。
- 備考は注記の小さな表で、ラベル（継続費繰越・繰越明許費・繰越明許費不用額など）の真下に金額を右端をそろえて並べる。行ごとに読むとラベルがつながり金額が1つしか残らないので、備考の quirk `labels_over_amounts` でラベルと金額の組を1つずつの注記にする。備考は内訳ではなく注記だけで、分け方は節だけ。
- R4 の特別会計は見出しの語の後ろに見えない文字（Poppler が U+FFFD と読む）が付くので、`text_layer.character_map` で落とす。
- 予算現額が 0 円の目（当初と補正が打ち消し合う目）は印字されないので、項の当初予算額・補正予算額と目の和がずれる（R4・R6 の災害復旧費など）。`expenditure.layout.json` の `source_inconsistencies` に置いた。
- 支出の無かった目は支出済額を空欄にし、予算現額の全額を不用額に印字する（林業木材産業改善資金の R6）。
