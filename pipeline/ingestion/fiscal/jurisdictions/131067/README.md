- **節は説明の欄**: 当初予算の歳入は目の下の節を「節及び計上説明」の欄に番号つきの行（`1 特別区民税`）で印字し、その下の番号の無い行（`均等割 3,000`、字で引いた表の行 `医療連携推進 1,345`）が節の額の積算になる。説明の欄を内訳（`indent`）で読み、opt-in の axis quirk `unnumbered_notes` で番号の無い行を注記（積算）にした。番号の行が額を印字しないときは、名前の下の行（`123,284 〔危機・災害対策課〕`）がその節の額になる。
- **字で引いた表の補助率**: 表の行の額の右に補助率（`健康づくり啓発推進 2,925 1／2`）があると、額が行の最後の語にならず読まれなかった。額の後の補助率は名前の側に寄せる（共通の変更）。
- **見開きの枠のずれ**: 左右の頁で枠の位置が 41pt 違い、右頁に続く目の欄が左頁の位置のままになって、次の目の見出しが欄を二つに割った。続きの目の欄は、幅が同じなら右頁の枠の位置に移す（`subject_cards` の共通の変更）。頁の下で切れた目の枠の下の罫が空の行だけを囲むときは、その罫を目の終わりにしない。
- **総括の頁**: 当初の総括（款別）は `pages` で除き、明細だけを読む。決算も選定の scope の総括（物理11–14頁）は款・項を明細と別のノードに作って款が2重になるので、`pages` で明細（72–170頁）だけを読む。
