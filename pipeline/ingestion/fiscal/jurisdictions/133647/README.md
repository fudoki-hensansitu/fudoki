# 神津島村 133647

## 2022年度当初予算・歳出（R4、一般会計、2026-11-15）

一般会計予算書（`yosansyo`）の事項別明細書の歳出（物理27〜119頁）を `generic_text` で取り込む。3,177ノード・3,332金額。款の和 3,029,409 千円は、予算書の総括（5頁・8頁）の歳出合計と一致する。

- **頁**: A3 横の見開き1枚に、左に科目（款・項・目）・本年度・前年度・比較・財源内訳・節、右に説明を1つの枠で印字する。款・項は頁の上に `（款）1 議会費` / `（項）1 議会費` を印字し、款・項・目は同じ欄に階段で印字する（`subject: indent`、`codes: right`）。財源内訳の欄は取り込まない。
- **説明**: 目の下に、4桁の番号の事業（`0102 議会費 33,846`）、`◎` の節（金額）、`・` の内訳（金額）の順に並べる。事業・◎・・は同じ欄に始まるので、`◎`・`・` を印の段（2・3）で読む（`marks`）。節は目の右の節の欄（`節: flat`）。
- **円の内訳**: `・` の下に円で印字した行（`職員研修 494,000円`、`村道14号線道路改修工事 20,000,000円`）は千円の項目の内訳なので、注記の積算にした（`yen_marked`・`yen_notes`）。
- **名前に充当を含む項目**: `長期債償還充当分` は充当の注記ではなく項目なので `plain_names` に宣言した。
- **名前の折り返し**: 長い名前は金額を次の行に印字する（`個人番号通知書・個人番号カード関連事務の委任に係る交付金` / `685`）。`wrap: amount_on_last_line`・`bare_amounts` で金額を名前の行に結ぶ。
- **公債費の円の内訳**: 公債費の元金・利子の説明に、地方債の種類・口数・円の額を1語に印字した行がある（117頁）。千円の項目の列に入らないので `excluded_boxes`（経費内訳）で外した。
- **COFOG**: 既存の規則に当たらない目が3つ（精神保健福祉費、上水道費、下水処理対策費）で、`cofog_rules.csv` の `kozushima-2022-01`〜`03` に置いた。
- 説明の分け方は「事業」。
