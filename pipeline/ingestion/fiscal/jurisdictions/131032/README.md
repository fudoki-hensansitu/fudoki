## 2026年度当初予算・歳出

当初予算書（1冊の text PDF）の事項別明細書を `generic_text` で取り込む。左頁に款・項・目（番号は3つの細い欄、名前は4つ目の欄、見出しは1つの「款 項 目」）・本年度・前年度・比較・財源内訳、右頁に節・説明を印字する。4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 会計 | ノード | 金額 | 款の和（千円）＝総括の歳出合計 |
| --- | ---: | ---: | ---: |
| 一般会計 | 951 | 1,263 | 214,300,000 |
| 国民健康保険事業 | 102 | 206 | 25,504,463 |
| 介護保険 | 70 | 136 | 20,007,381 |
| 後期高齢者医療 | 36 | 72 | 8,272,085 |

- **見開き**: 左頁は見出しの罫線しか引かず、右頁は目ごとに罫線を引くので、共通の見開きの判定では左右の頁が1つにならない。layout の `facing_pages` で「款 項 目」の欄のある頁と、その次の欄のない頁を1つの見開きにする。表の上に毎頁印字する「（款）」「（項）」の題は開いている款・項の繰り返しなので読まない。
- **款・項・目の番号**: 2桁の番号は右に揃えて印字するので、subject の `codes: right` で1桁と同じ段に読む。
- **読む頁**: 総括（款別の表）は明細と同じ木に入れないので、`pages` で明細の頁だけを読む。款の和は総括の頁（物理頁13・23・31・39）に印字された「歳出合計」と上の表のとおり一致することを別に確かめた。
- **金額の見出し**: 「本年度」「前年度」「比較」を `columns` の `heading` で本年度予算額・前年度予算額と宣言する。財源内訳は `excluded`。
- **説明**: 事業・施策の行と括弧の小計、・の内訳、円で印字する月額などの積算が1つの欄に並び、事業の木をまだ組めないので、今回は `excluded` で取り込まない。右頁は説明の見出しのすぐ下の罫の行に最初の目の目的を印字し、2段目の見出しとして読まれるので、`facing_pages` が欄を「説明」にそろえる。目の和は節の金額で確かめる。
- **2024・2025年度**: scan PDF。OCR の補読みが、罫線のすぐ脇のインクから左右の逆転した領域を作って止まるので、共通の OCR の直し（別 PR）を当てて2025年度の OCR は揃えたが、scan では見出しの下の罫線が拾えず見出しに本文が入るので、見出しを本文の縦罫から描き直して取り込んだ（下の節）。
