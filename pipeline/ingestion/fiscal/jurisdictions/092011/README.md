# 宇都宮市（092011）

栃木県宇都宮市。予算書・予算に関する説明書・決算書・決算審査意見書を公開していないので、財政課の要約の資料から一般会計の歳出と歳入を款の粒度だけで取り込む。

| 資料 | 年度 | 出典 |

| 当初予算 | R2〜R8 | 「予算の大綱」（https://www.city.utsunomiya.lg.jp/shisei/johokokai/zaisei/1010664.html）の「一般会計（歳出：目的別）」1頁と、その2頁前の「一般会計（歳入）」1頁 |
| 決算 | R2〜R7 | 決算の頁（https://www.city.utsunomiya.lg.jp/shisei/johokokai/zaisei/1010665.html）の「計数資料」4頁「歳出の状況（一般会計，目的別）」と2頁「歳入の状況（一般会計）」 |

## 読み方

- 科目の欄の見出しは「区分」とだけ印字されているので、見出しを「款」と宣言する。構成比・増減比（増減率）の欄は率なので読まない。前年度の欄は「前年度予算額」「前年度決算額」、増減の欄は「比較」と宣言する。
- 款の番号は欄の右に寄せて印字される（`1` と `10` の書き出しが1桁ずれる）ので、`hierarchy.subject.codes: right` で同じ段として読む。
- 決算の計数資料は、番号と名前が詰めて印字され、1語に読まれる（`1議`、`10教`）。そこで文書の quirk `glued_subject_codes` で語の頭の数字を番号として読み、`code_run_into_name` で右寄せをそろえる。`glued_subject_codes` が区切りの点の無い番号も読めるように、共通コードを直した。
- 決算の計数資料は、款と合計をそれぞれ千円に四捨五入して印字する（「※四捨五入の関係で内訳と合計が一致しない場合があります」）。R6・R7 は款の和と合計が1千円ずれるので、文書の quirk `rounded_items` を新しく作った。この quirk は、款の数から見て四捨五入で生じうる差の範囲なら一致とみなす。
- 款の和は、当初予算ではすべての年度で歳出合計と一致する。決算では R2〜R5 で合計と一致し、R6・R7 は四捨五入の範囲で一致する。

## R3 決算（OCR、2026-11-16）

計数資料の4頁は文字層の無いスキャンなので、OCR で読み、R4 と同じ見出しの宣言と quirk で取り込む。款の和 249,158,784 千円は印字された合計と一致する。合計の行は「合」「計」が離れて1字ずつ読まれ、単位の検査は桁の検査だけになる。

## 歳入（2026-11-23）

歳入は歳出と同じ冊の別の頁にあるので、選定の scope に足した（保存済みの出典はそのまま）。歳出の宣言を写し、次を変えた。

- **当初予算（予算の大綱「一般会計（歳入）」）**: 款の番号を印字せず、款を「自主財源」「依存財源」に分けて、その小計の行を款の上に挟む。小計の行は款の上の段に読まれるので、文書の quirk `uncounted_subject_lines` を新しく作り、宣言した名前の行を合計の行として読む（款にせず、段も作らず、数字は網羅の検査で `総括` として外す）。番号の無い款は、同じ年度の決算の計数資料が印字する番号を seed `fiscal_kan_code_fill` で当てる（款の名前は1対1で同じ。R8 は決算がまだ無いので R7 の番号）。
- **決算（計数資料「歳入の状況」）**: 款の番号を詰めずに印字し、名前を番号の上下の2行に折り返す（`株式等譲渡所得割` / `5` / `交付金`）。`code_between_name_lines` で3行を1つの款にし、`glued_subject_codes` で折り返した2桁の番号（`11`・`14`）の右寄せを番号の行で測る（歳出の `code_run_into_name` は使わない）。市債の下に「うち臨時財政対策債」を再掲するので、`uncounted_subject_lines` で款の和から外す（網羅の検査では `経費内訳`）。R2 は市債と「うち」の行の間に罫が無く、1つの款の名前に読まれるので、quirk が番号の行の下の宣言した行を切り離す。
- **R3 決算**: 2頁も文字層の無いスキャンなので OCR（Paddle、`vlm_fallback: false`）で読んだ。R4 の計数資料の前年度の欄（文字層）と款の金額がすべて一致する。款7・8の名前の行の組み違いと「繰人金」は `name_corrections`、市債と「うち」の行の間の点線の罫は `rule_ink` で宣言した。scan の変換が `rounded_items` を読むように共通コードを直した（款の和が四捨五入で合計と1千円ずれる）。
- 款の和は、当初予算ではすべての年度で歳入合計と一致する。決算は R2・R5・R6・R7 で合計と一致し、R3（1千円）・R4（2千円）は四捨五入の範囲で一致する。
