# 新島村（133639）

## 当初予算・歳出（2024・2025）

事務報告（令和6年・令和7年）の物理7頁「（３）令和<年度>年度一般会計当初予算」から、一般会計の款の総括（`<年度>/initial/`）を `paired_summary` で取り込む。項・目以下と特別会計・公営企業会計の明細は載っていない（出典の選定は `pipeline/source_selection/133639.json`。2026 は事務報告がまだ掲載されていない）。設定は `layouts/general_initial_<年度>.json`。

2023 は事務報告（令和5年）の同じ頁を `layouts/general_initial_2023.json` で読む（2024 と表の題の年度だけが違う）。

## 出典の癖（実測）

- **歳入と歳出が左右に並ぶ。** 表の題の1行の下に、左に歳入、右に歳出の款を同じ行の高さで印字する。頁には財政指数・特別会計・公営企業会計の小さな表も載る。右の「歳出」の枠の語だけを読み、網羅の検査にもその枠の語だけを渡す
- **款の番号が無く、名前が1字ずつ離れて印字される**（`議 会 費`）。字を左から繋いで名前にする
- **金額の欄に見出しが無い。** 表の題の「当初予算」のとおり `当初予算額` の見出しで持つ。単位は表の題の「（単位：千円）」
- 構成比の欄は取り込まない。款の和は「歳出合計」の行と一致する
- **dbt**: 款に番号が無いので、dbt では款を名前で同定する（seed `fiscal_kan_name_identity`）

## 当初予算・歳入（2023〜2025）

歳出と同じ頁の表の左の「歳入」の枠から、一般会計の款（村税〜村債）を `paired_summary` で取り込む（どちらの枠を読むかは設定の `frame` で決め、歳入も読めるようにした）。設定は `layouts/revenue_initial_<年度>.json`。款の番号は無く、金額の欄の見出しも無いので、歳出と同じく `当初予算額` の見出しで持ち、款は名前で同定する。款の和は3年度とも「歳入合計」と一致する（4,150,000・4,830,000・4,770,000千円）。

- 款「国有提供施設所在市町村助成交付金」（「等」の無い表記）を seed `fiscal_revenue_category` に足した
