一般会計と同じ予算書の会計ごとの頁から、国民健康保険・介護保険・後期高齢者医療・戸倉財産区・テレビ共同受信事業・武蔵引田駅北口土地区画整理事業の特別会計を、一般会計と同じ宣言（`ruled`、財源内訳の欄は取り込まない）で読む。

- 2024年度の後期高齢者医療は、見開きの右の頁（物理15頁）の紙面が左の頁（物理14頁）の紙面より説明の行が1つ少なく（`01 講師等謝礼 (138)` が無い）、右の頁の紙面から切り出すと節・説明が科目より1行上にずれる。右の頁も左の頁の紙面から切り出す（quirk `left_sheet_crop`）。物理12・13頁の紙面は同じ。款の和 2,639,075千円は総括の歳出合計と一致（96ノード・144金額）。

## 歳入（当初 R5〜R8・決算 R5・R6、2026-11-17）

歳出と同じ冊を、歳出の宣言を写して読む。説明・備考の欄は「歳入の説明」で外し、款・項・目・節で取り込む。当初は歳出と同じく一般会計だけで、範囲は予算事項別明細書の歳入の明細（物理11-28頁、R7 は物理11-29頁）。決算は一般会計と特別会計6つ（国民健康保険・後期高齢者医療・介護保険・財産区・テレビ受信・土地区画整理）の歳入事項別明細書の頁。R7 決算は選定していない。

- 当初の総括の頁（物理10頁）は歳入と歳出を左右に並べて刷るので、範囲から外し、歳入の明細の頁だけを読む。
- 決算の一般会計は款の番号を右に揃えて刷る（`9 環境性能割交付金` と `10 地方特例交付金` で頭が1字ずれる）ので、`codes: right` で款の段を読む。款の和は歳入合計と一致する。
