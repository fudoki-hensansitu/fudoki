# 多摩市 132241

## 2024〜2026年度当初予算・2024年度決算の特別会計・歳出（R6〜R8、2026-11-17）

当初予算の特別会計3つ（国民健康保険、介護保険、後期高齢者医療）は、下水道事業会計と合わせた1冊の特別会計予算書から、会計ごとに読む。2026年度の一般会計と同じ読み方（`workflow`）を写した。2024・2025年度の一般会計は CSV から取り込んでいるので、特別会計だけがこの PDF の変換になる。

2024年度決算の介護保険特別会計は、国民健康保険・後期高齢者医療と同じ読み方で読む。選定の範囲の頭（156〜161頁）に歳入歳出決算書の款・項の表があり、明細書の款と2度数えて款の和が歳出合計の2倍になるため、明細書の頁（171〜185頁）だけを `pages` で読む。介護保険の頁は字の一部（`審`・`療`・`合` など）が pdfium の字の箱で落ちて科目の名前が欠けるので、`traced_glyphs` で読む。

2025年度当初の介護保険特別会計は、第1表（歳入歳出予算）の次の頁（70頁）に第2表 債務負担行為の限度額があり、款の行に付いて読まれるので、その頁を `pages` から外す。

## 2020年度決算・歳出（R2、2026-11-17）

一般会計と特別会計3つ（国民健康保険、介護保険、後期高齢者医療）を、会計ごとに分かれた決算書の scan から読む。一般会計は3冊に分かれる。見開きの左頁に款・項・目と予算現額、右頁に節・支出済額・翌年度繰越額・不用額・備考を印字する。6つの変換は同じ読み方（`workflow`）を使い、3冊目だけ備考に `note_kinds` を足す（下）。

- 罫が淡く傾いているので、罫を濃い灰まで拾い（`rules.dark: 220`）、傾きを許し（`skewed`）、見出しの短い罫も読む（`short_columns`）。罫の切れ目を足し（`gapped_column_rules`）、罫の切れ端を罫の墨とみなす（`rule_ink`）。
- 節の欄は番号の位置で段を読み（breakdown `position`）、備考は字下げで読む（`indent`）。見開きごとに頁の位置が数pt ずれるので、段は欄の左の罫から測る（`column_edge`）。
- 一般会計の2冊目・3冊目は、前の冊で開いた目の途中から始まる（2冊目は 3民生費・2児童福祉費・4児童福祉施設費の節、3冊目は 10教育費・1教育総務費・2事務局費の節。そのあと 3教育指導費が続く）。続きの款・項・目を `continued_rows` で宣言し、頭の行をその下に付ける。冊の切れ目で子の和が印字の額にならない款・項・目は `expenditure.layout.json` の `source_inconsistencies` に書いた。
- 予備費の備考の充用先のうち、「へ」を次の行の頭に1字だけ印字した3行は、`note_kinds` で充用とし、名前を `name_corrections` で直す。
- OCR が墨の点や罫を数字と読んだもの（`dropped_readings`）、桁区切りをセミコロンと読んだ金額（`amount_corrections`）、罫だけの読み残し（`rule_pieces`）は、原画で確かめて宣言した。

## 歳入（当初 R6〜R8・決算 R3〜R7、2026-11-17）

歳出と同じ冊を、歳出の宣言を写して読む。説明・備考の欄は「歳入の説明」で外し、款・項・目・節で取り込む。

- 当初の一般会計: R8 は歳出と同じ一般会計予算書の総括の歳入（物理23頁）と歳入の明細（物理28〜147頁）。R6・R7 の一般会計は歳出を CSV から取り込んでいるが、CSV の歳入は書式ごとの staging がまだ無いので、同じ予算書の頁に載る一般会計予算書（06ippan.pdf・07ippan-1.pdf、R8 と同じ様式）を選定に足して読む（総括 物理23頁、明細 物理28〜141頁・28〜143頁）。
- 当初の特別会計3つは、歳出と同じ特別会計予算書の総括の歳入と歳入の明細の頁だけを `pages` で読む。選定の歳入の範囲の頭（議案・第1表）から読むと、明細の頁が表として読まれず、款・項だけの表になる。
- 決算は各会計歳入歳出決算書の歳入の頁。特別会計は範囲の頭に歳入歳出決算書の款・項の表があり、明細の款と同じ科目に2度数えて dbt の木の検査が合わないので、明細の見開き（節の欄がある頁）からを `pages` で読む。R5 の介護保険は歳出も取り込んでおらず、歳入も物理163〜164頁の見開きで目「介護保険保険者努力支援交付金」の収入済額が右の頁の行に結ばれず止まるので、取り込んでいない。
