# 小金井市 132101

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険、介護保険、後期高齢者医療）を取り込む。下水道事業は公営企業会計の別様式なので対象外。

決算書は scan で、一般会計は款ごとの分冊11冊、特別会計は会計ごとの分冊の歳出の頁。左頁に科目（款・項・目）・予算現額・節の区分と金額、右頁に支出済額・翌年度繰越額・不用額・備考がある。どの冊も同じ様式なので、読み方（`workflow`）は共通にした。一般会計の分冊は1冊で歳出合計が閉じないので `partial` にし、11冊の款の和を印字の歳出合計と照らした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計（11冊） | 各冊の全頁（計261頁） | 8,163 | 13,553 | 57,299,029,841 |
| 国民健康保険 | 1–9 | 295 | 1,135 | 10,785,742,869 |
| 介護保険 | 1–17 | 537 | 1,675 | 9,403,333,969 |
| 後期高齢者医療 | 1–3 | 101 | 392 | 3,271,486,508 |

- **冊の継ぎ目**: 一般会計の分冊は款の境で頁を切らず、前の冊の最後の頁と次の冊の1頁目に同じ頁を印字する（前の款の終わりと次の款の始まりが同じ頁にある）。1頁目も読むよう出典の選定の範囲を1頁目からにし（OCR の依頼 `general-*-ocr-p1`）、`dropped_bands` で、前の冊の最後の頁は次の款の行から下を、次の冊の1頁目は見出しの下から次の款の行の上までを除いた。同じ金額を2冊で数えない。
- **節**: 節はすべて1段なので、`marks: {"1": 1}` で番号のある行を1段にした。
- **備考**: 事業（番号）と内訳を字下げで印字する。事業名の折り返しは `wrap`・`hang_chars`・`name_start_slack` で前の行につないだ。「(9人)」のように括弧で始まる折り返しの行も、金額の無い直前の行と同じ書き出し・1字以内の行間なら前の行の続きにした（共通の処理）。
- **括弧の内訳**: 事業の下に、内訳の一部を括弧で印字する（「(ジャッキ1式 975,150)」）。内訳の和で事業の額にならないので、`note_kinds: {"(": "内訳"}` で注記にし、和に加えない。2行に折り返した括弧の行は1つの注記にした（共通の処理）。括弧を閉じずに印字した額（「(… 1,234,567)」の開き括弧が前の行）は、`amount_brackets` で括弧の額として読む（共通の処理）。
- **その1・その2・人数**: 「施設警備委託料その1」の番号や「会計年度任用職員報酬(14人)」の人数を OCR が別の語に読み、金額と取り違えた。「その」「第」「(」の直後の1〜3桁の数字を前の語につなぎ、行をまたいだもの（「その」で行が終わり、次の行頭が「1 (平成27年度導入分)」）も番号を前の行へ戻した（共通の処理）。
- **読み違いの名前**: 民生費（general-04）の物理5頁「3歳児健康診査に要する経費」は、番号「9」と名前の頭の「3」を1語に読んだ（「93歳児…」）。読みを `dropped_readings` で除き、番号と名前を `code_readings` で宣言した。
- **見出しの読み違い**: 総務費（general-02）の物理57頁は、右頁の翌年度繰越額の升の「繰」を「杀」と読み（「杀越明許費」「事故杀越し」）、繰越の2欄が同じ見出しになった。升の見出しを `header_readings` で宣言した。
