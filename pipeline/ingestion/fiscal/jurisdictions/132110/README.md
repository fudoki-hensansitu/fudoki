# 小平市（132110）

当初予算書（2023〜2026年度）と決算書（2023〜2025年度）の歳出・歳入を、一般会計と特別会計3つ（国民健康保険事業・後期高齢者医療・介護保険事業）で `generic_text` で取り込む。対象頁は出典選定の scope から読む。下水道事業会計は企業会計の様式（収益的収支・資本的収支）で款・項・目の明細を持たないので取り込まない。

## 決算書（2023〜2025年度）

一般会計の歳入歳出決算書は A3 横の1頁に左右の表を印字し、特別会計の決算書は A4 の左右の頁で1見開きにする。どちらも左側に款・項・目と予算現額（当初・補正・繰越・流用増減・計）・節、右側に支出済額（歳入は調定額・収入済額・不納欠損額・収入未済額）・翌年度繰越額・不用額・備考を印字する（単位円）。

- **見出し**: 欄の見出しに記号を添える（「当初予算額 Ａ」「計 Ｅ=Ａ+Ｂ+Ｃ+Ｄ」「支出済額 Ｆ」）ので、`columns` の `heading` で記号を除いた見出しを宣言した。節の欄は予算現額の見出しの下に印字されるので `axis_header` で節の軸にした。
- **枠**: 一般会計は左右の表の間の支出済額の欄に罫が無く、右端の縦罫が 3pt ずれた2本に描かれる頁がある。この2本を1本の縁として読む document quirk `stacked_tables_apart` を宣言した。特別会計は左頁の右端に縦罫が無いので `open_edge` で読む。
- **頁をまたぐ行**: 目が頁をまたぐと次の頁の頭に款・項・目の番号だけを印字し（「3 4 6」）、節も番号だけを繰り返す（「10」）ので、節に `repeated_code_at_top` を宣言した。備考の流用の注記は金額が次の頁の頭に印字されることがあるので `amount_on_next_page` を、特別会計（見開き）では2頁先へ続けるため `wrapped_names_over_pages` も宣言した。
- **歳入**: 備考（還付未済額の件数・金額）は除外の種類「歳入の説明」で外した。2025年度の目「衛生費負担金」の収入未済額は還付未済額を含み、節には載らないので `2025/settlement/revenue.layout.json` で宣言した。
- **共通コードの変更**: 1行だけの表の節の縦罫が 39.96pt に測られ縁にならなかったので、`layout._frames` の縁の長さを 39.9pt 以上にした（2025年度 物理46頁）。見出しの1行目が見出し全体の上の段に読まれる頁（2023年度 物理20頁「予算現額／継続費及び繰越／継続費及び繰越事業費繰越財源充当額」）を辞書の見出しに寄せる規則を `headers.canonical` に足した。

## 当初予算書（2023〜2026年度）

A4 の左右の頁で1見開きにし、左頁に款・項・目と本年度・前年度・比較、節の区分・金額（単位千円）、右頁に財源内訳の小表と説明（所管課・事業・細節と積算）を印字する。款・項・目・節は左頁で閉じるので、左頁だけを `pages` で読む（右頁の説明は今回は取り込まない）。左頁の右端に縦罫が無いので `open_edge` で読む。

- 前年度にだけあった項（2023年度 一般会計 物理57頁「災害救助費」、2026年度 国民健康保険 物理37頁「傷病手当金」）は番号を印字しないので直前の項の子に読まれる。`parent_corrections` で款の下に置き直した。2023年度は項と目の2行が1つの科目に読まれるので、目の行の数字を `excluded_boxes`（親の繰り返し）で除いた。
- 2023年度の歳入 物理28頁の項「特別土地保有税」（前年度だけ、番号なし）も同じく款「市税」の下に置き直し、目の行の数字を親の繰り返しとして除いた。
- 2025年度の介護保険事業特別会計の歳入（物理117頁）は文字層のフォントが欠けて数字が読めないので、この会計の当初予算の歳入だけ取り込んでいない。
