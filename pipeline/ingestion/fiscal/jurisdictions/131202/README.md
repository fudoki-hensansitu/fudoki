# 練馬区 131202

## 当初予算（予算説明書）・歳出

2024〜2026年度の当初予算の歳出は、会計ごとの4冊（一般会計、国民健康保険事業、介護保険、後期高齢者医療）を読む。2024・2026年度は scan、2025年度は文字PDF。読み方は表のパターン `stacked_blocks` で、3年度・4会計とも同じ。どの表も款の和が印字の歳出合計と一致する。

- 目ごとに3つの表を縦に積む: 款・項・目の表（本年度・前年度・比較）、財源内訳（左半分）と節（右半分）の表、説明の枠。1頁に目が1つ、または複数あり、長い説明は次の頁へ続く（頁の上に `説明` の見出しだけを印字する）。枠を読むと3つの表が上の表の欄で1つの枠になり、節は前年度の欄、説明は全部の欄に入る。見出しの行（`款 項 目 本年度…`・`財源 内 訳 … 節`・`区分 金額 …`・`説 明`）で頁の行を表ごとに分け、節と説明をそれぞれ右へずらした欄として読む（見開きの右頁と同じくずらした量を持つので、網羅の検査は印字の位置で行う）。
- 説明の続きの頁は、前の頁と罫がそろうと見開きとしてつながれるので、1頁ずつに分け直す。
- 目の名前が長いと、番号と金額の行の上下に折り返す（`後期高齢者医療` / `1 12,248,824` / `保険料拠出金`）。上下の行を番号の行につなげる。番号の無い項・目（その年度で0の `傷病手当金`）は、名前の書き出しから番号1つ分左の段として読む。
- 財源内訳は取り込まず、除外枠（財源内訳）にした。説明の行末の丸数字は節の番号なので除外枠（本文）にした（OCR は `⑫` を `12`・`①2`・英字に読み、金額につなげることもある）。説明の中の見込みの数（`年間受診件数見込 2,174,553 件`、`1回 185,000 部`、`戸籍数 238,291 戸 6.1.1現在`）も除外枠（本文）にした。
- OCR の読み崩れ: 説明の太字の金額をカンマで2語に分ける（`12` `248,824`、`38` `,786`）、欄の金額を2つ以上に分ける（`118` `11` `2` `4`、`30` `00`）。つなげて3桁ごとに区切り直す。節の番号と字を空けた名前（`11` `役` `務` `費`）は1つの節にし、名前の書き出しをそろえる（節は1段だけ）。片仮名の後の長音を漢字の「一」に読む（`ホ一ル`）と行頭の `ホ` が番号に見えるので「ー」に直す。`(1) 事務費` の名前は番号の直後に置く（下の段の名前と同じ位置に来ると、下の行がその名前の続きと読まれる）。
- 国保の初めの頁は、会計の題（`3 歳出`）が枠の見出しに読まれる。番号の `3` は除外枠（本文）にした。
