# 練馬区 131202

## 当初予算（予算説明書）・歳出

2024〜2026年度の当初予算の歳出は、会計ごとの4冊（一般会計、国民健康保険事業、介護保険、後期高齢者医療）を読む。2024・2026年度は scan、2025年度は文字PDF。読み方は表のパターン `stacked_blocks` で、3年度・4会計とも同じ。どの表も款の和が印字の歳出合計と一致する。

- 目ごとに3つの表を縦に積む: 款・項・目の表（本年度・前年度・比較）、財源内訳（左半分）と節（右半分）の表、説明の枠。1頁に目が1つ、または複数あり、長い説明は次の頁へ続く（頁の上に `説明` の見出しだけを印字する）。枠を読むと3つの表が上の表の欄で1つの枠になり、節は前年度の欄、説明は全部の欄に入る。見出しの行（`款 項 目 本年度…`・`財源 内 訳 … 節`・`区分 金額 …`・`説 明`）で頁の行を表ごとに分け、節と説明をそれぞれ右へずらした欄として読む（見開きの右頁と同じくずらした量を持つので、網羅の検査は印字の位置で行う）。
- 説明の続きの頁は、前の頁と罫がそろうと見開きとしてつながれるので、1頁ずつに分け直す。
- 目の名前が長いと、番号と金額の行の上下に折り返す（`後期高齢者医療` / `1 12,248,824` / `保険料拠出金`）。上下の行を番号の行につなげる。番号の無い項・目（その年度で0の `傷病手当金`）は、名前の書き出しから番号1つ分左の段として読む。
- 財源内訳は取り込まず、除外枠（財源内訳）にした。説明の行末の丸数字は節の番号なので除外枠（本文）にした（OCR は `⑫` を `12`・`①2`・英字に読み、金額につなげることもある）。説明の中の見込みの数（`年間受診件数見込 2,174,553 件`、`1回 185,000 部`、`戸籍数 238,291 戸 6.1.1現在`）も除外枠（本文）にした。
- OCR の読み崩れ: 説明の太字の金額をカンマで2語に分ける（`12` `248,824`、`38` `,786`）、欄の金額を2つ以上に分ける（`118` `11` `2` `4`、`30` `00`）。つなげて3桁ごとに区切り直す。節の番号と字を空けた名前（`11` `役` `務` `費`）は1つの節にし、名前の書き出しをそろえる（節は1段だけ）。片仮名の後の長音を漢字の「一」に読む（`ホ一ル`）と行頭の `ホ` が番号に見えるので「ー」に直す。`(1) 事務費` の名前は番号の直後に置く（下の段の名前と同じ位置に来ると、下の行がその名前の続きと読まれる）。
- 国保の初めの頁は、会計の題（`3 歳出`）が枠の見出しに読まれる。番号の `3` は除外枠（本文）にした。

## 歳入（当初 R5〜R8・決算 R5・R6、2026-11-17）

歳出と同じ冊・同じ読み方で歳入を読む。選定の scope に各会計の歳入の頁を `revenue` で足し、歳出の宣言を写して、当初は説明の欄（`columns.説明.excluded`）、決算は備考の欄（`columns.備考.excluded`）を除外の種類「歳入の説明」で外した。節の breakdown は `flat`。当初 R6・R8 は scan で、歳入の冊を歳出と同じ設定（1帯・長辺 3600、`vlm_fallback: false`）で OCR した。

| 当初 R6 | 323,088,364 | 65,103,843 | 63,632,520 | 20,142,207 | |
| 当初 R7 | 351,685,775 | 64,627,639 | 64,092,086 | 20,359,840 | |
| 当初 R8 | 368,681,005 | 68,108,576 | 65,355,894 | 21,566,203 | |

各年度の前年度予算額の和は前の年度の本年度予算額の和と、決算 R5・R6 の当初予算額の和は同じ年度の当初の本年度予算額の和と、どの会計も一致する。決算の収入済額の和は R5 一般会計 323,588,004,376 円、R6 一般会計 337,795,193,375 円。

- **節の枠**: 歳入の目の下は、節の番号・名前と金額を款・項・目と本年度の欄に、その説明を右の欄に、同じ行で印字する（見出し `節 金額 説明`）。`stacked_blocks` は見出し「節金額説明」を歳入の節の表として読み、節を歳出の節の表と同じ欄へ移す。説明の行は表全体（説明の中の調定額・収入率などの小さな表も）を除外枠にし、その中の読めない墨は金額の欄の墨としない（`scan.declared_unread`）。
- **続きの頁**: 頁が目の途中の節から始まると、見出しの無い頁の初めの行が款・項・目か節か分からない。金額のある初めの行が前年度の欄にも金額を持つ（または比較の欄に金額を持ち前年度の欄に説明の字が無い）なら款・項・目、そうでなければ節として読む。scan は見出し `節 金額 説明` を知っている見出しに読み替えるので、見出しでは分けない。説明の折り返し（`(補助率10/10,`）の数字は金額としない。
- **枠のずれ**: 頁ごとに枠の左端が交互にずれる。見出しから欄を読めない頁は、前の頁の欄を枠のずれの分だけ動かす。節の表が款・項・目の欄を区切る頁（見出し `款項目` が節の番号の上だけにかかる）は、その頁の欄を使わない。
- **OCR の読み崩れ**: 節の金額と説明の書き出しを1語に読む（`536入院助産費本人負担金`）、金額の末尾の字を本年度の欄の外に分けて読む（`8` `5`）。欄の右端で分け、末尾の字は金額へ戻す。介護保険の初めの頁の題を旧字（`2 歲入`）に読むので、題の番号として外す。当初 R6 の頁5の款10は名前の2行目（`特別交付金`）を読み落としたので、`name_corrections` で直した。
