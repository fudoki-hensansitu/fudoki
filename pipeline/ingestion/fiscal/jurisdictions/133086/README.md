# 奥多摩町 133086

## 2024〜2026年度当初予算・歳出（一般会計）

一般会計予算書の事項別明細書を読む。1頁に目・節・説明を並べ、頁の上に `(款) ０１ 議会費 (項) ０１ 議会費` を1行で印字する（`running_titles`、`titles_on_one_line`）。項が頁の途中で替わると、次の項の題字と表を見出し無しで同じ頁に続ける。

- 範囲は総括の頁（款の金額と歳出合計）と明細の頁に絞る（`pages`）。財源内訳の欄は取り込まない。単位の検査は、項ごとの「合計」ではなく総括の頁の「歳出合計」と比べる。
- 見出しの「目(事業)」の欄に、目（`01 議会費`）と、その下の事業（`(01)議会事務局費`）を段に分けて印字する。欄を「目」と宣言して `bands` で読み、事業の段は `fourth_level_axis: 事業` で目の内訳にする。事業の行は `bracketed_subjects` で番号の付いた項目として読み、金額は名前の次の行に印字するので `amounts: next_row`。
- 目の行には節と説明（事業の一覧）を並べ、事業の行の下に事業ごとの節と説明を並べる。目は目の行の節・説明・事業のそれぞれで子の和と比べる。
- 事業の名前は金額の欄の縦罫を越えて印字され（その行だけ縦罫が無い）、文字層は罫の位置で語を切る。`rules.row_gaps` で前の語の欄で読む。
- 頁の頭に目を括弧で繰り返し（`09 （地域振興費）`）、金額も刷り直す。繰り返しの行は金額を持たず（`repeated_heading_owns_nothing`）、前の頁の目の金額と同じ行として網羅の検査から外す。
- 見出しは罫線1段（`one_row_header`）。
- その年に無くなった目は番号を印字せず、名前を事業の段の位置に置き、金額を名前の行に印字する。その下の事業は番号を空けて `( )参議院議員選挙費` と印字する。名前の行に金額のある番号の無い項目を目として読む（`codeless_priced_moku`）。番号の空いた事業の名前は印字のまま `()` で始まる。
- 分け方は 事業→事業、節→節、説明→その他（目の行の説明は事業の一覧、事業の行の説明は節の細目）。

## 2024年度決算・歳出

一般会計（text）と、scan の特別会計3つ（国民健康保険、後期高齢者医療、介護保険）を取り込む。text の都民の森・山のふるさと村の特別会計はこの管理JSONに含めない。下水道事業・病院事業は公営企業会計の別様式なので対象外。

決算書は会計ごとの冊の歳出の頁。左頁に科目（款・項・目・事業）・予算現額の内訳・節の区分と金額、右頁に支出済額・翌年度繰越額・不用額・備考がある。4冊とも同じ様式なので、読み方（`workflow`）はほぼ共通にした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 国民健康保険 | 13–20 | 152 | 864 | 644,125,807 |
| 後期高齢者医療 | 11–14 | 69 | 361 | 233,405,696 |
| 介護保険 | 16–23 | 162 | 787 | 845,628,363 |
| 一般会計（text） | 32–134 | 3,183 | 9,498 | 6,993,624,326 |

- **科目の欄**: 款・項・目・事業の名前は、段ごとに字下げした階段状の升に印字する。罫線で欄に分けると名前が升をまたいで切れるので、`columns` で「事業」の欄を科目の欄（`axis_header: 科目`）にし、款項目と1つの欄として字下げで段を決めた。節の見出し「予算現額／区分／節」も同じく節の欄にした（金額の見出しと読まれないようにするため）。
- **事業の段**: 款項目の下に事業（「(01)一般管理費」）の段がある。科目は款・項・目の3段なので、`hierarchy.subject.fourth_level_axis: 事業` で、4段目を目の内訳（事業の軸）にした。節と備考は事業の下に付く。事業の名前の行は、科目の欄と金額の欄の間の縦の罫線が途切れたところに印字され、名前が金額の欄へはみ出す。`rules.row_gaps` で、その行で途切れている罫線では OCR の行を切らないようにした（共通の処理）。
- **事業の金額**: 事業（「(01)一般管理費」）は名前の行に金額を印字せず、罫線で区切った次の行に金額だけを置く。`hierarchy.subject.amounts: next_row` で、その行の金額を1つ上の行の事業のものにした。頁の最後の事業の金額が次の頁の最初の行に来るものも同じ事業に付けた（共通の処理）。
- **備考**: 節の行の横に、節の内訳を備考として印字する（「10 需用費」の横に「消耗品費」「印刷製本費」）。備考は節の升の高さの中央に揃うので字下げでは節に結べない。`under: 節` で、備考を同じ罫線の行の節の子にした。頁の終わりで続く備考（「12 委託料」の内訳が次の頁の頭に続く）は前の頁の最後の節に付けた（共通の処理）。見出しだけで金額の無い備考は `headings` で子の和で閉じる。
- **予算現額の見出し**: 「継続費及び繰越事業費繰越額」「予備費支出及び流用増減」の升は3行に分けて印字し、OCR が字を重ねて読む（「繰越額額」「流流用増減」）頁がある。どの頁も同じ位置なので、升の見出しを `header_readings` で宣言した。
- **翌年度繰越額の見出し**: 升の見出しの下に繰越の種類（継続費逓次繰越・繰越明許費の別・事故繰越）を小さく並べ、行ごとにどの種類かを金額の横に印字する。種類は見出しではないので、升の見出しを `header_readings` で「翌年度繰越額」と宣言した。
- **読み違いの名前**: 「ケア」の「ア」を「了」、「サービス」の「ー」を「一」、「値」を「值」と読んだ4か所を `name_corrections` で直した。
- **2行の科目名**: 目の名前が2行に折り返し（「01 審査支払手数」/「料」）、金額が2行の間に印字されて2行目に付き、名前が分かれる。会計ごとに2〜5か所の読みを `dropped_readings` で除き、番号と名前を `code_readings` で宣言した。
- **後期高齢者医療の歳出合計**: 歳出合計の行の翌年度繰越額の欄に、繰越の種類の頭文字（逓・明・事・計）を縦に並べて印字する。見出しと読まれないよう欄を金額の欄（`kind: amount`）にし、頭文字の読みを `dropped_readings` で除いた。
- **繰出金の受け手**: 国民健康保険の目「病院事業会計繰出金」の受け手（国民健康保険病院事業会計）を、`account_kind_map` に「病院事業会計」→ 病院事業として足した。

### 一般会計（text）

特別会計と同じ様式で、1頁に左右の欄をまとめて印字する。読み方（`workflow`）は特別会計とほぼ同じにした。

- **科目の欄・事業の段・事業の金額・備考**: 特別会計と同じ設定（`columns` の「事業」を科目の欄、`fourth_level_axis: 事業`、`amounts: next_row`、備考の `under: 節`）。
- **事業名のはみ出し**: 事業の名前の行は、事業の欄と当初予算額の欄の間の縦の罫線が途切れたところに印字され、名前が当初予算額の欄へはみ出す。文字の層は名前をその罫線の位置で2語に分ける（「災害対策用職員住宅管」「理費」）。`rules.row_gaps` で、その行で罫線が引かれていなければ、前の語に続く語を前の語の欄で読むようにした（共通の処理。scan では OCR の行を切らない設定）。
- **2行の科目名**: 「03戸籍住民基本／台帳費」（項）のように名前が2行に折り返し、金額が2行目の高さに印字される。2行目は名前の書き出しに揃うので、番号と名前の1文字目が1語になった語（「03戸」）でも、番号の幅を半角で見積もって名前の書き出しを求めた（共通の処理。text の科目だけに効く）。
- **備考の名前**: 「高額調整事務委託」（物理68頁）の次の行から流用の備考（「070000事19節へ」「50,883円流用」）が始まり、1つの流用の注記と読まれた。`plain_names` で項目と宣言した。
- **番号の後に数字で始まる事業名**: 「(01)１歳６か月児健康診査事業費」など5件は、番号の閉じ括弧が名前の頭に残る（「)1歳6か月…」）。`name_corrections` で直した。
- **流用・充当の備考**: 「05項01目040000事03節へ／20,630円流用」のような備考は注記として取り込めず、網羅の検査では報告に回る（金額の和には関わらない）。
