## 当初予算の一般会計（文字 PDF、2026-11-11）

R6〜R8 の一般会計は予算説明書（歳出事項説明書、R6 fin03・R7 fin03・R8 fin07）を汎用の変換器で読む。特別会計と同じ設定に、quirk
`repeated_subject_headings` を足す。

- **目が頁をまたぐと、次の頁の科目の欄の最初に、開いている項・目の名前だけを番号なしで再掲する**（`総務管理費` / `一般管理費`）。
  再掲は本来の名前より 5pt 左（番号の位置）から始まり、次の番号と同じ罫の枠に入ると、その番号の名前の頭に付いて
  （`30 総務管理費企画費`）科目の段が4段に割れていた。quirk `repeated_subject_headings` で枠の番号より上の行を再掲として外す
- **R6 は説明の内訳の名前が頁の最後に来て、金額が次の頁の最初の行に1つだけ印字される箇所がある**（p23→p24 `155,353`、p24→p25）。
  R6 の説明の欄に quirk `amount_on_next_page` を付け、その金額を前の頁の名前の項目に付ける
- 款の和は最終頁の印字の「合計」と一致する（R6 127,830,000千円、R7 121,910,000千円、R8 133,090,000千円）
- R6 の特別会計・公営企業会計は輪郭線描画のスキャンで、まだ取り込んでいない（管理 JSON は一般会計だけ）

## 2023年度決算（R5、7表：一般会計・国保・後期・介護・公共用地・競走・下水道、2026-11-15）

2024年度の決算と同じ宣言で読む。R5 で足りなかった読みは3つで、どれも宣言した表にだけ効く（`scaled_spread_pages`・`tall_kind_stacks` は一般会計だけ）。ノード/金額は一般会計 2,841/6,640・国保 155/560・後期 66/244・介護 170/552・公共用地 31/73・競走 167/329・下水道 167/424。決算書は歳出合計を印字せず、款の和は照合できない（桁のみ確認）。7 表とも木の検査（`verify_sums`・`verify_coverage`）は不用額の宣言（下記）のほかすべて一致する。

- **p216 だけ、左頁が右頁より4.2%大きく印字される**（行の罫が 39pt 間隔、右頁は 37.4pt）。1つのずれでは行の罫が合わず、見開きの2頁が別々の論理頁になり、右頁の備考が最後に開いた目へ付いていた。quirk `scaled_spread_pages` で、罫の並びが最大10%の拡大で合うときは見開きとして結ぶ（座標は書き換えない）。
- **p94 `25 財産管理費` は種別の行が7行重なり、最後の `流用増減 -32,783,000` が目の名前から 62pt 下にある**（既定は名前から 6 行の高さ）。同じく p88 `予備費支出 300,000`、p128 `流用増減 -66,580,000` も届かない。quirk `tall_kind_stacks` で 8 行の高さまで読む。
- **下水道の不用額は項・目の和が印字より大きい**。支出済額が予算現額を超えた目は不用額が 0 と印字され、超過分は負にならない（款 13,748 円、項「営業費用」16,155,462 円、項「営業外費用」23 円）。`expenditure.layout.json` で宣言した。

歳出と同じ決算書の歳入の事項別明細書を、歳出の宣言を写して読む（`revenue.json`、歳入の頁は選定の scope）。一般会計と国保・後期高齢・介護・公共用地の4特別会計。特別会計の歳入は、各会計の歳出の前の「【歳入】」の頁。2025年度の特別会計は歳出が後期高齢だけ取り込み済みなので、後期高齢の宣言を写した。
