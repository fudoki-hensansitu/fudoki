## 当初予算の一般会計（文字 PDF、2026-11-11）

R6〜R8 の一般会計は予算説明書（歳出事項説明書、R6 fin03・R7 fin03・R8 fin07）を汎用の変換器で読む。特別会計と同じ設定に、quirk
`repeated_subject_headings` を足す。

- **目が頁をまたぐと、次の頁の科目の欄の最初に、開いている項・目の名前だけを番号なしで再掲する**（`総務管理費` / `一般管理費`）。
  再掲は本来の名前より 5pt 左（番号の位置）から始まり、次の番号と同じ罫の枠に入ると、その番号の名前の頭に付いて
  （`30 総務管理費企画費`）科目の段が4段に割れていた。quirk `repeated_subject_headings` で枠の番号より上の行を再掲として外す
- **R6 は説明の内訳の名前が頁の最後に来て、金額が次の頁の最初の行に1つだけ印字される箇所がある**（p23→p24 `155,353`、p24→p25）。
  R6 の説明の欄に quirk `amount_on_next_page` を付け、その金額を前の頁の名前の項目に付ける
- 款の和は最終頁の印字の「合計」と一致する（R6 127,830,000千円、R7 121,910,000千円、R8 133,090,000千円）

## 2024〜2026年度当初予算・2025年度決算・歳出（特別会計、2026-11-17）

- 2024年度当初予算の特別会計の scan は、科目の欄に段ごとの枠を引くが、右揃えの番号が段の枠をはみ出す（項「5」が目の枠に入る）。番号の始まりで段を学び、2桁の番号は1桁の番号の始まりに揃えて読む（opt-in の quirk `codes_across_level_rules`）。`digit_set_codes` は内訳の番号だけに効く。2桁の番号は罫をまたいで刷られ、OCR が「10」を罫のところで「1」と「0」に分けて読む（款は表の枠の左端、項は項の枠の罫）。そのため opt-in の quirk `two_digit_codes_over_rules` で、罫を1本だけまたぐ2桁の番号を分けずに読む。2024年度は罫から右の枠の番号として読む（`true`）。2025年度当初予算の国民健康保険の scan は、2桁の番号が1桁の番号と同じ位置から刷られるので、OCR の位置のまま読む（`left`、`codes_across_level_rules` は使わない）。番号は 2026年度の文字 PDF の番号と合う（移送費 13・国民健康保険事業費納付金 18・特定健康診査等事業費 3 を含む）。

## 歳入 2023〜2026年度当初予算（一般会計と4特別会計、2026-11-23）

当初予算の歳出に揃えて歳入を取り込む（`initial/revenue.json`）。2023年度は歳出が一般会計だけなので一般会計だけ。公営企業会計（競走・下水道）は収益的収入・資本的収入で、歳入の木とは別の体系なので取らない。

- **一般会計の歳入は別冊の予算説明書（歳入事項説明書、R5〜R7 fin02・R8 fin06、文字 PDF、全頁が歳入）にある**。歳出の選定は歳出事項説明書だけだったので、各年度の選定に冊を足して保存し直した（`archive.ts --replacement-selection`。新しい冊は `initial-8.pdf`、既存の冊の key・sha は変えない）
- **特別会計の歳入は、歳出と同じ冊の【歳入】の頁**（各会計の歳出の前。国保 p6〜8・後期 p6〜7・介護 p6〜9・公共用地 p7〜8）。冊の頭の第1表（款・項の総括）は scope に入れず、明細の頁だけを読む。明細の末に印字の「合計」がある
- 宣言は同じ年度の歳出の宣言を写す。財源内訳の欄は歳入に無いので外し、説明の欄（調定額・収入歩合・補助の基本額と率）は除外の種類「歳入の説明」で外す。説明の breakdown は持たない
- 文字 PDF は、頁の頭に続きの項・目の名前を番号なしで印字し直し、それが次の番号の名前に付く（一般会計 `国庫負担金衛生費国庫負担金`、2026 介護 `財産運用収入利子及び配当金`）。特別会計にも歳出の一般会計と同じ quirk `repeated_subject_headings` を選ぶ
- scan（2024年度の4特別会計・2025年度の国保）は歳出と同じ依頼（`page_strips: 1`・`detection_limit_side_len: 3600`・`letterspaced_names`・`vlm_fallback: false`）で歳入の頁だけを OCR した。頁の頭の印字し直した見出しは `dropped_readings` で除く（2024 介護 p7、2025 国保 p8）。2024 公共用地の項 `財産売払収入` は Paddle が「売」を「壳」と読むので `name_corrections` で直す。国保の節 `22 財政安定化支援事業繰入金` は最後の字「金」を次の頁の頭に刷るので、続きの字の読みを除いて名前を直す（2024・2025）
- **2025年度の国保の歳入の頁は2桁の番号を右揃えで刷る**（`10 国庫補助金` は `5 都補助金` より1桁左から始まる。同じ冊の歳出の頁は1桁の番号と同じ位置から刷る）。`codes: right` と `digit_set_codes` の両方が2桁の番号をずらし、2桁の目が4段目に読まれたので、歳入の宣言からは `codes: right` を外して `digit_set_codes` だけでずらす。p8 の節 `25 その他一般会計繰入金` は番号と名前を1語に読み、名前が他の節より6pt右に置かれて前の節の細節に読まれたので、`code_readings` で番号と名前を印字の位置で読む
- 2024年度の公共用地の款 `繰入金`（0千円）は本年度に廃した款で、款・項・目とも番号を印字しない。印字のとおり番号なしで持つ（手元の dbt は通る）
- 単位は16表すべて、款の和が印字の「合計」と一致する（受領書の注記）。単位の検査の区分は一般会計が `digits`、特別会計が `unchecked`
