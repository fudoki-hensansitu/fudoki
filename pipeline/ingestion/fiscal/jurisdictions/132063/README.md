# 府中市（132063）

## 当初予算の一般会計（文字 PDF、2026-11-11）

R6〜R8 の一般会計は予算説明書（歳出事項説明書、R6 fin03・R7 fin03・R8 fin07）を汎用の変換器で読む。特別会計と同じ設定に、quirk
`repeated_subject_headings` を足す。

- **目が頁をまたぐと、次の頁の科目の欄の最初に、開いている項・目の名前だけを番号なしで再掲する**（`総務管理費` / `一般管理費`）。
  再掲は本来の名前より 5pt 左（番号の位置）から始まり、次の番号と同じ罫の枠に入ると、その番号の名前の頭に付いて
  （`30 総務管理費企画費`）科目の段が4段に割れていた。quirk `repeated_subject_headings` で枠の番号より上の行を再掲として外す
- **R6 は説明の内訳の名前が頁の最後に来て、金額が次の頁の最初の行に1つだけ印字される箇所がある**（p23→p24 `155,353`、p24→p25）。
  R6 の説明の欄に quirk `amount_on_next_page` を付け、その金額を前の頁の名前の項目に付ける
- 款の和は最終頁の印字の「合計」と一致する（R6 127,830,000千円、R7 121,910,000千円、R8 133,090,000千円）
- R6 の特別会計・公営企業会計は輪郭線描画のスキャンで、まだ取り込んでいない（管理 JSON は一般会計だけ）
