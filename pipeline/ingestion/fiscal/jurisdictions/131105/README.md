# 目黒区 131105

## 当初予算・歳出（2024〜2026年度）

一般会計・特別会計3つ（国民健康保険、後期高齢者医療、介護保険）を取り込む。読み方は共有の reading `labelled_spread`（宣言は `layouts/text_budget/reading.json`）で、4会計・3年度とも同じ。

予算書は1冊の text PDF。各会計の歳出は、款・項の総括（款｜項｜金額、末尾に歳出合計）のあと、見開きの事項別明細が続く。左頁は題に款と項を1行で印字し（`１款 議会費 １項 議会費`）、枠に目・予算額・本年度の財源内訳・節（区分・金額）を持つ。右頁は説明の1欄で、目の区切りの罫線を左頁と同じ高さに引く。

- **款・項**: 総括の頁から款・項と本年度の金額を読み、明細の題で目を項に結んだ。項の金額は項の最後の「計」の欄（本年度・前年度・比較）から取り、総括の項の金額は同じ額の再掲として除外（総括）にした。
- **予算額の欄**: 1つの欄に `本年度`・`前年度`・`比較`・`増減率(%)` の行を印字する。前の3つを本年度予算額・前年度予算額・比較とし、増減率は率で金額でないので除外（数量表）にした。
- **番号の無い款・項・目**: 前年度にあって本年度の予算が無い款・項・目は、番号を付けず括弧で名前を印字する（`（退職被保険者等療養給付費）`）。番号の無い項目として取り込み、款・項は総括に載らないので題から作った。
- **説明**: 番号 `1`・`(1)` の項目と右端の金額（千円）を説明の内訳にした。人数・か所などの数量の行は除外（数量表）にした。
- **枠の辺**: 2025・2026年度の冊は、枠の上辺と右辺を1本の折れ線で描く。reading の中で、折れ線の軸に平行な辺を罫線として読む。
