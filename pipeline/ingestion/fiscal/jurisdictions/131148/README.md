# 中野区 131148

## 2023〜2026年度当初予算・2023〜2025年度決算・歳入（2026-11-17）

一般会計・用地特別会計・国民健康保険事業・後期高齢者医療・介護保険の歳入を、歳出と同じ冊から generic で取り込む（`revenue.json`）。

- **当初予算**（予算説明書、文字PDF）: 歳出と同じ `running_titles` で読み、金額の見出し「本年度」「前年度」を「本年度予算額」「前年度予算額」と宣言する。説明は除外の種類「歳入の説明」で外す。
- **決算**（決算書、文字PDF、`ruled`・`bands`・節は `indent`）: 備考を「歳入の説明」で外す。
- **2023・2024年度決算の右頁**: 見開きの右頁は、最初の欄（調定額）の左に縦の罫が無く、横の罫だけが頁の左端から引かれている。罫の縦線だけで欄を切ると調定額の欄が表の外になり、調定額が黙って抜けた。`spread.gutter: 0.05` で、頁の左端の近くで横の罫が始まる位置を表の左端にする（2025年度の冊は左の罫がある）。
- 調定額と収入済額が同じ額の行で収入済額が落ちる件は、共通コードで直した（#874）。歳入の宣言に quirk は要らない。
