## 当初予算・一般会計の歳出（2026-11-11）

2026（R8）当初は予算書（`R8_yosansyo_2.pdf`）の歳出事項別明細書を `generic_text` で取り込む。宣言と保存参照は `2026/initial/expenditure.json`。ノード2,580・金額2,966、木の検査は一致350／不一致0、款の和は207,674,590千円、数字の網羅は止まり0、Jevへの質問0件。

- **先頭の金額の欄**: 見出しが「本年度」だけで、その文字がどれも財源内訳の4欄の見出しに含まれるため、見出しの文字で欄を引く規則が財源内訳と読んで除外していた。`columns` に `本年度: {kind: amount}` を宣言して金額の欄として読む。
- **説明の主な内訳**: 説明の欄は番号のある事業（`1. 議員人件費 417,158`）の下に、番号の無い主な経費を `)` の右の金額で印字する（`議員報酬 239,040` など）。一部だけを挙げる（`3. 議会活動費 79,670` の下は `速記料 11,956`・`政務活動費 25,920` だけ）うえ千円未満の端数で1千円ずれる事業もあり、事業の額にならない。quirk `listed_highlights` で注記（内訳）にし、事業の和に加えない（876件）。事業の和は目の本年度と一致する。
- 総括の頁（25頁）の財源内訳の欄は見出しが明細の頁と違う（`本年度予算額の財源内訳／…`）ので、取り込んだままにした。

## 当初予算 R6・R7 の歳出（一部、2026-11-11）

2024（R6）・2025（R7）当初は公式に予算書の掲載が無く、部別予算概要説明書(2)の「事業別支出科目一覧」を `generic_text` で取り込む。宣言と保存参照は `2024/initial/expenditure.json`・`2025/initial/expenditure.json`。一般会計と特別会計4会計（国民健康保険事業・介護保険事業・後期高齢者医療事業・鶴川駅南土地区画整理事業）を保存した。

- **一部だけ（`partial`）**: この一覧は職員人件費・会計年度任用職員人件費・予備費の行を載せず、款・項は番号だけで名称も金額も印字しない。歳出合計も印字しないので、款の和は照合しない。全会計を `partial` とした。
- **白文字の重ね刷り**: 各行に款項目の番号・目名・事業名を白文字で重ね刷りしている。修復 `white_text` で白い文字を除いて語を組み直す（pdfium は同じ字が同じ位置に重なると白い方を残すので pdfplumber で読む）。語は字間 0.3 行高を超えたら切る（事業名・所属名が隣の列の数ポイント手前まで伸びるため）。
- **列と行**: 本文に縦の罫線が無いので、layout `listed_projects` で見出しの列の罫線を枠の下まで伸ばし、本文の各行の間に横の罫線を引いて1行ずつ読む。
- **所属名**: 列 `所属名` は取り込まない（課の名前で、金額でも木の段でもない）。
- **全角数字で始まる名前**: 節の `２１世紀職業財団賛助会員負担金` が番号21と読まれないよう、document quirk `full_width_names` を選ぶ（番号は半角だけで印字される）。
