## 2026年度当初予算・一般会計（2026-11-13）

出典は予算書の事項別明細書の scan で、款ごとに分かれた13冊（選定の scope の PDF）。汎用の生成機 `generic_scan` で1冊ずつ読み、どの冊も `partial` にする（冊ごとに歳出合計とは照合できない）。13冊の款の和 38,889,000 千円は第13冊（予備費）に印字の歳出合計と同じ。13冊とも木の不一致 0・未所属の額 0。

- 見開きの左の頁に款・項・目と本年度・前年度・比較・財源内訳、右の頁に節と説明を印字する。罫で読み（`ruled`）、見出しは段組み（`staircase`）と見開き（`facing_pages`）。財源内訳の4欄は歳出の金額ではないので外す。
- 節の番号は法定の番号（`legal_setsu_codes`）。説明は 事業 → 節 → 細節・項目 の段で、番号の位置では事業と節を分けられないので、法定の節の名前と番号で分ける（`setsu_lines`）。
- 節の額が欄の右の罫に寄り、説明の番号と1つに読まれる（`445,6791`、2桁の額の箱が罫を越える `15`）ものは `code_after_amount` で分ける。額が3桁以下で区切りの無いもの（`1124 共済費`）と、本年度の額の末尾に前年度の頭の字が重なったもの（`2,821,3332`）は、原典の描画で確かめて読みを宣言する。
- 第5冊（労働費 14 千円）は額が小さく金額の欄と判定できないので、欄の種類を宣言する。第13冊の節「予備費」は番号を持たず見開きの左の目と同じ高さに印字されるので、節の欄の読みは使わない（同じ額は説明にある）。

## 2024・2025年度当初予算・歳出（一般会計）

予算書は款ごとの13冊に分かれ（総括の冊は款を二重に数えるので選ばない）、各冊を1表にする（`partial`）。13冊の款の和は歳出合計（2025年度 37,620,000千円）と合う。見開きの左頁に款・項・目と金額、右頁に節と説明を印字する。左頁は目ごと、右頁は説明の行ごとに横罫を引くので、`running_titles` の見開き（`facing_pages`）で組む。

- 財源内訳の欄は取り込まない。財源の名前の金額が「その他」と「一般財源」の罫をまたいで印字された語は `excluded_boxes` にする。
- 前の見開きから続く目は左頁の頭に `9 1 2 (非常備消防費)` と括弧で刷り直す。新しい目ではない（`carried_names`）。
- 金額の小さい冊（労働費）は金額の列が番号の列に見えるので、金額の列を宣言する（`kind: amount`）。
- 説明は事業・節・細節（`○1 消耗品費`）・品目（`・`）の4段。印は段を表す（`marks`）。節の欄の `○1` も細節。
- 比較の列と次の列の金額が接して1語に読まれるので、罫で分ける（`split_at_rules`）。
