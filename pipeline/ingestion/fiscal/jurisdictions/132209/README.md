  - 不用額の最後の桁が備考の番号と1語に読まれる（`72,3641介護給付費等準備基金積立金`）のは、`code_after_amount` の option `cut_after_group`（羽村市で足したもの）で桁の区切りの後で切る。罫の手前で終わる区切り済みの金額は、次の行の番号と同じ末尾の数字でも削らない。

## 2026年度当初予算・一般会計（2026-11-13）

出典は予算書の事項別明細書の scan で、款ごとに分かれた13冊（選定の scope の PDF）。汎用の生成機 `generic_scan` で1冊ずつ読み、どの冊も `partial` にする（冊ごとに歳出合計とは照合できない）。13冊の款の和 38,889,000 千円は第13冊（予備費）に印字の歳出合計と同じ。13冊とも木の不一致 0・未所属の額 0。

- 見開きの左の頁に款・項・目と本年度・前年度・比較・財源内訳、右の頁に節と説明を印字する。罫で読み（`ruled`）、見出しは段組み（`staircase`）と見開き（`facing_pages`）。財源内訳の4欄は歳出の金額ではないので外す。
- 節の番号は法定の番号（`legal_setsu_codes`）。説明は 事業 → 節 → 細節・項目 の段で、番号の位置では事業と節を分けられないので、法定の節の名前と番号で分ける（`setsu_lines`）。
- 節の額が欄の右の罫に寄り、説明の番号と1つに読まれる（`445,6791`、2桁の額の箱が罫を越える `15`）ものは `code_after_amount` で分ける。額が3桁以下で区切りの無いもの（`1124 共済費`）と、本年度の額の末尾に前年度の頭の字が重なったもの（`2,821,3332`）は、原典の描画で確かめて読みを宣言する。
- 第5冊（労働費 14 千円）は額が小さく金額の欄と判定できないので、欄の種類を宣言する。第13冊の節「予備費」は番号を持たず見開きの左の目と同じ高さに印字されるので、節の欄の読みは使わない（同じ額は説明にある）。

## 2023年度決算・歳出（一般会計・国民健康保険事業特別会計）（2026-11-16）

2023年度の決算書は scan（`generic_scan`）。2024年度（text）と同じ様式で、科目は bands、備考は shape、節は indent。

- 罫線が薄く、既定の濃さでは列の罫線の多くを拾えないので `rules.dark: 200` で読む。
- 科目の欄は階段状で、款・項・目の間の罫線が見出しまで届かない頁は「科目」と「款項目」が1つの升に読まれる。`header.staircase` で款・項・目の列に分ける（`layout.level_cells` が頭の「科目」を外す）。
- 備考の節の番号は右揃えなので、備考の軸に `bracketed_remainder` を置き、2桁と1桁の番号を同じ段に読む。
- 不用額が備考の罫線に接して印字され、OCR が右の備考の番号まで1つの読みにまとめた行（7件）、名称を2行に印字し節が次の頁へ続く事業（2件）、読みの枠がずれて段を誤った行（2件）は、`dropped_readings`・`name_readings`・`amount_readings` で読み直した（理由は各宣言）。
- 款の和は印字の歳出合計と一致（一般会計 37,929,215,366 円、国保 8,414,282,441 円）。

## 2023〜2025年度当初予算・歳出（一般会計）

予算書は款ごとの13冊に分かれ（総括の冊は款を二重に数えるので選ばない）、各冊を1表にする（`partial`）。13冊の款の和は歳出合計（2025年度 37,620,000千円、2023年度 34,008,000千円）と合う。見開きの左頁に款・項・目と金額、右頁に節と説明を印字する。左頁は目ごと、右頁は説明の行ごとに横罫を引くので、`running_titles` の見開き（`facing_pages`）で組む。

- 財源内訳の欄は取り込まない。財源の名前の金額が「その他」と「一般財源」の罫をまたいで印字された語は `excluded_boxes` にする。
- 前の見開きから続く目は左頁の頭に `9 1 2 (非常備消防費)` と括弧で刷り直す。新しい目ではない（`carried_names`）。
- 金額の小さい冊（労働費）は金額の列が番号の列に見えるので、金額の列を宣言する（`kind: amount`）。
- 説明は事業・節・細節（`○1 消耗品費`）・品目（`・`）の4段。印は段を表す（`marks`）。節の欄の `○1` も細節。
- 比較の列と次の列の金額が接して1語に読まれるので、罫で分ける（`split_at_rules`）。
- 2023年度は2024年度の宣言を移した。財源の名前の金額（p23・p75）の位置が違うので `excluded_boxes` は2023年度の位置で宣言し直した。冊の頁数も違うので `pages` は選定の頁をそのまま使う。取り込みは13表、ノード 6,780・金額 7,070。

## 歳入（当初 R5〜R8・決算 R5〜R7）

選定には歳入の範囲が既にある。当初は一般会計の歳入の冊（「２ 歳入」、見開きの文字 PDF）を、歳出の冊の宣言（`running_titles`）を写して読み、説明を「歳入の説明」で外す。決算は歳出と同じ冊の歳入の事項別明細を読み、範囲は決算書の款・項の頁を除いた明細の頁に絞る（`pages`。選定の範囲は決算書の頁から始まり、款の和が2重になる）。備考は「歳入の説明」で外す。会計は歳出と同じ（R6 は一般会計・国保、R7 は後期高齢も）。款の和は歳入合計と一致する。

採用済みの歳入（2026-11-23）: 当初 R5〜R7 一般会計（文字）、R6〜R8 国保・介護・後期（scan）、R8 一般会計（scan）。決算 R5 一般会計・国保（scan）、R6・R7 一般会計・国保・介護・後期（文字）。歳出の取り込みと同じ範囲で、欠けている冊・会計は無い。

- 決算 R6 の介護・後期、R7 の介護は、同じ冊の国保の宣言を写した（範囲は決算書の頁を除いた明細の頁）。
- scan の冊（決算 R5、当初 R6〜R8 の特別会計、R8 の一般会計）は、同じ冊の歳出の宣言を写して OCR を取り直した（`page_strips: 1`）。財源内訳の欄の宣言は外し、説明・備考は「歳入の説明」で外す。特別会計の冊の最初の頁（総括）は範囲から外す（`pages`）。総括の歳入合計は款の和と一致する。
- 歳入の節は細節を持たないが、OCR の番号の位置の揺れで次の節が前の節の細節に読まれたので、節は `flat` で読む。
- 決算 R5 は見出しの「収入」を OCR が「収人」と読む（調定額と1語に読んだ頁もある）ので、調定額・収入済額・収入未済額の升を `header_readings` で宣言した。科目名の 入→人・売→壳・土→十・手→于・ロ→口 の誤読は `name_corrections` で直した。当初の特別会計の見出し「比，較」も `header_readings` で「比較」とした。
- 款の和: 決算 R5 一般会計 39,947,463,674円・国保 8,647,739,552円（収入済額、印字の歳入合計と一致）。決算 R6 介護 8,201,762,240円・後期 2,731,026,053円、R7 介護 8,398,090,250円。当初（千円）R6 国保 8,599,719・介護 7,925,171・後期 2,624,155、R7 国保 8,329,457・介護 8,301,058・後期 2,721,469、R8 一般会計 38,889,000・国保 8,417,608・介護 8,675,226・後期 2,958,603（特別会計は総括の歳入合計、R8 一般会計は歳出合計と一致）。

## 特別会計・歳出（当初 R6〜R8・決算 R6〜R7、2026-11-17）

国民健康保険・介護保険・後期高齢者医療を、同じ年度の一般会計の宣言を写して読む（当初は scan の見開き、決算は文字 PDF）。決算は R6 の介護・後期、R7 の介護（国保と R7 後期は保存済み）。

- 当初 R6・R7 の介護保険・後期高齢者医療は、見開きの右頁が節・説明の行ごとに罫を引き、左頁は見出し・目・財源の小計の下線にしか罫を引かないので、共通の見開きの判定（行の罫の多くが合うこと）が左右を結ばず、右頁の節が左頁の最後の目に付いた。opt-in の quirk `framed_spread_pages` で、款・項・目の欄の無い頁が前の頁と同じ枠（上下の罫が 1.5pt 以内）なら見開きとする。
- 金額の右の罫に桁が切られた読み、3段の金額の升を1語に読んだ読みは、`dropped_readings` と `amount_readings` で読み直した（理由は各宣言）。
