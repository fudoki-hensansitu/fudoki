# 大島町（133612）

2024年度決算の歳出は、一般会計の款の総括（`2024/settlement/`）だけを取り込んでいる。出典は「令和6年度各会計決算資料」の物理5頁「4．一般会計目的別歳出」で、項・目以下の明細と特別会計・公営企業会計の歳出は載っていない（出典の選定は `pipeline/source_selection/133612.json`）。

## 出典の癖（実測）

- **表が頁に90°回して組まれている。** 頁の回転（`/Rotate`）は0で、文字層の語が頁の下から上へ並ぶ。汎用の読み取り（`generic_text`）は行を1つも読めないので、語の位置を表の向きに回して読む `turned_summary` で読む（設定は `layouts/purpose_summary_2024.json`）。保存する位置は表示頁の座標のまま
- **款の番号と名前の1字目が1語になっている**（`１．議`）。網羅の検査では番号の数字を項目の番号として照合する
- **空欄の款がある。** 土石流災害対策費・災害復旧費の令和6年度の総額は空欄（土石流災害対策費は対前年度増減率の欄に「皆減」）。空欄は金額の行を作っていない
- 金額の欄は8欄（令和6年度の総額・左の内訳2欄・一般財源・左の内訳2欄、令和5年度の総額・一般財源）。8欄すべてで款の和が計の行と一致する。左の内訳4欄（事業費・その他の経費の別）は和と計を照合したうえで取り込まず、網羅の検査に経費内訳・財源内訳として渡す（辞書に見出しが無く、足すと全表の指紋が古くなるため）

## 当初予算・歳出（2024〜2026）

議案の当初予算の説明資料の物理3頁「3．一般会計目的別歳出」から、一般会計の款の総括（`<年度>/initial/`）を `turned_summary` で取り込む。項・目以下と特別会計の当初予算は載っていない。設定は `layouts/purpose_summary_initial_<年度>.json`。

- 2025・2026 は決算と同じく表が頁に90°回して組まれている。2024 は頁ごと回してあり（文字層が表の向きのまま）、設定の `turned: false` でそのまま読む
- 本年度の総額の金額は `当初予算額`、前年度の総額は `前年度予算額` の見出しで持つ。左の内訳4欄（事業費・その他の経費）は和と計を照合したうえで取り込まない
- 2024 は前年度だけの款「土石流災害対策費」が番号の代わりに「-」で印字され、本年度の一般財源の欄も「-」。番号の無い款として置き、「-」だけの金額の欄は空欄として扱う
