# 豊島区 131164

## 2023年度決算・歳出

一般会計・国民健康保険・後期高齢者医療・介護保険の4会計を取り込む。2024年度は文字 PDF だが、2023年度の決算書は文字層の字の対応が壊れていて（埋め込みの字形に Unicode の対応が無い）正しい字が取れないので、OCR で読む（scan）。見開きを横向きの1頁に印字し、左半分に科目・予算現額・節、右半分に支出済額・翌年度繰越額・不用額・備考がある。読み方は 2024年度と同じ（科目は `bands`、節は `indent`）にし、scan だけの違いを足す。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 67–105 | 2,154 | 7,170 | 144,107,950,011 |
| 国民健康保険 | 114–119 | 155 | 1,078 | 29,498,680,151 |
| 後期高齢者医療 | 125–128 | 83 | 475 | 7,007,413,670（印字なし） |
| 介護保険 | 136–141 | 189 | 1,189 | 20,401,729,291 |

- 款・項・目の見出しは1つの升に「款 項 目」と並べて印字し、OCR は「款項」と「目」に読む。升の下で欄が分かれる階段なので `header.staircase` で3つの欄に分ける。
- 予算現額の「継続費及び繰越事業費繰越額」「予備費支出及び流用増減」の升は字が小さく、OCR が升をまたいで切れ切れに読む。罫線の位置はどの頁も同じなので `header_readings` で升の見出しを宣言する。
- 介護保険の項「1 介護予防・生活支援サービス事業費」（頁138）と「1 償還金及び還付加算金」（頁141）は名前を折り返し、行の間の番号を OCR が読まない。番号と名前を `code_readings` で宣言し、行ごとの読みは `dropped_readings` で除く。
- 国民健康保険の頁116で、科目の欄の罫線の切れ端を OCR の読み直しが「|1」と読み、番号1の科目になった。`dropped_readings` で除く。
- 名前の読み違い（`サ一ビス`・`センタ一`）は `name_corrections` で直す。

## 2023年度当初予算・歳出

一般会計・国民健康保険・後期高齢者医療・介護保険の4会計を取り込む（text PDF）。読み方は2024〜2026年度の当初予算と同じ様式で、節・説明とも `shape` で読む。

- **金額の注記（基準額）**: 一般会計 p208「監査委員報酬［3人分］」の下の「識見者 月額 310,000円」は、千円の欄に円で印字された基準額なので、2025年度と同じく `note_kinds` で注記（金額の注記）にし、`yen_marked` で単位を円にする。
- **読めていない注記**: 同じ頁の「議会選出者 月額 155,000円」は、文字層が「155」と「,000円」を別の語に分けているため金額として読めず、注記として扱うが額を持たないため、ノードの表にも金額の表にも行を作らない。歳出合計・款の和・目の額には影響しない（注記は合計に加えない）。2025年度は1語で読めて注記金額 155,000 になる。語をつなぐ読み方を共通コードに足すかは、ほかの自治体の影響を見て別に決める。
