# 豊島区 131164

## 2023年度当初予算・歳出

一般会計・国民健康保険・後期高齢者医療・介護保険の4会計を取り込む（text PDF）。読み方は2024〜2026年度の当初予算と同じ様式で、節・説明とも `shape` で読む。

- **金額の注記（基準額）**: 一般会計 p208「監査委員報酬［3人分］」の下の「識見者 月額 310,000円」は、千円の欄に円で印字された基準額なので、2025年度と同じく `note_kinds` で注記（金額の注記）にする。
- **読めていない注記**: 同じ頁の「議会選出者 月額 155,000円」は、文字層が「155」と「,000円」を別の語に分けているため金額として読めず、注記の行になるが額を持たない。歳出合計・款の和・目の額には影響しない（注記は合計に加えない）。2025年度は1語で読めて注記金額 155,000 になる。語をつなぐ読み方を共通コードに足すかは、ほかの自治体の影響を見て別に決める。
