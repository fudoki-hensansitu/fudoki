# 栃木市（092037）

栃木県栃木市。財政課の「予算書」の頁（https://www.city.tochigi.lg.jp/soshiki/14/36214.html）に、年度ごとの予算書が1冊の text PDF で載る（一般会計・特別会計6つの予算書と予算に関する説明書、水道・下水道の企業会計予算書と説明書）。

| 資料 | 年度 | 様式 |
| --- | --- | --- |
| 当初予算（予算に関する説明書の歳出事項別明細書、企業会計は予算実施計画） | R6・R7・R8 | text PDF（`generic_text`）、1冊に全会計 |
| 決算 | なし | 決算書・事項別明細書・決算審査意見書を公開していない（決算カードと広報の要約だけ） |
| 事業評価 | なし | 事業ごとの評価シートを公開していない |

R5 以前の予算書も同じ頁にあるが、事項別明細書の頁の文字が字の対応表（ToUnicode）を持たず文字として読めないので、同じ宣言で読める R6 で止めた。補正予算は取らない。

## 当初予算

見開き（A3横）を1枚の頁に刷り、同じ頁を2回入れて左頁と右頁を CropBox で切り分けている（`text_layer.crop_box`）。左頁に目と本年度・前年度・比較・本年度の財源内訳、右頁に節（区分・金額）・細節（区分・金額）と説明を千円単位で印字し、款・項は表の上に「（款）1 議会費」「（項）1 議会費」と印字する（`running_titles`）。表の罫線は罫線素片の文字（┃━│など）で描く。一般会計と特別会計6つは同じ様式なので、読み方（`workflow`）は共通にした。

款の和は、各会計の予算書の第1表（歳入歳出予算）に印字された歳出合計と全会計・全年度で一致する。

- **財源内訳**: 特定財源の種類と額を名前の下に複数行で印字し、名前と金額を1対1に組めないので `excluded` で取り込まない。
- **節と細節**: 節の欄の右に細節の欄（区分・金額）があり、細節は番号を印字しない。目の最初の行に印字された細節は、目の行の注記と読まれて金額が節に付いたので、文書の quirk `codeless_column_items` で細節として読む。細節は一部の節だけに印字されるので、節とは別の軸に置き、quirk `under: 節` で同じ罫の行の節の下に入れて節の額で確かめる（目の下に置くと目の額に足りない）。細節の金額（`細節／金額`）は当初予算の段階として `shared/fiscal_amount_map.csv` に足した。名前を2行に折り返す細節が字下げで1段深く読まれたので、`indent_chars: 1`（欄の左端からの字数）で段を決める（細節は全部1段）。
- **説明**: 番号の無い事業（`議員人件費 203,534`）の下に、主な経費を「・」で始めて挙げる（`・議員報酬 143,040`）。一部だけを挙げて事業の額にならないので、`note_kinds` で「・」の行を注記（内訳）にし、事業の和に加えない。事業の和は目の本年度と一致する。分け方は「事業」（seed `fiscal_detail_breakdown`）。
  - 欄の幅が見開きごとに違い（R7 の一般会計の後半は欄が狭い）、名前の書き出しの位置を文書全体で学ぶと頁をまたいで事業が前の事業の下に入ったので、`indent` の `indent_chars: 1` で欄の左端から段を決める。
  - 事業の名前と「・」の行は2行に折り返し、金額を2行目に印字する（`wrap: amount_on_last_line`）。「・」の行の2行目は1字下げて始まるので、`name_start_slack: 10` で1行目に結ぶ。
  - 「（仮称）…」のように開き括弧で始まる事業は、組み直した語が括弧の墨の位置から始まり半字右に置かれるので、quirk `opening_bracket_ink` を `indent_chars` の段の計算にも効かせた（共通コード）。
- **見えない複製の頁**: R7 は多くの頁で文字を見えない複製と一緒に描き、語を見える字から組み直す（`repair.drop_invisible`）。共通コードを2つ直した。組み直した語に罫線素片の文字が残り欄の見出しが「│」になっていたので、罫線素片を罫線として読む。字を語にまとめる走査が、別の行の背の低い字（下の行の「,」）で早く止まり `14,124` を `14,` と `124` に割っていたので、走査の止めを頁で一番背の高い字の届く距離にした。
- **産業団地の会計**: 2つの産業団地特別会計は「整備」を名前に含まないので、seed `account_kind_map` に「産業団地特別会計」を足して産業団地整備の種類に当てた。

### 企業会計（予算実施計画）

水道事業会計・下水道事業会計は予算に関する説明書の予算実施計画（款・項・目・予定額・備考、千円）を読む。収益的支出と資本的支出は別の頁に印字されるので、それぞれの頁だけを `pages` で読み、収益的と資本的の2つの表（`statement_kind: public-enterprise`）にする。読み方は栃木県（090000）の企業会計と同じ `ruled`。
