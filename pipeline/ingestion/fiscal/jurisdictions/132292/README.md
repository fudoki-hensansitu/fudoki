# 西東京市 132292

## 当初予算・歳出（2024〜2026年度）

一般会計は款ごとの分冊13冊（01〜13）で、1冊を1変換（`general-01`〜`general-13`）にする。各冊は `partial: true` なので、単位の確かめは印字の歳出合計と照らさず、会計全体の欠落は保存の関門で止まらない。01・02・04〜10・13 を先に保存し、03・11・12 を後から同じ管理 JSON に1変換ずつ足す（`--extend-plan`。03→11→12 の順）。

03・11・12 は、先の10冊と同じ宣言に次の癖（ADR 0043 の opt-in の quirks）を足して通した（2026-11-11 に `generic_text` で実測。候補の木はすべて一致）。

- 03 民生費（木の一致 914・934・931）:
  - 説明欄の積算の行（`事務費 21,956,352円`、`成人`・`児童`）は、名前の全体が一致する行だけを積算にする（説明の軸の `whole_name_notes`）。`note_kinds` は前方一致なので、`事務費` と宣言すると事業「事務費繰出金」まで積算になる。先の10冊に残る `事務費21,956` などの額入りの語は、名前に額が入らないため効かない。03 では外した。
  - 頁の最後の積算（`日常生活支援住居施設委託事務費`）の額 `2,800,000円` が次の頁の先頭行に印字される（2026）。次の頁の名前の無い額を前の頁の最後の行の額にする（説明の軸の `amount_over_page`。円の印字は額のある頁で読む）。
  - 2024 の文字層は積算の額を2語に切る（`12,49` `8,500円`）。円の付いた右の語も数字の続きとしてつなぐ（文書の `yen_split_amounts`）。
  - `note_kinds` に `日常生活支援住居施設委託事務費` を足した。
- 11 公債費・12 諸支出金（木の一致 各15）: 説明欄の番号は段ごとに右で揃い、2桁の節「22」「24」「27」が事業の1桁の番号「1」とほぼ同じ位置から始まる。1桁の節の無い冊では節が事業と同じ段に読まれていた。番号の位置を、同じ段の1桁の番号が始まる位置で読む（説明の軸の `numbers_set_right`）。「(財政課) 190,982」のような課ごとの額の行は、既存の課の見出しの判定でその下の節の親になる。
- 2024 の 12 は節の金額が `3`・`73` だけで、金額の欄と読まれない。`節／金額` を `kind: amount` と宣言した。
