# 西東京市 132292

## 当初予算・歳出（2024〜2026年度）

一般会計は款ごとの分冊13冊（01〜13）で、1冊を1変換（`general-01`〜`general-13`）にする。各冊は `partial: true` なので、単位の確かめは印字の歳出合計と照らさず、会計全体の欠落は保存の関門で止まらない。01・02・04〜10・13 を先に保存し、03・11・12 を後から同じ管理 JSON に1変換ずつ足す（`--extend-plan`。03→11→12 の順）。

03・11・12 は、先の10冊と同じ宣言に次の癖（ADR 0043 の opt-in の quirks）を足して通した（2026-11-11 に `generic_text` で実測。候補の木はすべて一致）。

- 03 民生費（木の一致 914・934・931）:
  - 説明欄の積算の行（`事務費 21,956,352円`、`成人`・`児童`）は、名前の全体が一致する行だけを積算にする（説明の軸の `whole_name_notes`）。`note_kinds` は前方一致なので、`事務費` と宣言すると事業「事務費繰出金」まで積算になる。先の10冊に残る `事務費21,956` などの額入りの語は、名前に額が入らないため効かない。03 では外した。
  - 頁の最後の積算（`日常生活支援住居施設委託事務費`）の額 `2,800,000円` が次の頁の先頭行に印字される（2026）。次の頁の名前の無い額を前の頁の最後の行の額にする（説明の軸の `amount_over_page`。円の印字は額のある頁で読む）。
  - 2024 の文字層は積算の額を2語に切る（`12,49` `8,500円`）。円の付いた右の語も数字の続きとしてつなぐ（文書の `yen_split_amounts`）。
  - `note_kinds` に `日常生活支援住居施設委託事務費` を足した。
- 11 公債費・12 諸支出金（木の一致 各15）: 説明欄の番号は段ごとに右で揃い、2桁の節「22」「24」「27」が事業の1桁の番号「1」とほぼ同じ位置から始まる。1桁の節の無い冊では節が事業と同じ段に読まれていた。番号の位置を、同じ段の1桁の番号が始まる位置で読む（説明の軸の `numbers_set_right`）。「(財政課) 190,982」のような課ごとの額の行は、既存の課の見出しの判定でその下の節の親になる。
- 2024 の 12 は節の金額が `3`・`73` だけで、金額の欄と読まれない。`節／金額` を `kind: amount` と宣言した。

### 特別会計（2024〜2026年度）

特別会計（国民健康保険・介護保険・後期高齢者医療・駐車場事業）は会計ごとの冊で、一般会計の冊と同じ様式なので、一般会計の宣言（`ruled`、説明の軸の `bands`）を写して1冊を1変換にする。財源内訳の欄は取り込まず、構成比は読まない。

- 2025年度の国民健康保険は、番号の無い名前（説明の見出し）の最初の字が罫の位置から始まり、罫の右へ字の幅の半分ほどはみ出して印字される。罫の右の段と読まれて1段深くなるので、quirk `unnumbered_names_at_rule` の許容を字の高さの半分まで広げた（字は正方形なので高さで幅を見る）。
- 2026年度の介護保険は scan なので、まだ取り込まない。下水道事業会計は公営企業会計なので対象外。

## 2023年度決算・歳出

2024年度の決算と同じ様式（一般会計は分冊12冊、特別会計4つ）なので、2024年度の宣言を冊の順に写した。2023年度の備考欄には「円」の付かない額があり、それも額として読むよう各変換の備考の軸に `bare_amounts` を足した。

## 2023年度当初予算・歳出（R5、2026-11-15）

2024年度の宣言を、選定の冊の並びで移した。款ごとの13冊を13表にした（`partial`）。13冊の款の和は 77,490,000千円（丸い額）で、分冊をまたぐ照合は検査の外。ノード 8,052・金額 8,306。

## 歳入・特別会計（当初 R5〜R8・決算 R5〜R7、2026-11-17）

特別会計4つ（国民健康保険・駐車場事業・介護保険・後期高齢者医療）の歳入を、歳出と同じ冊から取り込む。説明・備考の欄は「歳入の説明」で外し、款・項・目・節で取り込む。一般会計の歳入は款ごとの分冊で選定に無いので、別に取り込む。下水道事業会計は取り込まない。

- 決算は各会計の決算書の歳入の頁（歳出の頁の前）を、歳出の宣言を写して読む。
- 当初は特別会計の歳出をまだ取り込んでいないので、一般会計の款の分冊（`general-01`）の宣言を写して会計と入力を変えた。範囲は歳入の頁で、総括の頁（物理1頁）は款の行が明細の題字の款と別の根に読まれて二重になるので外した。R8 の介護保険は scan なので取り込まない。
- 節は1段だけで、番号の位置で段を分けると `3 滞納繰越分` が前の節の下に入る。どの冊も `flat` で読む。
- 節の名前を2行に折り返し、番号と金額を2行目の高さ（または2行の間）に刷る（`特別徴収保険料` / `1 現年分`）。1行目が番号の無い行として落ちるので、共通の quirk `code_between_name_lines` を内訳にも効かせ（従来は科目だけ）、opt-in で読む。この quirk を使う 131130・132233 の表は変わらない。
- 当初の国民健康保険の節「未就学児均等割保険料繰入金」は3行に字間を空けて刷り、2行目と3行目の字が交ざるので `name_corrections` で直す。
- R6 当初の国民健康保険は、無くした項「基金繰入金」と目を番号無しで一段深く刷り、目「一般会計繰入金」の子に読まれる（前年度予算額の和が合わない）。科目の段を名前の位置で決める quirk は `indent` の読み方にしか無く、この冊では款の和が合わなくなるので、この表は取り込んでいない。R8 当初の後期高齢者医療は、無くした款「国庫支出金」（番号の無い題字、本年度0）の頁（物理7頁）を範囲から外した。
