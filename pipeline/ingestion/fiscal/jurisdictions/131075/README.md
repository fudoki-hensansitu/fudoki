歳出合計は各会計の総括（選定の範囲の外）に印字された値。款の金額は明細に印字されないので、単位の検査は `unchecked` になる。項の和との一致は上の表で確かめた。

- **款・項**: 各頁の枠の上に `款 1 議会費  項 1 議会費  （単位 千円）` と印字する。款・項の行は表の中に無いので、題から款・項の項目を作る。見開きの各頁が同じ題を繰り返すので、2頁目以降の題の番号は再掲（反復見出し）として網羅の検査から外す。題の右端の頁番号は読まない。
- **項の金額**: 項の最後の頁の枠の下に `計` の行があり、本年度予算額・前年度予算額・比較を印字する。これを項の金額にした。款の合計は印字されない。
- **見出しの無い頁**: 見出し（本年度予算額・節・計上説明…）は見開きの左の頁にだけあり、右の頁は同じ欄の罫線だけを引く。欄の境界は全頁・全年度で同じなので、profile の x で欄を決める（頁の縦罫がその位置に無ければ止める）。続きの頁は目の名前を括弧つきで再掲する（`（議会費）`）。
- **目と節の名前の折り返し**: 2〜3行に折り返す名前は、番号を2行目に印字する（`使用料及び` / `13` / `賃借料`、`高額介護予防…` / `4 サービス費相当…` / `事業費`）。番号の行の直前の行を名前の頭にする。行末の `…` は名前に含めない。
- **番号の無い目・款・項**: 前年度に予算があり本年度0の目は、番号なしで括弧に入れて印字する（`（母子生活ホーム費 0 29,611 △29,611）`）。2024年度の国保には括弧の款・項（`（款 共同事業拠出金 項 共同事業拠出金）`）もある。番号の無い項目として取り込む。
- **財源内訳**: 計上説明の欄の、各目の頭と計の行に罫線で囲んで財源内訳（財源の名前の行と金額の行）を印字する。財源の種類ごとの額で、本年度予算額の別の切り口なので取り込まない（除外の種類は財源内訳）。罫線で囲んだ帯は、計上説明の欄を横切る2本の罫と、その間を通る財源の欄の縦罫（x 690〜790）で見分ける。
- **説明の項目**: 番号（`1`・`⑴`・`ア`・`(ア)`・`①`）で始まる行を項目とし、行の右端の金額（下に小さく `千円` を印字する）をその項目の金額にする。段は番号の印字の位置で決める。2024年度は `⑵` の位置に全角の `２` を印字した行が9件ある。番号の形ではなく位置で段を決め、受領記録の notes に頁と番号を残した。名前が折り返して金額が次の行にある項目は、次の行の右端の金額を取る。
- **説明の中の数**: 番号の無い行の数（単価・人数・回数・基金現在高・補助率・限度額・日付など）と、罫線で囲んだ数量の表は取り込まない（除外の種類は本文・数量表）。番号の無い行の右端に千円の金額があり、直前の項目が金額を持つ場合は止める。
- **債務負担行為**: `（翌年度への債務負担行為額 56,000 ）` は注記（種類は債務負担行為）として、その時の項目の下に置く。
- **見出しの辞書**: 計上説明の項目の金額は、共有辞書の見出し `説明` で持つ（当初予算の approved）。目の金額は `本年度予算額`・`前年度予算額`・`比較`、節は `節／金額`。
