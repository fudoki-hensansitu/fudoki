# 足立区 131211

## 2024年度決算・歳出

歳出事業別決算説明書（scan）から、一般会計（分冊5〜11 の7冊）と特別会計3つ（国民健康保険・介護保険・後期高齢者医療）を1冊1表ずつ取り込む。

決算説明書は1つの横長の表を見開きに割った様式で、左頁に款・項・目・事務事業と予算現額・決算額、右頁に翌年度繰越額・不用額・執行率と決算説明の文を印字する。行は左右の頁で y が揃う。事務事業の行の下には、担当部課ごとの行（同じ番号・同じ名前に `(区民部)` などが続く）と、決算説明の項目（`ア` `イ`…、その下の `(ア)` `a` `(a)`）の金額を左頁に、項目の名前を右頁に印字する。10表とも同じ様式なので、読み方（`workflow`）は共通にした。

- **読み方**: 事業別決算説明書の読み方は組版の設定 `explained_projects`（`ingestion/generic/explained_projects.py`）で、設定のある文書だけに効く。見開きの右頁の金額は左頁に同じ額を印字するので取り込まず、数字の網羅の検査では本文として外す。決算額の欄の左に印字する行番号の写し（`1` `(2)`）も本文として外す。
- **担当部課の行**: 同じ番号・同じ名前で総額の行の下に並ぶ担当部課の行を、総額の行の子にした（名前の末尾に `(区民部)` を付ける）。その下の小事業（`(1) 情報システムの構築、改造事業`）は担当部課の行の子。
- **決算説明の項目**: 金額と記号は左頁、名前は右頁から、その行の説明（行の番号・名前・担当部課で探す）の中で記号の順に当て、`決算説明` の軸に置いた（事務事業と足さない。dbt では事務事業の枝の中の内訳になる）。名前の長い行が2帯の OCR の境目で落ちたため、右頁は1帯（`page_strips: 1`）で OCR し直した。OCR が名前を読まなかった31項目（「Ｊ－Ｌｉｓ証明書交付センター運営負担金等」など）は、描画した頁を読んで `explained_names` に宣言した。
- **不用額・繰越額**: 行の下の記号の無い金額は、予算現額−決算額に等しければ不用額、2つ並んで和が等しければ上を翌年度繰越額・下を不用額として、注記の軸に置いた。説明の文の `(令和5年度繰越明許費分 28,464,700円)` は前年度からの繰越額の注記にした。どれも金額の段階を付けず、合計に加えない。
- **冊の境目**: 一般会計は分冊5〜11に分けて印字し、冊は事業の途中でも切れる。各冊の頭の柱（`2 総務費 4 戸籍及び住民基本台帳費 2 戸籍事務費`）から金額の無い款・項・目を組み立て、前の冊から続く事務事業の行を `continued_rows` に宣言してその下に続きの行を置いた。dbt で前の冊の同じノードとまとまる。冊の終わりの行の印字値が続きの分だけ足りない29か所は、次の冊の頭の続きの和と一致することを確かめて、`expenditure.layout.json` の `source_inconsistencies` に宣言した。分冊10 は全部が教育費の中なので、款は柱にだけあり金額を持たない（分冊の款の支出済額の検査は目だけで行う）。
- **款別節別の一覧**: 分冊11 の物理7頁以降は款×節の一覧表で事業単位ではないため、頁から外した。
- **読み違い**: 片仮名の形の漢字（`創工ネ` `防犯力メラ`）、長音の `一`、`污` は、総額の行と担当部課の行の照合の鍵だけで揃える（名前は印字の読みのまま）。項目の記号 `イ` を `1` と読んだ行は記号として読む。`0円` が1語に読まれた金額は数字と単位に分けて読む。
