# 東京都（130001）

都道府県として初めて収録する。区市町村の合計ではなく、都そのものの決算（歳入歳出決算事項別明細書）を読む。2024・2025年度決算の歳出を、一般会計と特別会計18会計（特別区財政調整・地方消費税清算・小笠原諸島生活再建資金・国民健康保険事業・母子父子福祉貸付資金・心身障害者扶養年金・地方独立行政法人東京都立病院機構貸付等事業・中小企業設備導入等資金・林業・木材産業改善資金助成・沿岸漁業改善資金助成・と場・都営住宅等事業・都営住宅等保証金・都市開発資金・用地・公債費・臨海都市基盤整備事業・工業用水道事業清算）で `generic_text` により取り込む。宣言は `<年度>/settlement/expenditure.json`、対象頁は出典選定の scope から読む。

## 出典の読み方

- 見開きの左頁に予算現額と節、右頁に支出済額から不用額・備考が載る。右頁は支出済額の欄の左に縦罫が無いため、表のパターン `open_edge` で行の罫線の端に縦罫を補う。2024年度の冊は頁の四隅にトンボがあり、表の行が届かない罫線は枠の端にしない。
- 罫線は淡い特色で、多くの右頁は備考の見出しに濃い線が数本ある。濃い線より淡い線が十分多い頁は淡い線を読む（共通の変更。経緯は消した汎用のノード生成の設計書にあり、git の履歴で読める）。
- 見出しは頁ごとに組み方が揺れる。`予算現額` の下の `予備費支出及び流用増減` は列の見出し指定で、頁の表題の「歳」「出」は `ignore_frame_title` で、文字の並びが崩れた見出しは `characters` で読む。
- `0△` のように符号が前の欄に付く印字は `split_at_rules` で罫線で切る。
- 節と細節は1字下げで、2024年度の物理498頁は他の頁より約6pt右に印刷されている。段は `indent_chars: 1`（欄の左端からの字数）で決める。
- 備考の流用は `０１項０２…費` ／ `から流用 13,281,000円` の2行で印字されることがあり、一つの注記として読む。

数字の聞き直し（Jev）は2025年度44問・2024年度57問で、答えは `expenditure.digit-recheck.jsonl` に保存して再現する。

### 出典の読み方

- 頁ごとに1つの枠で、款・項・目、本年度予算額・前年度予算額・比較増減、本年度の財源内訳、節（細節）の区分と金額、計上説明の欄が並ぶ。見出しは OCR が頁ごとに違う字に割って読むので読まず、本文の縦罫から欄の位置を決めて見出しを描き直す（レイアウトのパターン `drawn_header`）。頁は枠の左端が 31〜37pt の範囲で揺れて印刷されているので、多くの頁の位置に揃えて読み、元の位置は `offset` に残す。
- 本年度の財源内訳の欄は取り込まない（本年度予算額の別の切り口）。
- 計上説明の番号は縦に並べて印字され、OCR が1つの縦長の読み（`2,345`、`四` など）にまとめたり読まなかったりする。番号の間の名前の行数から番号を振り直す。
- 細節は小さい括弧付きの番号で、OCR が括弧を落とす。節の法定の番号と名前が合わない番号は細節と読む。
- 目「一般歳入」は本年度予算額 0 の科目で、計上説明は財源の内訳を印字する。和が 0 にならないのは原典どおりで、`expenditure.layout.json` に宣言している。
- 頁の終わりで切れた節の名前（`16公有財産購`）は次の頁の先頭に番号無しで続く（`入費`）。続きは前の頁の名前の行に戻して読む。
- 2行に分けて印字した同じ金額（節とただ1つの細節など）を OCR が1つの読み（`4545`）にまとめた所は、読みを外して行ごとに読み直す宣言にしている。

## 注意

- 都の歳出には区市町村への交付金・特別区財政調整交付金が含まれる。区市町村の決算と足すと、同じお金を二重に数える。
- 公債費会計への繰出（`公債費会計繰出金`）は各会計に現れ、公債費会計の元金・利子と重なる。COFOG は分類不能とし、金額の消去はしない（ADR 0023）。
