# 大田区（131113）

## 2026年度当初予算・歳出

- 節の欄は番号つきの節の下に、番号の無い細節（`3 職員手当等` の下の `扶養手当`・`期末手当`、`8 旅費` の下の `普通旅費`・`特別旅費` など）を金額つきで印字する。細節は節の名前の位置から書き始めるので、字下げでは節と同じ深さになる。節の欄の quirk `unnumbered_shift: 1` で、節の欄の金額を持つ番号の無い行を1段下に置く。
- 目の金額の下の `補正経過`（第１次補正・…・計）は目の注記で、同じ行の高さに節の欄が印字する金額（`2 給料 86,968`）は節のもの。
- 一部の頁（p39 の防災対策費など）は節の金額の字体の文字対応表が壊れている。`text_layer.character_map` で U+0013〜U+001C を 0〜9、U+000F をカンマに置き換える（131091 と同じ）。

- **見出し**: scan では見出しの下の罫線が拾えず、本文が見出しに入る。layout `redrawn_facing_pages` で本文の縦罫から見出しを描き直してから `facing_pages` に渡す。2025年度は見出しが低く、見出しの下端は枠の上から最初の長い横罫で決める。
- **款・項・目**: 2024年度は `indent`（`codes: right`）。2025年度は頁ごとに横にずれて字下げの段が割れるので、番号の欄ごとに段を読む `names` にした。
- **節**: 番号つきが節、番号の無い行がその下の細節。scan では細節の字下げがそろわないので、breakdown `numbered` で番号の有無だけで深さを決める。
- **補正経過**: 頁の頭から始まる補正経過は前頁の最後の目に付ける（quirk `revision_history`）。
- **OCR の直し**: 墨の読み直しが金額と説明を1語に読んで桁を落とした行（2024 p69・p119）は `dropped_readings` と `amount_readings` で読み直し、p167 の「5O」は `amount_corrections` で直した。
- 説明と財源内訳は2026年度と同じ理由で `excluded`。
