# 八王子市 132012

## 2024〜2026年度当初予算・歳出（一般会計）

2026年度は予算説明書の歳出の分冊（02saisyutsu.pdf）、2024・2025年度は予算書（yosansyo.pdf）の事項別明細書を読む。様式は3年とも同じ。見開きの左頁に目・本年度・財源内訳、右頁に節と説明を印字し（`header.facing_pages`）、頁の上に `（款）2 総務費` / `（項）6 監査委員費` を印字する（`running_titles`）。

- 金額の欄は1つの升に本年度・(前年度)・<比較> を3段に印字する（`columns.<見出し>.lines`）。段の間は24pt（`line_pitch`）で、比較の下の増減率（`<10.1%増>`）は取り込まない。財源内訳の欄は取り込まない。
- 見出しは罫線1段で、`千円` の行は本文に入る（`one_row_header`）。
- 説明は所管課つきの事業（`１ 職員費 一般職 17人 ［労務課］ 171,617`）と、その下の `(1)` の細目。事業の下に括弧で印字した財源の内訳（`（特定財源 400 一般財源 40,694）`）は事業の行に結ばず（`notes`）、桁の網羅では財源内訳として外す。
- 3段の升が頁の下で切れ、前年度・比較の段が次の頁の表の頭に印字されることがある（2025年度の選挙啓発費、2026年度の項 監査委員費の比較）。その段は前の頁の科目の金額として読む。
- 明細の最後の頁の「歳出合計」は3段の中段にだけ題字があるので、桁の網羅の検査から外す（`excluded_boxes`）。款の和は3年とも本年度・前年度の歳出合計と一致する（2026年度 245,100,000・235,900,000 千円、2025年度 235,900,000・227,200,000 千円、2024年度 227,200,000・217,300,000 千円）。
- その年に無くなった目（`○都知事選挙費`）は本年度を `-`、比較を「皆減」と印字するので、項の比較が目の比較の和と合わない。`expenditure.layout.json` に印字のずれとして書く。2025年度の総合教育相談は内訳を1行（就学相談）しか印字していない。
- 説明の分け方は「事業」。

## 2024年度決算・歳出

### 下水道事業会計（収益費用明細書の費用）

「下水道事業会計決算書」（scan、物理頁＝印字頁+4）の収益費用明細書のうち費用の側（物理34–37頁、印字30–33頁）を1表にする。単位は「円・税抜」。款は公共下水道事業費用と浄化槽事業費用の2つで、和 12,203,317,751 円は37頁の「費用合計」の印字と一致する。ノード/金額は 122/122、木の検査は不一致 0。

- **科目の欄**: 見出しは「款」「項」「目」「節」が1つの升なので `header.staircase: "款項目節"` で割り、款・項・目の欄は `columns` で科目の欄（`axis_header: 科目`）にして字下げで段を決める（節は形 `shape`）。
- **名前のはみ出し**: 款・項・目の名前の行では縦の罫線が途切れ、名前が右の欄へはみ出す（「流域下水道管理費」「過年度損益修正損」「営業外費用」）。`rules.row_gaps` で、その行で途切れている罫線では OCR の行を切らない。
- **金額の見出し**: 金額の欄の見出しは「金額」。`columns` で「決算額」と宣言する（武蔵野の水道事業会計と同じ）。
- **dbt**: 款に番号が無いので、公営企業会計の前例に合わせて dbt の入力から外す（`fiscal_inputs.py` の EXCLUDE）。

決算報告書（物理6–9頁、款・項の予算と決算、税込）と、事業報告書の建設改良費の繰越決算（物理29頁）は表にしない。資本的支出は、この繰越事業（北野ポンプ場建設改良、物理29頁）の款・項・目・節と支出済額 724,513,900 円までを出典で確認でき、その他の事業別・目別の明細は未確認。
