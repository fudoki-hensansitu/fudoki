# 八王子市 132012

## 2024年度決算・歳出

### 下水道事業会計（収益費用明細書の費用）

「下水道事業会計決算書」（scan、物理頁＝印字頁+4）の収益費用明細書のうち費用の側（物理34–37頁、印字30–33頁）を1表にする。単位は「円・税抜」。款は公共下水道事業費用と浄化槽事業費用の2つで、和 12,203,317,751 円は37頁の「費用合計」の印字と一致する。ノード/金額は 122/122、木の検査は不一致 0。

- **科目の欄**: 見出しは「款」「項」「目」「節」が1つの升なので `header.staircase: "款項目節"` で割り、款・項・目の欄は `columns` で科目の欄（`axis_header: 科目`）にして字下げで段を決める（節は形 `shape`）。
- **名前のはみ出し**: 款・項・目の名前の行では縦の罫線が途切れ、名前が右の欄へはみ出す（「流域下水道管理費」「過年度損益修正損」「営業外費用」）。`rules.row_gaps` で、その行で途切れている罫線では OCR の行を切らない。
- **金額の見出し**: 金額の欄の見出しは「金額」。`columns` で「決算額」と宣言する（武蔵野の水道事業会計と同じ）。
- **dbt**: 款に番号が無いので、公営企業会計の前例に合わせて dbt の source から外す（`generate_sources.py` の EXCLUDE）。

決算報告書（物理6–9頁、款・項の予算と決算、税込）と、事業報告書の建設改良費の繰越決算（物理29頁）は表にしない。資本的支出は、この繰越事業（北野ポンプ場建設改良、物理29頁）の款・項・目・節と支出済額 724,513,900 円までを出典で確認でき、その他の事業別・目別の明細は未確認。
