# 北区 131172

## 2025・2026年度当初予算・歳出

各会計予算説明書（1冊の scan PDF）の事項別明細書を `generic_scan` で取り込む。見開き1頁の左に目・本年度・前年度・比較・財源内訳・節、右に説明を印字する。2年度・4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 年度 | 会計 | ノード | 金額 | 項の和（千円）＝総括の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 2025 | 一般会計 | 1,065 | 1,288 | 191,733,000 |
| 2025 | 国民健康保険事業 | 99 | 144 | 38,136,073 |
| 2025 | 介護保険 | 121 | 174 | 33,993,926 |
| 2025 | 後期高齢者医療 | 49 | 59 | 10,509,792 |
| 2026 | 一般会計 | 1,063 | 1,286 | 212,018,000 |
| 2026 | 国民健康保険事業 | 96 | 144 | 36,126,769 |
| 2026 | 介護保険 | 121 | 175 | 34,772,082 |
| 2026 | 後期高齢者医療 | 49 | 61 | 11,444,988 |

- **款・項**: 表は目だけを持ち、款・項は表の上に「（款） 1 議会費」「（項） 1 議会費」と印字する。layout の `paren_titles` でこれを頁の款・項として読む。項の金額は表を閉じる「計」の行の本年度予算額（`header.title_amount`）で、目の和をこれで確かめる。款は会計の総括にしか金額を印字しないので、保存時の単位の確かめはできない（unchecked）。項の和が総括の頁に印字された「歳出合計」と上の表のとおり一致することを別に確かめた。
- **読む頁**: 総括（款別の表）は明細と同じ木に入れないので、`pages` で明細の頁だけを読む。2026年度の国民健康保険事業は、番号を印字しない款「（共同事業拠出金）」の頁（本年度0円・前年度1千円）を読まない。歳出合計は変わらない。
- **金額の見出し**: 金額欄は「本年度」「前年度」「比較」とだけ印字する。`columns` の `heading` で「本年度予算額」「前年度予算額」と宣言し、本年度を当初予算の金額として読む。
- **財源内訳**: 目の行に財源の種類と額を複数行で印字し、名前と金額を1対1に組めないので、`excluded` で取り込まない。
- **説明**: 事業の金額の間に罫線のない積算表（区分・単価・人員・年額）が印字され、事業の木を組めないので、今回は `excluded` で取り込まない。OCR は見出しを「說明」とも読むので、両方の見出しを宣言した。目の和は節の金額で確かめる。
- **節**: 節の欄は法定の節だけを1段で印字する。OCR は番号と名前を詰めて読む行（`4共済費`）と空けて読む行（`3 職員手当等`）とで名前の書き出しが数pt違い、短い会計では字下げの段が2つに割れるので、breakdown の `flat` で番号つきの行を1段にした。
- **OCR の読み違い**: 減額の印△を∆（U+2206）やΔ（ギリシャ文字）と読むので、`name_corrections` で△に直した。金額のあとに財源内訳の名前まで1行に読んだもの（`Δ929,175特別区債`）は、その読みを `dropped_readings` で外し、金額を数字の位置の `amount_readings` で読んだ。字の間を空けて印字する款の題「土 木 費」を「木費」「土木」と読む頁は、`name_corrections` で直した。2025年度の共済費3件は頭の4を1と読んだので `amount_corrections` で直した。
## 2024年度当初予算・歳出

各会計予算説明書（1冊の text PDF）の事項別明細書を `generic_text` で取り込む。様式は2025・2026年度と同じなので、読み方（`workflow`）は2025年度の宣言をそのまま使い、text PDF で違う点だけを足した。

| 会計 | ノード | 金額 | 項の和（千円）＝総括の歳出合計 |
| --- | ---: | ---: | ---: |
| 一般会計 | 1,061 | 1,282 | 181,367,000 |
| 国民健康保険事業 | 105 | 163 | 37,538,284 |
| 介護保険 | 118 | 172 | 33,135,870 |
| 後期高齢者医療 | 48 | 60 | 10,327,418 |

- **減額の印**: 比較の欄の減額の印を文字層がΔ（ギリシャ文字）で持つので、文書の quirk `delta_minus` で△として読む。
- **字の線**: 一部の字（`使用料及び` の `用` など）の線を3〜4ptの線として描いており、行の罫線と読まれて節の名前の折り返し（`使用料及び` / `賃借料`）を切るので、文書の quirk `glyph_strokes` で語の中の短い線を罫線として読まない。
- **説明の見出し**: 字を空けて印字する「説　明」を1つの見出しとして読むので、`columns` には `説明` だけを宣言した（OCR の `說明` は要らない）。
- 項の和は総括の頁（物理頁6・187・231・274）に印字された「歳出合計」と上の表のとおり一致することを別に確かめた。国民健康保険事業の廃目「（退職被保険者等療養給付費）」など5件は、番号なしの目として本年度0円・前年度の金額のまま取り込んだ。
