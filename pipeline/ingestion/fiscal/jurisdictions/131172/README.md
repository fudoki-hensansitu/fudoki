# 北区 131172

## 2025・2026年度当初予算・歳出

各会計予算説明書（1冊の scan PDF）の事項別明細書を `generic_scan` で取り込む。見開き1頁の左に目・本年度・前年度・比較・財源内訳・節、右に説明を印字する。2年度・4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 年度 | 会計 | ノード | 金額 | 項の和（千円）＝総括の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 2025 | 一般会計 | 1,939 | 2,162 | 191,733,000 |
| 2025 | 国民健康保険事業 | 141 | 186 | 38,136,073 |
| 2025 | 介護保険 | 177 | 230 | 33,993,926 |
| 2025 | 後期高齢者医療 | 66 | 76 | 10,509,792 |
| 2026 | 一般会計 | 1,932 | 2,155 | 212,018,000 |
| 2026 | 国民健康保険事業 | 136 | 184 | 36,126,769 |
| 2026 | 介護保険 | 178 | 232 | 34,772,082 |
| 2026 | 後期高齢者医療 | 66 | 78 | 11,444,988 |

- **款・項**: 表は目だけを持ち、款・項は表の上に「（款） 1 議会費」「（項） 1 議会費」と印字する。layout の `paren_titles` でこれを頁の款・項として読む。項の金額は表を閉じる「計」の行の本年度予算額（`header.title_amount`）で、目の和をこれで確かめる。款は会計の総括にしか金額を印字しないので、保存時の単位の確かめはできない（unchecked）。項の和が総括の頁に印字された「歳出合計」と上の表のとおり一致することを別に確かめた。
- **読む頁**: 総括（款別の表）は明細と同じ木に入れないので、`pages` で明細の頁だけを読む。2026年度の国民健康保険事業は、番号を印字しない款「（共同事業拠出金）」の頁（本年度0円・前年度1千円）を読まない。歳出合計は変わらない。
- **金額の見出し**: 金額欄は「本年度」「前年度」「比較」とだけ印字する。`columns` の `heading` で「本年度予算額」「前年度予算額」と宣言し、本年度を当初予算の金額として読む。
- **財源内訳**: 目の行に財源の種類と額を複数行で印字し、名前と金額を1対1に組めないので、`excluded` で取り込まない。
- **説明**: 目の下を「1」「(1)」「ア」の3段で事業に分けて印字するので、breakdown の `shape` で事業の木にし、段は `marks` で決める。事業の金額の間に罫線のない積算表（「区分 単価 人員 年額」の見出しと、その下の行）を印字するので、axis の quirk `rate_tables` で見出しの「区分」から次の番号の行までを積算の注記にする。単価と人数だけの行（`1人当り保険者負担額 年間平均被保険者数`）は `notes`、基金の積立金の下の「令和N年度末基金現在高見込」は `note_kinds` で注記にする。括弧の番号のすぐ後に数字で始まる名前（`(2) ７歳以上６９歳以下`）と、数字で始まる括弧の注記（`(26所 児童定員2,928人)`）は、文書の quirk `bracketed_numbers` で読み分ける。scan の年度は説明の額を全角の数字で字を空けて印字し、Paddle が数字のかけらに分けて読むので、文書の quirk `spaced_digits` で1つの額につなぐ。目の和は節の金額で確かめる。
- **節**: 節の欄は法定の節だけを1段で印字する。OCR は番号と名前を詰めて読む行（`4共済費`）と空けて読む行（`3 職員手当等`）とで名前の書き出しが数pt違い、短い会計では字下げの段が2つに割れるので、breakdown の `flat` で番号つきの行を1段にした。
- **OCR の読み違い**: 減額の印△を∆（U+2206）やΔ（ギリシャ文字）と読むので、`name_corrections` で△に直した。金額のあとに財源内訳の名前まで1行に読んだもの（`Δ929,175特別区債`）は、その読みを `dropped_readings` で外し、金額を数字の位置の `amount_readings` で読んだ。字の間を空けて印字する款の題「土 木 費」を「木費」「土木」と読む頁と、2026年度の項の題「徴 税 費」「公 債 費」を真ん中の字を落として「徴費」「公費」と読む頁（79頁・154頁）は、`name_corrections` で直した。2025年度の共済費3件は頭の4を1と読んだので `amount_corrections` で直した。

## 2024年度当初予算・歳出

各会計予算説明書（1冊の text PDF）の事項別明細書を `generic_text` で取り込む。様式は2025・2026年度と同じなので、読み方（`workflow`）は2025年度の宣言をそのまま使い、text PDF で違う点だけを足した。

| 会計 | ノード | 金額 | 項の和（千円）＝総括の歳出合計 |
| --- | ---: | ---: | ---: |
| 一般会計 | 1,928 | 2,149 | 181,367,000 |
| 国民健康保険事業 | 147 | 205 | 37,538,284 |
| 介護保険 | 175 | 229 | 33,135,870 |
| 後期高齢者医療 | 64 | 76 | 10,327,418 |

- **減額の印**: 比較の欄の減額の印を文字層がΔ（ギリシャ文字）で持つので、文書の quirk `delta_minus` で△として読む。
- **字の線**: 一部の字（`使用料及び` の `用` など）の線を3〜4ptの線として描いており、行の罫線と読まれて節の名前の折り返し（`使用料及び` / `賃借料`）を切るので、文書の quirk `glyph_strokes` で語の中の短い線を罫線として読まない。
- **説明の見出し**: 字を空けて印字する「説　明」を1つの見出しとして読むので、breakdown は `説明` の見出しで宣言する。
- 項の和は総括の頁（物理頁6・187・231・274）に印字された「歳出合計」と上の表のとおり一致することを別に確かめた。国民健康保険事業の廃目「（退職被保険者等療養給付費）」など5件は、番号なしの目として本年度0円・前年度の金額のまま取り込んだ。

## 2023年度決算・歳出（R5、4会計、2026-11-15）

2024年度の決算と同じ宣言（`clipped_columns`、profile は `layouts/text_settlement/reading.json`）で読む。ノード/金額は一般会計 1,149/7,449、国保 111/966、介護 129/989、後期 51/411。

- **見開きの最後の目が節のない目（予備費）のとき、頁をまたいで目を閉じていなかった**。国保 p101 は 款・項・目 すべてが「予備費」で終わり、次頁（p102）は歳出合計だけを印字する。目を葉行にする判断は頁ごとに捨てていたため、予備費の金額 33 桁が未読になった。葉にするかどうかの判断を頁をまたいで持ち越すようにした（共通コード）。次の頁が節で始まれば葉にしない。

各会計予算説明書（1冊の scan PDF）を2025・2026年度と同じ様式・同じ読み方（`workflow`）で読む。頁の範囲と OCR の依頼だけを2023年度の選定の scope から作った。

- **減額の印**: OCR が△を∆（U+2206）やΔと読んだ読みは、2025年度と同じく `name_corrections` で△に直した。金額のあとに財源内訳の名前まで1行に読んだもの（`71,256繰入金`・`Δ1,719都支出金`）は、その読みを `dropped_readings` で外し、金額を数字の位置の `amount_readings` で読んだ。

- 項の和は総括の頁（物理頁6・185・229・272）に印字された「歳出合計」と上の表のとおり一致する。
