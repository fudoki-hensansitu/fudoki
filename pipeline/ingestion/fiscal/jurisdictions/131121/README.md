# 世田谷区（131121）

## 2023年度当初予算・歳出（R5、5表、2026-11-15）

2024年度の当初と同じ宣言で読む。ノード/金額は一般会計 2,915/3,254・国保 230/344・後期 80/118・介護 301/405・学校給食 8/14。款の和は一般会計 361,986,572千円（印字の歳出合計の頁は読まない。桁のみ確認）。

- **事業の名前が行いっぱいに印字され、金額はその下の財源の行（`特財：国庫支出金 17,519、都支出金 7,254 220,985`）の末尾に置かれる**（p79 など）。財源の行は注記なので、事業に金額が付かなかった。quirk `amount_on_funding_line` で、金額の無い事業の下の財源の行のうち、頁の事業の金額と右端がそろう金額を事業へ移す。
- 頁11・頁70 の財源内訳の欄に、前の版の数字が重なって残る箱がある。`excluded_boxes` で外した。
- 選挙費・社会福祉費は前年度にだけあった目が印字されず、項の前年度・比較の欄が子の和と合わない（本年度の欄は一致）。`2023/initial/expenditure.layout.json` の `source_inconsistencies` で宣言した。

## 2023年度決算・歳出（R5、5会計、2026-11-16）

事項別明細書2冊（scan）の5会計を読む。款の和はどれも印字の歳出合計と一致する（一般会計 371,696,775,421 円、国民健康保険 84,528,777,286 円、後期高齢者医療 24,419,243,045 円、介護保険 72,395,853,624 円、学校給食費 3,165,185,275 円）。

- 予算現額の「継続費及び繰越事業費繰越額」「予備費支出及び流用増減」の升を OCR が切れ切れに読み、両方の欄が「予算現額」になる（後期高齢者医療では予備費の額がぶつかった）。特別会計4つは全頁、一般会計は升が切れ切れになる最後の頁（物理117頁、升が2〜3pt 左）だけ、升の見出しを `header_readings` で宣言した。升の右の罫線をまたぐと見出しの語が罫線で切れるので、箱は升の中に収める。
