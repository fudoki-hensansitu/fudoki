# 世田谷区（131121）

## 2023〜2026年度当初予算・歳入（2026-11-17）

一般会計・国民健康保険事業・後期高齢者医療・介護保険・学校給食費（2025年度まで）の歳入を、予算・同説明書の歳入の冊から generic で取り込む（`revenue.json`）。

- 款・項・目は `indent`、節も `indent`。金額の見出し「本年度」「前年度」を「本年度予算額」「前年度予算額」と宣言する。説明は除外の種類「歳入の説明」で外す。
- **節の金額と説明の番号**: 節の金額が短いと、説明の最初の番号と罫を挟んで隙間なく並び、文字層では1語になる（節の `7` と説明の番号 `2` が `72`）。quirk `digits_across_rules` で、数字だけの語を、字の境目にある欄の罫で切る。罫が字を横切るときは切らない。
- **他の頁の文字の写し**: 頁には、別の頁の文字の写しが、互いに重ならない2つの矩形で切り抜かれて入っている。共通コードはこれまで切り抜きの矩形を包む箱で見え方を決めていたので、見えない写しを読み、名前が崩れたり説明の行を見出しに読んだりしていた（2025年度 p93、2023年度 p54）。PDF と同じく切り抜きの交わりで決めるよう共通コードを直した。
- **廃目の前年度**: 本年度に無くなった目は行として印字されない。そのため親の前年度の額と比較の額が、子の和と合わない。`revenue.layout.json` の `source_inconsistencies` に、印字値のまま宣言する。

## 2023年度当初予算・歳出（R5、5表、2026-11-15）

2024年度の当初と同じ宣言で読む。ノード/金額は一般会計 2,914/3,254・国保 230/344・後期 80/118・介護 301/405・学校給食 8/14。款の和は一般会計 361,986,572千円（印字の歳出合計の頁は読まない。桁のみ確認）。

- **事業の名前が行いっぱいに印字され、金額はその下の財源の行（`特財：国庫支出金 17,519、都支出金 7,254 220,985`）の末尾に置かれる**（p79 など）。財源の行は注記なので、事業に金額が付かなかった。quirk `amount_on_funding_line` で、金額の無い事業の下の財源の行のうち、頁の事業の金額と右端がそろう金額を事業へ移す。
- 頁11・頁70 の財源内訳の欄に、前の版の数字が重なって残る箱がある。`excluded_boxes` で外した。
- **白で塗りつぶされた行の写し**（頁80、2026-11-18）: 説明の行の写しが 18pt 下に文字層で入り、その上に白の矩形が後から描かれて隠れている。写しには切り抜きが無いので、切り抜きだけで見え方を決めると写しを読み、事業の名前が「会会計計年年度…」と崩れ、財源の注記が重複した。repair `white_cover` で、後から描かれた不透明の白い塗りに中心が入る字を見えないものとする。同じ白塗りの旧値は頁22・23・77〜79 にもあり、頁22・23・77 は隠れる字が2割前後で語を字から組み直すため、行の座標が動いてノードの ID が10件変わる（名前と金額の値は変わらない）。
- 頁80 の財源の行では、特財の額が次の財源の「、」と1語に読まれる（`8,027、その他`・`2,735、その他`）。財源内訳は取り込まないので `excluded_boxes` で外した。
- 選挙費・社会福祉費は前年度にだけあった目が印字されず、項の前年度・比較の欄が子の和と合わない（本年度の欄は一致）。`2023/initial/expenditure.layout.json` の `source_inconsistencies` で宣言した。

## 2023年度決算・歳出（R5、5会計、2026-11-16）

事項別明細書2冊（scan）の5会計を読む。款の和はどれも印字の歳出合計と一致する（一般会計 371,696,775,421 円、国民健康保険 84,528,777,286 円、後期高齢者医療 24,419,243,045 円、介護保険 72,395,853,624 円、学校給食費 3,165,185,275 円）。

- 予算現額の「継続費及び繰越事業費繰越額」「予備費支出及び流用増減」の升を OCR が切れ切れに読み、両方の欄が「予算現額」になる（後期高齢者医療では予備費の額がぶつかった）。特別会計4つは全頁、一般会計は升が切れ切れになる最後の頁（物理117頁、升が2〜3pt 左）だけ、升の見出しを `header_readings` で宣言した。升の右の罫線をまたぐと見出しの語が罫線で切れるので、箱は升の中に収める。

## 2024年度決算・歳出 特別会計（R6、4会計、2026-11-17）

国民健康保険事業・後期高齢者医療・介護保険事業・学校給食費の各会計を、一般会計と同じ宣言で特別会計の冊（005r6kessan.pdf）から読む。款の和は印字の歳出合計と一致する（国保 82,474,584,991円・後期 25,576,387,897円・介護 74,330,134,134円・学校給食費 3,315,149,376円）。

- **文字層の数字**: 特別会計の冊は数字が U+0013〜U+001C、カンマが U+000F の字で入っている（品川区の決算書と同じ）。`text_layer.character_map` で 0〜9 とカンマに対応付ける。一般会計の冊は普通の数字なので要らない。
