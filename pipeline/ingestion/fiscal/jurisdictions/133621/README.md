## 当初予算・歳出（2024〜2026）

議案書の当初予算書から、後期高齢者医療事業特別会計（2024〜2026）を `generic_text` で取り込む。宣言と保存参照は `<年度>/initial/expenditure.json` に置く。

- 本年度の財源の特定財源の欄（国都支出金・地方債・その他）は取り込まない。目の行の財源額の下に財源の種類と額が複数行で印字され、目の財源額と1対1に組めない。
- 款別の総括の頁の本年度予算額・前年度予算額とその財源内訳は取り込まない（`総括`）。同じ款の額を明細の頁が本年度・前年度として印字し、取り込むと同じノードに当初予算の額が二重に付く。
- 説明欄は事業の番号（1・2）と節の番号（12〜29）が同じ位置から始まるので、`breakdown.説明.options.marks` で節の番号を2段目、細節の名前（負担金・償還金など）を3段目と宣言する。
- 一般会計・国民健康保険事業特別会計（事業勘定・直営診療施設勘定）・介護保険事業特別会計（2024〜2026）も同じ読み方で取り込む。説明欄の節の番号が全角の右寄せで、2桁（「１０需用費」）が1桁の事業の番号と同じ位置から始まるので、番号の無い行を1段下げる `unnumbered_shift: 1` を宣言する。
- 前年度にだけあった目（一般会計の選挙費・道路橋りょう費・住宅費・中学校費・社会教育費の下、介護 2026 の介護サービス等諸費の下、国保 2024 の保険給付費の下）は印字されず、項の前年度と比較の欄が子の和と合わない。本年度の欄は一致する。印字値は書き換えず、`<年度>/initial/expenditure.layout.json` の `source_inconsistencies` で宣言した。
- 簡易水道事業会計は金額の見出しを解決できない行、浄化槽事業会計は2024が科目の名前と金額を1行に読み違え（目と節の和が合わない）、2025が備考の文中の金額、2026が科目の段の読み違いで止まる。いずれも未保存。
