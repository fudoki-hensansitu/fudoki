# 江戸川区 131237

## 2024年度決算・歳出

一般会計・特別会計3つ（国民健康保険事業、介護保険事業、後期高齢者医療）を取り込む。

決算書は1冊の scan で、見開きを物理2頁に分けて印字する。左頁に科目（款・項・目）・予算現額・節、右頁に支出済額・翌年度繰越額・不用額・備考がある。4会計とも同じ様式なので、読み方（`workflow`）は共通にした。

| 会計 | 頁 | ノード | 金額 | 款の和＝印字の歳出合計 |
| --- | --- | ---: | ---: | ---: |
| 一般会計 | 170–301 | 1,325 | 7,627 | 333,451,801,763 |
| 国民健康保険事業 | 323–341 | 127 | 848 | 60,374,045,772 |
| 介護保険事業 | 365–377 | 59 | 420 | 51,551,064,296 |
| 後期高齢者医療 | 395–409 | 49 | 382 | 16,821,607,767 |

- **見出し**: 見出しは字間を空けて印字されていて、OCR が升ごとに字を落とす（「科目」「予算現額」の升に「算」の1字だけ、など）。罫線の位置はどの頁も同じなので、升ごとの印字を `header_readings` で宣言した。各会計の最初の見開きだけ、枠の中の見出しの上に題字（「歳出」）の箱があり、見出しが 71.4pt 下がる。そのため見出しの揃えは `header.agree_on_bottom` で見出しの下端の罫線に合わせ、題字の箱は `header.ignore_frame_title` で見出しから外す。
- **節**: 節は番号と名前を左に揃えて印字する（`2給料`・`10需用費`）。字下げで読むと二桁の番号の節が一桁の節の子になるので、`shape` で読む。
- **予備費**: 予備費の備考は充用先の科目と金額を並べる（`総務費 219,321,000` など）。項目ではないので `note_kinds` で注記にした。注記の語は会計ごとに違う。
- **白紙の頁**: 国民健康保険の342頁と介護保険の378頁は白紙で、OCR が止まるので選定の範囲から外した。
- **読み違いの宣言**: 罫線をまたいで2つ・3つの金額を1つにつないだ読み（頁172・290・301）は `dropped_readings` で除き、`amount_readings` で欄ごとに宣言した。頁228の「マイナンバー推進費」の長音は `name_corrections` で補った。
- **COFOG**: 新しい目17個は `cofog_rules.csv` の `edogawa-2024-*` で、名称から仮に分類した（`tentative`）。
