# 福生市 132187

## 2024〜2026年度当初予算・歳出（一般会計）

予算書の事項別明細書を読む。見開きの左頁に款・項・目と本年度・前年度・比較・財源内訳、右頁に節と説明を印字するので、`facing_pages` で読む。款・項・目の見出しは階段に組まれている（`header.staircase`）。

- 範囲は明細の頁に絞る（`pages`）。総括の頁は字下げの位置が明細と違い、目の段を崩すので読まない。単位の検査は桁の検査になる。
- 財源内訳の欄は取り込まない。
- 予備費は節の区分を印字せず、節の欄に目と同じ金額だけを印字するので、その金額を `excluded_boxes`（親の繰り返し）で外す。
- 説明は3段で、事業（`1 議員人件費 [177,212]`）、事業の中の事務（`1 議員人件費（議会事務局） (177,212)`）、節の番号を付けた細節（`10 消耗品費（１） 454`）の順。同じ節の2つ目からの細節は番号を付けずに、番号の後の名前の位置から印字する（`印刷製本費（２）`）。分け方は「事業」。
- 番号と名前の間は半角の空白で、文字層の作り直しで番号が名前に付くと、`12 階段昇降機…` が数に読まれ、細節の深さもずれるので、番号と名前を離したままにする（repair `spaced_codes`）。
- 字の箱を墨ではなく字の枠で取る（repair `em_boxes`）。`トレーニング機器借上料` の `ト` が半段深く読まれるため。
- 見開きによって説明の欄が7〜8pt横にずれるので、字下げを欄の左の罫から測る（`column_edge`）。
- 頁の最後の節の名前が次の頁の頭に続く（`13 使用料及び` / `賃借料`）。次の頁の頭の行を前の節の名前に結ぶ（`name_tails_over_pages`）。
- 2024年度と2025年度の PDF は、各行の文字を2度ずつ持ち、片方を面積の無いクリップで隠す。2024年度の3頁（物理211・229・257）だけは、印字に当たる文字も同じクリップの下にあり、15.6pt 左にずれている。この3頁はクリップの下の文字を読み、他の頁で2つの写しが離れている距離だけ右へ動かす（repair `line_clips`）。字を線でも描くので、短い線は罫として読まない。

## 2023年度決算・歳出（4会計）

2024 年度の宣言を移して読む。選定の範囲には総括の頁も入るが、総括は款を字下げで組み直していて科目の段を崩すので、明細の頁に絞る（`pages`）。項の名前が2行に折り返し（`3 戸籍住民基本` / `台帳費`）、翌年度繰越額の欄は1行目に `繰越明許費`、2行目に金額を印字する。金額が折り返した名前の行のものと読まれていたので、欄の中で種類の語の下に印字した金額は、種類の語の行の科目のものと共通の読み方を直した。

## 2023年度当初予算・歳出（一般会計）

2024 年度の宣言を移して読む。見開きは物理58頁（左）・59頁（右）から始まるので、`pages` と選定の範囲は58頁から取る（59頁から取ると左頁の款1・議会費が落ち、款の和が総括の歳出合計 27,280,000 千円より 285,487 千円足りない）。総括の頁（20〜21）は款の和を重ねるので読まない。

- 物理58頁の「３ 歳出」の章番号、219・221・243頁の積算の注記（`63,820円×7校×12月` など）の金額、279頁の予備費の節の欄の金額は `excluded_boxes` で外す。
- 259頁の「17 備品購入費」は 4,180 千円と印字し、内訳は「図書 4,123」の1行だけで 57 千円足りない。出典の印字そのもので、`expenditure.layout.json` に宣言した。

## 2024〜2026年度当初予算・歳出（特別会計）

国民健康保険・介護保険・後期高齢者医療の3会計を、一般会計と同じ予算書の事項別明細書から、一般会計の宣言を写して読む（公営企業会計は読まない）。範囲は各会計の明細の頁に絞る。

- 予備費は一般会計と同じく節の欄に目と同じ金額だけを印字するので、その金額を `excluded_boxes` で外す。
- 2024年度の介護保険の物理111・112頁は文字層を持たない画像の頁で、この2頁だけ OCR で読む（`ocr_inputs`）。OCR は説明の番号と名前を1行に読み、行の箱が番号の左の余白まで含むので、名前の始まりがずれて説明の段が崩れる。番号の後に字の高さの3割より広い空きがある1〜3桁の番号は名前と別の語に分ける（quirk `spaced_ocr_codes`）。
- 各年度の本年度・前年度の款の和は年度をまたいで一致する（2024年度の本年度 = 2025年度の前年度、2025年度の本年度 = 2026年度の前年度）。

## 歳入（当初 R5〜R8・決算 R5〜R6）

歳出と同じ冊の歳入の事項別明細を、歳出の宣言を写して読む。当初の説明の欄（調定見込額・収納率など）と決算の備考は「歳入の説明」で外し、款・項・目・節で取り込む。当初は歳出と同じく一般会計だけ、決算は4会計。範囲は明細の頁に絞り、款の和は総括の歳入合計と一致する。
