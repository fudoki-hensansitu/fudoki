# 福生市 132187

## 2024〜2026年度当初予算・歳出（一般会計）

予算書の事項別明細書を読む。見開きの左頁に款・項・目と本年度・前年度・比較・財源内訳、右頁に節と説明を印字するので、`facing_pages` で読む。款・項・目の見出しは階段に組まれている（`header.staircase`）。

- 範囲は明細の頁に絞る（`pages`）。総括の頁は字下げの位置が明細と違い、目の段を崩すので読まない。単位の検査は桁の検査になる。
- 財源内訳の欄は取り込まない。
- 予備費は節の区分を印字せず、節の欄に目と同じ金額だけを印字するので、その金額を `excluded_boxes`（親の繰り返し）で外す。
- 説明は3桁の事業（`1 議員人件費 [177,212]`）、事業の中の事務（`1 議員人件費（議会事務局） (177,212)`）、節の番号を付けた細節（`10 消耗品費（１） 454`）の順。同じ節の2つ目からの細節は番号を付けずに、番号の後の名前の位置から印字する（`印刷製本費（２）`）。分け方は「事業」。
- 番号と名前の間は半角の空白で、文字層の作り直しで番号が名前に付くと、`12 階段昇降機…` が数に読まれ、細節の深さもずれるので、番号と名前を離したままにする（repair `spaced_codes`）。
- 字の箱を墨ではなく字の枠で取る（repair `em_boxes`）。`トレーニング機器借上料` の `ト` が半段深く読まれるため。
- 見開きによって説明の欄が7〜8pt横にずれるので、字下げを欄の左の罫から測る（`column_edge`）。
- 頁の最後の節の名前が次の頁の頭に続く（`13 使用料及び` / `賃借料`）。次の頁の頭の行を前の節の名前に結ぶ（`name_tails_over_pages`）。
- 2024年度と2025年度の PDF は、各行の文字を2度ずつ持ち、片方を面積の無いクリップで隠す。2024年度の3頁（物理211・229・257）だけは、印字に当たる文字も同じクリップの下にあり、15.6pt 左にずれている。この3頁はクリップの下の文字を読み、他の頁で2つの写しが離れている距離だけ右へ動かす（repair `line_clips`）。字を線でも描くので、短い線は罫として読まない。
