列ごとの説明は `describe_expenditure_columns`（REST は `GET /v1/expenditure/columns`）が正本です。このページは、その前提になる考え方をまとめます。

## 資料区分（document_kind）

| 値 | 金額（`amount_yen`）の意味 |
| --- | --- |
| `settlement` | 決算の支出済額（円） |
| `initial` | 当初予算額（円） |

意味の違う金額なので、資料区分をまたいで足さないでください。

## 歳出の木

一つの原典の歳出は、会計ごとに款・項・目と続く木になっています。木の一つひとつの項目をノードと呼び、`node_kind` に段の見出し（`款`・`項`・`目` など）が入ります。親は `parent_node_id` です。会計はノードではなく各行の `account_name` の値なので、木の根は款で、款の親は null です。

`node_id` は団体・年度・会計・番号などから作る ID で、年度をまたいだ同一性は保証しません。年度をまたいで比べるときは、`kan_name`・`kou_name`・`name` や COFOG で揃えてください。

## 軸（axis）

目の下の内訳は、科目・節・備考など**同じ支出の別の切り口**です。軸の違う子を混ぜて足すと、同じ金額を二重に数えます。`get_expenditure_node` は子を軸ごとに分けて返します。

`is_leaf` は同じ軸の子を持たないノードです。総額を末端から求めるときは、一つの軸の末端だけを足します。

## COFOG

団体間で比べるため、風土記は目を COFOG（政府支出の機能別分類）で分類しています。これは原典にない風土記の判断です。コード（`cofog_code`）は `cofog_status` が `assigned` か `tentative` の目にだけ一つ付き、`unclassifiable`・`out-of-scope` の目には付きません。

| `cofog_status` | 意味 |
| --- | --- |
| `assigned` | コードを割り当てた |
| `tentative` | 境界の判断で確信が持てないまま付けた暫定の割り当て |
| `unclassifiable` | 分類できない |
| `out-of-scope` | 分類の対象外 |

上位の分類は `cofog_code` の前方一致で求めます（例：`10` は社会保護、`10.4` は家族及び児童）。

## 金額を足すときの条件

- 比較には提供された款・項・目の金額を使い、親と子を混ぜて合算しません。当初予算CSVの親金額は子の和から生成した値で、原典の印字値ではありません。
- COFOG で比べるときは、`cofog_code` の前方一致で目（`node_kind = "目"`）を集めて足します。コードの付いた目には一つだけ付くので、二重計上は起きません。
- division のコードだけを持つ目（例：`"10"`）は、配下のどの group に属するか決まっていません。`"10.2*"` の和にはそうした目を含めません。
- 同じ団体・年度・資料区分・会計の目について、COFOG の全 division の和と、`cofog_status` が `unclassifiable` と `out-of-scope` の目の和を足すと、歳出の総額になります。
- 軸の異なる末端を混ぜて足しません。

## 会計と繰出

`account_name` は原典の会計名、`account_kind` は団体をまたいで揃えた会計の種類（一般会計・国民健康保険・介護保険など）です。団体をまたぐ比較は `account_kind` で行ってください。

会計から別の会計へ移す繰出金には `is_interfund_transfer` の印と、受け手の会計の種類 `interfund_transfer_to` が付きます。金額の消去（連結）はしていないので、会計をまたいで足すと繰出の分が二重になります。印は網羅ではありません。名称から繰出と判断できないものや、節・備考の内訳を持たない団体の繰出には付かないので、印で除いても二重計上が残ることがあります。

## 原典の位置

`source_page` は項目が印字された頁、`amount_source_page` は採用した金額が印字された頁です。どちらも原典ファイル（`origin_id` が指す 1 つの PDF）の 1 から数えたページ番号で、紙面に印刷されたページ番号ではありません。分冊や抜粋のファイルでは、そのファイルの中での番号です。原典の URL に `#page=<番号>` を付けると、Chrome・Edge・Firefox・Acrobat の PDF ビューアではその頁が開きます（Safari やダウンロードした PDF では効きません）。CSV の原典では頁ではなく、1 から数えた物理行（見出しの行が 1 行目）が入ります。

PDF の場合は `source_x0`〜`source_y1`・`amount_source_x0`〜`amount_source_y1` に、頁の左上を原点とする印字の枠（pt）が入ります。ただし団体によっては横の座標（x0・x1）が null で、金額の座標は一つの印字が全額のときだけ入ります（複数の印字を足した金額や位置が分からない金額では null）。CSV の原典は座標を持ちません。

- **評価対象年度**は、評価された実績の決算の年度です。北区の「令和8年度」の資料は、令和7年度（2025 年度）の決算を評価しています。入力の `fiscal_year` には資料の題の年度ではなく、評価対象年度を指定します。収録していない団体・年度は `not_covered` を返し、原典に無いという意味ではありません。
- **返すのは所在と短い抜粋だけ**です。原典の URL・SHA-256・物理頁（PDF ファイルの 1 から数えた頁。紙面の印刷頁とは別）・その頁を指す `page_url`、150 文字以内の抜粋を返します。頁の本文は返しません。評価資料の著作権は各自治体にあります。内容は `page_url` の原典 PDF で読んでください。
- 抜粋は所在を示すためのもので、評価・目標値・実績の根拠にはなりません。候補は検索の結果で、目的の事業の評価とは限りません。事業・年度の列・指標は、原典の頁で確かめてから使ってください。
- 評価資料の金額は、歳出の木の金額（決算書の支出済額・当初予算額）の代わりにはなりません。決算書の目と評価の事業の対応は、風土記では定めていません。
