## 金額を足す前に

:::warning
- 資料区分（`settlement` 決算の支出済額 ／ `initial` 当初予算額）をまたいで足さない。
- 親と子を混ぜて足さない。当初予算 CSV の親の金額は子の和から作った値で、出典の印字値ではありません。
- 科目と内訳を混ぜて足さない。分け方（`breakdown`：事業・節・その他）の違う内訳も混ぜて足さない。同じ支出を二重に数えます。
- 会計をまたいで足すと、繰出の分が二重になる。
:::

## 科目（款・項・目）を辿る

出典の歳出は、会計ごとに款・項・目と続く科目の木です。科目は `search_expenditure_subjects` で引き、`level` に段（`款`・`項`・`目`）、`parent_subject_id` に親の科目が入ります。会計は科目ではなく `account_name` の値なので、款の親は null です。同じ資料・会計の款を足すと、その会計の総額になります。`is_leaf = true` の科目（目と、目の無い項）の和もふつうは同じですが、出典で子の印字が親に満たない科目があると款の和より小さくなります（例: 神戸市の 2025 年度決算の一般会計は 170,000 円少ない）。

`subject_id` は年度をまたいだ同一性を保証しません。年度をまたいで比べるときは `kan_name`・`kou_name`・`name` か COFOG で揃えます。同じ年度の決算と当初予算の同じ科目は `node_key` が同じです。

## 目の下の内訳を分け方（breakdown）ごとに見る

目の下の内訳は `search_expenditure_details` で引きます。内訳は分け方（`breakdown`）で分かれます。`事業` は備考・説明の欄の事業、`節` は経済的な性質による区分、`その他` は事業とも節とも読めない欄です。分け方は**同じ支出の別の切り口**なので、足すのは一つの分け方の中だけです。

`depth = 1` の内訳（科目の直下）を同じ分け方の中で足すと、おおむね科目の金額になります。出典が目の金額の一部しか内訳を印字していないときは一致しません。`is_subject_remainder` は、目を持つ項の直下に付いた内訳の印です。子の科目と並んで科目の額の一部になるので、科目の `is_leaf` の和には入っていません。`department` は名前の末尾の【】から取った所管課です。

`get_expenditure_line` は、科目なら子の科目と直下の内訳を、内訳なら内訳の子を、分け方ごとに分けて返します。

## COFOG で自治体をまたいで比べる

自治体間で比べるため、目を COFOG（政府支出の機能別分類）で分類しています。出典に無い、風土記の判断です。

| `cofog_status` | 意味 | `cofog_code` |
| --- | --- | --- |
| `assigned` | 割り当てた | 一つ付く |
| `tentative` | 境界の判断で確信が持てない暫定の割り当て | 一つ付く |
| `unclassifiable` | 分類できない | 無し |
| `out-of-scope` | 分類の対象外 | 無し |

- 上位の分類は前方一致で求めます（`10` は社会保護、`10.4` は家族及び児童）。目（`level = "目"`）を前方一致で集めて足しても二重計上は起きません。
- division のコードだけを持つ目（例：`"10"`）は、`"10.2*"` のような group の和に入りません。
- 同じ自治体・年度・資料区分・会計の目について、全 division の和と `unclassifiable`・`out-of-scope` の目の和を足すと、歳出の総額になります。

## 会計をそろえ、繰出を見分ける

`account_name` は出典の会計名、`account_kind` は自治体をまたいで揃えた会計の種類（一般会計・国民健康保険・介護保険など）です。自治体をまたぐ比較は `account_kind` で行います。

繰出金には `is_interfund_transfer` が付きます。受け手の会計の種類 `interfund_transfer_to` は、受け手を特定できたときだけ入り、ほかは `NULL` です。金額の消去（連結）はしていません。印は網羅ではありません。目の名称が「〇〇会計繰出金」の形なら付きますが、そうでない繰出は節・備考などの内訳から拾うので、内訳を持たない自治体では付かないことがあります。

## 出典の頁と位置を確かめる

印字の位置は歳出の行の取得（`get_expenditure_line`）の `locations` に、行の ID（`line_id`）ごとに入ります。

| 列 | 中身 |
| --- | --- |
| `kind` | 出典の形式（`pdf`・`csv`） |
| `source_page` | 項目が印字された頁 |
| `amount_source_page` | 採用した金額が印字された頁 |
| `source_x0`〜`source_y1`、`amount_source_x0`〜`amount_source_y1` | 頁の左上を原点とする印字の枠（pt） |

- 頁は出典ファイル（`origin_id` が指す 1 つの PDF）の 1 から数えた番号で、紙面の印刷頁とは別です。URL に `#page=<番号>` を付けると、Chrome・Edge・Firefox・Acrobat ではその頁が開きます。
- 横の座標（x0・x1）が null の自治体があります。金額の座標は、一つの印字が全額のときだけ入ります。
- CSV の出典（`kind = "csv"`）は頁の代わりに `source_line`・`amount_source_line` に 1 から数えた物理行（見出しが 1 行目）が入り、頁と座標は持ちません。
