列ごとの説明は `describe_expenditure_columns`（REST は `GET /v1/expenditure/columns`）が正本です。このページはその前提をまとめます。

## 金額を足す前に

:::warning
- 資料区分（`settlement` 決算の支出済額 ／ `initial` 当初予算額）をまたいで足さない。
- 親と子を混ぜて足さない。当初予算 CSV の親の金額は子の和から作った値で、出典の印字値ではありません。
- 軸の違う子（科目・節・備考）を混ぜて足さない。同じ支出を二重に数えます。
- 会計をまたいで足すと、繰出の分が二重になる。
:::

## 歳出の木

出典の歳出は、会計ごとに款・項・目と続く木です。木の項目をノードと呼び、`node_kind` に段（`款`・`項`・`目` など）、`parent_node_id` に親が入ります。会計はノードではなく `account_name` の値なので、款の親は null です。

`node_id` は年度をまたいだ同一性を保証しません。年度をまたいで比べるときは `kan_name`・`kou_name`・`name` か COFOG で揃えます。

## 軸（axis）

目の下の内訳は、科目・節・備考など**同じ支出の別の切り口**です。`get_expenditure_node` は子を軸ごとに分けて返します。`is_leaf` は同じ軸の子を持たないノードで、末端から総額を求めるときは一つの軸の末端だけを足します。

## COFOG

自治体間で比べるため、目を COFOG（政府支出の機能別分類）で分類しています。出典に無い、風土記の判断です。

| `cofog_status` | 意味 | `cofog_code` |
| --- | --- | --- |
| `assigned` | 割り当てた | 一つ付く |
| `tentative` | 境界の判断で確信が持てない暫定の割り当て | 一つ付く |
| `unclassifiable` | 分類できない | 無し |
| `out-of-scope` | 分類の対象外 | 無し |

- 上位の分類は前方一致で求めます（`10` は社会保護、`10.4` は家族及び児童）。目（`node_kind = "目"`）を前方一致で集めて足しても二重計上は起きません。
- division のコードだけを持つ目（例：`"10"`）は、`"10.2*"` のような group の和に入りません。
- 同じ自治体・年度・資料区分・会計の目について、全 division の和と `unclassifiable`・`out-of-scope` の目の和を足すと、歳出の総額になります。

## 会計と繰出

`account_name` は出典の会計名、`account_kind` は自治体をまたいで揃えた会計の種類（一般会計・国民健康保険・介護保険など）です。自治体をまたぐ比較は `account_kind` で行います。

繰出金には `is_interfund_transfer` が付きます。受け手の会計の種類 `interfund_transfer_to` は、受け手を特定できたときだけ入り、ほかは `NULL` です。金額の消去（連結）はしていません。印は網羅ではなく、名称から判断できない繰出や、節・備考の内訳を持たない自治体の繰出には付きません。

## 出典の位置

| 列 | 中身 |
| --- | --- |
| `source_page` | 項目が印字された頁 |
| `amount_source_page` | 採用した金額が印字された頁 |
| `source_x0`〜`source_y1`、`amount_source_x0`〜`amount_source_y1` | 頁の左上を原点とする印字の枠（pt） |

- 頁は出典ファイル（`origin_id` が指す 1 つの PDF）の 1 から数えた番号で、紙面の印刷頁とは別です。URL に `#page=<番号>` を付けると、Chrome・Edge・Firefox・Acrobat ではその頁が開きます。
- 横の座標（x0・x1）が null の自治体があります。金額の座標は、一つの印字が全額のときだけ入ります。
- CSV の出典は頁の代わりに 1 から数えた物理行（見出しが 1 行目）が入り、座標は持ちません。
