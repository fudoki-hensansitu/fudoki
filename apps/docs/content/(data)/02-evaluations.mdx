`search_evaluations`（REST は `POST /v1/evaluations:search`）に自治体・評価対象年度・事業名などの検索文を渡すと、評価が載った出典 PDF の頁の候補を返します。

## 検索で返るもの

出典の URL・SHA-256・物理頁（PDF の 1 から数えた頁）・その頁を開く `page_url` と、150 文字以内の抜粋です。**頁の本文は返しません。** 内容は `page_url` の PDF で読んでください。`origin_format` が `csv` の出典（公開レポートの表）では、頁はデータ行の番号で、`page_url` はレポートを開きます。レポートの画面で事業名から探してください。評価資料の著作権は各自治体にあります。

## 気をつけること

- **評価対象年度**は、評価された決算の年度です。北区の「令和8年度」の資料は 2025 年度の決算を評価しているので、`fiscal_year` は 2025 にします。
- 候補は検索の結果で、目的の事業とは限りません。抜粋は所在を示すだけなので、指標や実績は出典の頁で確かめます。
- 評価資料の金額は、歳出の金額（支出済額・当初予算額）の代わりになりません。決算書の目と評価の事業の対応は、風土記では定めていません。

| 状態 | 意味 |
| --- | --- |
| `not_covered` | その自治体・年度を収録していない（出典が無いという意味ではない） |
| `no_candidates` | 候補が 0 件。言い方を変えて引き直せる |
| `RESOURCE_EXHAUSTED`（REST は 429） | 回数の上限。`retry_after_seconds`（`Retry-After`）だけ待つ |
| `UNAVAILABLE`（503） | 停止中か検索の失敗。0 件ではない |
