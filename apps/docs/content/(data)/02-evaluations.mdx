事業評価シートと予算案のプレス発表は、資料から読み取った表で返します。収録している年度と ID は `list_jurisdictions`（REST は `GET /v1/jurisdictions`）の `evaluations`・`budget_proposals` にあります。

## 事業評価

| tool | REST | 返すもの |
| --- | --- | --- |
| `get_evaluation` | `GET /v1/evaluations/{evaluation_id}` | 1 つの自治体・年度の事業評価と、評価シートの一覧（ページ送り） |
| `get_evaluation_sheet` | `GET /v1/evaluations/sheets/{sheet_id}` | 評価シート 1 枚と、その指標・指標の値 |
| `search_evaluation_sheets` | `POST /v1/evaluations/sheets:search` | 評価シートを年度・自治体・事業名・評価などで絞って一覧する |

## 予算案

| tool | REST | 返すもの |
| --- | --- | --- |
| `get_budget_proposal` | `GET /v1/budget-proposals/{budget_proposal_id}` | 1 つの自治体・年度の予算案のプレス発表と、その施策 |
| `search_budget_measures` | `POST /v1/budget-proposals/measures:search` | 施策を年度・自治体・新規かどうかなどで絞って一覧する |

## 気をつけること

- 評価シートと施策の金額は、歳出の金額（支出済額・当初予算額）に足しません。
- 評価（A〜D など）の意味は自治体ごとに違います。自治体どうしの順位付けには使えません。
- 行の `origin_id` と `page` が、出典の資料と物理頁（PDF の 1 から数えた頁）を指します。出典は応答の `origins` にあります。資料の著作権は各自治体にあります。
