事業評価シートと予算案のプレス発表は、資料から読み取った表で返します。収録している年度と ID は `list_jurisdictions`（REST は `GET /v1/jurisdictions`）の `evaluations`・`budget_proposals` にあります。

## 事業評価

| tool | REST | 返すもの |
| --- | --- | --- |
| `get_evaluation` | `GET /v1/evaluations/{evaluation_id}` | 1 つの自治体・年度の事業評価と、評価シートの一覧（ページ送り） |
| `get_evaluation_sheet` | `GET /v1/evaluations/sheets/{sheet_id}` | 評価シート 1 枚と、その指標・指標の値 |
| `search_evaluation_sheets` | `POST /v1/evaluations/sheets:search` | 評価シートを年度・自治体・事業名・方向性の区分（`direction_code`）などで絞って一覧する |

## 予算案

| tool | REST | 返すもの |
| --- | --- | --- |
| `get_budget_proposal` | `GET /v1/budget-proposals/{budget_proposal_id}` | 1 つの自治体・年度の予算案のプレス発表と、その施策 |
| `search_budget_measures` | `POST /v1/budget-proposals/measures:search` | 施策を年度・自治体・新規かどうかなどで絞って一覧する |

## 事業

予算書・決算書の事業の行を、年度をまたいでつないだものです。つなぎ方は風土記の判断で、今は品川区だけを収録しています。

| tool | REST | 返すもの |
| --- | --- | --- |
| `get_project` | `GET /v1/projects/{project_id}` | 事業 1 つの年度ごとの当初予算額・支出済額と、直下の事業 |
| `search_projects` | `POST /v1/projects:search` | 事業の年度を年度・自治体・名前・款項目などで絞って一覧する |

事業に付いた評価シートと施策は、事業の年度の `settlement_expenditure_detail_id`・`initial_expenditure_detail_id` を、`search_evaluation_sheets`・`search_budget_measures` の `where` の `expenditure_detail_id` に渡して引きます。

## 気をつけること

- 評価シートと施策の金額は、歳出の金額（支出済額・当初予算額）に足しません。
- 事業は予算書の入れ子のまま親子を持ち、子の事業の額は親の事業の額に含まれます。事業どうしを足しません。
- 評価の印字（`grade_label`）と今後の方向性の印字（`direction`）は、自治体ごとに書き方が違います。`direction_code` はそれを共通の区分に当てたもの、`outlook.grade`（A 広げる・B 続ける・C 見直す・D 終える）はその区分を4つにまとめたもので、どちらも風土記の判断です。`outlook` は表の列ではないので `where` では絞れません。A〜D で絞るときは `direction_code` で絞ります（A は new・expand、B は keep・statutory・as_planned、C は improve・resize・reduce、D は merge・complete・end・consider_end）。
- 評価は各自治体が自ら付けたものです。自治体どうしの順位付けには使いません。
- 事業の年度の行は `origin_id` と `page` を持ちません。出典は `initial_expenditure_detail_id`・`settlement_expenditure_detail_id` を `get_expenditure_line` に渡して辿ります。
- ほかの行の `origin_id` と `page` が、出典の資料と物理頁（PDF の 1 から数えた頁）を指します。出典は応答の `origins` にあります。資料の著作権は各自治体にあります。
