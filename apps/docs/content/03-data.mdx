列ごとの説明は `describe_expenditure_columns`（REST は `GET /v1/expenditure/columns`）が正本です。このページは、その前提になる考え方をまとめます。

## 資料区分（document_kind）

| 値 | 金額（`amount_yen`）の意味 |
| --- | --- |
| `settlement` | 決算の支出済額（円） |
| `initial` | 当初予算額（円） |

意味の違う金額なので、資料区分をまたいで足さないでください。

## 歳出の木

一つの原典の歳出は、会計の下に款・項・目と続く木になっています。木の一つひとつの項目をノードと呼び、`node_kind` に段の見出し（`款`・`項`・`目` など）が入ります。親は `parent_node_id` で、款の親は null です。

`node_id` は団体・年度・会計・番号などから作る ID で、年度をまたいだ同一性は保証しません。年度をまたいで比べるときは、`kan_name`・`kou_name`・`name` や COFOG で揃えてください。

## 軸（axis）

目の下の内訳は、科目・節・備考など**同じ支出の別の切り口**です。軸の違う子を混ぜて足すと、同じ金額を二重に数えます。`get_expenditure_node` は子を軸ごとに分けて返します。

`is_leaf` は同じ軸の子を持たないノードです。総額を末端から求めるときは、一つの軸の末端だけを足します。

## COFOG

団体間で比べるため、風土記は目に COFOG（政府支出の機能別分類）のコードを一つだけ付けています。これは原典にない風土記の判断です。

| `cofog_status` | 意味 |
| --- | --- |
| `assigned` | コードを割り当てた |
| `tentative` | 境界の判断で確信が持てないまま付けた暫定の割り当て |
| `unclassifiable` | 分類できない |
| `out-of-scope` | 分類の対象外 |

上位の分類は `cofog_code` の前方一致で求めます（例：`10` は社会保障、`10.4` は家族・子ども）。

## 金額を足すときの条件

- 款・項・目の金額は原典に印字された値で、比較に和は要りません。
- COFOG で比べるときは、`cofog_code` の前方一致で目（`node_kind = "目"`）を集めて足します。目には COFOG のコードが一つだけ付くので、二重計上は起きません。
- division のコードだけを持つ目（例：`"10"`）は、配下のどの group に属するか決まっていません。`"10.2*"` の和にはそうした目を含めません。
- 同じ団体・年度・資料区分・会計の目について、COFOG の全 division の和と、`cofog_status` が `unclassifiable` と `out-of-scope` の目の和を足すと、歳出の総額になります。
- 軸の異なる末端を混ぜて足しません。

## 会計と繰出

`account_name` は原典の会計名、`account_kind` は団体をまたいで揃えた会計の種類（一般会計・国民健康保険・介護保険など）です。団体をまたぐ比較は `account_kind` で行ってください。

会計から別の会計へ移す繰出金には `is_interfund_transfer` の印と、受け手の会計の種類 `interfund_transfer_to` が付きます。金額の消去（連結）はしていないので、会計をまたいで足すと繰出の分が二重になります。

## 原典の位置

`source_page` は項目が印字された原典の物理頁、`amount_source_page` は採用した金額の物理頁です。PDF の場合は `source_x0`〜`source_y1`・`amount_source_x0`〜`amount_source_y1` に、頁の左上を原点とする印字の枠（pt）が入ります。
