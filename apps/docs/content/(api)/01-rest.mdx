| 項目 | 値 |
| --- | --- |
| ベース URL | `https://api.fudoki.dev` |
| 認証 | なし |
| 応答 | JSON（出典 PDF の中継だけ `application/pdf`）、`Cache-Control: no-store` |

## 最初の問い合わせ

<Steps>
  <Step title="自治体と収録範囲を確かめる">
    ```bash
    curl 'https://api.fudoki.dev/v1/jurisdictions?name=%E6%AD%A6%E8%94%B5%E9%87%8E%E5%B8%82'
    ```

    `name`（部分一致。例は「武蔵野市」）か `code`（6 桁か 5 桁）で絞ると、6 桁の自治体コードと、収録している年度・資料区分・会計、事業評価と予算案の年度が返ります。検索の `jurisdiction_code` は 6 桁だけを受け付けるので、ここで引いたコードを使います。
  </Step>
  <Step title="科目を検索する">
    ```bash
    curl -X POST 'https://api.fudoki.dev/v1/expenditures/subjects:search' \
      -H 'Content-Type: application/json' \
      -d '{
        "document_kind": "settlement",
        "fiscal_year": { "min": 2025, "max": 2025 },
        "where": { "level": { "eq": ["目"] }, "cofog_code": { "prefix": "10.4" } },
        "order_by": [{ "column": "amount_yen", "desc": true }],
        "page_size": 50
      }'
    ```

    `document_kind`（`settlement` は決算、`initial` は当初予算）と `fiscal_year`（西暦、5 年以内）が必須です。款・項・目は科目（`subjects:search`）、その下の事業・節は内訳（`POST /v1/expenditures/details:search`）を同じ形で検索します。列の意味と金額を足すときの条件は、[API リファレンス](/reference)の各操作の説明と schema にあります。
  </Step>
  <Step title="内訳を辿る">
    ```bash
    curl 'https://api.fudoki.dev/v1/expenditures/lines/<subject_id>'
    ```

    科目と、子の科目、直下の内訳を分け方（`breakdown`：事業・節・その他）ごとに返します。内訳の子も同じ `GET /v1/expenditures/lines/<detail_id>` で辿ります。印字の位置は `locations` に入ります。
  </Step>
</Steps>

## 検索を条件で絞る

`where` は列名をキーにした条件で、列どうしは AND です。

| 列の型 | 使える条件 |
| --- | --- |
| string | `eq`・`not_eq`（`eq` は OR）、`prefix`・`suffix`・`contains`、`is_null` |
| integer | `eq`・`not_eq`（`eq` は OR）、`min`・`max`、`is_null` |
| number | `min`・`max`、`is_null` |
| boolean | `eq` |

- 列をまたぐ OR と NOT は無いので、2 回に分けて問い合わせます。
- `fiscal_year` の年数と条件の値は合わせて 90 個まで、文字列の値は 200 文字までです。`prefix`・`suffix`・`contains` はさらに、escape（`*` `?` `[` は 3 バイト）と前後の `*` を含めて UTF-8 で 50 バイトまでです（和文はおよそ 16 文字）。

## 続きのページを取る

応答の `next_page_token` が null でなければ、次の要求に `page_token` として渡します（科目・内訳の取得と自治体の一覧では query に付けます）。`page_size` は 1〜1000（既定 100）、自治体の一覧は 1〜100（既定 20）。100,000 件目より先は条件を絞ってください。

## 出典を確かめる

応答の `origins` に、行の `origin_id` が指す出典（資料名・公開 URL・形式・SHA-256）が入ります。1 つの自治体（`GET /v1/jurisdictions/{jurisdiction_code}`）は会計ごとの出典も返します。

`GET /v1/expenditures/origins/{origin_id}/pdf` は自治体の公開 PDF を表示用に中継します。取得 URL は `X-Origin-Url`（percent-encoding 済み。`decodeURIComponent` で戻す）、取得日時は `X-Origin-Fetched-At` で返し、取り込み時との一致は検査しません。上限は [MCP の表示](/mcp#表で見るmcp-apps)と同じです。

## エラーに対処する

`{"error": {"code": "...", "message": "..."}}` の形で返ります。

| HTTP | code | 起きるとき |
| --- | --- | --- |
| 400 | `INVALID_ARGUMENT` | 入力が schema に合わない |
| 404 | `NOT_FOUND` | 科目・内訳や path が無い |
| 405 | `METHOD_NOT_ALLOWED` | 受け付けないメソッド |
| 413 | `PAYLOAD_TOO_LARGE` | body が 16 KiB を超える |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | `Content-Type` が `application/json` でない |
| 429 | `PDF_UNAVAILABLE` | PDF 中継の上限を超えた |
| 502 / 504 | `PDF_UNAVAILABLE` | PDF を取れない・32 MiB 超・20 秒超 |
| 503 | `UNAVAILABLE` | 提供を止めている |

各操作の詳細は [API リファレンス](/reference)にあります。
