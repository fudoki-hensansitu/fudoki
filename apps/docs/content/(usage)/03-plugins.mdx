ChatGPT・Claude などの AI クライアントから、会話で風土記のデータを調べられます。[MCP の接続案内](/mcp)に従って `https://api.fudoki.dev/mcp` を登録してください。

<img src="/images/chatgpt-plugin.png" alt="ChatGPT の風土記プラグイン画面。収録範囲の確認や歳出の検索の質問例が並ぶ" width="2184" height="1641" loading="lazy" />

風土記の plugin は、既存 MCP の接続設定と、共通 skill `compare-expenditure` を含みます。この skill は歳出を比較・集計するときの手順で、収録範囲を確認し、比較する団体または年度以外の条件（会計・資料区分・粒度）を揃え、親子や異なる切り口の二重集計を避けてから原典を確認します。事業の評価を問われたときは、同梱の reference に従って評価が載った原典の頁を探し、候補の頁を自分で取得して読み、出典つきで答えます。

接続先は `https://api.fudoki.dev/mcp`。認証、API key、ローカル MCP プログラムは不要です。URL だけで使う場合は [MCP の接続案内](/mcp)に従ってください。

## plugin を導入する

Codex・Claude Code・Cursor には、公開 Git リポジトリ `wwwyo/fudoki` から plugin を導入できます。

| クライアント | 導入方法 |
| --- | --- |
| Codex | `codex plugin marketplace add wwwyo/fudoki` で登録し、`codex plugin add fudoki@fudoki-plugins` でインストールする。 |
| Claude Code | `claude plugin marketplace add wwwyo/fudoki` で登録し、`claude plugin install fudoki@fudoki-plugins` でインストールする。 |
| Cursor | Customize の Plugins で「From GitHub Repository」を選び、`https://github.com/wwwyo/fudoki` を指定する。 |

詳しい設定や更新方法は [導入ガイド](https://github.com/wwwyo/fudoki/blob/main/docs/prd/mcp-distribution/install.md)を参照してください。導入後に `compare-expenditure` skill と5つの MCP tool が読み込まれたことを確認します。

## 更新する対象

サーバーの API・MCP・UI と、インストール済みの skill・接続設定は別に更新されます。サーバー更新後も同じ URL を使い、host の tool metadata を必要に応じて再取得します。ChatGPT の個人用接続は Plugins の Refresh を使って新しい会話で確認します。公開 plugin には各社のレビュー手順が適用されます。

plugin の package が変わった場合は、各 host の更新手順で取り直します。MCP の `serverInfo.version` は自動更新の通知ではありません。[OpenAI](https://developers.openai.com/plugins/deploy/connect-chatgpt)・[Claude Code](https://code.claude.com/docs/en/plugins/publish)・[Cursor](https://cursor.com/docs/plugins#keep-plugins-up-to-date)
