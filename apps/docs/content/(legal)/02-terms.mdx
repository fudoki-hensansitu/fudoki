制定日：2026年10月14日

この規約は、風土記の運営者（以下「運営者」）が提供する文書サイト、REST API、MCP サーバーの利用条件を定めます。配布するコード・plugin のライセンスと、自治体の出典の利用条件は、下記のとおり別に適用されます。

## 提供するサービス

風土記は自治体が公開した予算・決算資料から歳出の金額や科目を取り込み、検索、比較、内訳と出典の確認に使えるデータを提供します。自治体や国の公式サービスではなく、各自治体からの承認を示すものでもありません。

現在の API・MCP は収録済みの歳出データと、収録済みの事業評価・予算案のプレス発表から読み取った表（[事業評価と予算案](/evaluations)を参照）の読取りに対応します。全自治体・全年度・全会計の収録、個別の支払取引、歳入、データの書込みには対応していません。料金とアカウント登録は不要です。ただし、商用での利用は[商用での利用](#商用での利用)の条件に従います。利用者が選ぶ AI クライアントや通信の費用は、各提供元の条件に従います。

## データを比較・公表するとき

収録範囲、年度、資料区分、会計、金額の段階と粒度を確認し、[データの読み方](/data)に従ってください。親子の明細や異なる内訳を重複して合算しないでください。

出典の金額と、COFOG 分類など風土記の判断は区別してください。取り込みや分類には誤りがあり得ます。未収録のデータをゼロと解釈せず、重要な判断や公表の前には出典と注記を確認してください。AI クライアントが作成した説明・計算は、風土記が返すデータそのものとは異なり、別途確認が必要です。

## ライセンスと出典

コードは [リポジトリの MIT ライセンス](https://github.com/fudoki-hensansitu/fudoki/blob/main/LICENSE)、plugin のコードと付属文書は [plugin の MIT ライセンス](https://github.com/fudoki-hensansitu/fudoki/blob/main/plugins/fudoki/LICENSE)に従います。これらのライセンスを財政データや出典にそのまま適用することはできません。

出典や出典由来のデータについては、各自治体・各出典の利用条件を確認してください。評価資料を含め、出典の著作権は各自治体にあり、風土記が返すデータは出典の利用を許諾するものではありません。内容は出典の PDF で確認し、利用はその条件に従ってください。風土記による分類等の利用条件は、配布物に明示されたものがある場合にそれに従います。明示がない部分に、MIT や CC BY が適用されると推定しないでください。著作権法等により認められる利用を、この規約が制限するものではありません。

データを紹介・再配布するときは、適用される利用条件が求める出典・加工の表示を行ってください。表示には、出典の自治体名、資料名、年度、URL と、風土記で取り込み・分類を行った旨を含めることを推奨します。風土記の判断や利用者の加工結果を、自治体が作成・承認した結果と誤認させないでください。

## API の利用

公開データの調査・分析や、ツール・アプリからの自動アクセスに利用できます。[API リファレンス](/reference)に記載した入力・件数等の制限を守り、エラーや上限への到達時は連続して再試行せず、間隔を空けてください。

次の行為を禁止します。

- サービスの提供を妨げる大量アクセスや、設定された制限を意図的に回避する行為。
- 不正アクセス、他者の情報・認証情報の取得、データやサービスの改ざん。
- 第三者の権利を侵害する行為や、法令に違反する行為。

不正利用への対応、障害、保守、費用や配信基盤の制限などにより、アクセスの制限や提供の停止を行う場合があります。安全のために緊急の対応が必要な場合は、事前に告知できないことがあります。

## 商用での利用

API・MCP を商用で利用する場合は、事前に [support@fudoki.dev](mailto:support@fudoki.dev) へ問い合わせてください。用途・規模に応じたビジネスプランを案内します。

次の利用を商用での利用とします。

- 事業者が、API・MCP を自社の製品・サービス・アプリに組み込んで提供すること。
- 事業者が、業務のために API・MCP を継続して、または大量に呼び出すこと。

個人の調べもの、学習、非営利の研究・報道・活動、自治体・議会での利用は無料です。事業者による単発の調べものへの利用は、問い合わせを要しません。

この項は API・MCP の利用に関する条件です。取得したデータの利用条件は、[ライセンスと出典](#ライセンスと出典)のとおり各出典と配布物の条件に従います。

## 正確性と提供の継続

運営者は訂正の報告を受け付けますが、データの完全性・最新性・特定の用途への適合、継続的な稼働や返信・修正の期限を保証しません。出典公開サイト、AI クライアント等の変更や障害により、検索・表示・出典の確認ができない場合があります。表示用に取得した PDF が、取り込み時の PDF と同じ内容とは限りません。

これらの説明は、運営者に法令上生じる責任を一律に免除するものではありません。運営者が損害賠償責任を負う場合は、消費者契約法その他の適用法令に従います。

## 情報の取扱いと問い合わせ

情報の取扱いは [プライバシーポリシー](/privacy)、不具合・訂正の報告方法は [サポート](/support)を確認してください。不具合やデータ訂正は GitHub Issues、非公開の相談は [support@fudoki.dev](mailto:support@fudoki.dev) で受け付けます。

## サービスと規約の変更

データの追加・訂正、API の変更、サービスの終了などを行う場合があります。利用者への影響が大きい変更は、可能な範囲で文書サイトまたは GitHub リポジトリで告知します。

規約を変更するときは、法令に従い、このページで変更内容と施行日を示します。個別の同意が必要な変更を、掲載や利用の継続だけで同意したものとは扱いません。

## 準拠法

この規約は日本法に従います。紛争の管轄は適用法令に従い、利用者に認められる権利をこの規約で制限するものではありません。
