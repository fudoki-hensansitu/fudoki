風土記の運営者（以下「運営者」）は、風土記の文書サイト、REST API、MCP サーバーおよび配布する plugin に関する情報の取扱いを、次のとおり定めます。自治体の公開財政資料と、サービスを利用する人から受け取る情報は区別して扱います。

## 受け取る情報と利用目的

### API・MCP の要求

風土記は、クライアントから送信される検索条件、明細 ID、出典 ID、MCP 接続に必要なクライアント名・バージョン等の情報を受け取り、接続の処理と公開財政データの検索・応答に利用します。風土記のアカウント登録やログインは不要です。

会話全文や氏名、住所、支払情報、認証情報を求める入力項目はありません。ただし、クライアントが要求に含めて送信した情報は風土記に届きます。検索文字列などに個人情報や秘密情報を含めないでください。受け取った検索条件を、利用者別の検索履歴としてデータベースに保存する機能はありません。

### Web の AI との会話

Web（fudoki.dev）で風土記の AI に質問すると、質問と画面で見ている内容を Cloudflare の Workers AI で処理し、回答を作ります。画面の会話の履歴はブラウザ内の保存領域（sessionStorage）に置き、タブを閉じると画面からは消えます。

サービスの改善のため、会話を次のとおり保存します：会話ごとの無作為な ID、質問を始めたページ、質問の文と質問と一緒に送った画面の内容、AI の回答の文と AI が使った検索の条件（ここまでのメールアドレスと、国内の形式・+81 で始まる電話番号は伏せ字にします）、検索の結果（風土記の公開データ）、失敗の有無、使用した AI のモデル、処理量（token 数）、所要時間、日時。IP アドレス、ブラウザの種類、Cookie は保存しません。保存した会話は会話ごとの無作為な ID で束ねますが、IP アドレスとは結びつけません。伏せ字は形で判定するため、海外の形式の電話番号や、それ以外の個人情報は質問や回答の文に含まれたまま保存されます。保存した会話は質問の傾向や答えられなかった質問の分析に使い、利用者を識別する目的には使いません。質問に氏名や連絡先などの個人情報を含めないでください。

### 通信・障害に関する情報

配信と API の実行には Cloudflare を使用します。Cloudflare は通信の処理に伴い、IP アドレスなどの通信情報を扱います。運営者は API と Web の実行ログ・エラーログと、処理の経路と所要時間を記録するトレースを、障害の調査、サービスの保護、不正利用への対応に利用します。実行ログには要求の日時、URL、HTTP メソッド、応答状況、実行に関する情報が記録され、障害時には例外メッセージ等が記録されます。文書サイトでは、配信基盤（Cloudflare Workers）の実行ログとトレースの保存を有効にしていません。

要求本文全体を保存する専用の処理は実装していませんが、URL や例外メッセージに入力情報が含まれる可能性があります。「一切記録しない」サービスではありません。

### 問い合わせ・報告

GitHub Issues で投稿されたアカウント名、本文、添付、コメントを、問い合わせへの対応と不具合・データ訂正の確認に利用します。これらは他の利用者にも公開されます。

脆弱性の報告は GitHub の非公開報告機能で受け付けます。報告に含まれるアカウント名、本文、添付、コメントを、問題の確認・修正と報告者への連絡に利用します。いずれの投稿にも、不要な個人情報を含めないでください。

メールでの相談では、送信元のメールアドレス、表示名、件名、本文、添付等を受け取り、問い合わせ・個別請求への対応と本人への連絡に利用します。必要な情報だけを送信してください。本人確認書類や秘密情報を最初から添付する必要はありません。

感想・要望は Google フォームで受け付けます。フォームに入力した内容（本文と、入力した場合は連絡先）を、サービスの改善と、必要な場合の連絡に利用します。フォームの回答は Google が受け取り、保存します。連絡先が不要な場合は入力しないでください。

## ブラウザ内の保存と解析

文書サイトは、表示テーマなどの設定をブラウザ内の保存領域（localStorage）に保存します。風土記のサイトは、ホームで選んだ自治体と最近見た自治体を同じ保存領域に保存し、風土記のサーバーには送りません。設定はブラウザのサイトデータを消去することで削除できます。端末内の設定に有効期限は設けていません。

風土記は、利用状況を把握してサービスを改善するため、Google アナリティクス 4 を使用しています。計測は Cloudflare を経由して送るため、ブラウザが Google と直接通信することはありません。閲覧したページの URL、参照元、端末・ブラウザの種類、おおよその地域、Cookie に保存する無作為な ID を Google に送り、Google はこれを日本国外で処理する場合があります。広告や個人の特定には使いません。

風土記独自の広告用 Cookie は設定していません。Cloudflare、Google（フォーム・アナリティクス）、GitHub、AI クライアントがそれぞれのサービスで扱う Cookie 等については、各提供元の説明を確認してください。

## 外部サービスが扱う情報

- **Cloudflare**：サイト・API の配信、財政データの保持、実行ログの処理、問い合わせメールの転送を担います。通信情報や転送するメールなどは日本国外で処理される場合があります。[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)も確認してください。
- **Google（Gmail・Google フォーム・Google アナリティクス）**：問い合わせメールの受信・保存と返信、感想・要望のフォームの受付と回答の保存、サイトの利用状況の計測に使用します。フォームを開くと、送信元の IP アドレスや Cookie 等の通信情報を Google が扱います。メールやフォームの回答の内容などは日本国外で処理される場合があります。[Google のプライバシーポリシー](https://policies.google.com/privacy)も確認してください。
- **GitHub**：コードと問い合わせの場を提供します。アカウント情報や投稿を GitHub が扱い、日本国外で処理する場合があります。[GitHub のプライバシー声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)も確認してください。
- **AI クライアント**：利用者が選んだ ChatGPT、Claude、Cursor 等は、会話、送信するツール引数、風土記の応答をそれぞれの規約・設定に基づいて扱います。風土記の検索 API 自体は、要求の処理に外部の生成 AI を呼び出しません。配布する skill は利用者のクライアント上で利用されます。
- **国土地理院**：ホームで「うちのまち」を選んでいないときに開いた時点と、「現在地から選ぶ」を押したときに、ブラウザで位置情報の利用を許可していれば、ブラウザが取得した緯度・経度を国土地理院の逆ジオコーダーへ送り、市区町村を求めます。送信元の IP アドレスも国土地理院へ届きます。緯度・経度は風土記のサーバーへ送らず、保存しません。
- **自治体等の出典公開サイト**：出典へのリンクを直接開くと、そのサイトへ通信します。風土記の PDF 表示用中継を使う場合は、風土記のサーバーが公開 PDF を取得します。この中継処理は、利用者の IP アドレスや Cookie を自治体へ転送するための処理を持ちません。

運営者は利用者の情報を販売せず、広告や利用者の行動プロファイルの作成に利用しません。サービスの運用に必要な委託、法令に基づく場合などを除き、利用者の個人データを本人の同意なく第三者へ提供しません。国外での処理に必要な措置は適用法令に従って行います。

## 保存期間

検索条件を利用者別の履歴として保持する機能はありません。Web の AI との会話は、新しい質問を保存するたびに、最後の発言から90日を過ぎたものを削除します。API と Web の実行・エラーログとトレースは Cloudflare Workers の Observability で最大7日間保存します。自動的に別のサービスへ転送する設定はありません。障害調査のため運営者が取り出したログの複製は、取得から30日以内に削除します。

公開 Issues は、対応が完了しても不具合や訂正の記録として残ります。Issue を閉じる操作は削除ではありません。個人情報が不要になった場合や削除を求められた場合は、対象と権限を確認し、削除・編集等の対応を検討します。GitHub 自体の保持や第三者の複製を、運営者が一律に削除できるわけではありません。

問い合わせメールは対応中に保持し、対応終了後90日以内に運営者が管理する問い合わせメール、添付とその複製を削除します。削除時はごみ箱からも取り除きます。感想・要望のフォームの回答は、改善の検討や連絡が済んでから90日以内に削除します。Cloudflare の転送状況に関する活動記録や、Google 自体の保管・バックアップは各提供元の保持方針に従います。

非公開の脆弱性報告は、問題の調査・修正・再発防止のために保持します。報告の本文・添付等に含まれる不要な個人情報は、対応終了後90日以内に運営者が編集・削除できる範囲で取り除きます。公開する技術情報からは不要な個人情報を除き、報告者の名前を掲載する場合は本人の意向を確認します。GitHub が管理するアカウント情報・投稿に付随する情報等は、GitHub の管理と保持方針に従います。

法令により保存が必要な記録は、必要な期間に限って保持します。Cloudflare が独自に扱う通信・セキュリティ情報、Google、GitHub や AI クライアント自身の保存は、各提供元のポリシーに従います。Workers Logs の7日という期間を、これらの情報全体の保存期限として約束するものではありません。

## 安全管理と利用者の選択

運営者は、管理用の認証情報を公開せず、管理画面等へのアクセスを制限して情報を扱います。利用者は AI クライアントの接続設定から風土記の接続を解除でき、ブラウザ内の設定を削除できます。GitHub では自分の Issue 本文の編集、コメントや編集履歴の削除ができます。Issue 本体の削除には運営者の対応が必要です。接続の解除だけで、各提供元に保存された会話や投稿が消えるわけではありません。

運営者が保有する個人データについて、利用目的の通知、開示、訂正、利用停止、削除等を求める場合は、[support@fudoki.dev](mailto:support@fudoki.dev) で受け付け、法令に従って対応します。運営者の氏名・住所等の法定の公表事項は、この窓口への照会に対して遅滞なく回答します。受付に手数料は設けていません。

メールには希望する対応と、対象の投稿の URL や利用日時など、対象を特定するために必要な情報を記載してください。本人確認は、対象の GitHub アカウントからの確認や、既存の問い合わせのメールアドレスへの確認等、対象データに応じた必要最小限の方法で行います。追加の確認が必要な場合は、その目的と必要な情報を個別に案内し、回答は確認した本人宛てにメール等で行います。公開 Issue に本人確認書類、住所、IP アドレス等を投稿するよう求めません。

自分の GitHub 投稿の訂正・削除は、その投稿に使用したアカウントから対象の URL と希望する対応を Issues へ記載する方法でも受け付けます。非公開の脆弱性報告の訂正・削除等は、その報告の非公開スレッドでも受け付けます。

対象の情報を保有していない場合、本人や対象を特定できない場合、法令に基づき請求に応じられない場合は、その理由をお知らせします。第三者の個人情報や非公開情報を、請求への公開の返信に含めることはありません。

## このポリシーの変更

情報の取扱いを変更するときは、このページで変更内容と施行日を示します。法令上の同意が必要な変更は、掲載だけで同意したものとは扱いません。
