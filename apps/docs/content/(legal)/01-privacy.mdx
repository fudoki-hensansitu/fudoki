風土記の運営者（以下「運営者」）は、風土記の文書サイト、REST API、MCP サーバーおよび配布する plugin に関する情報の取扱いを、次のとおり定めます。自治体の公開財政資料と、サービスを利用する人から受け取る情報は区別して扱います。

## 受け取る情報と利用目的

### API・MCP の要求

風土記は、クライアントから送信される検索条件、明細 ID、原典 ID、MCP 接続に必要なクライアント名・バージョン等の情報を受け取り、接続の処理と公開財政データの検索・応答に利用します。風土記のアカウント登録やログインは不要です。

会話全文や氏名、住所、支払情報、認証情報を求める入力項目はありません。ただし、クライアントが要求に含めて送信した情報は風土記に届きます。検索文字列などに個人情報や秘密情報を含めないでください。受け取った検索条件を、利用者別の検索履歴としてデータベースに保存する機能はありません。

### 通信・障害に関する情報

配信と API の実行には Cloudflare を使用します。Cloudflare は通信の処理に伴い、IP アドレスなどの通信情報を扱います。運営者は API の実行ログとエラーログを、障害の調査、サービスの保護、不正利用への対応に利用します。API の実行ログには要求の日時、URL、HTTP メソッド、応答状況、実行に関する情報が記録され、障害時には例外メッセージ等が記録されます。文書サイトと一時停止中の Web サイトでは、配信基盤（Cloudflare Workers）の実行ログの保存を有効にしていません。

要求本文全体を保存する専用の処理は実装していませんが、URL や例外メッセージに入力情報が含まれる可能性があります。「一切記録しない」サービスではありません。

### 問い合わせ・報告

GitHub Issues で投稿されたアカウント名、本文、添付、コメントを、問い合わせへの対応と不具合・データ訂正の確認に利用します。これらは他の利用者にも公開されます。

脆弱性の報告は GitHub の非公開報告機能で受け付けます。報告に含まれるアカウント名、本文、添付、コメントを、問題の確認・修正と報告者への連絡に利用します。いずれの投稿にも、不要な個人情報を含めないでください。

メールでの相談では、送信元のメールアドレス、表示名、件名、本文、添付等を受け取り、問い合わせ・個別請求への対応と本人への連絡に利用します。必要な情報だけを送信してください。本人確認書類や秘密情報を最初から添付する必要はありません。

## ブラウザ内の保存と解析

文書サイトは、表示テーマなどの設定をブラウザ内の保存領域（localStorage）に保存します。設定はブラウザのサイトデータを消去することで削除できます。端末内の設定に有効期限は設けていません。

風土記独自の広告用 Cookie や、第三者のアクセス解析タグは設定していません。Cloudflare、GitHub、AI クライアントがそれぞれのサービスで扱う Cookie 等については、各提供元の説明を確認してください。

## 外部サービスが扱う情報

- **Cloudflare**：サイト・API の配信、財政データの保持、実行ログの処理、問い合わせメールの転送を担います。通信情報や転送するメールなどは日本国外で処理される場合があります。[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)も確認してください。
- **Google（Gmail）**：問い合わせメールの受信・保存と返信に使用します。メールの内容などは日本国外で処理される場合があります。[Google のプライバシーポリシー](https://policies.google.com/privacy)も確認してください。
- **GitHub**：コードと問い合わせの場を提供します。アカウント情報や投稿を GitHub が扱い、日本国外で処理する場合があります。[GitHub のプライバシー声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)も確認してください。
- **AI クライアント**：利用者が選んだ ChatGPT、Claude、Cursor 等は、会話、送信するツール引数、風土記の応答をそれぞれの規約・設定に基づいて扱います。風土記の検索 API 自体は、要求の処理に外部の生成 AI を呼び出しません。配布する skill は利用者のクライアント上で利用されます。
- **自治体等の原典公開サイト**：原典へのリンクを直接開くと、そのサイトへ通信します。風土記の PDF 表示用中継を使う場合は、風土記のサーバーが公開 PDF を取得します。この中継処理は、利用者の IP アドレスや Cookie を自治体へ転送するための処理を持ちません。

運営者は利用者の情報を販売せず、広告や利用者の行動プロファイルの作成に利用しません。サービスの運用に必要な委託、法令に基づく場合などを除き、利用者の個人データを本人の同意なく第三者へ提供しません。国外での処理に必要な措置は適用法令に従って行います。

## 保存期間

検索条件を利用者別の履歴として保持する機能はありません。API の実行・エラーログは Cloudflare Workers Logs で最大7日間保存します。自動的に別のサービスへ転送する設定はありません。障害調査のため運営者が取り出したログの複製は、取得から30日以内に削除します。

公開 Issues は、対応が完了しても不具合や訂正の記録として残ります。Issue を閉じる操作は削除ではありません。個人情報が不要になった場合や削除を求められた場合は、対象と権限を確認し、削除・編集等の対応を検討します。GitHub 自体の保持や第三者の複製を、運営者が一律に削除できるわけではありません。

問い合わせメールは対応中に保持し、対応終了後90日以内に運営者が管理する問い合わせメール、添付とその複製を削除します。削除時はごみ箱からも取り除きます。Cloudflare の転送状況に関する活動記録や、Google 自体の保管・バックアップは各提供元の保持方針に従います。

非公開の脆弱性報告は、問題の調査・修正・再発防止のために保持します。報告の本文・添付等に含まれる不要な個人情報は、対応終了後90日以内に運営者が編集・削除できる範囲で取り除きます。公開する技術情報からは不要な個人情報を除き、報告者の名前を掲載する場合は本人の意向を確認します。GitHub が管理するアカウント情報・投稿に付随する情報等は、GitHub の管理と保持方針に従います。

法令により保存が必要な記録は、必要な期間に限って保持します。Cloudflare が独自に扱う通信・セキュリティ情報、Google、GitHub や AI クライアント自身の保存は、各提供元のポリシーに従います。Workers Logs の7日という期間を、これらの情報全体の保存期限として約束するものではありません。

## 安全管理と利用者の選択

運営者は、管理用の認証情報を公開せず、管理画面等へのアクセスを制限して情報を扱います。利用者は AI クライアントの接続設定から風土記の接続を解除でき、ブラウザ内の設定を削除できます。GitHub では自分の Issue 本文の編集、コメントや編集履歴の削除ができます。Issue 本体の削除には運営者の対応が必要です。接続の解除だけで、各提供元に保存された会話や投稿が消えるわけではありません。

運営者が保有する個人データについて、利用目的の通知、開示、訂正、利用停止、削除等を求める場合は、[support@fudoki.dev](mailto:support@fudoki.dev) で受け付け、法令に従って対応します。運営者に関する法定の公表事項の照会も、この窓口で受け付けます。受付に手数料は設けていません。

メールには希望する対応と、対象の投稿の URL や利用日時など、対象を特定するために必要な情報を記載してください。本人確認は、対象の GitHub アカウントからの確認や、既存の問い合わせのメールアドレスへの確認等、対象データに応じた必要最小限の方法で行います。追加の確認が必要な場合は、その目的と必要な情報を個別に案内し、回答は確認した本人宛てにメール等で行います。公開 Issue に本人確認書類、住所、IP アドレス等を投稿するよう求めません。

自分の GitHub 投稿の訂正・削除は、その投稿に使用したアカウントから対象の URL と希望する対応を Issues へ記載する方法でも受け付けます。非公開の脆弱性報告の訂正・削除等は、その報告の非公開スレッドでも受け付けます。

対象の情報を保有していない場合、本人や対象を特定できない場合、法令に基づき請求に応じられない場合は、その理由をお知らせします。第三者の個人情報や非公開情報を、請求への公開の返信に含めることはありません。

## このポリシーの変更

情報の取扱いを変更するときは、このページで変更内容と施行日を示します。法令上の同意が必要な変更は、掲載だけで同意したものとは扱いません。
