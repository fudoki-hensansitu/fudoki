未収録のデータは、支出がゼロという意味ではありません。データが見つからないときは、まず収録されている自治体・年度・資料区分・会計を確かめてください。

## 不具合を報告する

既存の Issue に同じ問題が無いか確かめてから、[新しい Issue](https://github.com/fudoki-hensansitu/fudoki/issues/new) を作ります。次があると確認しやすくなります。

- 使ったクライアント（ChatGPT、Claude、Cursor、REST など）とバージョン
- 日時、操作の手順、期待した結果と実際の結果、エラーメッセージ
- 検索条件、明細 ID や出典 ID

:::warning
Issues は公開されます。会話全文、API key、パスワード、Cookie、個人情報は載せないでください。画像はアカウント情報や他の会話を隠してから添えます。
:::

## 金額や分類の訂正

自治体名・年度・会計・資料区分、明細 ID か出典 ID、出典の URL と頁を書き、出典の値と風土記の値のどこが違うかを示してください。COFOG の分類など風土記の判断への指摘は、期待する分類と根拠を添えます。

## 個人情報

開示・訂正・削除などの請求は [support@fudoki.dev](mailto:support@fudoki.dev) へ。対象を特定するのに必要な情報だけを書き、本人確認書類は最初から添付しないでください。自分の GitHub 投稿は、その投稿のアカウントから対象の URL と希望する対応を Issues に書く方法でも受け付けます。Issue 本文に個人情報を含めてしまったときは、まず本文を編集して消し、その後に該当する[編集履歴](https://docs.github.com/en/communities/moderating-comments-and-conversations/tracking-changes-in-a-comment)を削除してください。詳しくは[プライバシーポリシー](/privacy)を見てください。

## 対応の範囲

返信や修正の期限、常時の対応、個別の分析の代行は約束していません。AI クライアントのアカウント・課金・会話履歴は、その提供元へ問い合わせてください。
