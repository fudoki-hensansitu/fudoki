風土記は、自治体の歳出データを検索・比較するサービスです。不具合やデータ訂正は [GitHub Issues](https://github.com/wwwyo/fudoki/issues)、非公開の相談は [support@fudoki.dev](mailto:support@fudoki.dev) で受け付けます。Issues への投稿には GitHub アカウントが必要で、本文・添付・コメントはインターネット上に公開されます。

## 問い合わせる前に

[MCP の接続方法](/mcp)、[REST の使い方](/rest)、[データの読み方](/data)を確認してください。データが見つからないときは、まず収録されている自治体・年度・資料区分・会計を確認します。未収録のデータは、支出がゼロであることを意味しません。

## 不具合や接続の問題を報告する

既存の Issue に同じ問題がないか確認し、なければ [新しい Issue](https://github.com/wwwyo/fudoki/issues/new) を作成してください。次の情報があると確認しやすくなります。

- 利用したクライアント（ChatGPT、Claude、Cursor、REST など）と、分かればそのバージョン。
- 発生日時とタイムゾーン、操作の手順。
- 期待した結果と実際の結果、エラーメッセージ。
- 再現に必要な公開データの検索条件、明細 ID や出典 ID。

画面の画像を添える場合は、アカウント情報・他の会話・個人情報・秘密情報を隠してください。会話全文、API key、パスワード、認証用 URL、Cookie は投稿しないでください。

## 金額や分類の訂正を依頼する

自治体名、年度、会計、資料区分、対象の明細 ID または出典 ID、出典の URL と頁を記載してください。出典に書かれている値と風土記の値のどこが違うかを示すと、訂正を確認できます。

COFOG 分類など風土記の判断に関する指摘は、期待する分類とその根拠を添えてください。出典の記載と分類の判断は分けて確認します。新しい自治体・年度の収録希望も Issues で受け付けますが、収録時期は約束していません。

## 個人情報に関する相談

[プライバシーポリシー](/privacy)に関する一般的な質問は、個人を特定する情報を含めずに Issues へ投稿できます。個別の開示・訂正・削除等の請求や、公開できない内容の相談は [support@fudoki.dev](mailto:support@fudoki.dev) へ送ってください。希望する対応と、対象を特定するために必要な情報だけを記載し、本人確認書類や秘密情報を最初から添付しないでください。

自分の投稿に個人情報を含めてしまった場合は、Issue 本文から該当情報を除き、[編集履歴](https://docs.github.com/en/communities/moderating-comments-and-conversations/tracking-changes-in-a-comment)からも該当する変更を削除してください。自分のコメントは削除できます。Issue 本体の削除が必要な場合は、個人情報を再掲せず運営者へ依頼してください。公開済みの情報は第三者が取得している可能性があり、全ての複製を消せるとは限りません。

自分の GitHub 投稿の訂正・削除等は、メールに加え、その投稿に使用したアカウントから対象の Issue・コメントの URL と希望する対応を Issues に記載する方法でも受け付けます。削除したい情報そのものを再掲する必要はありません。本人確認書類、住所、IP アドレス等は公開の場に投稿しないでください。脆弱性報告フォームは一般の個人情報相談の窓口ではありません。

## 脆弱性は非公開で報告する

情報漏えいや不正アクセスにつながる問題は、公開 Issue に詳細を書かず、[GitHub の非公開脆弱性報告](https://github.com/wwwyo/fudoki/security/advisories/new)を利用してください。通常の不具合・収録希望は Issues を利用してください。

## 対応の範囲

運営者が内容を確認し、必要に応じて追加情報を求めます。返信や修正の期限、常時の対応、個別の分析代行は約束していません。接続先の AI クライアントのアカウント・課金・会話履歴については、その提供元へ問い合わせてください。
