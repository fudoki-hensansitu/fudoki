<Steps>
  <Step title="カスタム MCP サーバーを追加する">
    Plugins の「＋」から「Add custom MCP server」を選びます。
  </Step>
  <Step title="URL を入れる">
    - Name：風土記
    - Server URL：`https://api.fudoki.dev/mcp`
    - Authentication：No authentication
  </Step>
  <Step title="plugin として作る">
    「Create as a plugin」で作成し、個人用 plugin をインストールします。
  </Step>
  <Step title="会話で呼ぶ">
    新しい Work の会話で、`@` から風土記を選びます。
  </Step>
</Steps>
