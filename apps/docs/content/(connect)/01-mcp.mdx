| 項目 | 値 |
| --- | --- |
| URL | `https://api.fudoki.dev/mcp` |
| 通信 | Streamable HTTP |
| 認証 | なし |

クライアントごとの手順は [ChatGPT](/chatgpt)・[Claude](/claude)・[Codex](/codex)・[Claude Code](/claude-code)・[Cursor](/cursor) にあります。ほかのクライアントでも、リモートの MCP サーバーとして上の URL を登録すれば使えます。

## 使える tool

すべて読み取りだけです（`readOnlyHint: true`）。入力と応答の schema は [API リファレンス](/reference)と同じです。

| tool | 使いどころ |
| --- | --- |
| `list_jurisdictions` | 自治体と、人口の推移、収録している年度・資料区分・会計、事業評価と予算案の年度を返す |
| `search_expenditure_subjects` | 科目（款・項・目）を自治体・年度・段・COFOG などで絞って一覧する |
| `search_expenditure_details` | 科目の下の内訳（事業・節）を分け方・所管課などで絞って一覧する |
| `get_expenditure_line` | 科目か内訳を一つと、その直下（科目なら子の科目と内訳、内訳なら子）を分け方（事業・節など）ごとに返す |
| `get_evaluation`・`get_evaluation_sheet`・`search_evaluation_sheets` | 事業評価の評価シートと指標を返す（[事業評価と予算案](/evaluations)） |
| `get_budget_proposal`・`search_budget_measures` | 予算案のプレス発表の施策を返す（[事業評価と予算案](/evaluations)） |
| `get_project`・`search_projects` | 予算書・決算書の事業を年度をまたいでつないだものを返す（[事業評価と予算案](/evaluations)） |

## 表で見る（MCP Apps）

MCP Apps に対応したクライアントでは、科目・内訳の検索と取得の結果を表やグラフで描けます。描くのは別の tool `render_expenditure_view` で、AI が呼んだときだけ出ます。出ないときは「表で見せて」と頼んでください。明細の「出典」を押すと、出典 PDF の該当頁を開き、印字の位置を枠で囲みます（枠が欠けている明細や、項目が次頁へ続く明細は頁だけを表示します。CSV や頁の分からない明細は出典リンクを案内します）。対応していないクライアントでも、同じ内容が構造化された結果で返ります。

表示用の PDF は自治体の公開 URL から取り直すので、取り込み時と内容が違う可能性があります。取得は 32 MiB・20 秒まで、全利用者の合計で閲覧 120 回/分・取得 6 回/分（同じ URL は 1 回/分）です。取得結果は 24 時間再利用し、保持は 16 URL までです。取れないときは出典 URL と頁番号を案内します。

## 使えないことと上限

- POST だけを受け付けます。JSON-RPC の batch と `subscriptions/listen` は使えません。
- リクエストの body は 16 KiB までです。
- 提供を止めているあいだは HTTP 503 を返します。

## つながらないとき

1. クライアントの設定で、風土記の接続が有効になっているか確かめます。
2. 新しい会話で、もう一度頼みます。
3. それでも tool が呼ばれなければ、[サポート](/support)から知らせてください。

サーバーを更新しても URL は変わりません。tool の一覧が古いときは、クライアントで接続を更新（Refresh）します。
