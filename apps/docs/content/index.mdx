風土記は、自治体の行政情報をわかりやすく見せ、誰でも使えるオープンデータにします。登録も API key も要りません。

## AI につなぐ

使っている AI に、次の URL を MCP サーバーとして登録します。

```text title="MCP サーバーの URL"
https://api.fudoki.dev/mcp
```
