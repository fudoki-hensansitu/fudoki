風土記は、自治体の予算書・決算書から歳出の金額を款・項・目と事業の単位まで取り出し、自治体や年度をまたいで比べられるようにしたデータです。登録も API key も要りません。

## AI につなぐ

使っている AI に、次の URL を MCP サーバーとして登録します。

```text title="MCP サーバーの URL"
https://api.fudoki.dev/mcp
```
